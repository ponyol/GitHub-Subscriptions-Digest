Суммаризация (на русском)

Основное обновление — добавление поддержки аутентификации keyboard-interactive (RFC 4256). Эта реализация включает обработку сообщений `SSH_MSG_USERAUTH_INFO_REQUEST` и `INFO_RESPONSE`, вспомогательный инструмент командной строки для запроса данных у пользователя, а также поддержку потоков аутентификации с частичным успехом. Новая функциональность интегрирована в API `connect`/`authenticate`, тщательно протестирована с помощью модульных и интеграционных тестов, а также дополнена обновленной документацией и журналом изменений.

Исходный текст

- Add RFC 4256 keyboard-interactive auth support Implement callback-driven `keyboard-interactive` authentication, including: - SSH_MSG_USERAUTH_INFO_REQUEST / INFO_RESPONSE handling - CLI helper for prompting from stdin/stdout - partial-success continuation via `auth-partial-success` and restartable auth flow - support in `connect` / `authenticate` APIs - unit and Docker integration tests for keyboard-interactive and partial-success flows Also update docs, changelog, and integration test setup for the new SSH services.
