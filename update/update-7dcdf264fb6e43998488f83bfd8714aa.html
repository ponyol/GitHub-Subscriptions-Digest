MODULAR_ORIG_COMMIT_REV_ID: 6fcabef26bcd932e508b34782f7f775642c824df - [stdlib] feat: Enable linear types in `UnsafePointer`, `VariadicPack`, and other fundamental APIs (Part 7/N) A 'linear type' or 'non-implicitly-destructible' type is a type without a `__del__` method, that may only be destroyed by calling a named `deinit self` method. This means that linear types have even fewer restrictions than today's `AnyType`, which requires that a type at least have `__del__`. Many "core" operations like `size_of` or `rebind` don't actually depend on a type having an implicit destructor, so they can be updated to instead require the `UnknownDestructible` trait, which truly does have no requirements. This PR demonstrates that linear types are compatible with the primitive building blocks of Mojo, including `VariadicPack` (and the variadics helpers), `UnsafePointer`, and `Pointer`.
