Go SDK теперь включает иерархическую систему памяти для сохранения состояния и обмена данными, а также API заметок (Note API) для отправки обновлений прогресса в реальном времени в пользовательский интерфейс. В Python SDK исправлена ошибка `UnboundLocalError` путем перемещения условных импортов на уровень модуля. Кроме того, проект теперь позволяет внешним участникам запускать большинство функциональных тестов (92%) без необходимости использования ключей API, выборочно пропуская тесты, зависящие от LLM, для форкнутых запросов на слияние и улучшая логику CI.
