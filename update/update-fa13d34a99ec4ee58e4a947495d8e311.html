Суммаризация (на русском)

This update introduces an opt-in local daemon mode for queued MemPalace writes, with extensive fixes addressing its security, stability, and cross-platform reliability, particularly for Windows and macOS CI environments. It also expands support by adding new file extensions for languages like C#, .NET, Swift, Kotlin, and PHP, alongside new data import parsers (e.g., Pi agent, Gemini, Continue.dev). The release further includes various other bug fixes and performance enhancements. --- **Russian translation:** Это обновление вводит опциональный локальный режим демона для отложенной записи в MemPalace, с обширными исправлениями, направленными на повышение его безопасности, стабильности и кроссплатформенной надежности, особенно в средах CI Windows и macOS. Также расширена поддержка за счет добавления новых расширений файлов для таких языков, как C#, .NET, Swift, Kotlin и PHP, а также новых парсеров для импорта данных (например, Pi agent, Gemini, Continue.dev). Релиз также включает различные другие исправления ошибок и улучшения производительности.
