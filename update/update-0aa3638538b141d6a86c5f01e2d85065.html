Суммаризация (на русском)

Это обновление вводит новую V1-схему на основе JSON, которая будет использоваться по умолчанию для всех вновь создаваемых баз данных, при этом существующие V0-схемы по-прежнему поддерживаются. Кроме того, добавлена поддержка регулярных выражений для разрешенных источников, что обеспечивает более гибкую конфигурацию, и включен новый разработанный инструмент для Cloud Pub/Sub. Инструменты миграции для существующих баз данных ожидаются в последующем выпуске.
