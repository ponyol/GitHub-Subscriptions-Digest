Суммаризация (на русском)

This update introduces a major layout detection engine, enhancing PDF markdown extraction with improved structure recognition, reading order, and table reconstruction. Core document processing also sees advancements with a weighted OCR pipeline, auto-rotation, and better text chunking, alongside support for new file formats like dBASE, HWP, and Office templates. The release includes extensive bug fixes addressing CI failures, clippy warnings, benchmark accuracy, PDF password support, and cross-platform binding compatibility. --- Это обновление добавляет крупный движок определения макета, значительно улучшая извлечение Markdown из PDF за счет улучшенного распознавания структуры, порядка чтения и реконструкции таблиц. Основная обработка документов также получает улучшения благодаря взвешенному конвейеру OCR, автоматическому повороту и улучшенному разбиению текста на фрагменты, а также поддержке новых форматов файлов, таких как dBASE, HWP и шаблоны Office. Релиз включает обширные исправления ошибок, устраняющие сбои CI, предупреждения clippy, точность бенчмарков, поддержку паролей PDF и совместимость привязок между платформами.
