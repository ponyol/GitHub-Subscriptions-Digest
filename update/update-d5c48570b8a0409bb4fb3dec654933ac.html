Суммаризация (на русском)

This release significantly refactors memory management by aligning `pd_buffer_size` in the PD backend and introduces `MaruBackend` for zero-copy KV cache sharing via CXL. It enhances security with environment variable support for RESP adapter authentication and adds configurable `gds_path_sharding` for multi-GPU setups. L2 eviction capabilities are expanded to Native and Blend backends, including multiprocess modes, while core utilities are generalized for wider device compatibility. The update also includes bug fixes for MLA models and `save_decode_cache`, plus various CLI and CI improvements. --- **Russian Translation:** Этот выпуск значительно перерабатывает управление памятью путем выравнивания `pd_buffer_size` в бэкэнде PD и представляет `MaruBackend` для совместного использования кеша KV с нулевым копированием через CXL. Он повышает безопасность за счет поддержки переменных окружения для аутентификации адаптера RESP и добавляет настраиваемое разделение путей `gds_path_sharding` для конфигураций с несколькими графическими процессорами. Возможности вытеснения L2 расширены до нативных и Blend бэкэндов, включая многопроцессорные режимы, а основные утилиты обобщены для более широкой совместимости с устройствами. Обновление также включает исправления ошибок для моделей MLA и `save_decode_cache`, а также различные улучшения CLI и CI.
