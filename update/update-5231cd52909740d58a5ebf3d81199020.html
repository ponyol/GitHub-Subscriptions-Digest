Суммаризация (на русском)

This update introduces significant improvements across documentation, CLI tools, and the Inspector. Key changes include excluding auto-generated Python API docs from search for better relevance, enhancing CLI deployment with monorepo auto-deploy triggers and better GitHub App integration, and making MCP Apps the primary widget runtime for the Inspector. It also resolves user experience issues like redundant login prompts, scopes OAuth proxy fetches, and enforces `outputSchema` for tools, culminating in the release of Inspector v11.0.0 and TypeScript v1.33.0. --- Это обновление вносит значительные улучшения в документацию, инструменты командной строки (CLI) и Инспектор. Ключевые изменения включают исключение автоматически сгенерированных документов Python API из результатов поиска для повышения релевантности, улучшение развертывания через CLI с триггерами авторазвертывания для монорепозиториев и улучшенной интеграцией GitHub App, а также назначение MCP Apps основным исполняющим окружением для виджетов в Инспекторе. Также были решены проблемы пользовательского опыта, такие как избыточные запросы на вход в систему, ограничение области действия OAuth proxy и принудительное применение `outputSchema` для инструментов, что привело к выпуску Inspector v11.0.0 и TypeScript v1.33.0.
