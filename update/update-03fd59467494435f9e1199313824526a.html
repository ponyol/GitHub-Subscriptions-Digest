This update introduces significant enhancements across Hindsight, focusing on LLM integrations, Claude Code capabilities, performance, and user experience. Key features include the LiteLLM Router for LLM fallback chains and z.ai as a new provider, alongside improved Claude Code integration with knowledge tools, subagent support, and critical fixes for recall token budgeting. The release also delivers substantial memory reduction in `retain` operations, adds AlloyDB ScaNN support, enables optional read-only database backends for recall, and enriches the Control Plane UI with access-key login and memory statistics, plus a new n8n community node. --- Это обновление представляет значительные улучшения в Hindsight, сосредоточенные на интеграциях с LLM, возможностях Claude Code, производительности и пользовательском опыте. Ключевые особенности включают LiteLLM Router для цепочек отката LLM и z.ai в качестве нового провайдера, а также улучшенную интеграцию с Claude Code с инструментами для работы со знаниями, поддержкой субагентов и критическими исправлениями для бюджетирования токенов отзыва. Релиз также обеспечивает существенное сокращение потребления памяти при операциях `retain`, добавляет поддержку AlloyDB ScaNN, включает опциональную поддержку баз данных только для чтения для запросов отзыва и обогащает пользовательский интерфейс Control Plane входом по ключу доступа и статистикой памяти, а также новым узлом сообщества n8n.
