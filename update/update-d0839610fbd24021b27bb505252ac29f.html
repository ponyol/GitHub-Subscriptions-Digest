Суммаризация (на русском)

This update introduces a comprehensive video processing pipeline, enabling audio extraction, ASR transcription, intelligent frame sampling with scene change detection and sharpness scoring, and optional speaker diarization, along with new CLI controls. It also adds the ability to parse native MS Word and PowerPoint charts as classified pictures with embedded data, and exposes Google Cloud Storage, Azure Blob, and Google Drive as new source/target types. Numerous fixes improve document processing across JATS, MS Word, AsciiDoc, Markdown, and USPTO formats, addressing issues like nested list preservation, table cell duplication, and robust error handling. --- Это обновление представляет комплексный конвейер обработки видео, позволяющий извлекать аудио, выполнять транскрипцию ASR, интеллектуальную выборку кадров с обнаружением смены сцен и оценкой резкости, а также опциональную диаризацию дикторов, наряду с новыми элементами управления CLI. Также добавлена возможность анализировать встроенные диаграммы MS Word и PowerPoint как классифицированные изображения со встроенными данными, и реализована поддержка Google Cloud Storage, Azure Blob и Google Drive в качестве новых типов источников/целей. Многочисленные исправления улучшают обработку документов в форматах JATS, MS Word, AsciiDoc, Markdown и USPTO, устраняя такие проблемы, как сохранение вложенных списков, дублирование ячеек таблицы и надёжная обработка ошибок.
