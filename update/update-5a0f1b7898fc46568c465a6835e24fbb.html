Суммаризация (на русском)

Это обновление значительно переводит документацию на использование `uuid7()` для улучшенных UUID, наряду с многочисленными исправлениями в примерах кода для повышения точности. Введено повышение гибкости, позволяющее изменять параметры конфигурации типа словаря/списка и ключ Pixeltable API через переменные окружения в ходе сессии, а также добавлена функция экспорта медиа в S3. Кроме того, внесены исправления для видимости выходных данных ноутбуков в темном режиме, улучшена обработка исключений и повышена стабильность CI.
