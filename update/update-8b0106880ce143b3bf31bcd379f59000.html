Суммаризация (на русском)

This release features major new extensions, including Sign-In-With-X (SIWX) for multi-chain wallet authentication and a payment identifier for idempotency. It enhances CDP facilitator authentication with mainnet support and adds new network integrations like MegaETH and Solana. The SDK also received various improvements, such as simplified MCP interfaces, better error messages for insufficient funds, and retry logic for API calls. Additionally, new ecosystem partners and tooling like x402lint were introduced. *** Этот выпуск представляет новые важные расширения, включая Sign-In-With-X (SIWX) для многоцепочечной аутентификации на основе кошелька и идентификатор платежа для обеспечения идемпотентности. Улучшена аутентификация посредников CDP с поддержкой основной сети и добавлены новые сетевые интеграции, такие как MegaETH и Solana. SDK также получил различные улучшения, включая упрощенные интерфейсы MCP, более подробные сообщения об ошибках при недостаточном количестве средств и логику повторных попыток для вызовов API. Кроме того, были представлены новые партнеры по экосистеме и инструменты, такие как x402lint.
