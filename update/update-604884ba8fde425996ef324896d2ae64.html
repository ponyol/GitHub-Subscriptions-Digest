Суммаризация (на русском)

В данном обновлении исправлены критические ошибки в документации Kotlin SDK, касающиеся координат Maven и версий, которые теперь соответствуют опубликованным артефактам. Из репозитория был удален Java SDK сообщества, а также связанные с ним действия GitHub, что указывает на изменение подхода к его поддержке. Кроме того, Go SDK был улучшен за счет добавления необязательного поля `name` в события текстовых сообщений, что обеспечивает согласованность с другими SDK и улучшает идентификацию подогентов. Также, управление обновлениями зависимостей для GitHub Actions было перенесено на Renovate.
