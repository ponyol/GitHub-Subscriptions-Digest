Суммаризация (на русском)

This update introduces a new feature allowing plugins to include a `resources` directory, improving their ability to convey necessary files. It also enhances the CLI by making `stop` and `delete` commands error out for non-existent containers, consistent with the `kill` command. Several bug fixes address a compilation error and improve testing, alongside general code cleanup and CI updates. --- Это обновление представляет новую функцию, позволяющую плагинам включать каталог `resources`, что улучшает их способность передавать необходимые файлы. Также улучшен интерфейс командной строки (CLI) путем введения ошибок при использовании команд `stop` и `delete` для несуществующих контейнеров, что соответствует поведению команды `kill`. Несколько исправлений ошибок устраняют проблему компиляции и улучшают тестирование, наряду с общей очисткой кода и обновлениями CI.
