This update introduces significant enhancements across the platform, focusing on improved user experience, LLM configuration, and knowledge base management. Key changes include a complete overhaul of the Knowledge tab's save, re-index, and profile-switching UI, ensuring accurate status feedback and user-triggered re-indexing. It also adds direct RITS integration with flexible environment overrides, strengthens ToolGuard capabilities with UI generation and viewing, and resolves numerous LLM parameter, chunking, and security issues. These changes collectively boost performance, stability, and configurability for agents and their knowledge retrieval systems. --- Это обновление представляет собой значительные улучшения по всей платформе, сосредоточенные на улучшении пользовательского опыта, конфигурации LLM и управлении базой знаний. Среди ключевых изменений — полная переработка пользовательского интерфейса вкладки "База знаний" для сохранения, переиндексации и переключения профилей, обеспечивающего точную обратную связь о статусе и переиндексацию по запросу пользователя. Также добавлена прямая интеграция с RITS с гибкими переопределениями из переменных окружения, расширены возможности ToolGuard с генерацией и просмотром через пользовательский интерфейс, а также устранены многочисленные проблемы с параметрами LLM, разбиением на чанки и безопасностью. В совокупности эти изменения повышают производительность, стабильность и настраиваемость агентов и их систем извлечения знаний.
