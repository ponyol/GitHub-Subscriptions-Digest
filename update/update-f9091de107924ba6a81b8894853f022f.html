Суммаризация (на русском)

This update introduces support for powerful new models like Mistral Large 3 and GPT-5.1-codex-max, alongside significant enhancements to multimodal capabilities, including improved image generation handling in the Responses API and more accurate cost calculation for Gemini image tokens. The UI receives several upgrades, such as a new login page, customer usage tracking, image comparison support, and OCI private key input. The release also includes numerous fixes to improve stability, addressing flaky tests, dynamic rate limiting, MCP gateway functionality, Ollama authentication, and various guardrail and streaming issues. --- Это обновление добавляет поддержку новых мощных моделей, включая Mistral Large 3 и GPT-5.1-codex-max, а также значительно расширяет мультимодальные возможности, улучшая обработку генерации изображений и расчет их стоимости. Пользовательский интерфейс получил ряд улучшений: новую страницу входа, отслеживание использования клиентами, поддержку сравнения изображений и возможность ввода закрытого ключа OCI. Кроме того, релиз включает многочисленные исправления для повышения стабильности, устраняющие проблемы с нестабильными тестами, динамическим ограничением скорости, функциональностью MCP-шлюза, аутентификацией Ollama и ошибками в механизмах защиты и потоковой передачи данных.
