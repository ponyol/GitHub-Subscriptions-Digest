This update significantly enhances external table support in REST v2, adding features like schema validation and optimizing load paths, alongside numerous stability fixes for lifecycle management. Key bug fixes address QueryCoord panics, cached collection load failures, and performance regressions. Additionally, search capabilities are improved with aggregation and expression filter caching, while core dependencies and build infrastructure are updated. --- Это обновление значительно расширяет поддержку внешних таблиц в REST v2, добавляя такие функции, как проверка схемы и оптимизация путей загрузки, наряду с многочисленными исправлениями стабильности для управления жизненным циклом. Важные исправления ошибок касаются паники QueryCoord, сбоев загрузки кэшированных коллекций и регрессий производительности. Кроме того, улучшены возможности поиска с агрегацией и кэшированием фильтров выражений, а также обновлены основные зависимости и инфраструктура сборки.
