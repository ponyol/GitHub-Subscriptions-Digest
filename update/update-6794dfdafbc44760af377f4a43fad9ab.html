This release introduces significant enhancements across the platform, focusing on improved AI model interaction, developer tooling, and user experience. Key updates include multi-modal input support, configurable context window sizes, and a new concurrent CLI runner for batch execution. The VSCode extension received a unified UI architecture, better model selection, and new tool call components, while critical security fixes and enhanced retry logic bolster robustness. Additionally, the release expands internationalization with new language support and better display of extensions. --- Этот релиз включает в себя значительные улучшения по всей платформе, ориентированные на усовершенствованное взаимодействие с моделями ИИ, инструментарий для разработчиков и пользовательский опыт. Ключевые обновления включают поддержку мультимодального ввода, настраиваемые размеры контекстного окна и новый параллельный CLI-раннер для пакетного выполнения. Расширение VSCode получило унифицированную архитектуру пользовательского интерфейса, улучшенный выбор моделей и новые компоненты вызова инструментов, а критические исправления безопасности и улучшенная логика повторных попыток повышают надежность. Кроме того, релиз расширяет интернационализацию за счет поддержки новых языков и улучшенного отображения расширений.
