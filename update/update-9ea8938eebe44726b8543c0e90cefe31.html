Суммаризация (на русском)

Редактор получил поддержку пиксельного позиционирования плавающих окон, что позволяет точнее управлять UI и создавать плавную анимацию. Внедрен всесторонний режим Clojure с расширенными функциями IDE, такими как интеграция с nREPL, команды для оценки кода, запуск тестов, инспектор и инструменты рефакторинга. Добавлены новые языковые режимы для Perl, Kotlin, Zig и TOML, обеспечивающие подсветку синтаксиса и поддержку LSP. Также реализован режим Git Gutter для отображения изменений строк из системы контроля версий в реальном времени прямо в редакторе.
