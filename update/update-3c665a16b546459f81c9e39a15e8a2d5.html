Суммаризация (на русском)

This update significantly enhances security and user experience across the platform. Key changes include implementing bearer authentication for the `/sse` MCP transport and allowing Supabase URL overrides for self-hosted instances, alongside improving OAuth callback handling and error redaction. The Inspector now supports local LLM providers like Ollama, handles image tool results for vision models, and offers a more robust UI with a reconnect banner for authentication failures and improved widget fullscreen behavior. Additionally, a new CLI feature enables headless screenshots with auto-sizing, and CI stability is improved by conditionally skipping tests. --- Это обновление значительно улучшает безопасность и пользовательский опыт на всей платформе. Ключевые изменения включают внедрение аутентификации по токену для транспортного протокола `/sse` MCP и поддержку переопределения URL-адресов Supabase для самостоятельно размещенных экземпляров, а также улучшенную обработку обратных вызовов OAuth и скрытие ошибок. Инспектор теперь поддерживает локальные провайдеры LLM, такие как Ollama, обрабатывает результаты графических инструментов для моделей машинного зрения и предлагает более надежный пользовательский интерфейс с баннером переподключения при сбоях аутентификации и улучшенным поведением виджетов в полноэкранном режиме. Кроме того, новая функция командной строки позволяет делать скриншоты в безголовом режиме с автоматическим изменением размера, а стабильность CI улучшена за счет условного пропуска тестов.
