Версия ScrapeGraphAI 1.76.0 представляет новую значительную функцию — `PlasmateLoader`. Этот легковесный бэкенд для скрапинга устраняет необходимость в Chrome, значительно сокращая использование памяти и генерацию токенов, что повышает общую эффективность. Также обновление включает существенное сокращение затрат на GitHub Actions для запросов на слияние примерно на 85%.
