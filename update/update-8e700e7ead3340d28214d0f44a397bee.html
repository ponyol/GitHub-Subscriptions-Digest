Суммаризация (на русском)

Cognee 1.0.0 представляет собой крупное обновление с новым, учитывающим сессии API памяти (`remember`, `recall`, `forget`, `improve`) и комплексной панелью управления пользовательского интерфейса с визуализацией графов знаний. Ключевые изменения включают гибридный адаптер PostgreSQL для объединенных операций с графовыми и векторными базами данных, позволяющий выполнять унифицированные запросы и записывать данные в рамках одной транзакции. Релиз также унифицировал конечные точки API до `/api/v1/` и исправил критические ошибки, такие как чувствительность к регистру в именах директорий пользовательского интерфейса на Linux и улучшенная сериализация ответов API.
