Суммаризация (на русском)

This update significantly enhances prompt and context management by introducing a SHA-256 signature for system prompt caching and a new `/context` command to visualize detailed context-window usage. It improves agent interactions and reliability by clarifying rejected tool calls, preventing duplicate subagent notifications, and enabling provider-relative model aliases for greater flexibility. Additionally, the release supports image input for custom models and fixes several bugs, including a kill-job race condition and incorrect OpenAI OAuth context window detection. --- Это обновление значительно улучшает управление промптами и контекстом, вводя SHA-256 подпись для кэширования системных промптов и новую команду `/context` для визуализации подробного использования окна контекста. Оно повышает взаимодействие агентов и надежность, уточняя результаты отклоненных вызовов инструментов, предотвращая дублирование уведомлений субагентов и позволяя использовать относительные к провайдеру псевдонимы моделей для большей гибкости. Кроме того, релиз поддерживает ввод изображений для кастомных моделей и исправляет несколько ошибок, включая состояние гонки при завершении задачи и некорректное определение размера окна контекста для OpenAI OAuth.
