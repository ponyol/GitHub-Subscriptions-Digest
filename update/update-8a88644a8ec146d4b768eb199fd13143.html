Суммаризация (на русском)

This update significantly enhances LLM integrations, notably for Anthropic with new batch API support and prompt caching, alongside improvements to memory and tracing systems for better stability and recall accuracy. It also introduces comprehensive documentation and backend support for Oracle Database. Key integrations like Zed, Aider, Cursor, OpenClaw, and Vapi now feature persistent, cross-session memory capabilities. --- Этот апдейт значительно улучшает интеграции с LLM, в частности для Anthropic с новой поддержкой Batch API и кэшированием промптов, а также совершенствует системы памяти и трассировки для повышения стабильности и точности запоминания. Также добавлена исчерпывающая документация и бэкенд-поддержка для Oracle Database. Ключевые интеграции, такие как Zed, Aider, Cursor, OpenClaw и Vapi, теперь обладают возможностями постоянной памяти, сохраняющейся между сессиями.
