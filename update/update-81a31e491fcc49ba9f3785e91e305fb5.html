Суммаризация (на русском)

Эта серия обновлений значительно улучшает клиент файловой системы и SDK Tensorlake. Ключевые изменения включают введение новых SDK для Python и TypeScript, построенных на общем ядре Rust, а также капитальный пересмотр публикации файлов в блочное хранилище с использованием безопасных и эффективных механизмов, таких как предварительно подписанные PUT-запросы и параллельная загрузка. Обновления также внедряют общий журнал упреждающей записи (WAL) для надежного монтирования Git и файловых систем с автосохранением и контрольными точками, одновременно улучшая согласованность монтирования macOS FSKit, точность `tl fs status` и общую стабильность демона.
