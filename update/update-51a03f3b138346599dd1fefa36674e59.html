Text-to-speech applications often require fine-grained control over pronunciation that automatic phoneme generation cannot provide. Names, acronyms, technical terms, and numbers frequently need explicit pronunciation guidance or special interpretation rules. This change adds SSML (Speech Synthesis Markup Language) tag support to Kokoro TTS, enabling developers to override pronunciations with IPA phonemes via <phoneme>, substitute text before synthesis with \<sub\>, and control how content types like dates, numbers, and telephone numbers are spoken using \<say-as>\. The implementation follows W3C SSML standards and is designed to co-exist with the existing markdown-style [word](/phonemes/) phonetic override syntax as well as the [word](replacement) syntax —both approaches can be used together in the same text, with phonetic overrides from both sources merged during preprocessing. This gives developers flexibility to choose whichever annotation style fits their use case while maintaining full backward compatibility.
