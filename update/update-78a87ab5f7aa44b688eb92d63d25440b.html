Суммаризация (на русском)

Это обновление представляет значительные новые функции, включая динамическое обнаружение моделей от поставщиков LLM через новый CRD провайдера и пользовательский интерфейс, а также сквозную передачу ключа API для `ModelConfig` для прямой пересылки токенов в LLM. Также была обновлена минимальная версия Python до 3.10 и стандартизированы переменные среды OpenTelemetry для улучшения совместимости. Среди ключевых исправлений — устранение нестабильных потоковых тестов, улучшение конфигураций Helm-чартов (включая контексты безопасности подов и условное создание ресурсов), валидация имен агентов в CLI и критическая ошибка базы данных при отправке обратной связи.
