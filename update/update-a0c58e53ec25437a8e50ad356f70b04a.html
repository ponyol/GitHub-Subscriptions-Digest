Суммаризация (на русском)

This update introduces significant architectural and performance improvements, including a fully stateless MCP server, decoupled events and webhooks, and a refactored Temporal worker. Key developer enhancements involve the new `Inject()` dependency helper for FastAPI and a comprehensive Events API for webhook subscriptions. Performance is boosted by a bounded worker pool and optimized multi-architecture Docker builds, while diagnostics are improved with stack trace dumps for long-running syncs. New Sim integration documentation and Salesforce enhancements further extend platform capabilities. **Russian Translation:** Это обновление включает значительные архитектурные улучшения и повышение производительности, в том числе полностью несохраняющий состояние сервер MCP, разделение событий и веб-хуков, а также рефакторинг Temporal worker. Ключевые улучшения для разработчиков включают новый вспомогательный механизм внедрения зависимостей `Inject()` для FastAPI и комплексный Events API для подписок на веб-хуки. Производительность повышена за счет ограниченного пула воркеров и оптимизированных сборок Docker для нескольких архитектур, при этом улучшена диагностика благодаря дампам стека вызовов для длительных синхронизаций. Новая документация по интеграции Sim и улучшения Salesforce дополнительно расширяют возможности платформы.
