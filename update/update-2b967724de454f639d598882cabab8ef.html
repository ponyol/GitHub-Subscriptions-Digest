Суммаризация (на русском)

Это обновление повышает минимальные требования к Emacs до версии 27.1 и переводит систему CI на melpazoid. Ключевое функциональное улучшение касается подробного логирования: при установке `buffer-terminator-verbose` в `'inhibit-message`, сообщения теперь направляются исключительно в буфер `*Messages*`, предотвращая сбои в области эха.

Исходный текст

- Change minimum requirement to Emacs 27.1 - Update GitHub actions - Replace ci.yml with melpazoid - Implement echo area suppression for verbose logging Update buffer-terminator--verbose-message macro to dynamically bind inhibit-message. When buffer-terminator-verbose is set to 'inhibit-message, the modification ensures logs are written exclusively to the *Messages* buffer, avoiding echo area disruptions.
