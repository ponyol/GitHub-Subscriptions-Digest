Суммаризация (на русском)

The recent updates introduce significant improvements across the platform, enhancing agent management with namespace-scoped API access and proper memory configuration persistence. Security has been boosted through default compliance with restricted Pod Security Standards and remediation of critical CVEs in core dependencies. The user experience is refined with UI reconnection to in-progress tasks, while the backend gains a configurable stateless mode for the MCP and exposes context compaction in Helm charts for greater flexibility. Numerous Go and Python dependencies were also updated to ensure stability and incorporate the latest features. --- Недавние обновления значительно улучшают платформу, расширяя управление агентами за счет API с областью видимости по пространству имен и правильного сохранения конфигурации памяти. Безопасность повышена благодаря соответствию по умолчанию ограниченным стандартам безопасности подов (PSS) и устранению критических уязвимостей (CVE) в основных зависимостях. Пользовательский опыт улучшен за счет переподключения UI к выполняющимся задачам, а бэкенд получил конфигурируемый бессовестный режим для MCP и возможности настройки сжатия контекста в Helm-чартах. Также было обновлено множество зависимостей Go и Python для обеспечения стабильности и включения последних функций.

With multiple controller replicas, a request may land on a different replica than the one that created the session. `KAGENT_MCP_STATELESS=true` enables stateless mode, which skips session-ID validation and creates a temporary session per request, making any replica capable of handling any request.
