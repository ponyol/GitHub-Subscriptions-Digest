Система управления жизненным циклом задач GitHub была значительно улучшена для повышения качества коммуникации и автоматизации. Теперь при применении меток жизненного цикла (например, `needs-info`, `stale`) автоматически публикуются пояснительные комментарии, а процесс триажа, обнаружения устаревших задач и применения правил жизненного цикла объединен в единую, более надежную систему. Новый рабочий процесс GitHub Actions и унифицированный скрипт "sweep" обеспечивают последовательное применение правил, улучшенную обработку ошибок и своевременное закрытие задач на основе заданных таймаутов, при этом все настройки централизованы.
