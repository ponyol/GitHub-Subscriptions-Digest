Суммаризация (на русском)

This update significantly improves compatibility with Clojure by enabling a large number of `clojure.core-test` modules, covering various functions like `eval`, `merge`, `atom`, `sort`, and `get-in`. It revamps the build system to use binary-versioned directories, preventing unnecessary cleans and improving caching. Additionally, `refer-global` now allows `:rename` without `:only`. The update also includes further enhancements to math types and various bug fixes. --- Это обновление значительно улучшает совместимость с Clojure путем включения большого количества модулей `clojure.core-test`, охватывающих такие функции, как `eval`, `merge`, `atom`, `sort` и `get-in`. Переработан процесс сборки для использования каталогов с версиями бинарных файлов, что предотвращает ненужные очистки и улучшает кеширование. Кроме того, `refer-global` теперь позволяет использовать `:rename` без `:only`. Также представлены дальнейшие улучшения математических типов и различные исправления ошибок.
