Суммаризация (на русском)

Этот релиз приносит значительные улучшения производительности, включая включение перекрывающегося выполнения GPU/CPU для структурированного вывода и сокращение времени до первого токена для модели Eagle на 500 мс. Стандартная библиотека Mojo получила новый API для сегментации графемных кластеров, а строковые литералы (`\xhh`) теперь корректно представляют кодовые точки Юникода. Кроме того, обновление включает поддержку мульти-GPU для Gemma3, новые режимы параллелизма для DeepSeekV3/Kimi-K2.5 и различные оптимизации ядер для архитектур AMD и SM100. Обновленные логи конвейеров теперь явно указывают смещения во времени «Previous Execution».

In the `ep_comm.mojo` use case, lane 0 performs work to write to shared memory, then does a `syncwarp`, then all lanes consume that shared memory write.
