Суммаризация (на русском)

This release introduces significant new features including configurable custom OAuth providers, comprehensive management for edge functions (with improved upload/deployment error handling), and a storage settings dialog for adjustable maximum upload sizes. Key improvements also encompass adjustable pagination across various data grids, unified empty states, API key rotation, and critical fixes for Docker builds on fresh clones and mock data removal from deployments. --- Этот выпуск представляет значительные новые функции, включая настраиваемые пользовательские провайдеры OAuth, полное управление граничными функциями (с улучшенной обработкой ошибок при загрузке/развертывании) и диалоговое окно настроек хранилища для регулируемых максимальных размеров загружаемых файлов. Ключевые улучшения также включают настраиваемую пагинацию в различных таблицах данных, единые пустые состояния, ротацию ключей API и критические исправления для сборок Docker при чистом клонировании и удаление фиктивных данных из развертываний.
