Суммаризация (на русском)

The latest updates promote BigQuery agentic tools to stable, add support for Gemma 4 models, and significantly improve Gemini Live API session handling with cross-connection resumption and robust reconnection logic. New features include integration with Parameter Manager for centralized workload parameter management and enhanced flexibility for skill tools. Several fixes address security vulnerabilities, streamline the express mode user experience, and improve Agent Engine deployment validation. --- Последние обновления переводят агентские инструменты BigQuery в стабильную версию, добавляют поддержку моделей Gemma 4 и значительно улучшают обработку сессий Gemini Live API, включая возобновление кросс-соединений и надежную логику переподключения. Среди новых функций — интеграция с Parameter Manager для централизованного управления параметрами рабочей нагрузки и расширенная гибкость для инструментов навыков. Также были устранены уязвимости безопасности, оптимизирован пользовательский опыт в экспресс-режиме и улучшена валидация развертывания Agent Engine.
