Суммаризация (на русском)

This update significantly enhances the `Runner` by allowing `app_name` to override `app.name`, which enables Agent Engine deployments to utilize `App` objects with advanced features like event compaction and context caching. Key additions include a CLI command for database schema migrations from Pickle to JSON, support for SpannerVectorStore, and sending full history to stateless agents. The release also delivers multiple fixes addressing database keyword issues, API parsing, content handling, deployment stability, and a critical SSRF vulnerability. --- Это обновление значительно улучшает `Runner`, позволяя параметру `app_name` переопределять `app.name`, что позволяет развертываниям Agent Engine использовать объекты `App` с расширенными функциями, такими как компакция событий и кэширование контекста. Ключевые дополнения включают команду CLI для миграции схемы базы данных из Pickle в JSON, поддержку SpannerVectorStore и возможность отправки полной истории без сохранения состояния агентам. Релиз также включает множество исправлений, касающихся проблем с зарезервированными ключевыми словами базы данных, парсинга API, обработки контента, стабильности развертывания и критической уязвимости SSRF.
