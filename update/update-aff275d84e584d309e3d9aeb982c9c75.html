Суммаризация (на русском)

Это обновление представляет новые функции для выполнения инструментов, включая поддержку корней клиента MCP для ограничения доступа к файловой системе и улучшенную генерацию CLI для условных инструментов с предоставлением рекомендаций по их включению. Основные исправления касаются поведения инструментов: теперь разрешен доступ к временной директории даже без явной настройки клиентом, а также реализована проактивная обработка ошибок или отклонение вызовов инструментов при открытых диалоговых окнах. Релиз также включает обновления зависимостей, в частности, мажорное обновление `release-please-action` с переходом на Node24, а также различные внутренние улучшения и доработки тестирования.
