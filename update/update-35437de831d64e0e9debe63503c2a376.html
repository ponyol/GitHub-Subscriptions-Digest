Суммаризация (на русском)

Этот выпуск значительно улучшает опыт разработчиков и стабильность системы, особенно для разработки виджетов. Ключевые улучшения включают предварительную загрузку записей Vite для предотвращения ошибок 504 при первой отрисовке, доработку потоков аутентификации OAuth для исключения дублирования вкладок и обеспечения сохранения соединения, а также внедрение детализированного `MCP_DEBUG_LEVEL` для более подробного логирования сервера. Обновление также повышает удобство использования CLI, позволяя инициализировать проекты в текущем каталоге, улучшает обнаружение приложений Hono в инспекторе для лучшей совместимости и добавляет документацию по безопасности и директивы готовности для агентов LLM.
