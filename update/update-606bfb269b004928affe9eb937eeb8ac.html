Суммаризация (на русском)

Это обновление значительно улучшает взаимодействие с пользователем, добавляя всестороннюю поддержку вставки изображений для Emacs 29 и новее. Теперь пользователи могут напрямую вставлять изображения из системного буфера обмена в буферы Claude; система автоматически сохраняет их во временный файл и вставляет ссылку `@<path>`, которую обрабатывает CLI Claude. Эта функция бесшовно работает со всеми терминальными бэкэндами, включает автоматическую очистку временных файлов и удобно привязана к `C-c c p`.

- Adopt ghostel-set-title-function rename (#136) Ghostel 0.17.0 replaced the boolean `ghostel-enable-title-tracking` with the function-valued `ghostel-set-title-function` (nil disables tracking). Rename our buffer-local disable in the ghostel backend configuration and update the README accordingly. - Remove drag-and-drop references from image paste docs The yank-media handler only fires for clipboard image data; DnD goes through a separate Emacs subsystem (dnd-protocol-alist) and is not wired up here. - Add image paste support via yank-media (#135) * Add image paste support via yank-media On Emacs 29 and later, register a `yank-media-handler' for `image/.*' in every Claude buffer. When the user pastes an image from the system clipboard the handler writes the bytes to a temp file and injects `@<path> ' into the terminal via `claude-code--term-send-string' — Claude's CLI reads `@path' references natively and attaches the image to the next message. Temp files are tracked per-buffer and cleaned up on kill-buffer when `claude-code-image-paste-cleanup-on-kill' is non-nil. Works transparently across all three terminal backends (eat, vterm, ghostel) because the abstraction already dispatches send-string per backend. Two new defcustoms control the feature and cleanup behavior. Documents the feature in README and adds a Features bullet. * Bind claude-code-yank-media to C-c c p and add transient entry Wrap yank-media in an interactive command that targets the Claude buffer via claude-code--with-buffer, so the user can invoke it from anywhere — command map prefix on p, or the Send group of the transient menu. README updated to mention the binding. * Write pasted images to /tmp for shorter @-references The default temp dir on macOS is nested deep under /var/folders/... which makes the @<path> reference inserted at the prompt unreadable. New defcustom claude-code-image-paste-directory defaults to /tmp on systems that have it and falls back to temporary-file-directory on others. Users can override to e.g. ~/.claude/pastes/ for a project directory. * Note that ghostel backend supports C-v image paste natively
