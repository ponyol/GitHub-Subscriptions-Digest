Суммаризация (на русском)

Это обновление добавляет поддержку языкового сервера SystemVerilog и позволяет переопределять языковой бэкэнд для каждого проекта, предлагая большую гибкость. Значительно улучшена производительность сканирования портов благодаря его распараллеливанию. Кроме того, обновлены различные интеграции Language Server Protocol (LSP), в частности, устранена повторная загрузка Java для Kotlin LSP и повторная установка Metals для Scala LSP при их наличии. Также изменено автоматическое вращение баннеров на панели управления на ручное.
