Суммаризация (на русском)

This release significantly improves Streamlit's frontend by migrating `Tabs`, `Radio`, and `Checkbox` components from BaseWeb to React Aria, enhancing accessibility and removing the BaseWeb dependency. It also features notable test coverage increases for both Python and frontend code (~0.2% each, largely AI-assisted) and includes performance optimizations like memory reduction for session state dataclasses and a fix for a metrics endpoint error. --- Этот выпуск значительно улучшает внешний интерфейс Streamlit, перенося компоненты `Tabs`, `Radio` и `Checkbox` с BaseWeb на React Aria, что повышает доступность и устраняет зависимость от BaseWeb. Он также включает заметное увеличение покрытия тестов для кода Python и внешнего интерфейса (примерно на 0,2% каждое, в значительной степени с помощью ИИ) и содержит оптимизации производительности, такие как сокращение использования памяти для классов данных состояния сеанса и исправление ошибки в конечной точке метрик.
