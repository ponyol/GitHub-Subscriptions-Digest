Суммаризация (на русском)

Это обновление добавляет полную поддержку прокси для инструмента `get_video_info` в YoutubeDL, гарантируя, что все инструменты MCP единообразно учитывают настройки прокси. Ранее только функции, связанные с транскриптами, использовали прокси, а `get_video_info` этой возможности не имела. Изменение включало добавление вспомогательной функции для преобразования настроек прокси и обновление конфигурации жизненного цикла приложения, с сохранением обратной совместимости. Также было реализовано исправление аннотации типа для `ytdlp_params` для устранения ошибок mypy при объединении различных параметров прокси.
