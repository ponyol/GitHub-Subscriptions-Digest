The recent updates introduce significant enhancements, including new `crush_info` and `crush_logs` tools for real-time configuration inspection, status monitoring, and application log access. Hyper authentication has been improved with `HYPER_API_KEY` support for non-interactive workflows and automatic OAuth dialog prompting on unauthorized access. Key fixes address issues such as LSP UI display, `crush.json` schema generation, and better compatibility for local models with undefined token limits. Minor updates include dependency bumps and various bug fixes. --- Недавние обновления включают значительные улучшения, в том числе новые инструменты `crush_info` и `crush_logs` для проверки конфигурации в реальном времени, мониторинга состояния и доступа к логам приложения. Аутентификация Hyper улучшена за счет поддержки `HYPER_API_KEY` для неинтерактивных рабочих процессов и автоматического открытия диалога OAuth при несанкционированном доступе. Важные исправления касаются таких проблем, как отображение пользовательского интерфейса LSP, генерация схемы `crush.json` и улучшенная совместимость с локальными моделями с неопределенными лимитами токенов. Незначительные обновления включают повышение версий зависимостей и различные исправления ошибок.
