Суммаризация (на русском)

These releases primarily focused on improving chat variant persistence and per-chat scoping for model and agent configurations, addressing numerous regressions where user selections were lost. Key fixes ensured variant settings are preserved across model/agent changes and chat sessions, and enabled proper per-chat management of these configurations. Additionally, updates included enhancing authentication support for Claude and fixing issues with OpenAI's web search, alongside crucial bug fixes for subagent communication and tool name resolution. **Russian Translation:** Данные выпуски в основном были посвящены улучшению сохранения вариантов чата и привязки настроек модели и агента к конкретному чату, устраняя многочисленные регрессии, при которых пользовательские настройки терялись. Ключевые исправления обеспечили сохранение настроек вариантов при смене модели/агента и между сессиями чата, а также надлежащее управление этими конфигурациями для каждого чата. Кроме того, обновления включали улучшение поддержки аутентификации для Claude и исправление проблем с веб-поиском OpenAI, а также важные исправления ошибок для взаимодействия субагентов и разрешения имен инструментов.
