The update introduces major refactoring of Python packaging, moving it into the main repository with a streamlined build process and improved CI/CD. It significantly enhances Mixture-of-Experts (MoE) model handling by fixing VRAM estimation regressions, improving GPU throughput calculations, and adding support for new quantization formats and model families like DeepSeek V4 and Qwen3.6. The user interface and CLI tools receive new features, including a comprehensive download manager, advanced filtering options, and better detection of installed models, alongside critical security fixes and CI/dependency updates. --- Обновление включает значительный рефакторинг упаковки Python, перенося ее в основной репозиторий с оптимизированным процессом сборки и улучшенной CI/CD. Оно значительно улучшает обработку моделей Mixture-of-Experts (MoE), исправляя регрессии в оценке VRAM, улучшая расчеты пропускной способности GPU и добавляя поддержку новых форматов квантования и семейств моделей, таких как DeepSeek V4 и Qwen3.6. Пользовательский интерфейс и инструменты командной строки получили новые функции, включая полнофункциональный менеджер загрузок, расширенные параметры фильтрации и улучшенное обнаружение установленных моделей, а также критические исправления безопасности и обновления CI/зависимостей.
