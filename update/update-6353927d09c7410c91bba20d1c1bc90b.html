Суммаризация (на русском)

Это обновление внедряет новую мультиязычную CoreML G2P-модель, поддерживающую девять языков, а также CLI-команду для бенчмаркинга ее производительности. G2P-модели теперь используют только CPU для ускорения работы. Дополнительно, представлены новые API для предварительной регистрации дикторов в системе диаризации, а загрузка моделей теперь включает подробные колбэки прогресса. Ряд исправлений повышает стабильность сборки для iOS и улучшает документацию.
