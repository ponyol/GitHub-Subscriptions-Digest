Это обновление заменяет устаревший параметр `MaxTokens` на `MaxCompletionTokens` для вызовов OpenAI API. Изменение устраняет ошибку, возникающую с новыми моделями OpenAI, которые больше не поддерживают `max_tokens` и требуют использования `max_completion_tokens`.

- fix: use MaxCompletionTokens instead of deprecated MaxTokens for OpenAI (#1604) The OpenAI API deprecated 'max_tokens' parameter in favor of 'max_completion_tokens' for newer models (o1, gpt-4o, etc.). This change fixes the error: 'Unsupported parameter: max_tokens is not supported with this model. Use max_completion_tokens instead.'
