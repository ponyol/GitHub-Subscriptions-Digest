Суммаризация (на русском)

Последнее обновление представляет приложение для панели меню macOS (`af-tray`), предоставляющее живой статус флота, метрики с цветовой индикацией пороговых значений и управление ключами API. Оно также добавляет полноценную поддержку узлов Go-агентов, включая установку и выполнение, и вводит функциональность `Agent.Pause`, отчетность по затратам и режим инкрементальной схемы в SDK для Go и TypeScript, достигая паритета функций. Улучшен опыт разработчиков за счет автоматической подготовки интерпретатора Python и групп переменных окружения `require_one_of` для `af install`, а также нового стилизованного пользовательского интерфейса терминала. Критические исправления включают предотвращение атак повторного воспроизведения вебхуков и устранение гонки портов при запуске `af run`.

Root cause is a check-then-exec race between the runner and the SDK: 1. The runner probes a free port, releases the probe, exports PORT=N, then polls ONLY port N for readiness. 2. If N is momentarily unavailable when the child binds, the SDK SILENTLY moves to the next free port (N+1) — a port the runner never learns about. The 10s readiness window is also too short for nodes with large import graphs, independent of the race.
