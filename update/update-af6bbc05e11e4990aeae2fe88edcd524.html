Суммаризация (на русском)

Это обновление добавляет новую службу веб-пуш-уведомлений, основанную на протоколе VAPID. Она обеспечивает асинхронную отправку уведомлений, типобезопасные модели данных и комплексное управление подписками через новую модель PushSubscription, REST API и административный интерфейс. Сервис настраивается через django-cfg WebPushConfig, закладывая надежную и безопасную основу для системы пуш-уведомлений.
