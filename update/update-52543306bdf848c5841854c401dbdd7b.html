Суммаризация (на русском)

This extensive update introduces a major refactor of the MCP server, transitioning to an SDK-based architecture. It integrates a new executor system for various inference methods (local, official API, self-hosted) and redesigns the capability layer to manage pipeline-specific logic and default options. Furthermore, PaddleOCR skills are simplified to directly use the CLI, and documentation is updated to reflect the new flexible handling of binary response content, which can now be returned as pre-signed URLs. --- Это обширное обновление представляет собой масштабную рефакторинг сервера MCP, переходящего на архитектуру, основанную на SDK. Оно интегрирует новую систему исполнителей для различных методов вывода (локального, через официальный API, а также для самостоятельного хостинга) и перерабатывает слой возможностей для управления логикой конвейеров и параметрами по умолчанию. Кроме того, навыки PaddleOCR упрощены для прямого использования CLI, а документация обновлена, чтобы отразить новую гибкую обработку бинарного содержимого ответов, которое теперь может возвращаться в виде предварительно подписанных URL-адресов.
