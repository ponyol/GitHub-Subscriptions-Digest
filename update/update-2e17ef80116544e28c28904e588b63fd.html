This update introduces comprehensive multi-workspace support, including qualified ACP transport, dynamic workspace registration, and enhanced session and artifact management across multiple workspaces. It also significantly refines LLM interaction by optimizing context window management, safeguarding YOLO mode against unintended plan mode switches, and enhancing tool output rendering in the TUI with a full-detail transcript view. The release includes major improvements to the code review process with diff partitioning and inline suggestions, alongside various stability fixes, performance optimizations, and channel-specific integrations. --- Это обновление внедряет комплексную поддержку нескольких рабочих пространств, включая квалифицированный транспорт ACP, динамическую регистрацию и улучшенное управление сессиями и артефактами. Оно также значительно улучшает взаимодействие с LLM за счет оптимизации управления окном контекста, защиты режима YOLO от непреднамеренных переключений в режим планирования и улучшения рендеринга вывода инструментов в TUI с представлением подробной стенограммы. Релиз включает значительные усовершенствования процесса ревью кода с разделением изменений и встроенными предложениями, а также различные исправления стабильности, оптимизации производительности и интеграции для конкретных каналов.
