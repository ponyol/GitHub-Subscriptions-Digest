Суммаризация (на русском)

This update significantly enhances storage performance and observability, especially for MP mode. It introduces a Rust-based Raw Block Backend for zero-copy, O_DIRECT I/O, and a comprehensive observability stack with Prometheus integration. The system now supports dynamic creation of backends and lookup clients, alongside improved remote connectivity via shared memory and multi-threaded RESP. Additionally, there are fixes for layerwise save concurrency and updates to token matching and L2 storage management. --- Это обновление значительно улучшает производительность хранилища и возможности мониторинга, особенно для режима MP. Введен новый бэкенд Raw Block на Rust, обеспечивающий ввод-вывод без копирования и с O_DIRECT, а также комплексный стек мониторинга с интеграцией Prometheus. Система теперь поддерживает динамическое создание бэкендов и клиентов поиска, а также улучшено удаленное подключение через общую память и многопоточный RESP. Дополнительно устранены проблемы параллелизма послойного сохранения и обновлены механизмы работы с токенами и управление хранилищем L2.
