Суммаризация (на русском)

This release delivers several critical fixes and updates. It resolves an HTTPS failure for `LOAD CSV` on Linux and corrects path comparison logic, improving accuracy in weighted path procedures and addressing double-to-int truncation issues. Additionally, a memory leak in pathfinding algorithms (SPpaths/SSpaths) has been fixed, alongside an update to the RediSearch component and various minor dependency upgrades. Этот выпуск содержит ряд критических исправлений и обновлений. Кроме того, исправлена утечка памяти в алгоритмах поиска путей (SPpaths/SSpaths), а также обновлен компонент RediSearch и внесены различные минорные обновления зависимостей.
