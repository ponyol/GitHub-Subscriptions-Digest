Суммаризация (на русском)

Это обновление вводит новые флаги командной строки для настройки URI сервисов сессий и артефактов, заменяя устаревшие опции, а также рефакторит инициализацию этих сервисов. Оно значительно расширяет возможности моделей, позволяя использовать части изображений в пользовательских сообщениях для Anthropic Claude и добавляя поддержку нескольких провайдеров для Claude и LiteLLM. Кроме того, обновление включает исправления для прозрачного возобновления сессий с ключами Gemini API и добавляет предупреждения для неподдерживаемых сервисов.
