Суммаризация (на русском)

This release significantly overhauls content processing with new content-type aware chunking and a unified embedding system, enhancing compatibility with Ollama models. It also introduces Japanese language support, improves error logging for chat model configurations, and strengthens data integrity by preventing and cleaning up orphaned embedding records. Additional fixes address prompt output, frontend search issues, and update documentation including new Conda installation instructions. *** Этот выпуск значительно перерабатывает обработку контента, внедряя новое разделение на фрагменты с учетом типа контента и унифицированную систему встраивания, что улучшает совместимость с моделями Ollama. Он также добавляет поддержку японского языка, улучшает ведение журнала ошибок для конфигураций чат-моделей и повышает целостность данных, предотвращая и очищая записи встраиваний-сирот. Дополнительные исправления касаются вывода подсказок, проблем с поиском во внешнем интерфейсе и обновляют документацию, включая новые инструкции по установке с использованием Conda.
