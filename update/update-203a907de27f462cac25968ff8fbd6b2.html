Суммаризация (на русском)

This release brings substantial improvements across the platform, introducing new UI features for usage and agent management, alongside backend enhancements. It expands integrations with new API providers such as Azure AI Foundry Agents and Sendgrid, and adds configurable guardrails for enhanced security and PII masking. Key updates include support for OpenAI GPT-5.2, native parameters for DeepSeek, and `serviceTier` for Bedrock's Converse API, coupled with a new Prompt Management API. The update also addresses various bug fixes, performance optimizations, and Python version compatibility. --- Этот выпуск содержит значительные улучшения всей платформы, представляя новые функции пользовательского интерфейса для управления использованием и агентами, а также улучшения бэкенда. Расширены возможности интеграции с новыми поставщиками API, такими как Azure AI Foundry Agents и Sendgrid, а также добавлены настраиваемые механизмы защиты (guardrails) для повышения безопасности и маскирования PII. Среди ключевых обновлений – поддержка OpenAI GPT-5.2, нативные параметры для DeepSeek и `serviceTier` для Bedrock Converse API, в сочетании с новым API для управления промптами. Обновление также включает различные исправления ошибок, оптимизацию производительности и улучшение совместимости с версиями Python.
