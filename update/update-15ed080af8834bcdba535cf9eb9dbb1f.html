Этот релиз значительно улучшает JSON-сериализацию UUID в компонентах `django_sitemap` и Sitemap, устраняя предыдущие ошибки. Он уточняет метрики здоровья RQ для точного расчета `oldest_job_age_sec` с использованием `enqueued_at` и вводит гистерезис (`min_consecutive_breaches`) для оповещений о состоянии RQ, уменьшая количество ложных срабатываний. Кроме того, расширения теперь могут динамически объявлять вкладки и навигацию панели администратора, оптимизируя конфигурацию пользовательского интерфейса.

Co-Authored-By: Claude Opus 4.7 <noreply@anthropic.com> - fix(rq/health): use enqueued_at for oldest_job_age metric ``Job.created_at`` is set when the Job object is first instantiated. For RQ-scheduled periodic jobs that means scheduler-startup time — each fire re-uses the same created_at, so the metric falsely reports "oldest job age" as roughly process uptime on every cycle. The breach masks real stuck-job signal and floods the alerting channel once hysteresis clears. ``enqueued_at`` reflects the current iteration's queue-entry time and matches the metric's intent. Fall back to ``created_at`` only when enqueued_at is unset (legacy one-shot jobs).
