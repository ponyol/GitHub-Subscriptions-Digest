Суммаризация (на русском)

This update brings significant performance enhancements, notably through concurrent I/O for `LocalDiskBackend` to accelerate vLLM's hot read path and parallel chunk loading for multi-process operations. New features include a native Azure Blob Storage connector, batch and stream interfaces for the KVCache SDK, and dual-RoPE support. The release also features a major refactoring of memory allocators for improved maintainability, alongside numerous bug fixes and documentation updates. --- **Russian Translation:** Это обновление значительно повышает производительность, в частности, за счет одновременных операций ввода-вывода для `LocalDiskBackend` для ускорения "горячего" пути чтения vLLM и параллельной загрузки чанков для многопроцессорных операций. Среди новых функций — нативный коннектор Azure Blob Storage, интерфейсы пакетной обработки и потоковой передачи для KVCache SDK, а также поддержка dual-RoPE. Выпуск также включает крупный рефакторинг распределителей памяти для улучшения поддерживаемости, наряду с многочисленными исправлениями ошибок и обновлениями документации.
