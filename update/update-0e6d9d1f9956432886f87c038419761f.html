Суммаризация (на русском)

This update delivers substantial new features, such as native OpenTelemetry agentic metrics, comprehensive Firestore support for session and memory, and Vertex AI Agent Engine Sandbox integration for secure computer use. It also adds advanced evaluation options, support for refusal messages, and live avatar capabilities. Numerous fixes resolve issues including path type mismatches, agent state management, BigQuery plugin functionality, and improved console URL paths for deployed agents. --- Это обновление предоставляет значительные новые функции, такие как собственные метрики OpenTelemetry для агентов, комплексную поддержку Firestore для сессий и памяти, а также интеграцию Vertex AI Agent Engine Sandbox для безопасного использования компьютера. Также добавлены расширенные параметры оценки, поддержка сообщений об отказе и возможности живых аватаров. Многочисленные исправления устраняют проблемы, включая несоответствие типов путей, управление состояниями агентов, функциональность плагина BigQuery и улучшенные пути URL консоли для развернутых агентов.
