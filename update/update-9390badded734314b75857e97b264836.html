Суммаризация (на русском)

This update introduces the `bd batch` command for atomic multi-operation transactions, significantly boosting scripting performance. It greatly enhances shared-server deployments with configurable connection pooling, new telemetry metrics, and per-database circuit breakers for improved reliability and diagnostics. The release also brings extensive improvements for Git worktree support, removes the ICU runtime dependency for better portability, and strengthens security by storing secret configuration keys in local YAML. Critical auto-export and auto-backup errors are now surfaced to users for better visibility. --- **Русский перевод:** Это обновление представляет команду `bd batch` для атомарных многооперационных транзакций, значительно повышая производительность скриптов. Значительно улучшена работа развертываний на общем сервере благодаря настраиваемому пулу соединений, новым метрикам телеметрии и независимым прерывателям цепи для каждой базы данных, что повышает надежность и упрощает диагностику. Релиз также включает обширные улучшения поддержки рабочих деревьев Git, устраняет зависимость от ICU во время выполнения для лучшей переносимости и повышает безопасность за счет хранения секретных ключей конфигурации в локальном YAML. Критические ошибки автоэкспорта и авторезервного копирования теперь отображаются пользователям для лучшей видимости.
