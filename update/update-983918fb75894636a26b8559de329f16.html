Суммаризация (на русском)

This release significantly enhances remote client interaction by surfacing pending tool calls via the REST API and introduces a `read-chat` CLI command for direct access to chat records. Key improvements include richer prompt environment context, optimized dynamic instructions for Opus 4.8, and better chat trust configuration. Stability is boosted through fixes for chat persistence, cache concurrency, and cross-process OAuth refresh locking. --- Этот релиз значительно улучшает взаимодействие с удаленными клиентами, отображая ожидающие вызовы инструментов через REST API, и представляет CLI-команду `read-chat` для прямого доступа к записям чатов. Основные улучшения включают более информативный контекст окружения запросов, оптимизированные динамические инструкции для Opus 4.8 и улучшенную настройку доверия чатов. Стабильность повышена благодаря исправлениям, касающимся сохранения чатов, параллелизма кеша и блокировки обновления OAuth между процессами.
