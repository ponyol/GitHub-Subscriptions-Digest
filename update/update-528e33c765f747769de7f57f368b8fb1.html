Суммаризация (на русском)

This release significantly enhances guardrails by introducing LLM judges, prompt injection detection, and custom trained guardrails across the backend, frontend, and SDKs, with added support for CPU deployments. Both Python and TypeScript SDKs now feature automatic truncation of oversized span and trace payloads, as well as extraction of base64 attachments, to prevent ingestion failures and manage data size. Backend improvements include stricter UUIDv7 ID validation for data integrity, refined AI spend categorization and git context tracking for cost intelligence, better support for custom code metrics in the Optimization Studio, and enhanced visibility into data loss during SDK flushing. --- **Русский перевод:** Этот выпуск значительно улучшает механизмы защиты, добавляя судей на базе LLM, обнаружение инъекций промтов и пользовательские обучаемые правила защиты для бэкенда, фронтенда и SDK, а также поддержку развертывания на CPU. SDK для Python и TypeScript теперь включают автоматическое усечение больших полезных нагрузок спанов и трассировок, а также извлечение вложений в формате base64, что предотвращает сбои при приеме данных и помогает управлять их размером. Улучшения бэкенда включают более строгую валидацию идентификаторов UUIDv7 для обеспечения целостности данных, улучшенную категоризацию расходов на ИИ и отслеживание контекста Git для анализа затрат, расширенную поддержку пользовательских метрик кода в Optimization Studio и повышенную видимость потери данных во время отправки через SDK.
