Суммаризация (на русском)

Это изменение исправляет нарушение правила одного определения (ODR) для функций `cpp/raw` во время AOT-компиляции. Проблема возникала из-за многократной обработки идентичных вызовов. Решение реализует защиту `#ifndef/#define`, чтобы гарантировать, что вызовы `cpp/raw` с одинаковым строковым содержимым считаются эквивалентными и выполняются только один раз.

Исходный текст

- Fix ODR violation for cpp/raw functions during AOT compilation (#591) Fixes #582 . We use a simple #ifndef/#define guard, so all calls to `cpp/raw` that have exactly the same content (same string) will be considered equivalent and run only once.
