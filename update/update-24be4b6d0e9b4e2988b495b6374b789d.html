- v1.9.7: --ignore-scripts on auto-update for Shai Hulud-class supply-chain protection (#50) Adding --ignore-scripts to the launcher's auto-update path blocks the preinstall/install/postinstall lifecycle hooks that Shai Hulud-style worms (and any other npm postinstall malware) use as the entry vector for arbitrary code execution. Issue #50 by @steverhoades cites pi's own posture for the same protection — we now match it. Scope: auto-updater only (bin/update-check.mjs spawn args + the notice-only manual-recovery string shown on non-TTY pipelines). First install via install.sh / npm install -g still runs scripts so playwright's chromium download lands during onboarding; on patch upgrades the binary is already on disk from that first install, so --ignore-scripts is the safer default there. Two new tests pin the flag in the source — a removal in either the spawn args or the user-visible command string fails CI. Also includes @i-snyder's docs PR #53 (cherry-picked just before this commit, authorship preserved) with troubleshooting entries for the --update flag and the Windows ≤ v1.9.5 bootstrap caveat.
