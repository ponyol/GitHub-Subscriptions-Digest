Суммаризация (на русском)

Последние обновления преимущественно сосредоточены на повышении стабильности и расширении корпоративной поддержки ИИ-чатов, в особенности GitHub Copilot. В них реализована динамическая обработка API и усилена аутентификация для пользователей GitHub Enterprise, устранены многочисленные циклы повторных попыток и проблемы с аутентификацией во время выполнения потоковых вызовов инструментов. Кроме того, добавлены новые функции управления чатами, такие как именованные флаги сообщений, полное сохранение истории и настраиваемый период хранения, а также улучшена производительность за счет оптимизации кэширования запросов Anthropic и обработки контекста.
