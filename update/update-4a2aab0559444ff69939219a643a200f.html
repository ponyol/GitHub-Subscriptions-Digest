Суммаризация (на русском)

The `gptel` update introduces experimental token usage tracking for OpenAI, Kagi, Bedrock, and Ollama backends. It also includes important fixes for `gptel-openai` request data construction, robust Curl error checking in `gptel-request`, and visual improvements to the tool inspection buffer. Additionally, deprecated models were removed from Groq configurations, and new tests for non-streaming responses were added. Обновление `gptel` представляет экспериментальное отслеживание использования токенов для бэкендов OpenAI, Kagi, Bedrock и Ollama. Оно также включает важные исправления для формирования данных запросов `gptel-openai`, надежную проверку ошибок Curl в `gptel-request` и визуальные улучшения буфера инспекции инструментов. Кроме того, из конфигураций Groq были удалены устаревшие модели и добавлены новые тесты для нестриминговых ответов.

- gptel-openai: Construct request data without backquotes * gptel-openai.el (gptel--request-data): Creating a backquoted construct to hold the payload is causing issues with self-evaluating forms (#1301). This was previously addressed for the Gemini backend in 0cdc06c0. See (info "(elisp) Self-Evaluating Forms") Construct the payload plist explicitly instead. - gptel-request: Check Curl exit status before parsing response * gptel-request.el (gptel-curl--stream-cleanup, gptel-curl--sentinel, gptel-curl--parse-response): Check `process-exit-status' in both `gptel-curl--stream-cleanup' and `gptel-curl--sentinel'. When Curl exits with a non-zero status (network error, DNS failure, SSL misconfiguration, etc.), it never completes the transfer and the UUID marker written by `-w' is absent. Checking the exit status early short-circuits with a clear error message, also fixing #1234 (silent Curl failures). As defense-in-depth, also pass NOERROR to `search-backward' in both sentinels and in `gptel-curl--parse-response', so that even if the exit status is zero but the UUID is unexpectedly absent, the search returns nil instead of signaling `search-failed'. - gptel: Fix dangling overlays in tool-inspection buffer * gptel.el (gptel--inspect-tool-calls): Clear dangling overlays from a previous invocation of this command that can mess up the highlighting. - README: Update Groq configuration README.org: Remove another deprecated model (llama3-70b-8192) from the example Groq configuration. Fix #1294.
