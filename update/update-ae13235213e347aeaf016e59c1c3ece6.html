Суммаризация (на русском)

This update includes critical security fixes addressing potential vulnerabilities such as IDOR, Zip Slip path traversal, and SQL injection, alongside enforcing user suspension checks for browser extensions. Significant UI/UX improvements have been introduced, featuring a new v2 chat layout with chat bubbles, an enhanced citations UI with a sources sidebar, and a redesigned prompt input with a tools menu. Additionally, agent capabilities have been expanded with native tool calling support for various LLMs and improved metric reporting. --- Это обновление включает критические исправления безопасности, устраняющие потенциальные уязвимости, такие как IDOR, Zip Slip (обход пути) и SQL-инъекции, а также усиливает проверки приостановки учетных записей для расширений браузера. Были внесены значительные улучшения в пользовательский интерфейс, представив новый макет чата v2 с облачками сообщений, улучшенный интерфейс цитирования с боковой панелью источников и переработанный ввод подсказок с меню инструментов. Кроме того, расширены возможности агентов за счет поддержки нативного вызова инструментов для различных больших языковых моделей (LLM) и улучшенной отчетности по метрикам.
