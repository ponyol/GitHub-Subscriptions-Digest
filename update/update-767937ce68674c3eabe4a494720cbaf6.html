Суммаризация (на русском)

Функция `run` была рефакторизирована для значительного улучшения поддержки `stdin`/`stdout`, устраняя ряд проблем, возникших при разработке тестовых сценариев. Это обновление добавляет возможность передачи `Data` в `stdin`, исправляет блокировку каналов и облегчает прямое перенаправление двоичных данных из `stdout` в `stdin`. Данные изменения были реализованы в отдельном пулл-реквесте, чтобы не перегружать другие текущие работы.

- [tests]: refactor run function for stdin/stdout support (#830) When working on test cases for #827 and #734 the following issues occurred 1. There was no support to pass in `Data` for `stdin` (input pipe added + new argument for the data) 2. Pipes were getting blocked during the `try process.run()` and `process.waitUntilExit()` (order of operations were fixed) 3. We need the binary data for directly piping the `stdout` data to `stdin`, and converting the data to a `string`, returns `""` (added a new value to the tuple) I opened a new PR here for this as I did not want to bloat the other PRs with so many updates.
