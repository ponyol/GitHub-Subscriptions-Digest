Суммаризация (на русском)

Это обновление представляет несколько новых функций и устраняет многочисленные ошибки в различных компонентах. Основные новые возможности включают добавление `.yml` в отслеживаемые расширения файлов, улучшение API-инструментов с помощью `header_provider` и использование JSON-схемы для объявления функций-инструментов. Существенные исправления ошибок касаются ведения логов LiteLLM, нормализации содержимого, форматирования схем ответов, подключений к SQLite, инициализации клиента Spanner, установки зависимостей для Python 3.10 и рендеринга пользовательского интерфейса ADK web. Также обновлена версия до v1.21.0.
