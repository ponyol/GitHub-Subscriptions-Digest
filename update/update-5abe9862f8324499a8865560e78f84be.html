Суммаризация (на русском)

This LiteLLM update significantly expands model and provider support, integrating 227 new Fireworks AI models, Bedrock writer models, Cerebras Z.ai GLM 4.6, Nvidia Nim, and new providers like SAP Gen AI Hub and Helicone. Key bug fixes address Cerebras context window errors, OpenAI Responses API parameter handling, streaming tool calls, and Azure AI Anthropic cost calculations. The release also includes extensive documentation improvements, refactoring, and general stability enhancements. --- Это обновление для LiteLLM значительно расширяет поддержку моделей и провайдеров, интегрируя 227 новых моделей Fireworks AI, модели Bedrock writer, Cerebras Z.ai GLM 4.6, Nvidia Nim, а также новых провайдеров, таких как SAP Gen AI Hub и Helicone. Важные исправления ошибок касаются проблем с окном контекста Cerebras, обработки параметров OpenAI Responses API, потоковой передачи вызовов инструментов и расчетов стоимости Azure AI Anthropic. Выпуск также включает обширные улучшения документации, рефакторинг и общее повышение стабильности.
