Суммаризация (на русском)

This update includes several key improvements: enhanced Langfuse tracing to correctly link nested LLM calls, robust handling of multimodal content for the browser planner to ensure compatibility with diverse LLM endpoints, and refinements to agent description generation for Pydantic model compatibility. Additionally, significant amounts of dead and unused code were removed from both frontend and backend components, improving maintainability and reducing bloat. --- Это обновление включает несколько ключевых улучшений: усовершенствованное трассирование Langfuse для корректной связи вложенных вызовов LLM, надёжная обработка мультимодального контента для планировщика браузера для обеспечения совместимости с различными конечными точками LLM, а также доработки в генерации описаний агентов для совместимости с моделями Pydantic. Кроме того, значительное количество мёртвого и неиспользуемого кода было удалено как из фронтенд-, так и из бэкенд-компонентов, что улучшило сопровождаемость и уменьшило раздутость.
