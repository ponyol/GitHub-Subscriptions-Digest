Суммаризация (на русском)

This update significantly enhances LocalAI by improving backend installation robustness with fallback URI resolution and enabling better Windows Docker compatibility through named volumes. It introduces new model support, including presets for Qwen3.5 and a faster Qwen3-TTS backend, alongside adding `sample_rate` functionality to the TTS API. Various fixes address critical issues like file permissions, model reloading after configuration changes, and excessive logging. Additionally, documentation has been streamlined, merging container guides and removing the deprecated `install.sh` script. --- Это обновление значительно улучшает LocalAI за счет повышения надежности установки бэкендов с резервным разрешением URI и обеспечения лучшей совместимости с Docker в Windows благодаря именованным томам. Оно добавляет поддержку новых моделей, включая пресеты для Qwen3.5 и более быстрый бэкенд Qwen3-TTS, а также функциональность `sample_rate` в API TTS. Различные исправления устраняют критические проблемы, такие как разрешения файлов, перезагрузка моделей после изменений конфигурации и избыточное логирование. Кроме того, документация была оптимизирована, объединив руководства по контейнерам и удалив устаревший скрипт `install.sh`.
