Суммаризация (на русском)

This release focuses on significant performance enhancements for experiment data through pre-computed aggregates, Redis-based recomputation, and ClickHouse query optimizations. The SDK sees numerous improvements including accurate token/cost calculations, an enhanced evaluation suite API with new features like pass rate aggregation and batch item insertion, and robust local runner parallelism with process isolation. Furthermore, new user permissions are introduced across various features, model synchronization is automated, and the import migration system is upgraded to a more reliable SQLite database. --- **Russian translation:** Это обновление значительно повышает производительность и масштабируемость бэкенда для данных экспериментов за счет предварительно рассчитанных агрегированных таблиц, пересчета на основе Redis и обширных оптимизаций запросов ClickHouse. SDK получил многочисленные улучшения, включая точные расчеты токенов и стоимости для интеграций на базе OTEL, расширенный API для наборов оценок с такими новыми функциями, как агрегирование коэффициента прохождения и пакетная вставка элементов, а также надежную параллельную работу локальных раннеров с изоляцией процессов. Кроме того, введены новые пользовательские разрешения для различных функций, автоматизирована синхронизация моделей, а система миграции импорта обновлена до более надежной базы данных SQLite.
