Суммаризация (на русском)

This Milvus update introduces new features such as support for StructArray with element-level querying, enhanced TopK limits (up to 1M) for search operations, and Pinyin filtering. It also improves scalar index storage (V3 format) and reduces load latency through asynchronous cache warming. Key bug fixes address crashes during GROUP BY aggregations, correct StorageV3 segment manifest paths, and enhance partial updates with dynamic fields. The release further includes performance optimizations, RBAC improvements, and a security update. --- Это обновление Milvus представляет новые возможности, такие как поддержка StructArray с запросами на уровне элементов, расширенные лимиты TopK (до 1M) для операций поиска и фильтрацию по пиньиню. Также улучшено хранение скалярных индексов (формат V3) и уменьшена задержка загрузки благодаря асинхронному прогреву кеша. Основные исправления включают устранение сбоев при агрегации GROUP BY, корректировку путей манифестов сегментов StorageV3 и улучшение частичных обновлений с динамическими полями. Кроме того, выпуск содержит оптимизации производительности, улучшения RBAC и обновление безопасности.
