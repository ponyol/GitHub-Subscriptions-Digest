Суммаризация (на русском)

Это обновление включает важное исправление ошибки сборки мусора в обработке DAG, которая ранее препятствовала надлежащей очистке промежуточных значений в разделенных DAG-ах. Также представлена первоначальная интеграция вызова инструментов Llama CPP, хотя и с отмеченными ограничениями касательно совместимости моделей и параллельных вызовов. Кроме того, релиз улучшает функцию `add_embedding_index` для поддержки входных данных типа Array Column и устраняет различные мелкие проблемы, такие как подавление предупреждения pytest-benchmark и восстановление заголовков в блокнотах Gemini.

- Suppress pytest-benchmark/xdist warning in test runs (#1223) Gets rid of: ``` PytestBenchmarkWarning: Benchmarks are automatically disabled because xdist plugin is active.Benchmarks cannot be performed reliably in a parallelized environment. ``` in `make test`, `make slimtest`, etc. This is a no op because benchmarks are already excluded via addopts anyway. - Remove check_pending_ops=False during similarity expression deserialization (#1222) Co-authored-by: Pierre Brunelle <70675979+pierrebrunelle@users.noreply.github.com> - [PXT-1063] Garbage Collection in dispatch() can stop gc'ing intermediate values on split dags (#1194) Previously Sergey captured a bug during the dispatch() rework PR in which split DAGs could cause intermediate results to not be properly garbage collected. The mechanism for this was that intermediate values would be gc'ed before their dependencies which would then mean the dependencies wouldn't be cleaned up. Take a look at the DAG below, what would happen is that when we would compute V we would garbage collect T and set its has_val to False. Thus when we finally computed U and went to gc S we would incorrectly assume that we are still waiting on T to be able to gc S. The method used to fix this was to instead calculate missing dependents using missing_slots, which doesn't get zeroed out after the slot is gc'ed. ``` x | S (gc) / \ T | | | V | |\ / | U (gc) | | | W | (output: V, W) ``` --------- Co-authored-by: Claude Sonnet 4.6 <noreply@anthropic.com> - [PXT-565] Llama CPP tool call invocation integration (#1211) Limitations: 1. E.g. multiple (aka parallel) tool calls is one thing that I couldn't get to work with none of the four models I've tried.
