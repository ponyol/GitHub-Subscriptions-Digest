Also simplifies `test_rate_limits_scheduler_exception_before_pool` with fault injection. ### Fault injection A lightweight fault injection framework for testing failure and concurrency scenarios in instrumented code paths. Production code calls `process_fault(loc)` at each `FaultLocation`. In production this is a no-op (`ProdFaultManager`). In tests, a `TestFaultManager` can register a `Fault` at any location before triggering the code under test: - `ExceptionFault`: raises a given exception - `BlockFault`: pauses the thread at the fault point, letting the test inspect or manipulate shared state before calling `unblock()`. Useful for reproducing race conditions. ### MultiThreadedScenario A builder for deterministic multi-threaded test scenarios.
