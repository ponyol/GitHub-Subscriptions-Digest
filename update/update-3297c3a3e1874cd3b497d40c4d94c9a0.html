Суммаризация (на русском)

API Anthropic теперь повсеместно использует `output_config` для структурированных выходных данных во всех моделях, заменяя устаревшие методы, такие как заголовок `structured-outputs` и параметр `output_format`. Это изменение также устраняет зависимость `json-schema-to-pydantic`, которая ранее требовалась для бета-версии потоковой передачи. Кроме того, тестовые модели были обновлены с `claude-3.5-haiku` на `claude-haiku-4.5`, а в тестовые утверждения было добавлено поле `stop_details` для соответствия текущим ответам API.

Исходный текст

- Switch structured outputs to output_config, drop json-schema-to-pydantic dependency The Anthropic API now supports output_config for all models, not just 4.6+. This removes the need for the structured-outputs beta header, the deprecated output_format parameter (which caused deprecation warnings), and the json-schema-to-pydantic dependency that was only needed to convert JSON schemas to Pydantic models for the beta streaming path. Also switches test models from deprecated claude-3.5-haiku to claude-haiku-4.5, and adds stop_details field to test assertions to match current API responses.
