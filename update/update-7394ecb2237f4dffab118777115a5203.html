Версия 0.3.4 представляет новый, более легковесный логгер приложений, который заменяет поставляемый пакет `structlog`. Этот новый модуль сохраняет основные функции, такие как структурированное логирование в формате JSON, контекстная осведомленность для добавления дополнительной информации и трассировки стека в виде JSON-строк для улучшения вывода. Изменение направлено на предоставление более легковесного решения для логирования с сохранением критически важной функциональности.
