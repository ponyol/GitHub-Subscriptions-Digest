Суммаризация (на русском)

The vulpea v2.5.0 release significantly expands and solidifies schema functionality. Key additions include schema-driven note authoring, inheritance, target-tag restrictions, real-time in-buffer linting, and sync-time validation, complemented by tools for quick-fixing violations and aggregating schema health. Critical bug fixes address heading-level note scoping for meta/schema operations, prevent misinterpretation of Org properties within verbatim blocks, and improve external sync reliability on Windows. --- Выпуск vulpea v2.5.0 значительно расширяет и укрепляет функциональность схем. Ключевые добавления включают создание заметок на основе схем, наследование, ограничения по целевым тегам, линтинг в буфере в реальном времени и валидацию при синхронизации, дополненные инструментами для быстрого исправления нарушений и агрегирования состояния схем. Критические исправления ошибок касаются области видимости заметок на уровне заголовков для операций с метаданными/схемами, предотвращают неверную интерпретацию свойств Org внутри дословных блоков и улучшают надежность внешней синхронизации в Windows.
