Суммаризация (на русском)

The update primarily introduces a comprehensive server-side job engine for automating complex multi-step tasks, including model loading, inference, and conditional logic, with features like persistence and exclusive resource management. It also adds an ONNX Runtime classification backend with a new `/v1/classify` endpoint for text classification. Additionally, the release enhances CORS support, improves security for HTTP redirects and WebSocket API keys, and includes various fixes for backend management, model auto-loading, and audio processing. **Russian Translation:** Ключевым нововведением стал полноценный серверный движок заданий, позволяющий автоматизировать многошаговые задачи, такие как загрузка моделей, выполнение вывода и условная логика, с сохранением состояния и управлением эксклюзивным доступом к ресурсам. Также добавлена поддержка классификации текста через бэкенд ONNX Runtime, представленная новым эндпоинтом `/v1/classify`. Обновление включает расширенную поддержку CORS, улучшения безопасности HTTP-перенаправлений и ключей API WebSocket, а также различные исправления в управлении бэкендами, автоматической загрузке моделей и обработке аудио.
