This release introduces broad new language support, adding integrated language servers for GDScript (Godot Engine), Svelte, Ada/SPARK, and BSL (1C:Enterprise), with robust configuration options for new TCP-based servers. Significant refactoring of the language server architecture enhances modularity and simplifies future integrations. Additionally, the user interface and dashboard have undergone a comprehensive visual polish with updated typography and refined design elements, alongside various minor fixes and dependency updates. --- Этот выпуск значительно расширяет поддержку языков, добавляя интегрированные языковые серверы для GDScript (Godot Engine), Svelte, Ada/SPARK и BSL (1C:Enterprise), с гибкими возможностями настройки для новых серверов на базе TCP. Существенная переработка архитектуры языковых серверов повышает модульность и упрощает будущие интеграции. Кроме того, пользовательский интерфейс и панель управления получили всестороннее визуальное обновление с новой типографикой и улучшенными элементами дизайна, а также ряд мелких исправлений и обновлений зависимостей.
