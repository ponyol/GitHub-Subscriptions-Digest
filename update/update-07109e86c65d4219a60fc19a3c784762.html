Суммаризация (на русском)

Это обновление представляет собой новые основные модули: `(curry random)` для непрерывных распределений вероятностей, `(curry sets)` предлагающий мультимножества и логические множества, интегрированные с различными неклассическими логиками, а также `(curry logic)`, предоставляющий подключаемую структуру для шести неклассических логик с общим API базы знаний. Оно также включает обширную документацию по уникальным дизайнам систем акторов-объектов и модулей Curry. Кроме того, внесены критические исправления, касающиеся обработки строк UTF-8 и обеспечения соответствия R7RS для процедуры `command-line`, а модуль LDAP теперь необязателен по умолчанию.

Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com> - fix(r7rs): string-copy! handles variable-width UTF-8 correctly Previously string-copy! did a raw memmove of source bytes into the destination at the computed byte offset, which silently corrupted strings when source and destination character ranges had different UTF-8 byte widths (e.g. copying ASCII over multi-byte chars). Now mirrors the string-set! approach: if src_bytes == dst_bytes, memmove in-place; otherwise allocate a new pinned buffer, copy prefix + source slice + suffix, and redirect via String.ext. Also fixes a bounds-check bug where at_char >= char_count(to) caused utf8_char_offset to clamp both at_b and at_end_b to to->len, making at_end_b > to->len always false. Now validates at_char + char_count against the character count of to directly before calling utf8_char_offset.
