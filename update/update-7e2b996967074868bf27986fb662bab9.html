This set of updates significantly enhances the system's stability, model compatibility, and user experience. Key improvements include robust timeout handling and a configurable fast synchronization flag to prevent model failures, alongside improved error reporting for chat completions. The release process is streamlined with automated GitHub releases, integrated Sparkle release notes, and extensive `transformers` 5.x compatibility for a wider range of models like Kimi K2 Thinking and GPT-OSS. Additionally, network stability and Nix-based build reproducibility were greatly improved. --- Этот набор обновлений значительно повышает стабильность системы, совместимость моделей и удобство использования.
