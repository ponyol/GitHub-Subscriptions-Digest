Суммаризация (на русском)

Методы `.prompt()` и `.reply()` теперь поддерживают явный параметр `options=dict` для настройки модели. Хотя форма `**kwargs` по-прежнему работает для обратной совместимости, она больше не документируется, и смешивание обеих форм с пересекающимися ключами вызовет `TypeError`. Это обновление, применимое к различным методам `prompt` и `reply`, приводит их в соответствие с существующим шаблоном метода `.chain()`.

Исходный текст

- Add options= dict parameter to .prompt() and .reply() (#1432) Accepts model options as an explicit dict alongside the existing **kwargs form. The kwargs form continues to work unchanged for backwards compatibility but is no longer documented. Mixing the two forms with overlapping keys raises TypeError. Applies to Model.prompt, Conversation.prompt, Response.reply and their async equivalents. .chain() already used this pattern. Co-authored-by: Claude <noreply@anthropic.com>
