This release focuses on significant security enhancements, including hardening authentication posture with a default-deny redirect policy and fixing multiple transitive dependency vulnerabilities. It also brings improvements to the Compute service, ensuring more reliable Fly.io network naming and introducing new architecture documentation. Key updates further include UI refinements across the dashboard, such as a configurable job log retention policy, integration of Stripe payments, and backend support for project branching. --- **Russian Translation:** Этот выпуск сосредоточен на значительных улучшениях безопасности, включая ужесточение политики аутентификации с использованием принципа "запрещено по умолчанию" для перенаправлений и устранение множественных уязвимостей в зависимостях. Он также включает улучшения сервиса Compute, обеспечивая более надежное именование сетей Fly.io и представляя новую архитектурную документацию. Ключевые обновления далее включают доработки пользовательского интерфейса панели управления, такие как настраиваемая политика хранения логов заданий, интеграция платежей Stripe и поддержку ветвления проектов.

Fly's documented rule — "Network names can have letters, numbers, and dashes, but must start with a letter" — still rejects ~30% of generateAppKey() outputs because the charset `abcdefghijkmnpqrstuvwxyz23456789` plus a Fisher-Yates shuffle leaves the first character a digit roughly 3/8 of the time (e.g. `8mlfa9q2`).
