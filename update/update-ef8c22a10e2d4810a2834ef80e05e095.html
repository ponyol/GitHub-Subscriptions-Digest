Суммаризация (на русском)

**Summary:** This update introduces a list view toggle for notebooks and bulk context actions for sources and notes within chat. It significantly improves API error handling by consistently returning 404 for missing resources instead of 500, enhances search performance and functionality, and adds LaTeX math rendering to chat output. Key infrastructure upgrades include updating to Debian Trixie and Node 22.x, alongside making the API timeout configurable and persisting Ollama `num_ctx` settings. **Russian Translation:** Это обновление добавляет переключатель вида списка для блокнотов и массовые действия контекста для источников и заметок в чате. Значительно улучшена обработка ошибок API с последовательным возвратом 404 вместо 500 для отсутствующих ресурсов, оптимизирована производительность и функциональность поиска, а также добавлен рендеринг математики LaTeX в чате. Среди ключевых инфраструктурных обновлений — переход на Debian Trixie и Node 22.x, настройка таймаута API и сохранение параметра `num_ctx` для Ollama.
