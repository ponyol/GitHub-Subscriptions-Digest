The testing harness has undergone a major architectural shift to a distributed fleet model, featuring a control-plane managing jobs and multiple workers with a flexible driver registry, now capable of running all browser and HTTP probe families. Significant improvements include fixing systemic D5 dashboard errors by unifying its execution path with D6, and enabling on-demand triggering for HTTP probes directly from the control-plane. Developer experience is enhanced with a `showcase test` command that accurately reflects staging execution via the control-plane, and a hot-reload development mode for rapid iteration. --- **Russian translation:** Тестовый фреймворк претерпел значительное архитектурное изменение, перейдя на распределенную модель "флота" с управляющим узлом (control-plane), управляющим задачами, и несколькими рабочими узлами с гибким реестром драйверов, теперь способным запускать все семейства браузерных и HTTP-проб. Значительные улучшения включают исправление системных ошибок на дашборде D5 путем унификации его пути выполнения с D6, а также включение запуска HTTP-проб по требованию непосредственно с управляющего узла.
