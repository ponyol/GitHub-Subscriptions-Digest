Суммаризация (на русском)

This update introduces the Airweave Connect feature, an embeddable widget with a playground for live code generation and configuration, alongside new analytics and related infrastructure. It also adds a new SharePoint Online connector with ACL support and a browse tree, and enhances the GitHub connector to sync merged pull requests and review comments. The update further includes various bug fixes, architectural refactorings, and an upgrade to Python 3.13 and Poetry. --- Это обновление представляет функцию Airweave Connect, встраиваемый виджет с песочницей для генерации кода в реальном времени и настройки, а также новую аналитику и соответствующую инфраструктуру. Также добавлен новый коннектор SharePoint Online с поддержкой ACL и древовидным просмотром, и улучшен коннектор GitHub для синхронизации объединенных запросов на слияние и комментариев к ним. В обновление также вошли различные исправления ошибок, архитектурные рефакторинги и обновление до Python 3.13 и Poetry.
