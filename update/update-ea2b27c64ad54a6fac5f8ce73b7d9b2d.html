- [RyzenAI] WinML compatibility fix (#2026) - Reuse a single generator via RewindTo(0) in benchmark instead of creating multiple generators (#2002) Using multiple generators is not friendly for graph capture mode: 1. Each generator maps to its own captured graph. When the generator's lifecycle ends, there is no way to notify ORT to release the captured graph, so GPU memory is not freed until the ORT model session is released. 2. It also fails if the underlying EP does not support multiple captured graphs. This PR changes the benchmark to create a single generator and reuse it across prompt generation, warmup, and benchmark iterations by calling RewindTo(0) before each iteration.
