- fix: guard executor speedup division against zero elapsed time; correct UV install PATH (#569) * fix(execution): guard speedup division against zero elapsed time ParallelExecutor.execute() computes actual_speedup as sequential_time_estimate / total_time, where total_time is a wall-clock delta. For an empty plan — or any plan that finishes within the clock's resolution — total_time is exactly 0.0, raising ZeroDivisionError and crashing the entire run. This surfaced as a flaky failure of test_quick_execute_empty (~1 in 8 runs, depending on whether the clock ticked mid-call), but it is a real production defect: any fast execute() call can hit it. Guard the division and fall back to a 1.0x speedup when no measurable time elapsed. Adds a deterministic regression test that freezes the clock so elapsed time is 0.0 — it fails with ZeroDivisionError on the prior code and passes with the guard. * fix(install): use UV installer's real default PATH (~/.local/bin) After installing UV, the script exported ~/.cargo/bin — a legacy cargo-dist location. The current UV standalone installer installs to $XDG_BIN_HOME, or $HOME/.local/bin by default; ~/.cargo/bin is only used when explicitly opted in. So on a fresh machine the post-install `command -v uv` check failed and told the user to restart their terminal unnecessarily. Export the installer's actual default (${XDG_BIN_HOME:-$HOME/.local/bin}) so UV is found in the same session.
