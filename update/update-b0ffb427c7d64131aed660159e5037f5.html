Суммаризация (на русском)

This update introduces a foundational Playwright E2E testing suite for multi-step UI user flows, specifically targeting cross-component interactions against a mocked backend. It also significantly enhances the Helm chart's flexibility by adding support for arbitrary Kubernetes manifests (`extraObjects`) and improved pod template configurability (`podLabels`, `nodeSelector`). Furthermore, the UI now supports interactive chat widgets (MCP Apps) and improves readability by grouping tool calls, providing a richer and more dynamic user experience. --- Эта версия вводит базовый набор Playwright E2E тестов для многошаговых пользовательских сценариев UI, нацеленных на межкомпонентные взаимодействия с имитированным бэкэндом. Она также значительно повышает гибкость Helm чарта, добавляя поддержку произвольных манифестов Kubernetes (`extraObjects`) и улучшенную конфигурацию шаблонов подов (`podLabels`, `nodeSelector`). Кроме того, пользовательский интерфейс теперь поддерживает интерактивные виджеты чата (MCP Apps) и улучшает читаемость за счет группировки вызовов инструментов, обеспечивая более насыщенный и динамичный пользовательский опыт.
