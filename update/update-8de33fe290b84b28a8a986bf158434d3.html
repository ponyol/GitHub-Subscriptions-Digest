Это обновление добавляет бэкэнд хранения Milvus и позволяет пользователям определять шаблоны исключения (`exclude_patterns`) в стиле `.gitignore` для более детального контроля над майнингом файлов. Ключевые улучшения стабильности включают механизм самовосстановления для аренды записи MCP, предотвращающий застревание серверов в режиме только для чтения, и обработку стенограмм разговоров как изменяемых для обеспечения майнинга всего содержимого. Кроме того, были реализованы исправления для атомарных операций архивирования при восстановлении и для корректного применения ограничений режима только для чтения ко всем изменяющим инструментам.
