Суммаризация (на русском)

These updates for Faiss primarily focus on enhancing library robustness and security through extensive deserialization validation across various index types (e.g., HNSW, SVS, Quantizers, FastScan), preventing crashes and undefined behavior from malformed data. Additionally, several components were refactored for runtime SIMD dispatch to improve performance and build flexibility, alongside specific bug fixes and Python API updates. Кроме того, несколько компонентов были переработаны для динамической диспетчеризации SIMD для улучшения производительности и гибкости сборки, а также внесены конкретные исправления ошибок и обновления Python API.
