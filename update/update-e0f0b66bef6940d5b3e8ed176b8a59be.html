This release introduces significant enhancements to agent capabilities, including advanced workflow orchestration with parallel and pipeline execution, an experimental Agent Team feature for collaborative sub-agents, and a Plan Approval Gate for autonomous operations. User experience improvements span revamped web-shell panels, an interactive `/stats` dashboard, and improved context compression.
