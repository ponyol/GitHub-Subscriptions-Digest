Суммаризация (на русском)

This update introduces extensive support for experimental skills, including new CLI settings, hot reloading capabilities, and improved configuration documentation. It significantly enhances VS Code integration by correctly handling the `--acp` flag, improving cross-platform CLI execution, and adding Jupyter Notebook code selection. The release also includes numerous bug fixes across core functionalities, such as resolving issues with MCP server removal, OAuth authentication, logging initialization, and improving error message displays. Additionally, new features like custom sandbox environments, optional shell command timeouts, and customizable request headers have been added, alongside general performance improvements and documentation updates. --- Это обновление вводит обширную поддержку экспериментальных навыков, включая новые настройки CLI, возможности горячей перезагрузки и улучшенную документацию по конфигурации. Значительно улучшена интеграция с VS Code за счет корректной обработки флага `--acp`, повышения кроссплатформенной работы CLI и добавления функции выбора кода в Jupyter Notebook. Релиз также включает многочисленные исправления ошибок в основных функциях, таких как проблемы с удалением MCP-сервера, аутентификацией OAuth и инициализацией логирования, а также улучшение отображения сообщений об ошибках. Добавлены новые возможности, включая пользовательские среды песочницы, опциональные таймауты для команд оболочки и настраиваемые заголовки запросов, наряду с общими улучшениями производительности и обновлением документации.
