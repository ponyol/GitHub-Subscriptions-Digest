Суммаризация (на русском)

Это обновление в первую очередь добавляет поддержку Python 3.13 (и 3.14), включая обширную модернизацию кода для обеспечения совместимости с новыми версиями Python и NumPy 2.0. Тесты CI были расширены для охвата Python от 3.8 до 3.13, хотя некоторые закрепленные версии PaddlePaddle были отменены из-за ошибки вывода на ЦП. Кроме того, в Dockerfile шлюза HPS была добавлена критическая зависимость (`libglib2.0-0`) для исправления ошибки импорта.
