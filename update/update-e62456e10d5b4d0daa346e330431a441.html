Суммаризация (на русском)

Это обновление сосредоточено на значительных улучшениях управления сессиями и безопасности. Оно представляет улучшенное усечение сессий для сокращения количества токенов путем корректной обработки данных `tool_use` и метаданных `toolUseResult`, а также обнуляет метаданные использования для предотвращения клиентских ошибок. Критические исправления безопасности значительно усиливают обнаружение команды `rm` в сложных средах командной оболочки, включая конвейеры, фоновые процессы и вложенные подоболочки. Кроме того, добавлен новый инструмент командной строки `fix-session` и API для восстановления поврежденных цепочек сессий.
