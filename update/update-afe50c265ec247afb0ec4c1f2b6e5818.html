Суммаризация (на русском)

This release significantly refines the WebUI and mobile user experience, introducing a redesigned welcome screen, improved handling of modals and canvas elements, and optimized layouts for various devices. It also brings robust enhancements to LLM and tool interactions, including normalized tool schemas, support for parallel and plain-text responses, and more resilient API request fallbacks. Furthermore, the update features comprehensive documentation for new installation paths, lifted system limits for backup and Docker operations, and advanced skill management capabilities. --- Этот выпуск значительно улучшает пользовательский интерфейс WebUI и мобильных устройств, представляя обновленный стартовый экран, улучшенную обработку модальных окон и элементов холста, а также оптимизированные макеты для различных устройств. Он также содержит существенные усовершенствования взаимодействия с LLM и инструментами, включая нормализованные схемы инструментов, поддержку параллельных и простых текстовых ответов, а также более устойчивые механизмы обработки ошибок API-запросов. Кроме того, обновление включает обширную документацию по новым путям установки, снятие системных ограничений для операций резервного копирования и Docker, а также расширенные возможности управления навыками.
