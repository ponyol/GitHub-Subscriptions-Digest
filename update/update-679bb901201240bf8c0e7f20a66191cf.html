Суммаризация (на русском)

Это обновление добавляет поддержку весовых паттернов AMD Quark 0.11 для выходного слоя ChatGLM3, устраняя сбои при загрузке модели. Оно также исправляет ночную сборку Python, добавляет конвейер CI для тестирования моделей с WebGPU EP и обновляет примеры для использования новых API после выпуска ONNX Runtime GenAI v0.12.0.

Исходный текст

- Add missing Quark 0.11 weight patterns for ChatGLM3 output layer (#1983) AMD Quark 0.11 uses `weight_zero_point` and `weight_scale` naming convention instead of `qzeros` and `scales`. Support for this was added for `lm_head.*` patterns but the equivalent `transformer.output_layer.*` patterns used by ChatGLM3 were not included, causing ChatGLM3 model loading to fail Added the two missing patterns: - `transformer.output_layer.weight_zero_point` - `transformer.output_layer.weight_scale` Co-authored-by: Yu Yan <yu.yan@amd.com> - Fix Python nightly build (#1981) ### Description This PR fixes the Python nightly build of ONNX Runtime GenAI. ### Motivation and Context A [previous PR](https://github.com/microsoft/onnxruntime-genai/pull/1939) introduced changes to the CIs, and those changes were not brought over to the nightly pipeline. - Add CI pipeline for WebGPU EP model testing (#1956) - Update examples after 0.12.0 release (#1980) ### Description This PR updates all of the examples after the v0.12.0 release of ONNX Runtime GenAI to use new APIs. ### Motivation and Context Some of the new APIs required an official release to be published before the examples could use them (as mentioned [here](https://github.com/microsoft/onnxruntime-genai/pull/1939#discussion_r2744513301)).
