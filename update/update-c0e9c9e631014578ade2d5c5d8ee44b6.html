Суммаризация (на русском)

В LangGraph добавлена опция отключения (`emit_raw_events`), чтобы предотвратить раздувание полезной нагрузки за счет подавления повторной отправки необработанных данных событий, значительно уменьшая их размер. ADK-middleware теперь преобразует `oneOf` в `anyOf` в схемах для корректной интерпретации параметров инструментов моделями Google GenAI, а идентификаторы сообщений агента Mastra очищаются для совместимости с Responses API OpenAI в многопользовательских чатах. Кроме того, AWS Strands теперь корректно сверяет результаты выполнения клиентских инструментов с менеджером сессий, а `RequestStateSessionService` в ADK-middleware правильно делегирует вызовы `flush()` для предотвращения потери данных, повышая точность и надежность состояния сессии.
