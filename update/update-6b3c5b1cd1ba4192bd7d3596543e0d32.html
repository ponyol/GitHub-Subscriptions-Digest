Это обновление включает два основных изменения. Во-первых, улучшена обработка заголовков аутентификации для операций push: теперь заголовки копируются только для последующих запросов того же источника и пропускаются для перенаправлений на другие домены, таких как предварительно подписанные URL-адреса S3. Во-вторых, зависимость `pnpm/action-setup` обновлена с версии 5.0.0 до 6.0.8.
