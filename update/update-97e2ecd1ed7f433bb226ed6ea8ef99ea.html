Суммаризация (на русском)

Недавние обновления сосредоточены на значительных улучшениях безопасности и существенной переработке логики аутентификации. Ключевые улучшения безопасности включают TOCTOU-устойчивое хранение учетных данных, принудительное ограничение внешних привязок для HTTP/SSE, привязку GitHub Actions к полным SHA-хешам коммитов для защиты цепочки поставок и скрытие конфиденциальных данных файлов cookie из отладочных логов. Кроме того, система аутентификации была унифицирована с помощью единой функции `check_auth()` для последовательной проверки учетных данных, а парсинг файлов cookie теперь поддерживает формат Netscape/Mozilla, повышая совместимость.
