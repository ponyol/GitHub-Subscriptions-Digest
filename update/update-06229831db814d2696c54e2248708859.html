Суммаризация (на русском)

This update introduces the AG-UI .NET SDK, significantly expanding platform compatibility. LangGraph gains structured interrupt/resume capabilities and stable message IDs for consistent UI interactions. A2UI integration is enhanced with auto-injection, simplified configuration, and fixes for dynamic run completion. Additionally, extended features like state sync and multimodal support are added for Agno, and the Strands integration receives various fixes for tool call handling and Human-in-the-Loop context. --- Это обновление представляет SDK AG-UI для .NET, значительно расширяя совместимость с платформами. LangGraph получает возможности структурированного прерывания/возобновления и стабильные идентификаторы сообщений для единообразного отображения в UI. Интеграция A2UI улучшена за счет автоинъекции, упрощенной конфигурации и исправлений для динамического завершения выполнения. Кроме того, для Agno добавлены расширенные функции, такие как синхронизация состояния и поддержка мультимодальности, а интеграция Strands получила различные исправления для обработки вызовов инструментов и контекста Human-in-the-Loop.
