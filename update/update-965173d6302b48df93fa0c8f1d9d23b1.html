Суммаризация (на русском)

Основное внимание уделено существенной доработке интеграции с SharePoint, внедрению аутентификации на основе учетных данных клиента на уровне приложения и реализации фильтрации поиска по спискам контроля доступа (ACL) для обеспечения безопасного доступа к контенту с учетом разрешений. Это включает рефакторинг источников SharePoint на отдельные версии для OAuth и только для приложений, улучшение загрузки файлов и расширение поддержки групп Entra. Кроме того, система теперь поддерживает использование собственных учетных данных (BYOC) для интеграций OAuth и значительно упростила управление схемой базы данных, объединив 144 миграции Alembic в единую базовую версию.
