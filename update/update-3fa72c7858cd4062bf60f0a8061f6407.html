# awesome-selfhosted 1.0.0 Visit the improved version of the Awesome-Selfhosted list at **https://awesome-selfhosted.net/** _Awesome-Selfhosted is a list of [Free](https://en.wikipedia.org/wiki/Free_software) Software [network services](https://en.wikipedia.org/wiki/Network_service) and [web applications](https://en.wikipedia.org/wiki/Web_application) which can be hosted on your own server(s). Self-hosting is the practice of hosting and managing applications on your own server(s) instead of consuming from [SaaSS](https://www.gnu.org/philosophy/who-does-that-server-really-serve.html) providers._ The website at [awesome-selfhosted.net](https://awesome-selfhosted.net/) is now the recommended way to browse the list. It features improved search, categorization, layout, more detailed information, and should generally provide a better browsing experience. The old, familiar [markdown version](https://github.com/awesome-selfhosted/awesome-selfhosted) of the list will keep receiving automated updates for the foreseeable future. You are encouraged to use, modify, improve and redistribute the list under the terms [of the Creative Commons Attribution-ShareAlike 3.0 license](https://creativecommons.org/licenses/by-sa/3.0/). Raw data, tools used to build markdown and HTML versions, issues and pull requests are now available under the [awesome-selfhosted-data repository](https://github.com/awesome-selfhosted/awesome-selfhosted-data). You can find information on how to contribute to the project [here](https://github.com/awesome-selfhosted/awesome-selfhosted-data/blob/master/CONTRIBUTING.md). Thanks to more than [1200 contributors](https://github.com/awesome-selfhosted/awesome-selfhosted/graphs/contributors) for keeping this project going since 2015.
