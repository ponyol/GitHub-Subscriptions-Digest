Суммаризация (на русском)

Version 0.6.2 is a security and maintenance release that includes critical dependency CVE updates, particularly for Litellm, GitPython, and urllib3. It resolves significant bugs such as a `mental_models.subtype` migration issue and transient OID errors in embedding dimension handling, alongside fixes for CLI and Control Plane timestamp inputs. The update also features integration enhancements for Claude Code (configurable request timeout), Agent SDK, and Paperclip, as well as general documentation improvements and CI stability fixes. --- Версия 0.6.2 представляет собой выпуск безопасности и обслуживания, включающий критические обновления CVE для зависимостей, в частности Litellm, GitPython и urllib3. Он устраняет значительные ошибки, такие как проблема миграции `mental_models.subtype` и временные ошибки OID при обработке размерности встраивания, а также исправления для ввода отметок времени в CLI и Control Plane. Обновление также содержит улучшения интеграции для Claude Code (настраиваемый таймаут запроса), Agent SDK и Paperclip, а также общие улучшения документации и исправления стабильности CI.
