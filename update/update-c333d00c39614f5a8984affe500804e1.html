Суммаризация (на русском)

Это обновление исправляет проблему, при которой закрытые чаты некорректно открывались после перезапуска сервера, теперь они остаются закрытыми, а новые сессии чата инициализируются правильно. Введены команды для быстрого перехода к чатам, требующим внимания пользователя, и улучшен Doom Emacs путем раскрашивания вкладок рабочих пространств в зависимости от статуса сессии ECA. Кроме того, широкие таблицы Markdown теперь можно открывать в специальном буфере с горизонтальной прокруткой, а области чата вне поля ввода стали доступны только для чтения, чтобы предотвратить случайные изменения.
