Суммаризация (на русском)

Основное обновление добавляет поддержку хранения данных OpenCode в режиме только для чтения через SQLite, позволяя пользователям просматривать историю разговоров из `opencode.db` и объединяя результаты как из SQLite, так и из JSON источников. Эта интеграция включает многочисленные исправления для валидации, производительности, логики поиска и пользовательского интерфейса (отображение значков типа хранилища), а также добавление отслеживания изменений в файле `opencode.db`. Кроме того, были реализованы важные улучшения безопасности для предотвращения уязвимостей, связанных с обходом символических ссылок при работе с директориями, наряду с другими общими исправлениями ошибок и выпуском версии v1.7.0.
