Суммаризация (на русском)

This update introduces significant enhancements across the ADK framework, including new features like sampling callback support for MCP sessions, improved ADK-A2A integration with a new extension, and a CLI command for agent instruction optimization. It also adds pluggable authentication, advanced telemetry for agent versions and token usage, and performance improvements for session loading by filtering events during retrieval. Various bug fixes address issues in BigQuery, LiteLLM integrations, multi-agent simulation, and general stability. --- Это обновление вносит значительные улучшения во фреймворк ADK, включая новые функции, такие как поддержка обратных вызовов для сэмплирования в сессиях MCP, улучшенную интеграцию ADK-A2A с новым расширением и команду CLI для оптимизации инструкций агента. Также добавлена подключаемая аутентификация, расширенная телеметрия для версий агентов и использования токенов, а также улучшения производительности при загрузке сессий за счет фильтрации событий. Различные исправления ошибок касаются BigQuery, интеграций LiteLLM, многоагентного моделирования и общей стабильности.

Or, if no issue exists, describe the change: Problem: The agent's specific version wasn't being tracked in our telemetry data, limiting our ability to trace issues to specific agent versions. This change introduces the gen_ai.agent.version attribute to span context, defaulting to an empty string if omitted for backwards compatibility. Solution: We want to capture the specific version of an agent during execution by adding an optional version field to the base agent configurations (BaseAgent, BaseAgentConfig). Defaulting the value to an empty string ensures backwards compatibility without breaking existing agent implementations that do not specify a version.
