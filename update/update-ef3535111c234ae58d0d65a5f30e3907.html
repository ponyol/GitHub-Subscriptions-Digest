Суммаризация (на русском)

The main development effort centered on introducing and extensively refining an S3-compatible storage gateway, allowing external S3 clients like AWS CLI and SDKs to interact with InsForge storage using the S3 protocol. This involved implementing robust SigV4 authentication, comprehensive S3 access key management, and supporting all major S3 operations (bucket, object, multipart), along with numerous fixes for protocol compliance and streaming integrity. Other notable updates include new features for database backup and migration, enhanced email documentation for custom SMTP, and general documentation improvements. --- Основные усилия по разработке были сосредоточены на внедрении и значительном усовершенствовании S3-совместимого шлюза хранения данных, позволяющего внешним S3-клиентам, таким как AWS CLI и SDK, взаимодействовать с хранилищем InsForge по протоколу S3. Это включало реализацию надежной аутентификации SigV4, комплексное управление ключами доступа S3 и поддержку всех основных операций S3 (корзины, объекты, многокомпонентная загрузка), а также многочисленные исправления для обеспечения соответствия протоколу и целостности потоковой передачи. Среди других значительных обновлений — новые функции для резервного копирования и миграции баз данных, расширенная документация по электронной почте для пользовательских SMTP-серверов и общие улучшения документации.
