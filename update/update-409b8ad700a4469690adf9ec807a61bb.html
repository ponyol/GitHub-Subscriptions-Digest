This update introduces a major redesign of the compatibility leaderboard, featuring latest-run precedence, detailed metrics, contributor attribution, and new community evaluation guides with M4 Max model contributions. Performance is significantly enhanced through a new benchmarking CLI for per-model tuning, improved model memory management based on GPU working sets, and proactive model warm-up. Key new features include native web search with pluggable providers, full-text conversation search, and an in-chat `filesystem` menu. The release also includes numerous fixes for agent tool policies, remote provider stability, and overall app reliability, particularly addressing Metal GPU concurrency crashes and main-thread hangs. --- В этом обновлении значительно переработана таблица лидеров совместимости, теперь она включает приоритет последнего запуска, детализированные метрики, атрибуцию участников и новые руководства по оценке сообщества с вкладами моделей M4 Max. Ключевые новые функции включают встроенный веб-поиск с подключаемыми провайдерами, полнотекстовый поиск по разговорам и меню `filesystem` в чате.
