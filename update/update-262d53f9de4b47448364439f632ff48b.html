Суммаризация (на русском)

This release introduces a new HTML backend that uses a headless browser for rendering, preserving document structure and supporting HTML elements and styling. It also brings significant fixes to OMML-to-LaTeX conversion, addressing issues with fractions, math operators, functions, and multi-equation paragraphs. Additionally, critical stability improvements for the PDFium backend prevent crashes, and the VLM engine now allows user parameters to override defaults, while the CLI avoids unnecessary image generation. **Russian Translation:** Этот выпуск представляет новый HTML-бэкенд, использующий безголовый браузер для рендеринга, сохраняющий структуру документа и поддерживающий HTML-элементы и стилизацию. Он также включает значительные исправления в преобразовании OMML в LaTeX, устраняя проблемы с дробями, математическими операторами, функциями и абзацами с несколькими уравнениями. Кроме того, критические улучшения стабильности бэкенда PDFium предотвращают сбои, а движок VLM теперь позволяет пользовательским параметрам переопределять значения по умолчанию, в то время как CLI избегает ненужной генерации изображений.
