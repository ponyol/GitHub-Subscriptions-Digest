Суммаризация (на русском)

Функция `gptel--display-tool-results` в `gptel.el` была обновлена для корректного учета буферно-локальных настроек. Теперь она проверяет переменную `gptel-include-tool-results` в буфере запроса, а не в текущем буфере, при отображении результатов вызовов инструментов. Это гарантирует, что предполагаемое буферно-локальное значение для включения результатов инструментов всегда используется.

Исходный текст

- gptel: Check include-tool-results in request buffer * gptel.el (gptel--display-tool-results): When adding tool call results to a buffer, check the value of `gptel-include-tool-results' in the request buffer, and not the buffer current at this time. This respects the buffer-local value of `gptel-include-tool-results'.
