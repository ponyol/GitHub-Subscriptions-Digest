Суммаризация (на русском)

API Bedrock был значительно расширен для поддержки различных мультимедийных входов/выходов, включая генерацию изображений, видеомодели и эмбеддинги Cohere, с улучшенной асинхронной обработкой и различными кодировками URI данных. Важные обновления также включают `ResultCursor` для потоковой передачи больших наборов результатов запросов с целью повышения эффективности использования памяти, а также надежное принудительное применение первичных ключей для обеспечения уникальности и целостности данных. Кроме того, был представлен новый `FastAPIRouter` для облегчения предоставления операций с данными в качестве конечных точек API.
