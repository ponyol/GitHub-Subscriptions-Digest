- fix(pytest): fail if no disks or kernels are found Currently the absence of CI artifacts leads to the CI run passing after skipping all tests. This change ensures that the disks and kernels fixtures are not empty. For the disks, it will fail if the disk is missing (it would have crashed before as well, but this is more clar). For the kernel, it will inject a None so that the downstream code can gracefully fail. These checks are done inside the fixtures to avoid failing tests that don't rely on the artifacts.
