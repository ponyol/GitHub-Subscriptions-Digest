Эта версия добавляет поддержку для бэкенда Kilo AI и улучшает функцию `implement-todo` с заголовками Org TODO и подсказками намерений действия. Она включает значительные улучшения в интеграции с терминалом, особенно с Ghostel, путем исправления обработки буферов при выходе, адаптации к новому API и включения режима полной перерисовки для лучшего отображения TUI. Кроме того, релиз рефакторит логику, специфичную для терминалов, и позволяет использовать файлы вне Git в качестве кандидатов для контекста репозитория, а также содержит мелкие исправления ошибок.
