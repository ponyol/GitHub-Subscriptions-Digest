Суммаризация (на русском)

Добавлена поддержка для определения минимального и максимального количества контейнеров (`min_containers`, `max_containers`) для функций. Пользователи могут указывать эти лимиты для каждой функции с помощью декоратора, например, `@function(min_containers=3, max_containers=5)`. Такая настройка применяется для каждой функции отдельно, а не на уровне всего приложения, так как разные функции могут требовать различных параметров масштабирования.

Исходный текст

- Added support for min and max containers (#481) Support for min max containers ``` @function(min_containers=3, max_containers=5) def foo(): ... ``` Users can set this per function. Didn't set this at the app level because really it doesn't make sense for every function to have the same min and max
