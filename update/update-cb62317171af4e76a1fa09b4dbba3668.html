Суммаризация (на русском)

Это обновление значительно улучшает поддержку медиа OpenRouter в SDK для Python, TypeScript и Go, обеспечивая нативную маршрутизацию аудио, видео и изображений. Оно устраняет ранее существовавшие проблемы с моделями только для преобразования текста в речь и только для изображений, корректно маршрутизируя аудио и корректируя параметры модальности изображений. Кроме того, загрузка видео теперь корректно работает с аутентификацией, а обновление включает расширенное тестовое покрытие и исправление ошибки парсинга ответов с изображениями в TypeScript.
