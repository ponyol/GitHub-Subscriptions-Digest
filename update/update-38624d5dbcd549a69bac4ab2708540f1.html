Суммаризация (на русском)

This update for Milvus focuses on boosting performance and stability through an Arrow-based function chain for search post-processing, SIMD optimizations, PK compressed storage, and lazy system indexing, alongside introducing new features like function field backfill and enhanced language analysis. Extensive testing improvements include refactored RBAC, new chaos and query `ORDER BY` E2E tests, and fixes for numerous critical bugs in snapshot restore and segment processing, ensuring greater system reliability. --- **Russian translation:** Это обновление для Milvus направлено на повышение производительности и стабильности за счет использования конвейера на основе Arrow для постобработки результатов поиска, SIMD-оптимизаций, сжатого хранения первичных ключей (PK) и ленивой индексации системных данных, а также внедряет новые функции, такие как заполнение функциональных полей и улучшенный анализ для арабского/тайского языков. Масштабные улучшения тестирования включают переработанные тесты RBAC, новые E2E-тесты хаоса и запросов с `ORDER BY`, а также исправления множества критических ошибок в восстановлении снимков и обработке сегментов, что обеспечивает более высокую надежность системы.
