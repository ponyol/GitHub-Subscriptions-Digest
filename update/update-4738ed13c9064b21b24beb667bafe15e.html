Суммаризация (на русском)

This release brings a major overhaul of AI Spend calculations, now model-aware and token-native with a dedicated UI and APIs, alongside the ability to resume interrupted evaluation runs. Significant updates include comprehensive support for OpenAI Responses API (streaming, tool-calling), an upgrade to Java 25 LTS, and performance optimizations for listing large datasets of traces, spans, and dashboards. UI/UX improvements target prompt management, optimization empty states, and collapsible JSON in trace views, while developers also benefit from enhanced SDK error reporting and extensive E2E testing and debugging tools. --- **Russian translation:** Этот релиз представляет собой значительную переработку расчетов затрат на AI, теперь учитывающую модели и основанную на токенах, с выделенным пользовательским интерфейсом и API, а также возможность возобновлять прерванные запуски оценок. Важные обновления включают комплексную поддержку OpenAI Responses API (потоковая передача, вызовы инструментов), обновление до Java 25 LTS и оптимизации производительности для отображения больших наборов данных трассировок, диапазонов и дашбордов. Улучшения UI/UX затронули управление промптами, пустые состояния оптимизаций и сворачиваемые JSON-блоки в представлениях трассировок, а разработчики также получают преимущества от улучшенной отчетности об ошибках SDK и обширных инструментов для E2E-тестирования и отладки.
