Суммаризация (на русском)

Этот выпуск значительно расширяет возможности распределенных вычислений в фреймворке MAX, представляя новую инфраструктуру шардирования и распределенную диспетчеризацию для различных тензорных операций. Он также включает значительные улучшения производительности и рефакторинг для GPU-ядер, в том числе прирост производительности на 13% при предзаполнении MHA на AMD MI355X, а также оптимизации для FP8-квантования и операций TopK. Ключевые дополнения к стандартной библиотеке Mojo включают реализации `IterableOwned` и поддержку пользовательской функции `print()` для GPU-ядер Apple Metal. Наконец, новые функции MAX, такие как пакетная обработка в реальном времени (включена по умолчанию) и протокол `ToolParser`, улучшают общую функциональность API и производительность для онлайн-нагрузок.
