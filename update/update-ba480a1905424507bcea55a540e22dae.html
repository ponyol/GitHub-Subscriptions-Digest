This release introduces comprehensive support for the XRPL (XRP Ledger) exact scheme, including its TypeScript implementation, documentation, and facilitator integration. Significant improvements were made to Sign-In With X (SIWX), adding structured error handling across Go, Python, and TypeScript, alongside enhanced domain validation. Key fixes address EVM account wrapping, Go deposit balance issues, and Python/Flask error handling for unexpected settlement outcomes, complemented by hardened channel storage and various documentation updates. --- **Russian Translation:** Этот выпуск представляет всестороннюю поддержку точной схемы XRPL (XRP Ledger), включая ее реализацию на TypeScript, документацию и интеграцию с фасилитаторами. Значительные улучшения были внесены в Sign-In With X (SIWX), добавив структурированную обработку ошибок для Go, Python и TypeScript, а также улучшенную проверку доменов.
