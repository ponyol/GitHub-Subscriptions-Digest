Это обновление в первую очередь добавляет Novita AI в качестве нового провайдера LLM с API, совместимым с OpenAI. Оно значительно расширяет интеграцию с Novita, добавляя поддержку потоковой передачи, возможности многомодельной диспетчеризации для различных моделей (например, Kimi, DeepSeek) и исправление ошибок доступа к атрибутам. Кроме того, обновление включает общие исправления API для сохранения ложных значений в запросах на обновление сеансов и устранения сбоя при усечении состояния сеанса.
