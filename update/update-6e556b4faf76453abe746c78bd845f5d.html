- fix: remove unused checkpoint conversion script with unsafe torch.load (CWE-502) The nnscaler checkpoint conversion script used torch.load() without weights_only=True, allowing arbitrary code execution via malicious .pt files on PyTorch < 2.6. The script is not referenced anywhere in the codebase and is not needed by end users, so removing it entirely eliminates the vulnerability. Reported-by: Offgrid Security (https://www.offgridsec.com) - docs: minor wording fixes in contributing and VibeVoice guides - fix: correct speech_tok_compress_ratio default value in VibeVoiceASRProcessor The default value was set to 320, which is 10x smaller than the correct value of 3200. The compress ratio is the product of encoder ratios [8,5,5,4,2,2] = 3200, matching the value used consistently in vibevoice_processor.py, vibevoice_streaming_processor.py, vllm_plugin/model.py, and the checkpoint conversion script. This mismatch would cause incorrect vae_tok_len computation (10x too many speech tokens) whenever VibeVoiceASRProcessor is instantiated directly without loading from a pretrained config file. The from_pretrained() path already defaulted to 3200 correctly.
