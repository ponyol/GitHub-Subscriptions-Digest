This update brings substantial refactoring to the control plane, splitting core services and handlers into more focused modules for better maintainability. It introduces new features such as the `/agentfield` slash command, multi-provider media generation, and significant improvements to the Go SDK's tool calling. Key fixes address an SSRF vulnerability, resolve agents getting stuck in 'starting' status, and include important dependency updates, notably a security patch for `pytest`. --- Это обновление включает существенный рефакторинг в контрольной панели, разделив основные службы и обработчики на более сфокусированные модули для улучшения удобства сопровождения. Введены новые функции, такие как слэш-команда `/agentfield`, мультипровайдерная генерация медиа (видео, аудио, изображения) и значительные улучшения вызова инструментов в Go SDK.
