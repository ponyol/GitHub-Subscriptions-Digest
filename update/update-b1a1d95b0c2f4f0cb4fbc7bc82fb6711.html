This release delivers extensive documentation updates, including a reorganized `mcp101` guide, improved accuracy, and enhanced readability for AI agents. Key CLI improvements include a new `screenshot` command for visual feedback, a refactored Node.js OAuth client, and significant enhancements to `client` commands for better user experience and agent integration. Additionally, LLM model IDs were updated to their latest versions, and various TypeScript API fixes were implemented across the platform. **Russian Translation:** Этот выпуск содержит обширные обновления документации, включая реорганизованное руководство `mcp101`, улучшенную точность и повышенную читаемость для агентов ИИ. Ключевые улучшения CLI включают новую команду `screenshot` для визуальной обратной связи, переработанный клиент OAuth для Node.js и значительные доработки команд `client` для улучшения пользовательского опыта и интеграции с агентами. Кроме того, идентификаторы моделей LLM были обновлены до последних версий, и реализованы различные исправления API TypeScript по всей платформе.
