Суммаризация (на русском)

Этот релиз представляет новые функции API для управления HTTP-заголовками, файлами cookie и параметром `keepAlive` для браузерных сессий. Обновление значительно повышает стабильность, улучшает обработку ошибок и надёжность кроссплатформенной сборки, а также расширяет интеграции, добавляя поддержку провайдера Bedrock AI, публикацию пакетов Java/Kotlin и обновлённый режим CUA для моделей Claude Opus/Sonnet 4.6. Важным улучшением производительности является внедрение отключаемого серверного кэширования для вызовов API `act()`, `extract()` и `observe()`.
