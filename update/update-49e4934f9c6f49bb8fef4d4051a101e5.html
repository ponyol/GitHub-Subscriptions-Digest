Суммаризация (на русском)

This release features a comprehensive overhaul of the validation system, leveraging `Annotated` for clearer constraints, alongside significant performance optimizations for both validation and property tracking via new `@value` types. Key infrastructure changes include enhanced deprecation handling, consolidation of templates, and moving Flet client distribution to GitHub Releases. Additionally, new UI features like customizable scrollbars and improved auto-update logic have been added. --- Этот выпуск включает комплексную переработку системы валидации, использующую `Annotated` для более четких ограничений, наряду со значительными оптимизациями производительности как для валидации, так и для отслеживания свойств с помощью новых типов `@value`. Ключевые инфраструктурные изменения включают улучшенную обработку устаревших функций, консолидацию шаблонов и перенос дистрибуции клиента Flet в GitHub Releases. Кроме того, добавлены новые функции пользовательского интерфейса, такие как настраиваемые полосы прокрутки и улучшенная логика автоматического обновления.
