This PR fixes WebDAV sync behavior for unsupported file types ([#13795](https://github.com/infiniflow/ragflow/issues/13795)). Previously, the WebDAV connector selected files primarily by modified time (and size threshold) and could still pass unsupported extensions into the download/document-generation path. This caused unnecessary processing and inconsistent behavior compared with connectors that validate file type earlier. This change adds extension validation in two places: 1. **Early filter during recursive listing** to skip unsupported files before they enter the download flow. 2. **Defensive filter before download/document creation** to prevent unsupported files from being processed if any listing edge case slips through.
