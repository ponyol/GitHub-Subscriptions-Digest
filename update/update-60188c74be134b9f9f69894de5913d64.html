Суммаризация (на русском)

This gptel update primarily integrates OpenAI's Responses API, introducing a new backend and enabling its use for OpenAI and GitHub Copilot models, along with adding many new LLM models. Security is enhanced by passing API keys to Curl via stdin, and several default behaviors are adjusted for improved multi-turn conversations and media tracking. The update also includes UI improvements for rewrite status and tool call display, plus bug fixes. --- Это обновление gptel в основном интегрирует Responses API от OpenAI, представляя новый бэкенд и обеспечивая его использование для моделей OpenAI и GitHub Copilot, а также добавляя множество новых моделей LLM. Безопасность улучшена за счет передачи ключей API в Curl через стандартный ввод, и скорректировано несколько поведений по умолчанию для улучшения многоэтапных бесед и отслеживания медиа. Обновление также включает улучшения пользовательского интерфейса для статуса переписывания и отображения вызовов инструментов, а также исправления ошибок.
