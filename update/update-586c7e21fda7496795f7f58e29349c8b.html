- feat: add 'let' for immutable variable bindings Immutable bindings declared with (let x 42) cannot be reassigned. The compiler tracks immutability in the scope tracker and rejects assignment (=, +=, -=, etc.) at compile time. Binding immutability only — value mutation (e.g. .push on a let-bound array) is allowed.
