Суммаризация (на русском)

This update consolidates CopilotKit packages, fully integrates the Langroid framework, and adds extensive support for the Claude Agent SDK. It also introduces agent capabilities discovery, allowing agents to dynamically declare their features. Further improvements include critical fixes for LangGraph's Bedrock Converse API compatibility, Python SDK alignments, and various ADK middleware enhancements. --- Это обновление включает консолидацию пакетов CopilotKit, полную интеграцию фреймворка Langroid и расширенную поддержку для Claude Agent SDK. Также реализован механизм обнаружения возможностей агентов, позволяющий им динамически объявлять свои функции. Среди прочих улучшений — критические исправления совместимости LangGraph с Bedrock Converse API, приведение в соответствие Python SDK и ряд доработок промежуточного ПО ADK.
