Суммаризация (на русском)

The latest updates introduce comprehensive history tracking with UI diff views for both mental models and observations, allowing users to monitor changes over time. Major enhancements were made to the OpenClaw integration, alongside a new Pydantic AI integration, and core platform features like per-request file parser selection, a webhook system for `retain.completed` events, and configurable Gemini/Vertex AI safety settings. Performance for memory operations has been significantly improved, complemented by new features such as retaining timeless content and an advanced entity labeling system. --- **Russian translation:** Последние обновления включают всестороннее отслеживание истории с просмотром различий в пользовательском интерфейсе как для ментальных моделей, так и для наблюдений, что позволяет пользователям отслеживать изменения с течением времени. Были значительно улучшены интеграция OpenClaw, добавлена новая интеграция с Pydantic AI, а также ключевые функции платформы, такие как выбор парсера файлов для каждого запроса, система веб-хуков для событий `retain.completed` и настраиваемые параметры безопасности Gemini/Vertex AI. Производительность операций с памятью была значительно повышена, что дополняется новыми возможностями, такими как сохранение контента без привязки ко времени и расширенная система маркировки сущностей.
