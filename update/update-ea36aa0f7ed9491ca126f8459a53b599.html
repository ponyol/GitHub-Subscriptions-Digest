Суммаризация (на русском)

This release introduces significant enhancements to the Docling service, including the addition of confidence scores to API responses and an asynchronous client facade for improved client-side interactions. Key bug fixes address issues in parsing Asciidoc tables, handling rich tables in DOCX, correcting HTML list rendering, and ensuring proper OCR language model selection. Furthermore, the update brings vLLM support, new CLI capabilities for remote conversions, and comprehensive documentation for the API server. --- Эта версия включает значительные улучшения в сервис Docling, в том числе добавление оценок достоверности в ответы API и асинхронный клиентский фасад для улучшенного взаимодействия на стороне клиента. Ключевые исправления ошибок затрагивают проблемы парсинга таблиц Asciidoc, обработки форматированных таблиц в DOCX, корректировки рендеринга HTML-списков и обеспечения правильного выбора языковой модели OCR. Кроме того, обновление добавляет поддержку vLLM, новые возможности CLI для удаленных преобразований и всеобъемлющую документацию для API-сервера.
