Суммаризация (на русском)

This release features extensive improvements in model quantization (oQ) and memory management, enhancing stability under load and expanding support for models like Laguna S-2.1, Baidu Unlimited-OCR, and Nemotron-H with speculative decoding. It also includes critical performance fixes, notably for M5 GPUs and speculative prefill, along with more robust API tool call handling. Additionally, the update delivers numerous UI and administrative enhancements, especially for the macOS application, offering better logging, chat features, and external benchmark support. --- **Russian Translation:** Этот выпуск включает обширные улучшения в квантовании моделей (oQ) и управлении памятью, повышая стабильность под нагрузкой и расширяя поддержку новых моделей, таких как Laguna S-2.1, Baidu Unlimited-OCR, а также Nemotron-H со спекулятивным декодированием. Он также содержит критические исправления производительности, в частности для графических процессоров M5 и спекулятивного префикса, наряду с более надёжной обработкой вызовов API-инструментов. Кроме того, обновление приносит множество улучшений пользовательского интерфейса и администрирования, особенно для приложения macOS, предлагая улучшенное ведение журнала, функции чата и поддержку внешних бенчмарков.
