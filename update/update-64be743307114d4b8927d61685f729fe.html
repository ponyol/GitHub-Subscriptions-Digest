Суммаризация (на русском)

Это обновление представляет собой полную реализацию OAuth 2.1, улучшающую безопасность за счет полноценной реализации middleware для серверов авторизации и ресурсов, включая принудительное применение областей видимости на уровне инструментов, обработку JWT и надежные меры по предотвращению атак SSRF и DNS rebinding. Одновременно значительно улучшена стабильность и наблюдаемость компонента GraphRAG. Ключевые улучшения для GraphRAG включают изоляцию сборки графа во внешнем процессе для предотвращения сбоев, подсчеты индексирования графа в реальном времени с кэшированием, инструменты командной строки для восстановления графа и новую отладочную конечную точку для подписок.
