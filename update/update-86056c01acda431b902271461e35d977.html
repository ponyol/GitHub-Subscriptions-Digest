- feat(acp): native /compact forwarding and branch-at-head via session/fork (#554) ## Summary 🤖 Generated with [Nori](https://noriagentic.com/) Rebuilds the two still-live features from the stale PR #525 against the current `nori-harness` architecture (which had renamed/split the old `nori-acp` crate, leaving #525 unmergeable). The dependency-bump and ROADMAP commits from #525 were dropped as superseded. - **Native `/compact` forwarding** — when the connected agent advertises a native `compact` slash command, `/compact` forwards `/compact` as an ordinary in-session turn (no session swap, no summary re-injection) via a new `QueuedPromptKind::NativeCompact`; the existing summarize-and-swap flow remains the fallback for agents that don't advertise it. On completion the native path emits only the "Context compacted" divider. - **Branch-at-head via ACP `session/fork`** — a capability-gated "⎇ Branch from current point" entry in the `/fork` picker forks the current session at head via the unstable `session/fork` and swaps the active session to the forked id; the original session stays resumable. The entry only appears when the agent advertises `sessionCapabilities.fork` (claude-code does; codex/gemini don't). Rewind-to-message stays the existing local-summary fork. Fork-at-message is deliberately out of scope (blocked on upstream ACP PR #629, still an open RFD). - The inline compact session-swap machinery is extracted into a shared `harness/src/backend/session_swap.rs` (`swap_active_session`, mode `NewAfterCompact` | `ForkFromHead`) reused by both the compact fallback and branch. ## Known limitation Native-compact detection reads the reducer's advertised-command list, which is only populated by `available_commands_update` notifications that arrive **after** the `session/new` bootstrap window (bootstrap-window updates are dropped by design). Real agents typically advertise after that boundary, so this is expected to work in practice; the worst case is a graceful fallback to summarize-and-swap. Deterministically seeding the reducer from the bootstrap window is noted as a follow-up. Documented in `harness/docs.md`. ## Test Plan - [x] `cargo test -p nori-harness` (267 lib + boundary) and new `harness/tests/native_compact_and_branch.rs` (5 tests: native forward keeps session + no summary; fallback swaps + injects summary; branch forks active session; branch unsupported errors; branch leaves session intact when the fork RPC fails) — driven against the real mock ACP agent, asserting on the recorded ACP wire log (session ids + prompt text) and emitted events. - [x] `cargo test -p nori-tui` (1176) incl. 11 `fork_picker` tests + insta snapshot for the capability-gated branch entry. - [x] `cargo test -p nori-acp-host` (70). - [x] `just fmt` + `cargo clippy -D warnings` clean on all touched crates; `cargo build --bin nori` succeeds. - [ ] Manual TUI drive skipped: the local `elizacp` agent advertises neither a `compact` command nor `session/fork`, so it can't exercise either path; coverage is via the mock-agent integration tests above.
