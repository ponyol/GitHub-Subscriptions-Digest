Суммаризация (на русском)

Это обновление добавляет полную поддержку Voyage AI, интегрируя его возможности встраивания (эмбеддингов) и переранжирования. Новые асинхронные пользовательские функции (UDF) обеспечивают встраивание текста с настраиваемыми размерностями и переранжирование документов с фильтрацией по top-k. Интеграция включает пакетную обработку, ограничение скорости запросов, поддержку нескольких моделей Voyage AI и простую настройку через ключ API.

(#962) ### Changes * **New**: `pixeltable/functions/voyageai.py` - async embeddings and rerank UDFs * **New**: `tests/functions/test_voyageai.py` - integration tests * **New**: `docs/notebooks/integrations/working-with-voyageai.ipynb` - tutorial * **Modified**: `env.py`, `config.py`, `functions/__init__.py` - package registration ### Features * **Async text embeddings** via `voyageai.AsyncClient.embed()` with configurable dimensions (256-2048) * **Async document reranking** via `voyageai.AsyncClient.rerank()` with top-k filtering * Batch processing (128 texts per batch) * Rate limiting support * Models: `voyage-3.5`, `voyage-3-large`, `voyage-code-3`, `rerank-2.5`, `rerank-2.5-lite` ### API Conformance Implementation verified against official [Voyage AI Python SDK documentation](https://docs.voyageai.com/docs/embeddings): - `embed(texts, model, input_type, truncation, output_dimension, output_dtype)` - `rerank(query, documents, model, top_k, truncation)` ### Configuration Set `VOYAGEAI_API_KEY` environment variable or add to `config.toml`: ```toml [voyageai] api_key = "your-key" ``` ### Usage ```python from pixeltable.functions import voyageai # Embeddings t.add_computed_column(embed=voyageai.embeddings(t.text, model='voyage-3.5')) # Reranking t.add_computed_column(reranked=voyageai.rerank(t.query, t.docs, model='rerank-2.5')) ```
