Этот релиз значительно повышает стабильность, безопасность и удобство разработки Appwrite. Ключевые улучшения включают предотвращение создания "осиротевших" коллекций в базах данных, сохранение соединений с репозиториями VCS при обновлениях и устранение многочисленных уязвимостей (CVE) за счет обновления зависимостей. Merge branch '1.9.x' into test/account-mfa-authenticator-flows - Make webhooks worker coroutine-safe The webhooks worker held per-message state on the shared Action instance (`private array $errors`), which is reused across coroutines. Scope the error accumulator to each `action()` call and have `execute()` return its failure log (or null) instead of mutating instance state.
