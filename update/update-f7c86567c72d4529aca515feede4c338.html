Она рефакторит обработку формата GPU KV и добавляет такие функции, как настраиваемые переопределения дополнительных конфигураций, API для сброса метрик и журналирование идентификаторов запросов для операций хранения. Обновление также включает критические исправления ошибок для сопоставления вариантов FP8 и ошибок синтаксического анализа, а также всесторонние обновления документации и новые модульные тесты.

<slshen@uchciago.edu> - [Bug]: fix inconsistent round-trip mapping for FP8 variants (#2467) fix(utils): fix inconsistent round-trip mapping for FP8 variants Prior to this change, both 'float8_e4m3fn' and 'float8_e4m3fnuz' were mapped to the same string 'fp8_e4m3'. This caused an issue where 'float8_e4m3fn' would be incorrectly restored as 'float8_e4m3fnuz' during reverse lookup, leading to potential hardware incompatibility and precision errors. This commit assigns unique string identifiers to each FP8 variant: - torch.float8_e4m3fn -> "fp8_e4m3fn" - torch.float8_e4m3fnuz -> "fp8_e4m3fnuz" This ensures precise and idempotent dtype serialization.
