Суммаризация (на русском)

Недавние обновления направлены на повышение надежности системы и улучшение инструментов разработки. Основные изменения включают более информативное логирование ошибок при тайм-аутах сессий Browserbase и исправление CI-конвейеров путем обеспечения установки стабильной версии Chrome. Кроме того, была устранена ошибка, связанная с извлечением не-объектов из схемы Zod, и введены комплексные тесты API-контрактов для обеспечения согласованности типов публичного API при разработке SDK.
