This update introduces a major **Warp-style block-mode terminal**, featuring command blocks, in-block search, and a CodeMirror-powered shell editor. A **unified workspace-level input bar** now seamlessly switches between Shell and AI modes. Key UX enhancements include a **Command Palette** for quick actions, improved **Source Control context menus**, and terminal tab renaming. The update also brings performance optimizations (like WebGL reaping and native CSS animations), a **Zen mode** for distraction-free work, and cross-platform process-aware tab closing. --- **Russian translation:** В этом обновлении представлен новый **терминал блочного режима в стиле Warp**, включающий командные блоки, поиск внутри блоков и редактор командной оболочки на базе CodeMirror. **Унифицированная панель ввода на уровне рабочей области** теперь плавно переключается между режимами Shell и AI.
