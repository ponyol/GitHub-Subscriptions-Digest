Суммаризация (на русском)

Это обновление вводит новый интерактивный режим для цикла агента, позволяющий вести диалог в чат-стиле, где текстовые ответы приостанавливаются для ввода пользователя, а вызовы инструментов выполняются автономно. Также добавлена возможность определять специфические навыки для инструментов. Исправлена критическая ошибка, из-за которой инструмент `web_search` не загружался, если его ключ API хранился в файле конфигурации.
