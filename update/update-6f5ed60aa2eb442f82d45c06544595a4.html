Суммаризация (на русском)

This update significantly enhances Factory Droid integration, refining hook installation, permission handling, and decision flow to ensure proper interaction with Droid's native settings and prevent unintended command allowances. It also introduces support for `git checkout` commands. Furthermore, the release includes important fixes for `grep` output separators, improved Cargo build error surfacing, and `ccusage` period key acceptance. --- Это обновление значительно улучшает интеграцию с Factory Droid, уточняя установку хуков, обработку разрешений и поток принятия решений для обеспечения корректного взаимодействия с нативными настройками Droid и предотвращения нежелательных разрешений команд. Также добавлена поддержка команд `git checkout`. Кроме того, выпуск включает важные исправления для разделителей вывода `grep`, улучшенное отображение ошибок сборки Cargo и поддержку ключа `period` в `ccusage`.
