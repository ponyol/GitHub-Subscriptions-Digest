Суммаризация (на русском)

This update delivers a major overhaul of the user interface, notably redesigning Tools management, agent detail navigation, the Database workspace, and introducing a new "Abilities" overview for agent features. A significant new "Knowledge Collections" feature is added, allowing users to manage, search, and curate information with Git synchronization. Under the hood, the release focuses heavily on reliability, performance, and stability through a faster sandbox, improved memory safety (preventing background tasks from evicting active models), and fixes for various main-thread hangs and agent lifecycle issues. Additionally, it introduces premium web search, Bonsai models, and numerous bug fixes. --- **Russian translation:** Это обновление приносит значительную переработку пользовательского интерфейса, в частности, перепроектирование управления Инструментами, навигации по деталям агента, рабочего пространства Базы данных и представление нового обзора "Способностей" для функций агента. Добавлена значительная новая функция "Коллекции знаний", позволяющая пользователям управлять, искать и курировать информацию с синхронизацией через Git. В основе этого выпуска лежит значительное улучшение надежности, производительности и стабильности за счет ускоренной "песочницы", повышенной безопасности памяти (предотвращающей вытеснение активных моделей фоновыми задачами) и исправлений различных зависаний основного потока и проблем с жизненным циклом агентов. Кроме того, добавлен премиумный веб-поиск, модели Bonsai и множество исправлений ошибок.
