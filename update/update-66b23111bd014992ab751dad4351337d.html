Суммаризация (на русском)

Конфигурация `vim_mode` (булево значение) заменена перечислением `VimEnterBehavior` с тремя состояниями, что позволяет пользователям выбирать поведение клавиши Enter. Доступные варианты: «Enter is Newline» (Enter — новая строка) для полноценного Vim-подобного редактирования, «Enter is Submit» (Enter — отправить) для традиционной отправки в CLI, или «Off» (Выкл.). Это поведение настраивается через новый под-выборщик, при этом существующие настройки `vim_mode = true` автоматически сопоставляются с «Enter is Submit» для обратной совместимости.
