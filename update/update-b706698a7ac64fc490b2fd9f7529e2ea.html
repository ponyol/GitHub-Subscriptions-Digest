This update introduces significant new features, including configuration for LLM inference endpoints and AI-powered session search with summarization and retrieval models. It also enhances role-based access control by allowing usernames in role templates and expressions for dynamic resource access. Major improvements to workload identity management include better support for scoped tokens and bot joining, alongside new Terraform provider resources for UI configuration and workload clusters. The release addresses critical bugs, such as ensuring host accessibility for bound keypair joins with scoped tokens, fixing various MFA-related issues, and improving the reliability of enhanced session recording. --- Это обновление представляет значительные новые функции, включая конфигурацию конечных точек вывода LLM и поиск сеансов на основе ИИ с моделями суммаризации и извлечения. Оно также улучшает управление доступом на основе ролей, позволяя использовать имена пользователей в шаблонах ролей и выражениях для динамического доступа к ресурсам. Релиз устраняет критические ошибки, такие как обеспечение доступности хостов для присоединений связанных пар ключей с токенами с ограниченной областью действия, исправление различных проблем, связанных с MFA, и повышение надежности расширенной записи сеансов.
