Суммаризация (на русском)

This release introduces significant enhancements to browser functionality, including coordinate click actions and improved session/profile management. Text-to-Speech (TTS) capabilities received numerous fixes and now support Gemini style profiles. Daemon-level improvements include Nix Home Manager PATH support and more robust `launchd` restart handling. The update also refines security and access controls, enhances memory search visibility, and features extensive documentation updates alongside various bug fixes across integrations. *** Этот выпуск вводит значительные улучшения в функциональность браузера, включая действия клика по координатам и улучшенное управление сессиями/профилями. Возможности преобразования текста в речь (TTS) получили многочисленные исправления и теперь поддерживают профили стиля Gemini. Улучшения на уровне демона включают поддержку PATH для Nix Home Manager и более надёжную обработку перезапусков `launchd`. Обновление также улучшает безопасность и контроль доступа, повышает видимость поиска по памяти и содержит обширные обновления документации наряду с различными исправлениями ошибок в интеграциях.
