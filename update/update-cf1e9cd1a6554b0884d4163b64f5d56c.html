Суммаризация (на русском)

This update delivers numerous bug fixes across the application, addressing issues ranging from UI/UX (e.g., search highlighting, editor input, placeholder visibility) to core functionalities like agent exploration errors, document processing, and API stability. Key improvements include enhanced search results with term highlighting, increased file size support for documents (>2GB), and security patches for `pypdf` and `Apache Tika`. Additionally, new features such as default model management, new agent templates (data analysis, resume), and refined task resume mechanisms have been added, alongside various refactorings for API standardization and better internationalization support. --- Это обновление включает множество исправлений ошибок по всему приложению, касающихся как пользовательского интерфейса (например, подсветка поиска, ввод в редакторе, видимость заполнителей), так и основных функций, таких как ошибки при исследовании агентов, обработка документов и стабильность API. Важные улучшения также включают расширенные результаты поиска с подсветкой терминов, поддержку файлов большего размера (>2 ГБ) и исправления безопасности для `pypdf` и `Apache Tika`. Кроме того, были добавлены новые функции, такие как управление моделями по умолчанию, новые шаблоны агентов (анализ данных, резюме) и улучшенные механизмы возобновления задач, а также различные рефакторинги для стандартизации API и лучшей поддержки интернационализации.

The Agent does not display the referenced file cards below the response, unlike Chat applications. ### Root Cause The Agent's Retrieval tool (agent/tools/retrieval.py) calls retriever.retrieval() with aggs=False, which means the retrieval results do not include doc_aggs (document aggregation) data. Without doc_aggs, the frontend ReferenceDocumentList component has no data to render the file cards. In contrast, the Chat application (api/db/services/dialog_service.py) calls the same retriever.retrieval() method with aggs=True. ### Fix Changed aggs=False to aggs=True in agent/tools/retrieval.py so that document aggregation data is returned along with the retrieved chunks.
