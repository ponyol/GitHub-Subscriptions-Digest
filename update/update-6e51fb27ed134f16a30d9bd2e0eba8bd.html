Суммаризация (на русском)

Релиз Flet v0.84.0 содержит значительные изменения, включая перенос документации с MkDocs на Docusaurus и реструктуризацию примеров в проекты. Были реализованы существенные исправления для `flet pack` на macOS, наряду с обновлениями интеграционных тестов. Кроме того, добавлен новый API для подписки по электронной почте с верификацией hCaptcha и интеграцией Mailgun, а также улучшены функции поиска Algolia с помощью DocSearch и Ask AI. Среди прочих улучшений — доработка правил валидации и обновление устаревших атрибутов `DragUpdateEvent` в примерах.
