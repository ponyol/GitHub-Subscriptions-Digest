Суммаризация (на русском)

The Studio application received significant updates, including a comprehensive redesign of the chat composer, tool call UI, and sidebar, alongside improved project management and visual consistency. Key model enhancements introduce Gemma 4 audio input, enable GGUF tools with vision, and update model selection logic for various platforms (macOS, Linux GPU, NVIDIA CUDA) and architectures, changing the default chat model to Qwen3.5-4B-MTP. Other fixes address chat preset persistence, streaming optimization, installer issues on Apple Silicon and Windows, configurable dataset upload limits, and general system stability. --- Приложение Studio получило значительные обновления, включая комплексный редизайн компоновщика чата, пользовательского интерфейса вызова инструментов и боковой панели, а также улучшенное управление проектами и визуальную согласованность. Ключевые улучшения моделей включают поддержку аудиовхода Gemma 4, активацию инструментов GGUF с визуальными данными и обновление логики выбора моделей для различных платформ (macOS, Linux GPU, NVIDIA CUDA) и архитектур, изменив модель чата по умолчанию на Qwen3.5-4B-MTP. Прочие исправления касаются сохранения настроек чата, оптимизации потоковой передачи, проблем с установщиком на Apple Silicon и Windows, настраиваемых лимитов загрузки наборов данных и общей стабильности системы.
