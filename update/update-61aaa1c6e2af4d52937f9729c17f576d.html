We also remove `target_length_orig` and `target_length` from decoder graph, and here we support it in genai. - [WebGPU] Fix the prefill regression when graph capture is ON (#2021) **Problem: WebGPU Prefill Performance Regression with Graph Capture** When WebGPU graph capture is enabled, the upstream code sets p_device_inputs_ to GPU (WebGPU device) for model inputs. However, GeneratorParams::p_device was initialized from p_device_inputs_, which meant it also pointed to the GPU device. This caused a problem because: WebGPU uses GreedySearch_Cpu — the search/scoring logic runs entirely on CPU. But GeneratorParams::p_device (GPU) was used to allocate the sequences buffer and token arrays. AllocateInputIdsOnDevice allocated the initial input IDs tensor on the GPU device (via p_device), then immediately needed the data on CPU for the CPU-based search, causing unnecessary GPU↔CPU round-trips. GreedySearch_Cpu::AppendTokens similarly suffered from device mismatch — tokens were allocated on GPU but consumed on CPU, creating synchronization overhead on every token append during both prefill and generation. The net effect was that prefill throughput was significantly degraded (roughly ~5,000 tps vs ~5,900 tps expected) due to these unnecessary cross-device data transfers happening in the hot path. **Solution: Introduce p_device_scoring_** We added a dedicated p_device_scoring_ member to the Model class that represents the correct device for search/scoring operations: For WebGPU: p_device_scoring_ = CPU (since GreedySearch_Cpu is used) For CUDA: p_device_scoring_ = same as p_device_inputs_ (since CUDA has its own GPU-based greedy search) GeneratorParams::p_device now initializes from model.p_device_scoring_ instead of model.p_device_inputs_. This ensures input ID allocation, sequence buffers, and token operations all stay on CPU for WebGPU — eliminating the GPU↔CPU round-trips entirely. **Result** Prefill throughput improved from ~5,000 tps back to ~5,900 tps at 1024 prompt length. --------- Co-authored-by: kunal-vaishnavi <115581922+kunal-vaishnavi@users.noreply.github.com> - Nemotron ASR Support for Streaming (#1997) <img width="793" height="2206" alt="image" src="https://github.com/user-attachments/assets/11338b81-9fc0-4060-91dd-770812b543c5" /> <img width="1540" height="1284" alt="image" src="https://github.com/user-attachments/assets/54bc46d4-03bb-4ae9-9e71-a13f17053404" /> --------- Co-authored-by: Copilot Autofix powered by AI <62310815+github-advanced-security[bot]@users.noreply.github.com>
