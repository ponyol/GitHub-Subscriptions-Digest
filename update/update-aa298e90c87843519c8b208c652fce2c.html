Суммаризация (на русском)

Это обновление перерабатывает провайдеров LLM, улучшает функции интерпретатора кода (визуализация админ-панели, инструменты Python по умолчанию, развертывание в Docker) и добавляет комплексные ночные тесты для различных интеграций LLM. Были значительно улучшены ключевые корпоративные функции, включая соответствие протоколу SCIM 2.0 для управления пользователями, метрики Prometheus для каждого клиента и улучшенную обработку ограничений доступа и биллинга. Пользовательский интерфейс получил множество улучшений, особенно в компонентах "opal", взаимодействиях с карточками агентов и отображении чата, а также были внесены исправления бэкэнда, обновления зависимостей и различные исправления ошибок для таких компонентов, как SharePoint, MinIO и SSL базы данных.
