Суммаризация (на русском)

This update introduces a new built-in A0 CLI Connector, enabling connection via Flare Tunnel and providing setup guidance. It significantly enhances security by fixing critical vulnerabilities: a path traversal issue (CVE-2026-4307) and an SSRF vulnerability (CVE-2026-4308) in remote document fetching. Additionally, the Browser Agent now supports selectable model configuration presets, plugin uninstall procedures are clarified, and messaging integrations receive native chat controls. --- Это обновление представляет новый встроенный коннектор A0 CLI, позволяющий подключаться через Flare Tunnel и предоставляющий руководство по его настройке. Оно значительно повышает безопасность, исправляя критические уязвимости: проблему обхода пути (CVE-2026-4307) и уязвимость SSRF (CVE-2026-4308) при удаленной загрузке документов. Кроме того, Browser Agent теперь поддерживает выбираемые предустановки конфигурации модели, уточнены процедуры удаления плагинов, а интеграции сообщений получили собственные элементы управления чатом.

The issue was originally reported by @YLChen-007. This change replaces ad hoc remote document fetching with a centralized safe fetch flow that validates remote URLs before any network request is used for parsing. It blocks localhost and non-public IPv4/IPv6 targets, validates every redirect hop, disables implicit trust of proxy env settings for this path, and enforces a strict remote document size cap. It also removes direct third-party loader access to attacker-controlled URLs by prefetching remote content first and then parsing only trusted local bytes or temp files for HTML, text, PDF, image, and unstructured document handling.
