RagFlow introduced new features, including RSS/Atom feed support and a Go-based memory function, alongside an expanded Go CLI for context engine and API token management. Numerous critical bug fixes were implemented, addressing issues in PDF parsing, indexing, dataset management, UI display, and API performance, along with important security updates for `pyasn1` and `litellm` libraries. The project also underwent significant refactoring, transitioning APIs to a RESTful style and improving internal components, while completing Turkish localization. --- **Russian Translation:** RagFlow представил новые функции, включая поддержку RSS/Atom-лент и функцию памяти на Go, а также расширил CLI на Go для управления контекстным движком и токенами API. Было реализовано множество критических исправлений, касающихся парсинга PDF, индексации, управления наборами данных, отображения UI и производительности API, а также важные обновления безопасности для библиотек `pyasn1` и `litellm`. Проект также прошел значительный рефакторинг, переведя API на RESTful стиль и улучшив внутренние компоненты, одновременно завершив турецкую локализацию.
