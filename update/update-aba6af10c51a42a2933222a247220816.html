Суммаризация (на русском)

This comprehensive update significantly enhances document extraction, introducing OMML-to-LaTeX math conversion for DOCX files, new metadata fields in `ExtractionResult` such as keywords and annotations, and improved plain text output across multiple formats. Key extraction quality fixes address nested HTML tables, PDF text positioning, FB2 poem elements, CSV encoding, and JPEG 2000 OCR. The release also resolves critical build and runtime issues for WASM, Windows, and musl CLI environments, alongside extensive updates to test infrastructure, documentation, and various dependencies. --- **Russian Translation:** Это всеобъемлющее обновление значительно улучшает извлечение документов, добавляя преобразование математических формул OMML в LaTeX для файлов DOCX, новые поля метаданных в `ExtractionResult`, такие как ключевые слова и аннотации, а также улучшенный вывод обычного текста для различных форматов. Основные исправления качества извлечения касаются вложенных HTML-таблиц, позиционирования текста в PDF, элементов поэзии FB2, кодировки CSV и OCR для JPEG 2000. Выпуск также устраняет критические проблемы сборки и выполнения для сред WASM, Windows и musl CLI, наряду с обширными обновлениями тестовой инфраструктуры, документации и различных зависимостей.
