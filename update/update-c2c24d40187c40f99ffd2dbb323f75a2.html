Суммаризация (на русском)

This update significantly refactors error handling with the `merr` framework, enhancing classification, metrics, and retriability, alongside an upgrade to Go toolchain 1.26.4. It introduces new features like dynamic StructArray field APIs, REST and Go SDK support for search aggregation, and BM25/text_match for text fields. Performance is boosted by vectorized bitset operations and LIKE pattern caching. Key fixes address FileManager stream paths, nullable vector array offsets, replication checkpoint accessibility, and import 2PC timestamp preservation, supported by numerous test and build system improvements. --- **Russian Translation:** Это обновление значительно перерабатывает обработку ошибок с использованием фреймворка `merr`, улучшая классификацию, метрики и возможность повторных попыток, а также включает обновление набора инструментов Go до версии 1.26.4. Введены новые функции, такие как динамические API полей StructArray, поддержка агрегации поиска через REST и Go SDK, а также BM25/text_match для текстовых полей. Производительность повышена за счет векторизованных операций с битовыми множествами и кэширования шаблонов LIKE. Основные исправления касаются семантики путей потоков FileManager, смещений nullable векторных массивов, доступности контрольных точек репликации и сохранения меток времени для двухфазной фиксации импорта, что дополняется многочисленными улучшениями тестовой и сборочной систем.
