Суммаризация (на русском)

This gptel update introduces a key feature allowing users to log tool calls without their verbose results, enhancing clarity and debugging. It also brings significant stability improvements, such as preventing FSM hangs from unknown tool calls, ensuring accurate streaming tool call collection, and handling API errors in stream parsing. Performance is boosted by sending Curl request bodies directly via stdin, while new support for Claude Sonnet 5 is added, and link validation is improved for remote buffers. --- Это обновление gptel добавляет ключевую функцию, позволяющую регистрировать вызовы инструментов без их многословных результатов, что улучшает ясность и отладку. Оно также включает значительные улучшения стабильности, такие как предотвращение зависаний FSM при вызове неизвестных инструментов, корректный сбор потоковых вызовов инструментов и обработка ошибок API при потоковом анализе. Производительность повышена за счет прямой передачи тел запросов Curl через stdin, добавлена поддержка Claude Sonnet 5, и улучшена проверка ссылок для удаленных буферов.
