Суммаризация (на русском)

This update delivers major new features including a comprehensive background task system (SEP-2663) and multi-round-trip tools (SEP-2322) for interactive elicitation. It also introduces stateless session state, defaults the client to auto-negotiating the modern protocol, and adds server-side argument completion and machine-to-machine client authentication. The update officially launches v4 documentation and includes a critical fix for a Windows-crashing `burner-redis` issue, alongside numerous stability and quality enhancements. --- **Russian translation:** Это обновление предоставляет основные новые функции, включая комплексную систему фоновых задач (SEP-2663) и многораундовые инструменты (SEP-2322) для интерактивного взаимодействия. Также введено состояние сеанса без сохранения состояния, клиент по умолчанию автоматически договаривается о современном протоколе, добавлены завершения аргументов на стороне сервера и аутентификация клиента типа "машина-машина". Обновление официально запускает документацию v4 и включает критическое исправление для проблемы `burner-redis`, вызывающей сбой в Windows, наряду с многочисленными улучшениями стабильности и качества.
