The recent updates significantly refactor the application's authentication system by entirely removing WorkOS integration and implementing auto-login for single-user mode. Furthermore, environment variables for both backend and frontend have been consolidated into a single source, simplifying configuration. New features include adding team and workspace management with migration capabilities, alongside various bug fixes and improvements to diffusion paths and seeding processes.
