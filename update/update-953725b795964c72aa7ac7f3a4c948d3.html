Суммаризация (на русском)

This update significantly enhances the system with new features like per-key TTL and improved validation for the Valkey glide connector, and introduces a `HiddenStateStore` for efficient hidden-state caching. Architectural improvements include a device-agnostic IPC wrapper for better platform extensibility (e.g., AMD support) and a blocking prefetch status mechanism to optimize lookup latency. The release also includes multiple bug fixes, CLI and operator enhancements, and documentation updates. --- Это обновление значительно улучшает систему новыми функциями, такими как TTL для каждого ключа и улучшенная валидация для Valkey glide коннектора, а также вводит `HiddenStateStore` для эффективного кэширования скрытых состояний. Среди архитектурных улучшений — независимая от устройств оболочка IPC для лучшей расширяемости платформы (включая поддержку AMD) и механизм блокировки статуса предварительной выборки для оптимизации задержки поиска. Релиз также включает многочисленные исправления ошибок, улучшения CLI и оператора, а также обновления документации.
