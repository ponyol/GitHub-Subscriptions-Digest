Суммаризация (на русском)

This release significantly enhances OpenTelemetry integration with improved token usage deduplication and computation, along with refined cost calculation for new models like OpenAI TTS. It introduces a `ReplayManager` for reliable offline message delivery and a robust `EvaluationSuite` with `LLMJudge` for regression testing and advanced optimization studio features. Additionally, the update brings numerous UI/UX improvements, including granular permission checks, standardized table layouts, clickable links, and new agent configuration management and AI-assisted GitHub PR review tools. --- Этот релиз значительно улучшает интеграцию OpenTelemetry за счет дедупликации и расчета использования токенов, а также уточнения расчета стоимости для новых моделей, таких как OpenAI TTS. Введен `ReplayManager` для надежной доставки сообщений в офлайн-режиме и мощный `EvaluationSuite` с `LLMJudge` для регрессионного тестирования и расширенных функций студии оптимизации. Кроме того, обновление содержит многочисленные улучшения пользовательского интерфейса, включая детальные проверки разрешений, стандартизированные макеты таблиц, интерактивные ссылки, а также новые инструменты для управления конфигурацией агентов и ИИ-помощи при обзоре запросов на изменение в GitHub.
