Суммаризация (на русском)

This update significantly enhances the CTTI data synchronization process, introducing continuous sync with total limits, incremental updates, and more robust error handling for batch failures. It also improves tokenization and chunking logic by correctly handling special tokens in `tiktoken` and adding accurate token recounting to `CodeChunker`, preventing OpenAI API errors. Furthermore, critical fixes ensure user cache invalidation occurs reliably upon changes to organization membership, eliminating stale data issues and 403 errors. *** Этот релиз значительно улучшает процесс синхронизации данных CTTI, внедряя непрерывную синхронизацию с общими лимитами, инкрементальные обновления и более надежную обработку ошибок при пакетных сбоях. Также улучшена логика токенизации и разделения на чанки за счет корректной обработки специальных токенов в `tiktoken` и добавления точного пересчета токенов в `CodeChunker`, что предотвращает ошибки OpenAI API. Кроме того, критические исправления гарантируют надежную инвалидацию пользовательского кеша при изменении членства в организации, устраняя проблемы устаревших данных и ошибки 403.
