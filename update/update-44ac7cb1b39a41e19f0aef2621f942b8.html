Суммаризация (на русском)

This release for `@ag-ui/mastra` introduces several key features, including tracing options, surfacing Observational Memory and background tasks as AG-UI activity events, and streaming shared state with client edit synchronization. Tool interaction is significantly enhanced via incremental argument streaming, native interrupt suspend/resume for both local and remote agents, and improved A2UI support. Critical fixes address thread history duplication and ensure correct rendering order for tool cards, alongside a revamp of the CopilotKit integration. --- **Russian translation:** Этот релиз для `@ag-ui/mastra` представляет несколько ключевых функций, включая опции трассировки, отображение Observational Memory и фоновых задач как событий активности AG-UI, а также потоковую передачу общего состояния с синхронизацией клиентских изменений. Взаимодействие с инструментами значительно улучшено за счет инкрементальной потоковой передачи аргументов, нативной приостановки/возобновления прерываний как для локальных, так и для удаленных агентов, а также улучшенной поддержки A2UI. Критические исправления касаются дублирования истории потоков и обеспечивают правильный порядок рендеринга карточек инструментов, наряду с обновлением интеграции CopilotKit.
