Суммаризация (на русском)

This release series significantly enhances the assistant's capabilities, adding support for Claude Opus 5 and improving prompt stream cancellation across all providers for better responsiveness. It also strengthens system resilience by handling dropped connections gracefully, recovering from invalid image rejections, and surfacing more precise error reasons. Furthermore, the updates include transitive plugin dependency resolution and a new text chat context type for more flexible input. *** Эта серия релизов значительно расширяет возможности ассистента, добавляя поддержку Claude Opus 5 и улучшая отмену потоков запросов у всех провайдеров для повышения отзывчивости. Также повышена стабильность системы за счет корректной обработки разрывов соединений, восстановления после отклонения невалидных изображений и отображения более точных причин ошибок. Кроме того, обновления включают транзитивное разрешение зависимостей плагинов и новый тип контекста текстового чата для более гибкого ввода.
