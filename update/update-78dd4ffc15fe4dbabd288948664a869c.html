Суммаризация (на русском)

Это обновление для Faiss вносит значительные оптимизации производительности для различных типов индексов, используя архитектурно-специфичные SIMD-инструкции (например, AVX512-BF16, AVX512_SPR, NEON) для ускорения вычислений расстояний и декодирования. Оно также расширяет возможности GPU, добавляя поддержку индекса `MetalIndexIVFFlat` для бэкенда Apple Metal. Ключевые исправления включают устранение проблем сборки для Windows ARM64, повышение безопасности десериализации, а также общие улучшения кода и расширение гибкости системы сборки.

FAISS itself only ever writes the canonical encoding via WRITE1(bool), so well-formed indices roundtrip cleanly. The roundtrip succeeds iff the input byte was already the platform's canonical bool encoding. This stays ABI-portable: no assumption that 0 and 1 are the only valid encodings is baked into the source. A static_assert(sizeof(bool) == 1) makes the existing implicit FAISS assumption (WRITE1/READ1 of bool transfers exactly one byte) explicit at the one call site that depends on it for the byte compare.
