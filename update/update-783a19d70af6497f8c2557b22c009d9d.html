Суммаризация (на русском)

This update significantly enhances backend performance, particularly for trace thread closing jobs and experiment/optimization queries, achieved through optimized ClickHouse queries and indexing. Key new features include granular project scoping for various resources, a dedicated table for assertion results in evaluation suites, and a major overhaul of the optimization studio with advanced prompt evolution and visualization capabilities. The SDK now offers improved LLM Judge robustness, Anthropic beta API support, and enhanced client-side features like `search_threads` and deprecation warnings. Additionally, more granular workspace permissions have been introduced for critical operations, alongside numerous bug fixes and refactorings across the platform. --- Это обновление значительно повышает производительность бэкенда, особенно для задач закрытия потоков трассировки и запросов экспериментов/оптимизации, благодаря оптимизированным запросам ClickHouse и индексации. Среди ключевых новых функций — детализированное определение области видимости проектов для различных ресурсов, выделенная таблица для результатов утверждений в наборах для оценки, а также капитальный ремонт студии оптимизации с расширенной эволюцией промптов и улучшенной визуализацией. SDK теперь предлагает повышенную устойчивость LLM Judge, поддержку бета-версии Anthropic API и улучшенные клиентские функции, такие как `search_threads` и предупреждения об устаревании.
