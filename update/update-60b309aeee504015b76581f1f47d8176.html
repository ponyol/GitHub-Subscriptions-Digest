Суммаризация (на русском)

The primary update is the integration of the new PP-OCRv6 model, bringing enhanced OCR capabilities with updated metrics, extended language support (now 50 languages), and dedicated mobile demos for iOS and Android. This release also includes critical fixes for the PaddleOCR-VL pipeline to ensure proper vLLM server utilization, significantly improving performance and memory efficiency. Additionally, there are numerous documentation improvements, bug fixes, and refactoring efforts, particularly for the pure Swift implementation of the iOS OCR demo. --- **Russian Translation:** Основное обновление — интеграция новой модели PP-OCRv6, которая обеспечивает улучшенные возможности OCR с обновленными метриками, расширенной языковой поддержкой (теперь 50 языков) и выделенными мобильными демонстрациями для iOS и Android. Этот релиз также включает критические исправления для конвейера PaddleOCR-VL, обеспечивающие корректное использование сервера vLLM, что значительно повышает производительность и эффективность использования памяти. Кроме того, внесены многочисленные улучшения документации, исправления ошибок и усилия по рефакторингу, в частности для реализации OCR-демо на iOS полностью на Swift.

The vLLM server stays completely idle while inference runs unbatched in the pipeline container, causing much higher latency (~10x slower per image in our tests) and ~2 GiB of extra GPU memory for the duplicated model weights. Patch the config in prepare.sh to use `backend: vllm-server` with the compose service URL, matching the configuration shipped with the 1.5 SDK. Also restore batch_size from -1 to 4096 as in 1.5.
