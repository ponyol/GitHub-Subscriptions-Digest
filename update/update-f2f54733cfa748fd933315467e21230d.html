Суммаризация (на русском)

This series of updates substantially improves the system's security and stability. It enhances model loading by defaulting `trust_remote_code` to false, requiring explicit user opt-in, and introduces warnings for remote code execution. Additionally, multiple memory safety issues were resolved, including heap out-of-bounds vulnerabilities in beam search and C API functions, as well as a `new-delete-type-mismatch` in C API handle destruction. A critical fix for WebGPU graph capture with recurrent states was also implemented. --- Данная серия обновлений существенно улучшает безопасность и стабильность системы. Она улучшает загрузку моделей, устанавливая по умолчанию `trust_remote_code` в значение `false`, что требует явного согласия пользователя, и добавляет предупреждения о выполнении удаленного кода. Помимо этого, были устранены многочисленные проблемы с безопасностью памяти, включая уязвимости выхода за границы кучи в функциях Beam Search и C API, а также ошибку несоответствия типов `new-delete` при уничтожении дескрипторов C API. Также было реализовано критическое исправление для захвата графа WebGPU с рекуррентными состояниями.
