Суммаризация (на русском)

Это обновление в основном исправляет две проблемы, приводящие к утечкам акторов задач в асинхронной системе. Для `task-async` устранены утечки из обработчиков завершения путем лексического захвата контекста и обеспечения очистки с помощью `unwind-protect`, даже если обработчик выбрасывает ошибку. Кроме того, `task-await` теперь не допускает утечек акторов в своем "быстром пути", когда состояние задачи уже было установлено, благодаря перемещению операции очистки в блок `unwind-protect` для гарантии выполнения во всех сценариях.

Исходный текст

- Update README.md - Update sento.asd - Fix task-async on-complete-fun leaking task actors (#118) The completion handler runs on a worker thread where *task-context* is unbound, so (ac:stop *task-context* task) was a no-op. Capture the context lexically at call site, and run cleanup in unwind-protect so a throwing on-complete-fun does not leak. - Fix task-await leaking task actors when state already set (#118) task-await skipped ac:stop in the fast path where the worker had already set *state* before await ran -- the common case for short tasks under task-async-stream. Move ac:stop into unwind-protect so both paths clean up.
