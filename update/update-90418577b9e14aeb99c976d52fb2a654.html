This release significantly enhances LocalAI by enabling Multi-Token Prediction (MTP) and server-side prompt caching by default for llama.cpp models. It boosts security with keyless Cosign verification for backend OCI images and improves stability, especially for L4T13 backends like vLLM and SGLang, by resolving critical dependency issues. Key updates also include comprehensive API key and user usage tracking in the admin UI, asynchronous per-node backend installations, and fixes for OpenAI streaming usage, chat UI responsiveness, and text file attachments. Additionally, numerous dependencies have been updated. --- **Russian Translation:** Этот выпуск значительно улучшает LocalAI, по умолчанию активируя поддержку многотокенового предсказания (MTP) и серверное кэширование подсказок для моделей llama.cpp. Он повышает безопасность за счет бесключевой верификации Cosign для образов OCI бэкендов и улучшает стабильность, особенно для бэкендов L4T13, таких как vLLM и SGLang, путем устранения критических проблем с зависимостями. Среди важных обновлений также появились комплексное отслеживание использования по ключам API и пользователям в административном интерфейсе, асинхронная установка бэкендов на каждом узле, а также исправления для потокового использования OpenAI, отзывчивости пользовательского интерфейса чата и вложений текстовых файлов.
