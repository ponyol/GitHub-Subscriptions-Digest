Суммаризация (на русском)

Основные обновления включают внедрение L2-хранилища на базе NIXL и контроллеров предварительной загрузки/хранения L2 для многопроцессорного режима (MP), а также оператор Kubernetes для его развертывания. Введена новая подсистема телеметрии и наблюдаемости для MP-операций, наряду с исправлениями критических ошибок, таких как утечки памяти, и улучшением процессов непрерывной интеграции. Также была унифицирована обработка конфигураций для MP-серверов и добавлен новый API для явного освобождения блоков.
