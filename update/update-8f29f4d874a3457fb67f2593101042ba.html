This release brings significant improvements to the chat experience, including enhanced mobile responsiveness, real-time streaming answers, and smooth markdown rendering, alongside re-enabling Google sign-ins. Additionally, the update adds a single-origin reverse proxy for flexible deployments and refines image generation URL handling. --- Этот выпуск значительно улучшает возможности чата, включая улучшенную адаптивность для мобильных устройств, потоковую передачу ответов в реальном времени и плавный рендеринг Markdown, а также повторное включение входа через Google. Надежность и производительность бэкэнда повышаются за счет пакетной вставки фрагментов данных, явного порядка документов и критических исправлений, устраняющих зависания при запуске базы данных и заброшенные транзакции. Кроме того, обновление добавляет единый обратный прокси-сервер для гибкого развертывания и уточняет обработку URL-адресов для генерации изображений.
