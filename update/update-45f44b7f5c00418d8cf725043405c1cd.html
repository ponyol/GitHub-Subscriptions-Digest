Суммаризация (на русском)

This update significantly enhances Agent Zero's core functionality, focusing on tighter integration with the A0 Launcher for granular host access control and improved reliability. It vastly improves the extension ecosystem by exposing clearer model boundaries and streamlining loading processes. Key agent intelligence features are refined with robust goal management, sensitive data masking, and a unified global model preset system that now includes embedding support. The user experience is also polished through an improved Editor, better math rendering in chat, and more actionable notifications. --- **Russian translation:** Это обновление значительно улучшает основные функции Agent Zero, сфокусировавшись на более тесной интеграции с A0 Launcher для гранулированного контроля доступа к хосту и повышения надежности. Оно значительно улучшает экосистему расширений, раскрывая более четкие границы вызовов моделей и оптимизируя загрузку. Ключевые функции интеллектуального агента усовершенствованы за счет надежного управления целями, маскировки конфиденциальных данных и унифицированной глобальной системы предустановок моделей, теперь включающей поддержку эмбеддингов. Пользовательский опыт также улучшен благодаря усовершенствованному Редактору, лучшей отрисовке математических формул в чате и более действенным уведомлениям.
