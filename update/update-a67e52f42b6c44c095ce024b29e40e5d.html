Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com> * fix(cli): keep install-agent --dry-run converter writes inside the sandbox The OpenCode converter writes opencode.json at `target_dir.parent.parent`. During `--dry-run` the converter runs against a bare TemporaryDirectory, so that `parent.parent` escaped the sandbox to an ancestor — harmless on macOS (deep, writable temp paths) but on CI's shallow `/tmp/...` it resolved to `/` and raised PermissionError, failing the OpenCode dry-run. Root the dry-run temp target at `tmp + target.relative_to(anchor)` so the converter sees the same relative layout it would in a real install and every computed parent stays inside the throwaway dir. Codex keeps its existing `project_root=tmp` handling. Adds a deterministic regression test that pins the dry-run temp dir to a known-shallow path and asserts no stray opencode.json escapes the sandbox (fails on the old code, passes now).
