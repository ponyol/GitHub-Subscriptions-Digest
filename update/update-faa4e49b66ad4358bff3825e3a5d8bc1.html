Суммаризация (на русском)

This update significantly refactors the network model, simplifying XPC compatibility with a flat `NetworkStatus` struct and reorganizing network plugin targets for improved API evolution. A critical `PublishPort` integer overflow crash is fixed with added input validation. Key improvements include adopting `ManagedResource` for volumes, standardizing JSON output, and resolving several CLI issues, such as subcommand help, custom app root support, and the ability to configure integration tests. --- Это обновление значительно реорганизует сетевую модель, упрощая совместимость с XPC благодаря новой плоской структуре `NetworkStatus` и перестраивая цели сетевых плагинов для улучшения эволюции API. Исправлена критическая ошибка переполнения целочисленных значений в `PublishPort`, приводящая к сбою, путем добавления проверки входных данных. Ключевые улучшения включают использование `ManagedResource` для томов, стандартизацию вывода JSON и устранение нескольких проблем CLI, таких как справка по подкомандам, поддержка настраиваемого корневого каталога приложения и возможность настройки наборов интеграционных тестов.
