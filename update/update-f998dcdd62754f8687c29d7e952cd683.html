Суммаризация (на русском)

Это обновление представляет вариант Qwen3-ASR с квантованием int8, значительно сокращающий размер моделей и объем занимаемой ОЗУ примерно на 50% с незначительным влиянием на качество, а также обновляет API и CLI для его поддержки. Добавлен новый рабочий процесс CI для проведения смоук-тестов конвейера PocketTTS. Кроме того, выпуск включает функции переопределения каталогов, несколько исправлений ошибок и добавляет Flowstay в витрину проекта.
