Суммаризация (на русском)

Ядро этих обновлений представляет собой новую универсальную систему триггеров, позволяющую reasoners реагировать на внешние события из различных источников, таких как веб-хуки (Stripe, GitHub, Slack) и расписания cron. Эта функция включает комплексную поддержку бэкенда, улучшенные SDK для Python и Go с возможностями захвата источника кода и улучшенным опытом разработчика, а также полностью переработанный пользовательский интерфейс для управления, мониторинга и тестирования этих триггеров. Кроме того, система теперь расширяет цепочки проверяемых учетных данных для отслеживания происхождения событий-триггеров, обеспечивая лучшую аудируемость.
