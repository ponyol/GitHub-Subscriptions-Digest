Суммаризация (на русском)

The updates primarily focus on enhancing the security and reproducibility of the development environment by pinning GitHub Actions and pre-commit hooks. A major refactoring renames "private sandboxes" to "self-hosted sandboxes" across the codebase, documentation, and configuration, alongside improvements like using published SDKs and refining API usage. New self-hosted sandbox worker templates are introduced as reference implementations for managed agent sessions, complemented by a new Slack stateless webhook bridge template. --- Обновления в основном сосредоточены на повышении безопасности и воспроизводимости среды разработки путем привязки GitHub Actions и pre-commit хуков к определенным версиям. Крупный рефакторинг переименовывает "private sandboxes" в "self-hosted sandboxes" во всей кодовой базе, документации и конфигурации, а также включает улучшения, такие как использование опубликованных SDK и уточнение использования API. Введены новые шаблоны рабочих процессов для самохостинговых песочниц (self-hosted sandbox worker templates) в качестве эталонных реализаций для сессий управляемых агентов, а также новый шаблон моста для Slack-вебхуков без сохранения состояния.
