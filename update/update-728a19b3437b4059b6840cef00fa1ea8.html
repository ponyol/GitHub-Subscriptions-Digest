Суммаризация (на русском)

Это обновление значительно расширяет интеграции API, добавляя аутентификацию по ключу Bedrock API и расширенную поддержку моделей ИИ, включая возможности работы с видео для Gemini и VoyageAI. Введены значительные улучшения для параллелизма и потокобезопасности благодаря многопоточным вызовам API, совместимости с `uvloop` и обновленным рекомендациям по развертыванию. Исправлены критические ошибки, связанные с `drop_index` для физического удаления индексов PostgreSQL и уточнена логика `if_exists` для замены таблиц и представлений. Кроме того, улучшен опыт разработчиков благодаря новому декоратору `@pxt.iterator` и всесторонним обновлениям документации.
