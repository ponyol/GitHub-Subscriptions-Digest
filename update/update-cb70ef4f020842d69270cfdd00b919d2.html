Суммаризация (на русском)

This update significantly enhances performance for models like Qwen, GLM, and DeepSeek V4 through new Metal kernels, advanced routing, and a major rework of depth-k speculative decoding (MTP), alongside substantial improvements to quantization (oQ/TurboQuant) and new model support including Tencent Hy3. The release also boosts user experience with new admin UI features like model favorites, search, and external API benchmarking, plus expanded audio capabilities such as streaming STT and TTS voice listing. Numerous fixes address cache handling, memory management, and overall system stability. --- **Русский перевод:** Это обновление значительно повышает производительность для моделей, таких как Qwen, GLM и DeepSeek V4, благодаря новым ядрам Metal, улучшенной маршрутизации и серьезной переработке спекулятивного декодирования (MTP) с глубиной k, а также существенным улучшениям в квантовании (oQ/TurboQuant) и поддержке новых моделей, включая Tencent Hy3. Выпуск также улучшает пользовательский опыт за счет новых функций административного интерфейса, таких как избранные модели, поиск и бенчмаркинг внешних API, а также расширенные аудиовозможности, включая потоковую передачу STT и список голосов TTS. Многочисленные исправления касаются обработки кэша, управления памятью и общей стабильности системы.

Fixes: 606 - fix(cache): key paged SSD blocks by TurboQuant bit depth (#2071) TurboQuant packed state width is ceil(head_dim * bits / 32), so blocks written at different turboquant_kv_bits are shape-incompatible.
