The `cognee` project has released `cognee-mcp` version 0.5.5, which includes critical fixes for its cloud client, addressing issues with connecting to Cognee Cloud, listing datasets, and handling unscoped searches and environment variables. Major new features include the addition of Turso (libSQL) as a local graph database backend and a task for deterministic code graph extraction using `enola`. Further improvements involve productizing the evaluation framework with a unified CLI runner and optional DeepEval integration, along with enhancing `ImageLoader` with EXIF metadata extraction and perceptual hashing. Numerous other fixes address issues like recall prompt forwarding, API dry run rejection, and search result normalization. --- Проект `cognee` выпустил версию `cognee-mcp` 0.5.5, которая включает критические исправления для своего облачного клиента, устраняющие проблемы с подключением к Cognee Cloud, отображением наборов данных, а также обработкой неограниченных поисковых запросов и переменных среды. Среди значительных новых функций — добавление Turso (libSQL) в качестве локальной графовой базы данных и задача для детерминированной экстракции графа кода с использованием `enola`. Дальнейшие улучшения включают доработку фреймворка оценки с помощью унифицированной утилиты командной строки и опциональной интеграции DeepEval, а также расширение `ImageLoader` возможностями извлечения метаданных EXIF и перцептивного хеширования.
