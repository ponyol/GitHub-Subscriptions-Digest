Суммаризация (на русском)

Внедрены автоматизированные процессы выпуска для пакетов Python и TypeScript, позволяющие публиковать их в PyPI и npm при изменении версий. Внесены значительные улучшения и исправления в промежуточное ПО ADK, включая устранение ошибок сериализации JSON, оптимизацию поиска сессий до O(1) и улучшение кэширования сессий для предотвращения утечки данных между пользователями. Также решены проблемы с параллельными вызовами инструментов и обновлены примеры агентов с возможностями автоматического масштабирования. Обновлена документация для отражения поддержки AWS Bedrock AgentCore, и установлены верхние границы для зависимостей, чтобы предотвратить будущие критические изменения.
