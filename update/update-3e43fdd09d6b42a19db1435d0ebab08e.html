Суммаризация (на русском)

Функция "электрическая пара для режима prog" была удалена. Она вызывала больше проблем, чем решала, не работала для всех пар символов при выделении и не учитывала контекст, приводя к неуклюжим вставкам, например, кавычек внутри кавычек. Теперь система возвращается к настройкам Emacs по умолчанию, где эта функция отключена.

Исходный текст

- Removed electric pair for prog mode It caused more problem than it solved while using. It doesn't work for all pairs of characters when surrounding selection. It's not context-aware, so it might insert quotes inside of quotes is clumsy. Reverting to Emacs' default (disabled).
