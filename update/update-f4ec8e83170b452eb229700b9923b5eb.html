Суммаризация (на русском)

Были реализованы два исправления ошибок: одно обеспечивает корректный запуск обновления токена OAuth, а другое добавляет определение MIME-типа и значение по умолчанию для URI файлов, используемых с LiteLLM, для соответствия требованиям бэкэнда Vertex AI. Кроме того, была добавлена новая функция для учетных данных OAuth2, позволяющая пользователям указывать `token_endpoint_auth_method` для аутентификации на конечной точке токенов сервера авторизации, при этом сохраняя обратную совместимость.
