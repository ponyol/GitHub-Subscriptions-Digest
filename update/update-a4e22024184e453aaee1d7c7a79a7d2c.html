This update officially releases `langgraph` and its related packages (now at `1.x.x`), enhancing error handling with durable resume capabilities after crashes. It also introduces `StateGraph.set_node_defaults()` for simplified graph-wide node policy configuration. Minor updates include CLI support for prerelease API versions and dependency bumps like `urllib3` and `langchain-core`, which incorporate security fixes. --- Это обновление официально выпускает `langgraph` и связанные с ним пакеты (теперь версии `1.x.x`), улучшая обработку ошибок с помощью надежного возобновления после сбоев. Также добавлен метод `StateGraph.set_node_defaults()` для упрощенной настройки политик узлов для всего графа. Второстепенные обновления включают поддержку предварительных версий API в CLI и обновление зависимостей, таких как `urllib3` и `langchain-core`, что включает исправления безопасности.
