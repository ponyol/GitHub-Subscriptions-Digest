Суммаризация (на русском)

This release introduces a comprehensive Role-Based Access Control (RBAC) system, gating access to API keys, authentication providers, webhooks, billing, and rate limit mutations based on organization roles. Significant improvements were made to credential error handling, providing users with actionable UI feedback, pausing schedules on errors, and refining the OAuth reauthentication flow. The Temporal workflow management was enhanced with an admin sync dashboard showing schedule states, `SyncId` search attributes, and a robust `SyncJobStateMachine` for state transitions. Additionally, the release improves system stability by preventing sync crashes due to embedding failures, sanitizing data for Vespa, and strengthening security against XSS and open redirect vulnerabilities. --- Этот выпуск внедряет комплексную систему управления доступом на основе ролей (RBAC), ограничивая доступ к ключам API, поставщикам аутентификации, вебхукам, управлению биллингом и мутациям лимитов запросов в зависимости от ролей организации. Значительные улучшения коснулись обработки ошибок учетных данных, предоставляя пользователям информативный интерфейс, приостанавливая расписания при ошибках и улучшая процесс повторной аутентификации OAuth. Управление рабочими процессами Temporal было расширено за счет панели администратора синхронизации, отображающей состояния расписаний, атрибуты поиска `SyncId` и надежную машину состояний `SyncJobStateMachine` для переходов состояний. Кроме того, релиз повышает стабильность системы, предотвращая сбои синхронизации из-за ошибок встраивания, очищая данные для Vespa и усиливая защиту от XSS и уязвимостей открытого перенаправления.
