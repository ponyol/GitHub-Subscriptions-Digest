Суммаризация (на русском)

Основной новой функцией является поддержка встраиваний LiteLLM, позволяющая использовать различные облачные провайдеры встраиваний и избегать локальных зависимостей, с настройкой через переменную `LITELLM_EMBEDDING_MODEL_NAME`. Сервис LiteLLM также получил значительные улучшения, включая асинхронные операции, улучшенную обработку ключей API и настраиваемые параметры встраивания (`max_tokens`, `dimensions`) через переменные окружения. Среди других важных обновлений – исправления загрузки моделей HuggingFace с `trust_remote_code=True` и добавление переменной `QWEN_REGION` для выбора конечных точек API для адаптера Qwen NLP.
