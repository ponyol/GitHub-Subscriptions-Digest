Суммаризация (на русском)

This release brings a range of improvements, including multiple bug fixes that address critical issues like session event duplication, bash command sandbox escapes, and a CVE in `go-containerregistry`. Key new features enhance agent capabilities with a "Claude Code" user skill, memory tools in the Go ADK runtime, API key passthrough, and global default service account settings. Additionally, significant refactoring was done, consolidating Go modules, upgrading Go to version 1.26.1, updating frontend dependencies, and enabling secure defaults for deployments. --- Этот выпуск содержит ряд улучшений, включая многочисленные исправления ошибок, устраняющие критические проблемы, такие как дублирование событий сеансов, выход из песочницы при выполнении команд bash и уязвимость CVE в `go-containerregistry`. Новые ключевые функции расширяют возможности агента за счет добавления пользовательского навыка "Claude Code", инструментов памяти в среде выполнения Go ADK, сквозной передачи ключей API и глобальных настроек учетных записей служб по умолчанию. Кроме того, была проведена значительная реструктуризация кода: консолидация модулей Go, обновление Go до версии 1.26.1, обновление внешних зависимостей и включение безопасных настроек по умолчанию для развертываний.
