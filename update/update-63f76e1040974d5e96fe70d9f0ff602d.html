This update introduces several key features and fixes, including a robust solution for parallel chunked storage uploads and new API endpoints for managing and resetting default email templates. A new "Insights" module with a CTA framework was added, alongside support for organization scopes in the console API and the ability to skip deployments based on commit patterns. The release also includes extensive refactoring of queue publishers, platform migration support, numerous dependency updates (e.g., Utopia platform, GraphQL, Audit), and various API specification and SDK improvements. --- Это обновление представляет несколько ключевых функций и исправлений, включая надежное решение для параллельной загрузки файлов по частям и новые API-конечные точки для управления и сброса стандартных шаблонов электронной почты. Был добавлен новый модуль «Insights» с фреймворком CTA, а также поддержка областей видимости организаций в консольном API и возможность пропускать развертывания по шаблонам коммитов.
