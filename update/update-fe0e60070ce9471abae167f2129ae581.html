Суммаризация (на русском)

This update significantly enhances agent capabilities and tooling. Key additions include new BashTool and RunSkillScriptTool for executing skill scripts, along with improved sandbox lifecycle management in the agent engine. The release also introduces interceptor frameworks for custom logic in agent execution, better integration for agent optimization, and support for injecting custom `google.genai.Client` into Gemini models. Numerous bug fixes and internal refactorings further improve stability and functionality. Russian: Это обновление значительно расширяет возможности агентов и инструментария. Ключевые дополнения включают новые `BashTool` и `RunSkillScriptTool` для выполнения скриптов навыков, а также улучшенное управление жизненным циклом песочниц в движке агентов. Релиз также представляет фреймворки перехватчиков для пользовательской логики в выполнении агентов, улучшенную интеграцию для оптимизации агентов и поддержку внедрения пользовательского `google.genai.Client` в модели Gemini. Многочисленные исправления ошибок и внутренние рефакторинги дополнительно повышают стабильность и функциональность.
