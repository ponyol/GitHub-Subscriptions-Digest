Суммаризация (на русском)

This release primarily focuses on enhancing language bindings, resolving numerous compilation errors, and refining argument handling across Kotlin-Android, Swift, Dart, Java, and other languages, often leveraging updates to the `alef` code generation tool. Key improvements include offloading WASM extraction to Web Workers for better demo performance, optimizing PDF processing by eliminating redundant image decompression and improving glyph fragmentation heuristics. Additionally, core functionalities were strengthened with fixes for default embedding models, chunk sizing, and broad `serde_json::Value` compatibility for `code_intelligence`, alongside various build, CI, and documentation updates. **Russian Translation:** Этот выпуск сосредоточен на улучшении привязок к различным языкам, исправлении многочисленных ошибок компиляции и уточнении обработки аргументов для Kotlin-Android, Swift, Dart, Java и других, часто используя обновления инструмента кодогенерации `alef`. Среди ключевых улучшений — перенос извлечения WASM в Web Workers для повышения производительности демо-версии, оптимизация обработки PDF за счет устранения избыточной декомпрессии изображений и улучшения эвристики фрагментации глифов. Кроме того, были усилены основные функции, касающиеся моделей встраивания по умолчанию, настройки размера блоков и широкой совместимости `serde_json::Value` для `code_intelligence`, а также внесены различные обновления в процесс сборки, CI и документацию.
