Суммаризация (на русском)

This release, Hindsight v0.5.0, significantly expands Hindsight's capabilities with new LLM providers such as `llama.cpp` for local inference and OpenRouter support, alongside a configurable `append` mode for document content concatenation. It introduces comprehensive CLI coverage, enhances the OpenClaw integration with improved configuration and session filtering, and includes crucial fixes for billing accuracy and PostgreSQL compatibility. Performance improvements, like capping entity fanout in recall, further optimize the system. Russian translation: Этот релиз, Hindsight v0.5.0, значительно расширяет возможности Hindsight за счет новых провайдеров LLM, таких как `llama.cpp` для локального вывода и поддержка OpenRouter, а также настраиваемого режима `append` для конкатенации содержимого документов. Он вводит полное покрытие CLI, улучшает интеграцию OpenClaw благодаря усовершенствованной конфигурации и фильтрации сессий, а также включает критические исправления для точности расчетов и совместимости с PostgreSQL. Улучшения производительности, такие как ограничение расширения графа сущностей при вызове `recall`, дополнительно оптимизируют систему.

This is fine against a direct Postgres connection but fails intermittently when the caller is routed through PgBouncer in transaction pool mode: CREATE TEMP TABLE IF NOT EXISTS _ann_seeds (...) -- backend A TRUNCATE _ann_seeds -- backend B -> FAILS Temp tables are session-scoped to the backend that created them. In PgBouncer transaction mode the backend is only pinned to the client for the duration of an actual transaction, so between standalone statements the pooler can (and under concurrency, will) rebind the client to a different backend.
