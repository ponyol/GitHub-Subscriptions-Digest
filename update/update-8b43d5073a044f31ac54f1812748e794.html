Суммаризация (на русском)

Многие PR-запросы по новым средствам разработки в настоящее время включают интеграции, которые неправильно загружают навыки, что препятствует их автоматическому срабатыванию. Для решения этой проблемы будет добавлен приемочный тест, проверяющий автоматическое срабатывание навыков. Кроме того, PR-запросы по новым средствам разработки теперь будут требовать стенограмму сеанса для обеспечения корректного поведения навыков.

Исходный текст

- Require session transcript for new-harness PRs Most new-harness PRs ship integrations that copy skill files or wrap with `npx skills` instead of loading the using-superpowers bootstrap at session start. Those integrations look like they work but skills never auto-trigger. Add an acceptance test ("Let's make a react todo list" must auto-trigger brainstorming in a clean session) and require the transcript in the PR.
