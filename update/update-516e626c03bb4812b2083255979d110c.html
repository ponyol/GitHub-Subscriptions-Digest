Суммаризация (на русском)

Это обновление значительно расширяет возможности ИИ, прежде всего за счет интеграции с API Black Forest Labs (BFL) FLUX для расширенной генерации и редактирования изображений, а также улучшений во взаимодействии с существующими агентами ИИ и интеграции Gemini. Новые функции обработки данных включают UDF для работы с ограничивающими рамками и UDA для конкатенации видео. Релиз также направлен на повышение стабильности системы и удобства для разработчиков, предлагая исправления для сериализации данных, улучшенное логирование, механизмы повторных попыток транзакций и улучшенную поддержку многопоточности.
