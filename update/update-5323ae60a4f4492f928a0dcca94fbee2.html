Выпуск v1.14.0 добавляет поддержку провайдера CodeBuddy Code и надёжную систему аутентификации WebUI, оснащённую хешированием Argon2id, сессиями, защитой от CSRF, режимом только для чтения и поддержкой базового пути. Обновление также устраняет различные проблемы с обновлением и сбоями WebUI, исправляет ввод IME в Linux и добавляет рендеринг для новых типов контента.
