This release introduces significant database enhancements, primarily enabling read-replica routing for Prisma DBs with robust IAM token management and graceful degradation during outages. The update also focuses on security and stability, improving access control, input validation, and error handling across the proxy. Furthermore, it expands observability features, integrates new models like Grok-4.3 and NVIDIA Riva STT, and adds support for OpenAI's Realtime API. --- **Russian Translation:** В этом выпуске представлены значительные улучшения базы данных, в первую очередь реализующие маршрутизацию операций чтения на реплики для баз данных Prisma, с надежным управлением токенами IAM и плавной деградацией в случае сбоев. Обновление также уделяет внимание безопасности и стабильности, улучшая контроль доступа, валидацию входных данных и обработку ошибок на уровне прокси.
