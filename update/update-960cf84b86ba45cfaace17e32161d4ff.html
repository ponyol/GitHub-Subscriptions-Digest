Суммаризация (на русском)

This update significantly enhances the platform's performance, resilience, and flexibility. Key improvements include implementing routing hints for faster initial proxy connections and replacing multi-round-trip sandbox command execution with a single, efficient streaming POST request, drastically reducing latency. Additionally, the update improves desktop session resilience, fixes an SSH client panic, and makes sandbox images configurable, alongside adding local integration tests and SSH client enhancements. --- Это обновление значительно повышает производительность, отказоустойчивость и гибкость платформы. Ключевые улучшения включают внедрение подсказок маршрутизации для более быстрого начального подключения прокси и замену многоэтапного выполнения команд в песочнице одним эффективным потоковым POST-запросом, что резко снижает задержку. Кроме того, обновление повышает устойчивость настольных сессий, исправляет панику SSH-клиента, делает образы песочницы настраиваемыми, а также добавляет локальные интеграционные тесты и улучшения SSH-клиента.

- Use routing hints to skip proxy placement lookup on first request (#638) ## Summary Client-side implementation of [compute-engine-internal#680](https://github.com/tensorlakeai/compute-engine-internal/pull/680). When the server is configured with a hint signing key, the sandbox create/claim response now carries a short-lived `routing_hint` HMAC-SHA256 token. This PR threads that token through to the first proxy request as `X-Tensorlake-Route-Hint`, letting the sandbox proxy route directly to the dataplane without an Indexify placement lookup. - **Rust cloud-sdk** (`crates/cloud-sdk/`): adds `routing_hint` to `CreateSandboxResponse`, adds `with_routing_hint()` to `SandboxProxyClient`, includes `X-Tensorlake-Route-Hint` on all proxy requests when a hint is present - **Rust Python bindings** (`crates/rust-cloud-sdk-py/`): exposes `routing_hint` param on `CloudSandboxProxyClient` - **Python SDK** (`src/tensorlake/sandbox/`): parses `routing_hint` from create response, threads it through `connect()` into the proxy client; `create_and_connect()` fast-paths when status is already `running` (skips the redundant poll RTT) - **TypeScript SDK** (`typescript/src/`): same pattern — `routingHint` on `CreateSandboxResponse`, `SandboxOptions`, and `HttpClientOptions`; `connect()` accepts the hint; `createAndConnect()` has the same fast path The hint has a 5-second TTL and the proxy falls through silently on any failure, so no client-visible errors on expiry or misconfiguration. ## Test plan -
