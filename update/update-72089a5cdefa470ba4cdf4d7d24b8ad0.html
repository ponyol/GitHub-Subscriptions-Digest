Суммаризация (на русском)

This update introduces major new capabilities such as in-app rendering and editing of Docx files, and a significantly enhanced "Code Mode" featuring in-chat toggles, persistent coding agent sessions, and refined user experience. It also brings redesigned web search and tool-call cards, expanded Gmail integration (send, archive, delete), and a refactored file system for broader tool access with permission controls. Furthermore, the release improves LLM context persistence for conversation stability, addresses OAuth reconnection issues, and includes various UI/UX fixes and performance enhancements. --- Это обновление представляет значительные новые возможности, такие как рендеринг и редактирование файлов Docx прямо в приложении, а также значительно улучшенный «Режим кода» с внутричатовыми переключателями, постоянными сессиями агентов кодирования и доработанным пользовательским интерфейсом. Оно также включает переработанные карточки веб-поиска и вызовов инструментов, расширенную интеграцию с Gmail (отправка, архивирование, удаление) и переработанную файловую систему для более широкого доступа к инструментам с контролем разрешений. Кроме того, релиз улучшает сохранение контекста LLM для стабильности разговоров, устраняет проблемы с переподключением OAuth и содержит различные исправления UI/UX и улучшения производительности.
