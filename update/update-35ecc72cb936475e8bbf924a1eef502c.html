Суммаризация (на русском)

This release introduces extensive updates to telemetry, adding new metrics for GenAI agent invocations, refactoring existing ones, and ensuring consistent log exports. It significantly enhances mTLS support and OAuth credential handling across Google API clients and tools, addressing critical authentication stability issues. Key improvements to agent and workflow management include better language detection, more flexible tool node inputs, and fixes to prevent empty model responses after skill loading. Additionally, performance optimizations were implemented for LLM request processing. Russian translation: Этот выпуск содержит обширные обновления телеметрии, добавляя новые метрики для вызовов агентов GenAI, рефакторинг существующих и обеспечивая единообразный экспорт журналов. Он значительно улучшает поддержку mTLS и обработку учетных данных OAuth для клиентов и инструментов Google API, устраняя критические проблемы стабильности аутентификации. Основные улучшения в управлении агентами и рабочими процессами включают улучшенное определение языка агентов, более гибкие входные данные для узлов инструментов и исправления, предотвращающие пустые ответы моделей после загрузки навыка. Дополнительно были реализованы оптимизации производительности для обработки запросов LLM.
