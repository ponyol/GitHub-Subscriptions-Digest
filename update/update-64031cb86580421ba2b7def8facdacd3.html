Суммаризация (на русском)

This update primarily introduces advanced session targeting for cron jobs, enabling them to bind to specific or persistent user sessions. Key improvements include critical fixes for gateway request handling, preventing duplicate Feishu replies, and hardening browser session validation. The release also features numerous other bug fixes, refactors, and test enhancements to improve overall stability and code quality across various components. --- Это обновление в основном представляет расширенное таргетирование сессий для заданий cron, позволяя им привязываться к определенным или постоянным пользовательским сессиям. Ключевые улучшения включают критические исправления для обработки запросов шлюза, предотвращение дубликатов ответов в Feishu и усиление валидации сессий браузера. Релиз также содержит многочисленные другие исправления ошибок, рефакторинги и улучшения тестов для повышения общей стабильности и качества кода в различных компонентах.
