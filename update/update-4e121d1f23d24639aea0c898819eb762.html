Signed-off-by: James Curtis <jxcurtis@amazon.co.uk> - fix(aarch64): return error when PMU V3 feature is enabled On ARM, the PMU V3 may be enabled via kvm_vcpu_init->features[0] bit 3. This feature requires the hypervisor to do additional setup, making another ioctl to properly initialise the PMU. Firecracker does not handle this case, so setting the feature bit causes KVM to crash with EINVAL on KVM_RUN. Return an 'unsupported' error if this bit is set, to help prevent users from encountering the KVM crash.
