Суммаризация (на русском)

This update introduces a new "Beams" feature and significantly enhances scoped role assignments and access list management, providing more granular control over user permissions and SSH capabilities. It also expands cloud integration with added support for Azure regions and visible labels for Azure and GCP virtual machines. Key security improvements include stricter IP pinning enforcement for SSH connections and mandatory key ownership proof before MFA checks. Additionally, the release contains various UI/backend fixes, dependency updates, and improved usage reporting for identity security events. --- Это обновление представляет новую функцию "Beams" и значительно улучшает управление назначениями ролей по областям действия (scoped role assignments) и списками доступа, обеспечивая более гранулированный контроль над разрешениями пользователей и возможностями SSH. Также расширена облачная интеграция с добавленной поддержкой регионов Azure и видимых меток для виртуальных машин Azure и GCP. Ключевые улучшения безопасности включают ужесточение привязки IP-адресов (IP pinning) для SSH-соединений и обязательную проверку владения ключом перед MFA проверками. Кроме того, релиз содержит различные исправления пользовательского интерфейса/бэкенда, обновления зависимостей и улучшенную отчетность по событиям безопасности идентификационных данных.
