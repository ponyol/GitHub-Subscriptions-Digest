Суммаризация (на русском)

This update introduces comprehensive support for DeepSeek-OCR within the VLM pipeline, allowing for advanced parsing of annotated markdown and table structures. It also expands hardware compatibility with XPU device support for Intel GPUs and adds an option to report detailed execution timings. Key improvements include enhanced error logging with page numbers, new meta format for enrichment annotations, and fixes for dependencies and DOCX handling. --- Это обновление добавляет полную поддержку DeepSeek-OCR в конвейере VLM, что позволяет выполнять расширенный анализ аннотированного markdown и табличных структур. Оно также расширяет аппаратную совместимость с поддержкой устройств XPU для графических процессоров Intel и добавляет опцию для вывода подробных данных о времени выполнения. Среди ключевых улучшений — расширенное логирование ошибок с указанием номеров страниц, новый метаформат для аннотаций обогащения, а также исправления для зависимостей и обработки DOCX.
