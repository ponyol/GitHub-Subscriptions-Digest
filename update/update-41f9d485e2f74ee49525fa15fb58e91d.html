Это обновление добавляет кодирование вложений Mistral, улучшает обработку ошибок API и поддержку LaTeX. Важное изменение — переход на вызов нативных инструментов с отказом по умолчанию (opt-out), что активирует его для большинства провайдеров. Ключевые исправления включают предотвращение предупреждений о памяти EventEmitter в фреймворке агентов AIbitat при массовом веб-скрапинге и усиление безопасности вложений за счет возможности отклонения запросов из незадекларированных источников.
