Суммаризация (на русском)

This release marks a significant transition, making the `airframe` engine a public `crates.io` dependency and the default feature for GPU support in `shimmy`. This shift necessitated a comprehensive overhaul of the CI/CD pipeline, eliminating private path dependencies and access tokens, and greatly improving build robustness, especially for Linux ARM64 platforms. Additionally, documentation was updated to reflect the new architecture, alongside numerous fixes for dependencies, code quality, and Docker builds. --- Этот выпуск знаменует собой значительный переход, делая движок `airframe` публичной зависимостью `crates.io` и функцией по умолчанию для поддержки GPU в `shimmy`. Этот переход потребовал всеобъемлющей переработки конвейера CI/CD, удаления приватных зависимостей по пути и токенов доступа, а также значительного повышения надежности сборки, особенно для платформ Linux ARM64. Кроме того, была обновлена документация, отражающая новую архитектуру, наряду с многочисленными исправлениями для зависимостей, качества кода и сборок Docker.
