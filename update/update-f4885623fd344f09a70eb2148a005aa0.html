Version 3.4.0 introduces pluggable vector backends (Qdrant, pgvector, sqlite_exact), a Docker image, and a tool to normalize legacy wing names. The update significantly enhances data integrity by preventing drawer ID collisions and improving ChromaDB stability through fixes like pagination and efficient status queries. Additionally, publishing workflows are now more robust with manual triggers, PyPI Trusted Publishing, and refined Docker image builds. *** Версия 3.4.0 представляет подключаемые векторные бэкенды (Qdrant, pgvector, sqlite_exact), образ Docker и инструмент для нормализации устаревших имен "крыльев". Обновление значительно повышает целостность данных, предотвращая коллизии ID "ящиков" и улучшая стабильность ChromaDB за счет таких исправлений, как пагинация и эффективные запросы статуса. Кроме того, рабочие процессы публикации стали более надежными благодаря ручным триггерам, доверенной публикации в PyPI и улучшенным сборкам образов Docker.
