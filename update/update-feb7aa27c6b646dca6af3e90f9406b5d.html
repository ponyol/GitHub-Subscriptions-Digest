Этот релиз добавляет новые интеграции для SambaNova и PrivateModeAI, значительно улучшает использование API LMStudio и вводит всесторонние возможности редактирования подключений SQL-агентов, включая предотвращение дубликатов. Ключевые улучшения пользовательского интерфейса включают переработанную страницу входа, горячие клавиши для навигации по истории чата и переработанные компоненты переключателей, а также исправления различных сбоев пользовательского интерфейса и проблем с прокруткой. Обновление также содержит обширные улучшения качества кода, уточненную проверку имен пользователей и сохранение настроек контекста Ollama.
