Суммаризация (на русском)

This release significantly expands backend capabilities with new additions like MLX-distributed, ace-step, and fish-speech, alongside major updates to `llama.cpp` and `stable-diffusion.cpp`, while removing the HuggingFace backend. It addresses critical issues such as relative model path resolution, image processing in `diffusers`, and model isolation. New features include WebRTC support, enhanced UI for agents and apps, shell completion, and a dedicated `--data-path` CLI flag for persistent data, complemented by extensive new documentation. --- Этот выпуск значительно расширяет возможности бэкендов, добавляя MLX-distributed, ace-step и fish-speech, наряду с важными обновлениями `llama.cpp` и `stable-diffusion.cpp`, при этом удаляя бэкенд HuggingFace. Он устраняет критические проблемы, такие как разрешение относительных путей моделей, обработка изображений в `diffusers` и изоляция моделей. Среди новых функций — поддержка WebRTC, улучшенный пользовательский интерфейс для агентов и приложений, автодополнение командной строки и выделенный флаг `--data-path` для постоянных данных, что дополняется обширной новой документацией.
