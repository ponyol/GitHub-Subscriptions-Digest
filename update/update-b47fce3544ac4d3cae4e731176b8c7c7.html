The latest Studio update introduces a major GitHub integration, allowing users to scrape repository data (issues, PRs, commits) to generate synthetic support Q&A pairs, featuring a new "Easy mode" for simplified recipe creation. The release also brings significant enhancements to model control and stability, including a robust 'stop' button for generation, removal of the default 4096-token response cap, and improved AMD GPU detection. Additionally, it refines the overall UI/UX across chat composition, scrolling, and sidebar navigation, along with various critical bug fixes and performance optimizations. --- Последнее обновление Studio представляет крупную интеграцию с GitHub, позволяя пользователям собирать данные репозиториев (задачи, запросы на слияние, коммиты) для генерации синтетических пар "вопрос-ответ" для поддержки, с новым "Упрощенным режимом" для легкого создания рецептов. Релиз также содержит значительные улучшения в управлении моделями и стабильности, включая надежную кнопку "стоп" для остановки генерации, снятие ограничения на 4096 токенов в ответах по умолчанию и улучшенное обнаружение графических процессоров AMD. Кроме того, были доработаны общий пользовательский интерфейс и опыт (UI/UX) в области композиции чатов, прокрутки и навигации по боковой панели, а также внесены различные критические исправления ошибок и оптимизации производительности.
