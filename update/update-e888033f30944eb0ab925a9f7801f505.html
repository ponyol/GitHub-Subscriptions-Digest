Суммаризация (на русском)

This update introduces significant new features for Declarative Agents, primarily allowing users to specify the agent's runtime (Go or Python) via a new `runtime` field in the CRD. Go agents offer substantially faster startup times. Additionally, Human-in-the-Loop capabilities have been added, enabling agents to ask users questions and confirm actions. The update also includes support for built-in prompts and prompt templates, enhancing agent configuration flexibility. --- Это обновление представляет собой значительные новые функции для декларативных агентов, в первую очередь позволяя пользователям указывать среду выполнения агента (Go или Python) через новое поле `runtime` в CRD. Агенты на Go обеспечивают значительно более быстрое время запуска. Кроме того, были добавлены возможности взаимодействия человека с агентом (Human-in-the-Loop), позволяющие агентам задавать вопросы пользователям и подтверждать действия. Обновление также включает поддержку встроенных и шаблонных подсказок, что повышает гибкость конфигурации агентов.
