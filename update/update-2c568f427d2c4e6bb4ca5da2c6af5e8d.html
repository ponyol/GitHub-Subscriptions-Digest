Суммаризация (на русском)

This release significantly enhances document processing capabilities by adding support for parsing and rendering native Excel charts as images. New input backends were introduced for Box Notes (.boxnote) and DocLang archives (.dclx), complementing existing formats. Additionally, the command-line interface now supports outputting document content as chunks in JSONL format, alongside numerous bug fixes and stability improvements across various document types. Russian: Этот релиз значительно расширяет возможности обработки документов, добавляя поддержку парсинга и рендеринга нативных диаграмм Excel в виде изображений. Были введены новые бэкэнды для входных форматов Box Notes (.boxnote) и архивов DocLang (.dclx), дополняющие существующие форматы. Кроме того, интерфейс командной строки теперь поддерживает вывод содержимого документов в виде фрагментов в формате JSONL, а также содержит многочисленные исправления ошибок и улучшения стабильности для различных типов документов.
