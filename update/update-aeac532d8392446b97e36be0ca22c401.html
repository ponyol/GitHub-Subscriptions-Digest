The latest updates primarily address critical bugs, fixing issues where the recall API returned HTTP 409 errors when using trace or graph context, and resolving LLM connectivity check failures for Anthropic models. Significant infrastructure improvements include replacing Kuzu with Ladybug as the default graph database, implementing LLM client caching for better performance, and enhancing Docker compatibility. These releases also expand Python version support up to 3.14 by resolving various dependency conflicts and generally improve the overall stability and reliability of the system. --- Последние обновления в основном устраняют критические ошибки, исправляя случаи, когда API отзыва (recall) возвращал ошибки HTTP 409 при использовании контекста трассировки или графа, а также решая проблемы с проверкой подключения LLM для моделей Anthropic. Значительные улучшения инфраструктуры включают замену Kuzu на Ladybug в качестве графовой базы данных по умолчанию, реализацию кэширования клиентов LLM для повышения производительности и улучшение совместимости с Docker. Эти релизы также расширяют поддержку версий Python до 3.14 за счет разрешения различных конфликтов зависимостей и в целом повышают общую стабильность и надежность системы.
