Этот релиз включает значительные улучшения конфигурации обратного прокси, совместимости с Docker и общей стабильности. Внесены всеобъемлющие настройки таймаутов для Caddy, Traefik и Nginx, а также стандартизированы параметры прокси для использования стандартных переменных окружения `HTTP_PROXY`/`HTTPS_PROXY`. Новые функции, такие как каскадное удаление заметок с предварительным просмотром и обнаружение HTML-контента в буфере обмена, улучшают взаимодействие с пользователем. Также исправлены критические ошибки, связанные с сетью Docker, обработкой ошибок API и конфликтами асинхронных циклов.
