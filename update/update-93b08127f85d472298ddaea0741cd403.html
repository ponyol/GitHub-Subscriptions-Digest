Суммаризация (на русском)

Это обновление значительно улучшает возможности OCR, снижая использование памяти и добавляя постраничные переопределения для PDF-файлов смешанного качества, наряду с многочисленными исправлениями для Tesseract и PaddleOCR. Оно также представляет новый API для рендеринга PDF-страниц во всех языковых привязках и добавляет поддержку извлечения для файлов PST и JSONL. Релиз включает обширные улучшения паритета API, расширенное тестовое покрытие и критические исправления CI/сборки, особенно для сред Windows, что повышает общую надежность и полноту функций.
