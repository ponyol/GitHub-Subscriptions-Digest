Суммаризация (на русском)

The project introduced an ephemeral SQLite store for transient issues (wisps/molecules) to prevent Dolt database bloat and overhauled its synchronization, replacing the old JSONL pipeline with a native "Dolt-in-Git" approach. Key efforts focused on stabilizing the Dolt backend, addressing numerous locking deadlocks, improving query performance (e.g., for `bd list` and dependencies), and resolving various initialization and migration issues. Further enhancements include enabling CGO for release builds, fixing cross-compilation challenges, significant code cleanup by removing dead components, and refactoring core storage interfaces for better maintainability. --- Проект представил временное хранилище SQLite для транзитных задач (wisps/molecules), чтобы предотвратить раздувание базы данных Dolt, и обновил свою синхронизацию, заменив старый конвейер JSONL на нативный подход "Dolt-in-Git". Основные усилия были направлены на стабилизацию бэкенда Dolt, устранение многочисленных тупиков блокировок, повышение производительности запросов (например, для `bd list` и зависимостей) и решение различных проблем инициализации и миграции. Дальнейшие улучшения включают включение CGO для релизных сборок, устранение проблем кросс-компиляции, значительную очистку кода путем удаления неиспользуемых компонентов и рефакторинг основных интерфейсов хранения для улучшения поддерживаемости.
