Суммаризация (на русском)

This release primarily focuses on introducing new features like Voyage AI's rerank API, an expanded Containers API for file management and code interpretation, and UI settings management. Significant improvements include enhanced guardrail masking, better handling of Anthropic multi-turn conversations, and a critical performance fix for spend log memory usage. The update also brings various API-specific fixes, pricing corrections, and expanded support for Gemini endpoints and Azure AI Search. --- Этот выпуск в основном сосредоточен на внедрении новых функций, таких как API переранжирования Voyage AI, расширенный API контейнеров для управления файлами и интерпретации кода, а также управление настройками пользовательского интерфейса. Значительные улучшения включают улучшенное маскирование защиты (guardrail), более эффективную обработку многошаговых диалогов Anthropic и критическое исправление производительности для снижения использования памяти журналами расходов. Обновление также содержит различные исправления, специфичные для API, корректировки цен и расширенную поддержку конечных точек Gemini и Azure AI Search.
