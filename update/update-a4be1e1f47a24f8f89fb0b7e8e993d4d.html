Суммаризация (на русском)

Это обновление представляет новые провайдеры LLM и агентов, включая Z.ai и поддержку ключей API AWS Bedrock, а также значительные улучшения для существующих, таких как Ollama (парсинг контента "thinking") и OpenRouter (идентификация пользователя). Оно также направлено на повышение эффективности за счет внедрения кэширования запросов для моделей Anthropic и оптимизации условий кэширования для LMStudio/Ollama, параллельно исправляя различные ошибки. Кроме того, добавлены новые интеграции для веб-поиска SerpApi и коннектор данных Paperless ngx.
