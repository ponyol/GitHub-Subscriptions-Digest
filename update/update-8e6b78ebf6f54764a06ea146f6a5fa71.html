Release v1.0.3 promotes accumulated development work to the main branch. It introduces a dataset queue for managing concurrent operations, robustifies embedding operations with fixes for `OpenAICompatibleEmbeddingEngine` and better context handling, and parallelizes database writes for improved performance. Database reliability is enhanced through comprehensive vector database migrations, LanceDB schema drift fixes, and new table migrations. Frontend updates include a redesigned dashboard, integrated API key management, and improved dataset sharing. --- **Russian translation:** Выпуск v1.0.3 переносит накопленные разработки в основную ветку.
