Суммаризация (на русском)

This major update introduces an embedded MCP server for zero-setup harness integration and robust end-to-end token/cost usage tracking with a new tray UI. The CLI has been significantly enhanced with new commands like `af show-requirements`, `af wait`, `af catalog`, and improved diagnostics, while the desktop app features a redesigned UI and automatic control plane port management. Key security vulnerabilities, including SSRF, have been fixed, and SDKs now support model variants and offer a complete TypeScript trigger system. --- Это обновление включает встроенный сервер MCP для интеграции с тестовым стендом без дополнительной настройки и надежный сквозной учет использования токенов/стоимости с новым интерфейсом в системном трее. Интерфейс командной строки (CLI) значительно улучшен новыми командами, такими как `af show-requirements`, `af wait`, `af catalog`, и улучшенными средствами диагностики, в то время как десктопное приложение получило переработанный пользовательский интерфейс и автоматическое управление портом плоскости управления. Устранены ключевые уязвимости безопасности, включая SSRF, а SDK теперь поддерживают варианты моделей и предлагают полноценную систему триггеров на TypeScript.
