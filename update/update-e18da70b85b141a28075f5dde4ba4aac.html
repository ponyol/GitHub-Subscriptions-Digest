Суммаризация (на русском)

This update significantly enhances agent capabilities and user experience. Channels now support multi-agent routing and guided setup across Slack, Telegram, and Discord, while a new native Browser Use feature offers persistent, secure per-agent web sessions. Key improvements include auto-generated chat titles, grouped activity, chat pinning, and multi-selection in the UI. Additionally, the release delivers numerous performance fixes, improved knowledge base management with auto-categorization, and support for OpenAI-compatible TTS servers. --- Это обновление значительно расширяет возможности агентов и улучшает пользовательский опыт. Каналы теперь поддерживают маршрутизацию между несколькими агентами и пошаговую настройку для Slack, Telegram и Discord, а новая встроенная функция «Использование браузера» обеспечивает постоянные, безопасные веб-сессии для каждого агента. Основные улучшения интерфейса включают автоматически генерируемые заголовки чатов, группировку активности агентов, закрепление чатов и множественный выбор. Кроме того, выпуск содержит множество исправлений производительности, улучшенное управление базой знаний с автоматической категоризацией и поддержку TTS-серверов, совместимых с OpenAI.
