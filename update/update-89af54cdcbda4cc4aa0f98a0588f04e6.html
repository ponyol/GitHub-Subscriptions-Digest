Суммаризация (на русском)

Два новых изменения улучшают согласованность данных для vfiles. Во-первых, перед любой операцией записи (например, создание поста или реакции) система теперь синхронно загружает последнюю версию из удаленного источника, предотвращая перезапись параллельных изменений. Во-вторых, при открытии URL vfile всегда загружается удаленная версия (если доступна сеть), что исключает использование устаревшего локального кеша и предотвращает потерю данных при работе с нескольких клиентов.

Исходный текст

- feat(vfile): sync from remote before every write operation Add org-social-file--ensure-open-and-fresh, which synchronously downloads the latest version from the remote before any write action (new post, poll, reaction, boost, migration). This eliminates the window where Emacs could overwrite concurrent edits made from another client while the file was already open. - fix(vfile): remote is always source of truth when opening When using a vfile URL, always download from the remote before opening instead of reusing a stale local cache. This prevents silent data loss when editing from multiple clients (e.g. iOS). Falls back to cache if the network is unreachable.
