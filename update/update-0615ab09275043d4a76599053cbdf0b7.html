Суммаризация (на русском)

This release greatly enhances xberg's document processing and retrieval, introducing automatic OCR for scanned PDFs and new SPLADE sparse and ColBERT late-interaction retrieval modes. It significantly boosts reliability and security through enforced SHA256 checksums for all model downloads, a HuggingFace download watchdog, and critical CI/publishing fixes. Other notable changes include defaulting to PP-OCRv6, extensive model self-hosting, improved support for Jupyter and various markdown formats, and migration documentation. --- **Russian Translation:** Этот релиз значительно расширяет возможности xberg по обработке документов и поиску, вводя автоматическое распознавание текста (OCR) для отсканированных PDF-файлов и новые режимы поиска SPLADE sparse и ColBERT late-interaction. Он значительно повышает надежность и безопасность благодаря принудительной проверке контрольных сумм SHA256 для всех загружаемых моделей, механизму контроля загрузок HuggingFace и критическим исправлениям CI/публикации. Среди других заметных изменений — использование PP-OCRv6 по умолчанию, обширный собственный хостинг моделей, улучшенная поддержка Jupyter и различных форматов Markdown, а также документация по миграции.

Every check applied to a native text layer was lexical -- replacement chars, alphanumeric ratio, word fragmentation, consecutive repeats -- so that text passed and OCR never ran. The only escape was force_ocr, which is all-or-nothing and degrades clean PDFs. Nothing asked the question that settles it: is this page a picture of a document? Grade each page on raster coverage, whether its text layer is hidden or absent, its image codec, and the document producer. Neither signal works alone. A slide with a full-bleed background image is entirely raster but its text is visible, so it scores 0.50 and is never OCR'd by default. A scanned page under a hidden sidecar has lexically perfect text, so it scores 0.85. Detection is two-stage, so cost tracks how image-like a document is. A prefilter reads image placements without decoding pixels (~130us/page) and only image-dominated pages pay for content-stream inspection. A 455-page text book inspects one page instead of all 455. PdfMetadata gains scanned_confidence and scanned_pages so callers can tell beforehand. ExtractionConfig gains ocr_strategy: the default `auto` preserves today's behaviour exactly, and `scanned_pages { min_confidence }` additionally OCRs detected scans while leaving the rest on native text. The selected page set is the union of detected scans and pages failing today's quality gate, so it is never a subset of current behaviour. Detection is advisory and infallible: a page that cannot be read contributes no evidence rather than failing the extraction, and the classification call runs under the existing panic guard. It identifies that a scanner produced a text layer, not whether that text is accurate; a page carrying a good hidden sidecar is OCR'd too.
