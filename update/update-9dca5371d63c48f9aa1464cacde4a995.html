Суммаризация (на русском)

This extensive update for LiteLLM brings significant improvements across performance, security, and UI. Key changes include comprehensive Vitest coverage for cost tracking settings, several streaming latency optimizations, and critical fixes for JWT authentication and OIDC discovery. It also introduces robust RBAC for agent management, a new Projects page with access group synchronization, and defaults the Multi-Cloud Proxy to public access. Various other fixes cover Bedrock integration, caching, and support for new AI models. --- Это обширное обновление LiteLLM значительно улучшает производительность, безопасность и пользовательский интерфейс. Ключевые изменения включают полное покрытие Vitest для настроек отслеживания затрат, несколько оптимизаций задержки стриминга и критические исправления для аутентификации JWT и обнаружения OIDC. Также добавлены надежный RBAC для управления агентами, новая страница "Проекты" с синхронизацией групп доступа и установка по умолчанию публичного доступа для Multi-Cloud Proxy. Различные другие исправления касаются интеграции с Bedrock, кэширования и поддержки новых моделей ИИ.
