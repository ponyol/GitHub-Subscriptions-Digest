Суммаризация (на русском)

This update, leading to v0.37.0, introduces several new features, including comprehensive `crush stats` with provider breakdowns, automatic LSP discovery, and enhanced session management with file tracking, prompt history, and the ability to delete sessions. It also significantly improves the UI with multi-file drag & drop support for Windows, new command dialogs, and numerous bug fixes across layout, navigation, and error handling. *** Это обновление, ведущее к версии v0.37.0, представляет несколько новых функций, включая всеобъемлющую статистику `crush stats` с разбивкой по провайдерам, автоматическое обнаружение LSP и улучшенное управление сеансами с отслеживанием файлов, историей подсказок и возможностью удаления сеансов. Оно также значительно улучшает пользовательский интерфейс благодаря поддержке перетаскивания нескольких файлов для Windows, новым диалогам команд и множеству исправлений ошибок, касающихся макета, навигации и обработки ошибок.
