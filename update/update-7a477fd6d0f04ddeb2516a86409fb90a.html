Суммаризация (на русском)

This update significantly refines task execution support (SEP-1686) across various server configurations. A new `execution` field was added to the base `Tool` class to preserve task metadata, especially when tools are forwarded. To prevent naming conflicts in multi-mount setups, Docket function names are now prefixed for mounted servers, and a race condition in mounted server task result handling was fixed by sharing the parent's Docket. Importantly, task execution is now explicitly forbidden for proxies due to its complexity, while mounted servers retain full task support. *** Это обновление значительно улучшает поддержку выполнения задач (SEP-1686) в различных серверных конфигурациях. В базовый класс `Tool` добавлено новое поле `execution` для сохранения метаданных выполнения задач, особенно при пересылке инструментов. Чтобы предотвратить конфликты имен в конфигурациях с множественным монтированием, имена функций Docket для смонтированных серверов теперь имеют префиксы, а также было исправлено состояние гонки при обработке результатов задач смонтированных серверов за счет совместного использования Docket родителя. Важно отметить, что выполнение задач теперь явно запрещено для прокси из-за его сложности, в то время как смонтированные серверы сохраняют полную поддержку задач.
