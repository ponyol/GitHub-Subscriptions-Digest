- Fix WebSocketLogger event loop starvation when no clients are subscribed The start() drain loop processed queued messages without yielding to the event loop when Semaphore.acquire() and Lock.acquire() completed without contention (both return immediately without yielding in CPython). This caused progressive latency degradation over hours of usage as log message bursts grew larger with more guidelines and sessions. The fix short-circuits when no subscribers exist—skipping both lock acquisitions—and yields via asyncio.sleep(0) to prevent starvation.
