Суммаризация (на русском)

This release introduces a wide range of new integrations, including Google Tasks, BigQuery, Attio CRM, Gong, Devin for autonomous coding, Google Translate, and Hex, alongside significant enhancements for Confluence and other Google services. Key workflow improvements include lock/unlock features, expandable child workflow logs, and support for multiple credentials per provider. The update also features crucial fixes for data handling in Confluence, call-chain propagation, improved Redis stability, and strengthened security measures like SSRF prevention and public API access controls. Database optimizations and UI/UX refinements further enhance the platform's reliability and developer experience. --- Этот выпуск содержит широкий спектр новых интеграций, включая Google Задачи, BigQuery, Attio CRM, Gong, Devin для автономного кодирования, Google Переводчик и Hex, а также значительные улучшения для Confluence и других сервисов Google. Основные улучшения рабочего процесса включают функции блокировки/разблокировки, расширяемые логи дочерних рабочих процессов и поддержку нескольких учетных данных для каждого провайдера. Обновление также включает важные исправления для обработки данных в Confluence, распространения цепочки вызовов, повышения стабильности Redis и усиления мер безопасности, таких как предотвращение SSRF и контроль доступа к публичному API. Оптимизация базы данных и улучшения пользовательского интерфейса дополнительно повышают надежность платформы и удобство для разработчиков.
