On Windows Git Bash this took 60+ seconds, freezing terminal input even with async hooks. Replaced with bash parameter substitution (${s//old/new}) which runs each pattern as a single C-level pass. 7x faster on macOS, expected to be dramatically faster on Windows Git Bash where the original caused the worst hangs. Multiple users confirmed this workaround.
