Суммаризация (на русском)

This release significantly enhances model building and quantization, including fixes for GPT-OSS CUDA QMoE weights, support for INT8 precision, and WebGPU KV cache quantization. Performance is improved through FP16 I/O for Nemotron, shared-buffer KV cache for LFM2, and specific optimizations for Phi-4 models on TRT-RTX, while also implementing `no_repeat_ngram_size` for CPU search. Additionally, it improves model package detection, standardizes RoPE parameter handling, and allows opting out of DML graph capture for better debugging. --- Этот выпуск значительно улучшает сборку моделей и квантование, включая исправления для весов QMoE GPT-OSS CUDA, поддержку точности INT8 и квантование KV-кэша WebGPU. Производительность повышена за счет ввода/вывода FP16 для Nemotron, KV-кэша с общим буфером для LFM2 и конкретных оптимизаций для моделей Phi-4 на TRT-RTX, а также за счет реализации опции `no_repeat_ngram_size` для CPU-поиска. Кроме того, улучшено обнаружение пакетов моделей, стандартизирована обработка параметров RoPE и добавлена возможность отключить захват графа DML для более эффективной отладки.
