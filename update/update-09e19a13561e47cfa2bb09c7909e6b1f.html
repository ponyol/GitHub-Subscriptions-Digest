Ключевые особенности включают 44 новых руководства по интеграции и значительную переработку интеграции Devin Desktop для многобанковского охвата и видимого использования памяти. Выпуск также включает обширные исправления ошибок для различных компонентов, повышает стабильность тестирования и содержит многочисленные критические обновления безопасности для зависимостей.
