Суммаризация (на русском)

Последнее обновление значительно расширяет возможности инструментов и улучшает пользовательский опыт. Оно добавляет поддержку массовых операций для задач (todo) и выделенный инструмент для отслеживания задач агентов с увеличенным лимитом отображения. Новая опция CLI `--scan-mode` предлагает режимы тестирования `quick`, `standard` и `deep`, при этом `deep` теперь является режимом по умолчанию. Также обновление улучшает TUI за счет рендеринга сообщений агентов в Markdown, увеличивает время ожидания выполнения песочницы и добавляет поддержку моделей без функций зрения.
