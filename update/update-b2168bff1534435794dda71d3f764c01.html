Суммаризация (на русском)

Это обновление значительно повышает стабильность инициализации `trunc_normal_` в средах с низкой точностью и добавляет поддержку квантования FP8 для каждого тензора. Ключевая функция позволяет пользователям добавлять необязательные метаданные наборов данных в карточки моделей при операциях сохранения/отправки, повышая надежность для существующих репозиториев и улучшая обработку ошибок. Кроме того, серия патчей включает важные исправления для совместимости с несколькими графическими процессорами в функции потерь кросс-энтропии, улучшенную интеграцию с vLLM и усиленные проверки зависимостей Torch/Torchvision.
