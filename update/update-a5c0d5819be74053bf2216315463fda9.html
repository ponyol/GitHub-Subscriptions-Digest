This update brings significant core improvements, including a more robust ToolRegistry with lazy loading and concurrency deduplication, intelligent tool parallelism, and detection of infinite tool validation retry loops. Key new features allow for a dual-output sidecar mode for the interactive TUI, background subagents, and a comprehensive managed auto-memory and auto-dream system. The release also expands customization with path-based context rules and new HTTP/Function hooks, refines the UI (e.g., optimized compact mode), and addresses numerous bugs, alongside the discontinuation of the Qwen OAuth free tier. --- Это обновление приносит значительные улучшения ядра, включая более надежный ToolRegistry с ленивой загрузкой и дедупликацией параллельных операций, интеллектуальный параллелизм инструментов и обнаружение бесконечных циклов повторных попыток валидации инструментов. Ключевые новые функции включают режим двухканального вывода для интерактивного TUI, фоновые субагенты и комплексную систему управляемой авто-памяти и авто-сновидений. Релиз также расширяет возможности кастомизации с помощью контекстных правил на основе путей и новых HTTP/функциональных хуков, улучшает пользовательский интерфейс (например, оптимизированный компактный режим) и устраняет множество ошибок, наряду с прекращением бесплатного уровня Qwen OAuth.
