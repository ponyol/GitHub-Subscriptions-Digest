Суммаризация (на русском)

Это обновление значительно перерабатывает процесс создания параметров инициализации Language Server Protocol (LSP), вводя `InitializeParamsBuilder` для централизации общих настроек (таких как `processId`, `rootPath`, `workspaceFolders`) для большинства языковых серверов. Такая централизация обеспечивает согласованность, позволяет гибко настраивать рабочие папки и упрощает настройку различных серверов, включая улучшения производительности для TypeScript. Кроме того, обновление включает более гибкие возможности выполнения команд для языковых серверов и добавляет команду `activation_command` на уровне проекта, а также множество исправлений ошибок и улучшений стабильности.
