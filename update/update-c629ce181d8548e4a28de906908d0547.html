Суммаризация (на русском)

This update introduces major enhancements and fixes for the sandbox service. Key changes include a new asynchronous API for the sandbox SDK in Python, refined routing for sandbox lifecycle and proxy operations, and an improved CLI command to display detailed sandbox information. Additionally, the release addresses a critical bug in VNC port probing and enhances the registration of sandbox images by propagating snapshot format metadata. --- Это обновление содержит значительные улучшения и исправления для сервиса "песочниц" (sandboxes). Ключевые изменения включают новый асинхронный API для SDK "песочниц" на Python, улучшенную маршрутизацию для операций жизненного цикла и прокси "песочниц", а также расширенную команду CLI для отображения детальной информации о "песочнице". Кроме того, выпуск устраняет критическую ошибку в проверке портов VNC и улучшает регистрацию образов "песочниц" за счет распространения метаданных формата снимков.
