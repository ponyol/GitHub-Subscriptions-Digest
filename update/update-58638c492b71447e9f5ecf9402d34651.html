Суммаризация (на русском)

Этот выпуск добавляет хук `chatStatusChanged` для агрегированных снимков статуса чата, обновляет GitHub Copilot для использования `gpt-5.5` и добавляет поддержку моделей Claude Fable 5 и Mythos 5. Значительно повышена надежность чата за счет одновременной доставки запросов `ask_user` как редактору, так и клиентам SSE, отображения ошибок переполнения контекста и улучшения восстановления соединения с удаленными серверами. Также, аутентификация токенов OAuth MCP теперь привязана к проекту для предотвращения конфликтов токенов.
