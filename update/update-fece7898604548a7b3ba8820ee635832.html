Суммаризация (на русском)

The system underwent significant internal performance enhancements, most notably replacing the standard `Dict` implementation with a Swiss Table for faster operations and reduced memory usage. Core GPU kernels were extensively refactored to utilize new TileTensor APIs, alongside the introduction of a `OneShotScheduler` to optimize single-pass pixel generation pipelines. Further improvements include buffered detokenization for text generation, clearer error messages for legacy module usage, and expanded support for various operations within the MO graph interpreter. --- Система получила значительные внутренние улучшения производительности, в частности, замену стандартной реализации `Dict` на Swiss Table для ускорения операций и сокращения потребления памяти. Основные GPU-ядра были масштабно переработаны для использования новых API TileTensor, а также был внедрен OneShotScheduler для оптимизации однопроходных конвейеров генерации пикселей. Дополнительные улучшения включают буферизованную детокенизацию для генерации текста, более понятные сообщения об ошибках для устаревших модулей и расширенную поддержку различных операций в интерпретаторе графов MO.
