Это обновление включает значительное количество обновлений зависимостей, в частности для `vm-memory` (потребовавшее адаптации API), а также групп `rust-vmm` и `firecracker`, при этом несколько пакетов перешли на новые мажорные версии. Конкретные исправления касаются нестабильности тестов, проблем с восстановлением снимков состояния и обработки параметров гостевой памяти.

Signed-off-by: James Curtis <jxcurtis@amazon.co.uk> - fix(test): wait for uffd handler exit in mark_killed UffdHandler.mark_killed() asserted the handler process had already exited at the moment of the call. The malicious handler dies via a Rust panic whose exit timing is nondeterministic under parallel test load, so the one-shot assert is racy, it can fail whilst the handler is still mid-exit. Wait for the process to exit (mirroring Microvm.mark_killed(), which waits rather than asserts) and raise a diagnostic AssertionError with the handler log only if it is still alive after the timeout.
