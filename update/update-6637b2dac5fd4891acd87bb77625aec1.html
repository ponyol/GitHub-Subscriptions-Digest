Суммаризация (на русском)

This release introduces comprehensive handling for `McpError(-32042)` in MCP payment challenges, improving error processing. It also significantly enhances the Python SDK with new features like batch settlement, SIWX extension, and expanded lifecycle hooks. Crucially, several security vulnerabilities were fixed, including cross-site scripting (XSS) risks in paywall rendering and serialization, and a path normalization issue. Additionally, ERC-6492 unwrapping was added for key schemes. --- Этот выпуск вводит комплексную обработку `McpError(-32042)` для платежных вызовов MCP, что улучшает обработку ошибок. Он также значительно расширяет Python SDK новыми функциями, такими как пакетные расчеты, расширение SIWX и расширенные хуки жизненного цикла. Критически важно, что были устранены несколько уязвимостей безопасности, включая риски межсайтового скриптинга (XSS) при рендеринге и сериализации платежного экрана, а также проблему нормализации путей. Кроме того, добавлена распаковка ERC-6492 для ключевых схем.
