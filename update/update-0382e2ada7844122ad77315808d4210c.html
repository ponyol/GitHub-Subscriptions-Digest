This update significantly enhances A2UI (Agent-Generated UI) capabilities by introducing a subagent architecture for both Python and TypeScript, improving UI generation with robust validation and design guidelines. It features major fixes for long-running tool calls (LRO) and Human-in-the-Loop (HITL) interactions, ensuring accurate model resumption only after all results arrive, preventing duplicate events, and improving Gemini API compatibility. Furthermore, the release refines LangGraph integration for consistent reasoning display and reliable state management, complemented by crucial client-side performance and stability improvements. --- **Russian Translation:** Это обновление значительно расширяет возможности A2UI (UI, генерируемый агентами) за счет внедрения субагентной архитектуры как для адаптеров Python, так и TypeScript, улучшая генерацию пользовательского интерфейса с помощью надежной валидации и руководств по дизайну. Оно включает важные исправления для длительных вызовов инструментов (LRO) и взаимодействия с человеком в процессе (HITL), обеспечивая корректное возобновление работы модели только после получения всех результатов, предотвращая дублирование событий и улучшая совместимость с Gemini API.
