Это обновление в первую очередь устраняет критическую ошибку, при которой настройка языкового сервера Julia (Julia LS) нарушала работу канала stdio MCP Serena, приводя к сбоям при получении инструментов, путем перенаправления стандартного ввода подпроцессов в DEVNULL. Кроме того, значительно улучшена обработка ошибок при вызовах инструментов, гарантируя явное появление исключений на уровне MCP. Выпуск также включает обновления конвейера CI, внедряющие архитектуру параллельного тестирования со специализированным образом Docker для зависимостей.

- Prevent Julia LS setup from clobbering Serena's stdio MCP pipe (#1580) * Prevent Julia LS probe from clobbering Serena's stdio MCP pipe When Serena runs over the stdio MCP transport, stdin/stdout *are* the JSON-RPC channel. The Julia language-server setup spawns probe/install subprocesses with `capture_output=True`, which redirects the child's stdout/stderr but not its stdin, so the Julia child inherits Serena's stdin (the MCP pipe) and clobbers it. The stdio server then exits within milliseconds of `initialize`, and the client reports "tools fetch failed". - Pass `stdin=subprocess.DEVNULL` to both `subprocess.run` calls in `julia_server.py` (`_setup_runtime_dependency` probe and `_install_language_server` install). - Add a comment explaining the stdio-transport hazard.
