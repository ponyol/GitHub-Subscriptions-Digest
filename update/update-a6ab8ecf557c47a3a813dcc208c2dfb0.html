Суммаризация (на русском)

This update significantly enhances error reporting by introducing source-mapped stack traces for uncaught errors, support for `Error.cause` chains, and improved `console.log` formatting for Error objects. A major feature is the integration of real-user experience data from the Chrome User Experience Report (CrUX) into performance trace summaries. Furthermore, several key development dependencies, including Puppeteer and Chrome DevTools Frontend, have been bumped to newer versions, incorporating various fixes and minor features. --- Это обновление значительно улучшает отчетность об ошибках, внедряя трассировки стека с сопоставлением источников для необработанных ошибок, поддержку цепочек `Error.cause` и улучшенное форматирование `console.log` для объектов Error. Важной новой функцией является интеграция данных о реальном пользовательском опыте из отчета Chrome User Experience Report (CrUX) в сводки трассировки производительности. Кроме того, несколько ключевых зависимостей для разработки, включая Puppeteer и Chrome DevTools Frontend, были обновлены до новых версий, внося различные исправления и незначительные улучшения.
