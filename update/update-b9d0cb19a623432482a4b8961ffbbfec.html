The project received a significant update, highlighted by a complete overhaul of its homepage to an interactive React/Framer Motion Docusaurus page with scroll-driven animations and enhanced navigation. Key functional improvements include adding JuiceFS as a storage backend, implementing GPU visibility for compute providers (`show_gpus`), and introducing per-process CLI profiles. The update also features new research papers and blog posts, alongside various bug fixes, publication display refinements, and dependency bumps. **Russian Translation:** Проект получил значительное обновление, основной особенностью которого стала полная переработка главной страницы в интерактивную страницу Docusaurus на React/Framer Motion с анимацией, управляемой прокруткой, и улучшенной навигацией. Ключевые функциональные улучшения включают добавление JuiceFS в качестве серверной системы хранения данных, внедрение отображения GPU для поставщиков вычислений (`show_gpus`) и введение профилей CLI для каждого процесса. Обновление также содержит новые исследовательские работы и публикации в блогах, наряду с различными исправлениями ошибок, улучшениями отображения публикаций и обновлением зависимостей.
