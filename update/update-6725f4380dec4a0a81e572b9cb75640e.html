The iGPU filter in detect_amd_gpu_rocm_info() uses a 2 GB VRAM threshold with >= to distinguish discrete GPUs from iGPUs. The Ryzen 9 9950X's Granite Ridge iGPU has exactly 2 GB of VRAM (2,147,483,648 bytes), so it passes the >= check and is counted as a discrete GPU. This results in llmfit system reporting gpu_count: 2 with both labeled as the discrete GPU's name, even though only one discrete GPU is present. Change >= to > so that GPUs with exactly 2 GB VRAM (the iGPU boundary) are excluded, while all discrete GPUs which have well over 2 GB are still included. The fallback path for iGPU-only systems (the discrete_vram.is_empty() branch) still handles the case where no discrete GPU is found.
