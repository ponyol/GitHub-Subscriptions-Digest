Суммаризация (на русском)

This update introduces new features such as session-level feedback (thumbs up/down) for OpikAssist conversations and a comprehensive dataset export functionality, allowing users to download CSVs. Extensive backend and database optimizations were performed, particularly for datasets and experiments, complemented by various enhancements to the Python and TypeScript SDKs, including new integrations and improved API handling. Additionally, security was strengthened with configurable HTTP headers and Content Security Policy (CSP), and the Optimization Studio received several UI/UX improvements and better default settings. --- **Русский перевод:** Это обновление представляет функцию обратной связи на уровне сессии для OpikAssist и новую комплексную возможность экспорта наборов данных, позволяющую пользователям загружать CSV-файлы. Были проведены обширные оптимизации бэкенда и базы данных, особенно для наборов данных и экспериментов, а также различные улучшения в SDK для Python и TypeScript, включая новые интеграции и улучшенную обработку API. Кроме того, была усилена безопасность с помощью настраиваемых HTTP-заголовков и Политики безопасности контента (CSP), а Optimization Studio получила улучшения пользовательского интерфейса и настроек по умолчанию.
