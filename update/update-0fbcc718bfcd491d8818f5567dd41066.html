Суммаризация (на русском)

This update introduces a new agent optimizer interface and sampler for custom evaluations, significantly enhancing the ability to improve agent performance. It also brings numerous fixes to improve error handling across the ADK web server, database sessions, and LiteLLM integrations, alongside pre-deployment validation for agent modules. Key infrastructure improvements include better asyncio event loop management, enhanced test isolation, and new capabilities for accessing MCP resources and configuring Vertex AI tools. --- Это обновление представляет новый интерфейс оптимизатора агентов и сэмплер для пользовательских оценок, значительно расширяя возможности по улучшению производительности агентов. Оно также включает многочисленные исправления для улучшения обработки ошибок в веб-сервере ADK, сессиях базы данных и интеграциях LiteLLM, наряду с преддеплойментной валидацией модулей агентов. Ключевые инфраструктурные улучшения включают улучшенное управление циклом событий asyncio, повышенную изоляцию тестов и новые возможности для доступа к ресурсам MCP и настройки инструментов Vertex AI.
