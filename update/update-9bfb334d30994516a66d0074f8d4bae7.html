The latest update introduces several major features, including an "assumptions" driven discuss mode for deep codebase analysis, multi-project workspace management, and an advisor mode for research-backed discussions. Furthermore, the release includes important security hardening with prompt injection guards and CLAUDE.md compliance enforcement, alongside various fixes for issues like stdout truncation and temporary file cleanup. --- Последнее обновление включает несколько крупных функций, таких как режим обсуждения на основе "предположений" для глубокого анализа кодовой базы, управление рабочими пространствами с несколькими проектами и режим советника для дискуссий, подкрепленных исследованиями.
