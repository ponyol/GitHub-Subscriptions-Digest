This release significantly advances Dolt integration, introducing a robust server mode with peer-to-peer federation capabilities, authentication, and comprehensive migration tools. User experience is enhanced through new CLI commands like `bd rename`, improved `bd show` flag handling, and a stabilized `bd list --tree` output. The update also boosts reliability with refined SQLite transaction logic, daemon stability fixes, and improved auto-import/export mechanisms, alongside expanded `bd doctor` diagnostics and configurable merge strategies for conflict resolution. --- Этот выпуск значительно расширяет интеграцию с Dolt, представляя надежный серверный режим с возможностями одноранговой федерации, аутентификацией и комплексными инструментами миграции. Удобство использования улучшено новыми командами CLI, такими как `bd rename`, улучшенной обработкой флагов `bd show` и стабилизированным выводом `bd list --tree`. Обновление также повышает надежность за счет усовершенствованной логики транзакций SQLite, исправлений стабильности демонов и улучшенных механизмов автоимпорта/экспорта, наряду с расширенной диагностикой `bd doctor` и настраиваемыми стратегиями слияния для разрешения конфликтов.
