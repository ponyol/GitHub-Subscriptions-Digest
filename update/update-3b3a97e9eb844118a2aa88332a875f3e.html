Суммаризация (на русском)

This release significantly enhances document processing with the introduction of smart semantic chunking, allowing topic-aware document splitting, and adds comprehensive acceleration configuration for ORT models. Key operational improvements include LLM usage tracking and a new Helm chart for Kubernetes deployment. The update also features extensive documentation overhauls for improved accuracy and structure, alongside numerous bug fixes addressing OCR content integrity, structured output serialization, and build compatibility across various language bindings. --- Этот выпуск значительно улучшает обработку документов благодаря внедрению умной семантической сегментации, позволяющей разделять документы по темам, а также добавляет комплексную конфигурацию ускорения для моделей ORT. Ключевые операционные улучшения включают отслеживание использования LLM и новый чарт Helm для развертывания в Kubernetes. Обновление также содержит обширную переработку документации для повышения точности и структуры, наряду с многочисленными исправлениями ошибок, касающихся целостности содержимого OCR, сериализации структурированного вывода и совместимости сборки с различными языковыми привязками.
