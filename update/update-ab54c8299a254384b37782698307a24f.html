Суммаризация (на русском)

This release features extensive kernel refactoring, with many operations migrated to `TileTensor` for enhanced performance and consistency. It significantly expands model support by adding `Llama-405B-FP8`, `Qwen3-30B-A3B-Instruct-FP8`, and `Flux2-Klein` pipelines, alongside integrating `Kimi LM` and migrating `Pixtral` and `OLMo2` to the new `nn.Module` API. Performance is further boosted through GPU-accelerated post-processing for `FLUX.2`, KV cache optimizations, and parallel dispatch mechanisms. Additionally, the update includes Mojo language enhancements, such as a standalone assert statement and a unified device placement API for Modules. --- Этот выпуск содержит обширный рефакторинг ядер, многие операции переведены на `TileTensor` для повышения производительности и согласованности. Значительно расширена поддержка моделей за счет добавления `Llama-405B-FP8`, `Qwen3-30B-A3B-Instruct-FP8` и конвейеров `Flux2-Klein`, а также интеграции `Kimi LM` и миграции `Pixtral` и `OLMo2` на новый API `nn.Module`. Производительность дополнительно улучшена за счет пост-обработки `FLUX.2` с использованием GPU, оптимизаций KV-кэша и механизмов параллельной диспетчеризации. Кроме того, обновление включает улучшения языка Mojo, такие как отдельный оператор `assert` и унифицированный API размещения модулей на устройствах.
