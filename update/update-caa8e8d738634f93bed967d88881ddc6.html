Суммаризация (на русском)

This update introduces a control plane for multi-proxy worker management and significant UI modernizations, including an updated Teams table, AntD message system, and path-based API reference routing. A "Team MCP Server Manager Role" feature was initially added but subsequently reverted due to unforeseen issues. The release also includes various fixes for authentication, streaming, and cost calculation, enhanced Anthropic integration, new model support, and expanded test coverage and documentation. --- Это обновление включает в себя внедрение плоскости управления для управления рабочими процессами нескольких прокси-серверов и значительные модернизации пользовательского интерфейса, такие как обновленная таблица команд, система сообщений AntD и маршрутизация API-справки на основе путей. Функция "Роль менеджера сервера Team MCP" была первоначально добавлена, но впоследствии отменена из-за непредвиденных проблем. Релиз также содержит различные исправления для аутентификации, стриминга и расчета затрат, улучшенную интеграцию с Anthropic, поддержку новых моделей, а также расширенное тестовое покрытие и документацию.
