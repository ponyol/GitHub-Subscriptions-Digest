Суммаризация (на русском)

Представлена новая команда `rm` для управления данными сессий. Она позволяет удалять сокеты и логи для сессий, которые больше не запущены или завершили работу. Флаг `-a` предлагает удобный способ одновременного удаления всех таких устаревших сессий. Обратите внимание, что запущенные сессии сначала должны быть завершены командой `kill`, прежде чем их можно будет удалить с помощью `rm`.

Исходный текст

- Add `rm` command to remove stale and exited sessions Adds a new `rm` command that removes session sockets and logs for sessions that are no longer running. The `-a` flag sweeps all stale and exited sessions at once. Running sessions cannot be removed—`kill` must be used first.
