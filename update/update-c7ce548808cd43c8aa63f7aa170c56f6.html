Суммаризация (на русском)

This update brings significant security enhancements, addressing multiple critical vulnerabilities including CSRF, path traversal, SSRF/LFI, and updating key dependencies like PyJWT. New features include a browser-based UI for `fastmcp dev apps`, support for image and audio content in sampling handlers, and more flexible OAuth configurations. The release also delivers performance improvements for task processing and numerous fixes for API routing, error handling, and developer experience. --- Это обновление содержит значительные улучшения безопасности, устраняя несколько критических уязвимостей, включая CSRF, обход пути, SSRF/LFI, а также обновляя ключевые зависимости, такие как PyJWT. Среди новых функций — браузерный пользовательский интерфейс для `fastmcp dev apps`, поддержка изображений и аудиоконтента в обработчиках выборки, а также более гибкие конфигурации OAuth. Релиз также обеспечивает повышение производительности обработки задач и многочисленные исправления для маршрутизации API, обработки ошибок и удобства разработчиков.
