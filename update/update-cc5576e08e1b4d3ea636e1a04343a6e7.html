Any non-Latin-1 byte in a diff, commit message, or file (emoji, em-dashes, accented names) then raises: UnicodeDecodeError: 'charmap' codec can't decode byte 0x8f ... so both skills crash on Windows against any repo with UTF-8 content, while working fine on macOS/Linux.
