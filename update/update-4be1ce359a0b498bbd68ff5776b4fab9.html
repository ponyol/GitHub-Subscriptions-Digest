Суммаризация (на русском)

The update introduces significant CLI enhancements, including tools to generate client CLIs, install dependencies, and interact with MCP servers. It brings major API and protocol improvements such as Client ID Metadata Document (CIMD) support for OAuth, response limiting middleware, background task context, and automatic MIME type inference from OpenAPI definitions. Key fixes address HTTP 415 errors, strengthen OAuth redirect validation, improve schema compression, and remove `require_auth` for streamlined authentication, alongside important security dependency upgrades. *** Обновление включает значительные улучшения командной строки (CLI), такие как инструменты для генерации клиентских CLI, установки зависимостей и взаимодействия с серверами MCP. Внесены крупные улучшения API и протоколов, включая поддержку Client ID Metadata Document (CIMD) для OAuth, промежуточное ПО для ограничения размера ответов, контекст фоновых задач и автоматическое определение типов MIME из определений OpenAPI. Основные исправления касаются ошибок HTTP 415, усиления проверки перенаправлений OAuth, улучшения сжатия схем и удаления `require_auth` для упрощенной аутентификации, а также важных обновлений зависимостей для безопасности.
