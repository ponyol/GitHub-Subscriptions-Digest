Суммаризация (на русском)

This update significantly enhances LMCache's capabilities by introducing Tensor Parallelism (TP > 1) support for RustRawBlockBackend, enabling explicit per-TP device paths for multi-GPU deployments. It also adds first-class support for Redis/Valkey as an L2 storage backend, improves multi-path local disk I/O, and allows for different KV cache shapes and dtypes across layers in multiprocess environments. The release includes various fixes, performance optimizations, and CI/documentation updates. --- Это обновление значительно расширяет возможности LMCache, добавляя поддержку тензорного параллелизма (TP > 1) для RustRawBlockBackend, что позволяет использовать явные пути к устройствам для каждого TP в развертываниях с несколькими GPU. Также реализована полноценная поддержка Redis/Valkey в качестве бэкенда хранилища L2, улучшен ввод-вывод для локальных дисков с несколькими путями и обеспечена гибкость в форме и типе данных кеша KV для разных слоев в многопроцессорных средах. Выпуск включает различные исправления, оптимизации производительности и обновления CI/документации.
