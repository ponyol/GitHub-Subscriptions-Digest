Суммаризация (на русском)

This release focuses on significant stability and user experience improvements, particularly addressing various Windows-specific issues such like ConPTY reliability, shell argument handling, and PTY resize race conditions. It also refines OAuth authentication with better UX, resolves screen flickering, and updates token limits for GPT-5.x and GLM models. Additional enhancements include output truncation for directory listings, Tab key support in completion menus, and a refactored VS Code IDE companion layout. The update also removes unused debug logs and flaky tests. --- Этот релиз сосредоточен на значительных улучшениях стабильности и пользовательского опыта, в частности, устраняя различные проблемы, специфичные для Windows, такие как надежность ConPTY, обработка аргументов оболочки и условия гонки при изменении размера PTY. Также улучшена аутентификация OAuth с более удобным интерфейсом, устранено мерцание экрана и обновлены лимиты токенов для моделей GPT-5.x и GLM. Дополнительные улучшения включают усечение списков директорий, поддержку клавиши Tab в меню завершения и переработанный макет компаньона IDE для VS Code. Обновление также удаляет неиспользуемые отладочные логи и нестабильные тесты.
