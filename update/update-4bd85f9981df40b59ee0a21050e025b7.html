Суммаризация (на русском)

This release primarily refines the TON exact payment scheme (x402 v2), introducing robust validation rules, self-relay architecture, RPC integration, and enhanced security for jetton transfers. The user interface was updated with a hero section redesign, navigation improvements, and better x402 discoverability for scanners. Additionally, critical paywall fixes were implemented to dynamically handle token decimals (previously hardcoded to USDC) and ensure support for a wider range of blockchain networks by updating `viem` chain definitions. --- Этот выпуск в основном дорабатывает точную схему платежей TON (x402 v2), вводя надёжные правила валидации, архитектуру саморелея, интеграцию RPC и повышенную безопасность для переводов джеттонов. Пользовательский интерфейс был обновлён, включая редизайн главной секции, улучшения навигации и лучшую обнаруживаемость x402 для сканеров. Кроме того, были реализованы критические исправления платёжного шлюза, позволяющие динамически обрабатывать десятичные знаки токенов (ранее жёстко закодированные для USDC) и обеспечивающие поддержку более широкого спектра блокчейн-сетей за счёт обновления определений цепочек `viem`.
