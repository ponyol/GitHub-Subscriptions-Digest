Суммаризация (на русском)

This update significantly enhances security by addressing numerous vulnerabilities, including SurrealQL injection, Server-Side Request Forgery (SSRF), API URL spoofing, and internal data leakage. It also improves system stability and resilience by fixing API sorting errors, robustly handling invalid form data with 422 responses, and making provider connection tests more resilient to model retirements. Key performance gains come from batching database lookups and running file operations and DNS resolution off the event loop, alongside a major documentation restructure. --- **Russian Translation:** Это обновление значительно повышает безопасность, устраняя многочисленные уязвимости, включая инъекции SurrealQL, подделку запросов на стороне сервера (SSRF), спуфинг URL-адресов API и утечки внутренних данных. Оно также улучшает стабильность и отказоустойчивость системы, исправляя ошибки сортировки API, надежно обрабатывая неверные данные форм с ответами 422 и повышая устойчивость тестов подключения провайдеров к выводу моделей из эксплуатации. Ключевые улучшения производительности достигнуты за счет пакетной обработки запросов к базе данных и выполнения файловых операций и разрешения DNS вне цикла событий, а также за счет масштабной реструктуризации документации.
