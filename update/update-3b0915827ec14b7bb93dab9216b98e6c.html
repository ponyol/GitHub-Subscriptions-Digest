Этот релиз значительно переработал маршрутизатор моделей, улучшив точность подсчета токенов, введя "липкую" маршрутизацию, кэширование классификации LLM и правила с множественными условиями. Среди новых крупных функций — "Воспоминания/Персонализация" для хранения и внедрения пользовательских данных, а также "Навык агента: Опрос пользователя" для сбора обратной связи. Кроме того, обновление добавляет поддержку провайдера LLM MiniMax, контент для рассуждений в обработчиках потоков v2 и различные исправления ошибок для повышения стабильности API и удобства использования.
