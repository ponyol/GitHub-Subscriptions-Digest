Суммаризация (на русском)

This update includes a significant upgrade of the Redis base image to 8.6.2 (Debian 13) and improvements to Docker images for enhanced security by removing unnecessary packages and restoring `ca-certificates` for HTTPS operations. It also addresses a critical data race bug in `Cache_GetValue` using C11 atomics and introduces a new UDF `graph.getNodeById`. Additionally, several GitHub Actions and dependencies have been updated, and the submodule update workflow has been improved. --- Это обновление включает значительное улучшение базового образа Redis до версии 8.6.2 (Debian 13) и доработки образов Docker для повышения безопасности за счет удаления ненужных пакетов и восстановления `ca-certificates` для операций HTTPS. Также устранен критический баг состояния гонки данных в `Cache_GetValue` с использованием атомарных операций C11 и представлена новая пользовательская функция (UDF) `graph.getNodeById`. Кроме того, обновлено несколько GitHub Actions и зависимостей, а также улучшен рабочий процесс обновления подмодулей.
