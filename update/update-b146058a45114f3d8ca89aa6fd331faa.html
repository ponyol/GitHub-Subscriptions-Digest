Суммаризация (на русском)

Последние обновления FluidAudio значительно расширяют возможности ASR (автоматического распознавания речи) и TTS (синтеза речи), уделяя внимание производительности, интеграции новых моделей и стабильности системы. Улучшения производительности включают увеличение RTFx на 50% для потокового ASR Nemotron и опциональное использование GPU-кодировщика для Parakeet v3. Библиотека теперь поддерживает новые многоязычные ASR-модели (Nemotron 3.5 Multilingual, SenseVoiceSmall, Paraformer-large zh) и улучшенные TTS-модели (Supertonic-3, PocketTTS). Среди других заметных изменений — обновленная документация по моделям, режим загрузки только в офлайне и постоянное хранение TTS-моделей для iOS.

Closes #635. ## Changes - **`TtsCacheDirectory.ensure()`** now uses `.applicationSupportDirectory` on iOS/iPadOS. macOS is unchanged (`~/.cache/fluidaudio`). - **All 5 backend downloaders** (Kokoro, PocketTTS, Magpie, Supertonic3, StyleTTS2) now delegate to `TtsCacheDirectory.ensure()` + their own subdir instead of each maintaining a copy-pasted `#if os(macOS) / #else .cachesDirectory` block. Path layout per backend is unchanged (still `fluidaudio/Models/`, `fluidaudio/`, etc.); only the platform base moves. - **`DownloadUtils.clearAllModelCaches()`** clears the new location on iOS, and now removes the whole `fluidaudio/` root so every backend subdirectory is cleared, not just `Models/`. Net: ~89 lines removed, ~32 added; every TTS `.cachesDirectory` usage is gone. ## Scope notes - **macOS path preserved** at `~/.cache/fluidaudio` for backward compatibility. - **No migration included.** Existing iOS installs will re-download models once after updating (no copy from `Library/Caches/` to `Library/Application Support/`).
