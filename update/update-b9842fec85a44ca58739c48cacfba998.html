**English Summary:** Version 10.1.0 introduced the `agent-brain-uds` (Unix Domain Socket transport) and `agent-brain-mcp` (MCP server v1) packages, along with a CLI transport selector and a `/health/config` endpoint. This release also added an `explain=true` query parameter and the `agent-brain doctor` command for system diagnostics.
