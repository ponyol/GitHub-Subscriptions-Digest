Суммаризация (на русском)

Релиз v0.4.14 включает значительные новые функции, такие как интеграция Chat SDK для постоянной памяти чат-ботов и существенное расширение инструментов MCP с 18 новыми опциями. Также добавлена поддержка переранжировщика ZeroEntropy, API конфигурации банков теперь включен по умолчанию, и улучшены существующие функции, включая фильтрацию графов памяти по тегам и пакетную консолидацию наблюдений. Ключевые исправления затрагивают проблемы многопользовательского хранилища, корректную обработку ограничений размерности встраиваний и улучшают иерархический поиск агента отражения для обеспечения более полного доступа к информации.
