Суммаризация (на русском)

Обновления в основном сосредоточены на исправлении нескольких проблем в FalkorDB, включая корректировку маршрутизации графов для запросов `get_by_group_ids`, улучшение полнотекстового поиска за счет обработки спецсимволов и пустых запросов, а также устранение проблем со сборкой Docker. Кроме того, были отключены рабочие процессы Claude GitHub Actions. Документация была обновлена, чтобы включить инструкции по настройке среды разработки Cursor Cloud и уточнить информацию о проприетарном Context Graph Engine Zep.
