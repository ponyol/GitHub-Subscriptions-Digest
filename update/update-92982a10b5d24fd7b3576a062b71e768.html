Суммаризация (на русском)

This update notably reverts a prior change allowing experiments with null `dataset_name` due to reported issues. It introduces significant SDK enhancements, including annotation queue and dataset versioning for TypeScript, the G-Eval metric, and real-time score averages in the CLI, alongside changing the Optimizer's default model to `gpt-5-nano`. Backend performance has been substantially improved through various query optimizations, and the OpikAssist AI backend is now integrated. The frontend sees major UI overhauls with a unified "Logs" tab, image attachments in thread view, workspace-level color maps, and overall improved responsiveness and stability, with several security vulnerabilities also addressed. --- **Russian Translation:** Данное обновление отменяет ранее введенное изменение, разрешавшее эксперименты с пустым `dataset_name`, что было вызвано обнаруженными проблемами. Оно представляет значительные улучшения в SDK, включая поддержку очереди аннотаций и версионирования наборов данных для TypeScript, метрику G-Eval и отображение средних оценок в реальном времени в CLI, а также изменение модели по умолчанию для Optimizer на `gpt-5-nano`. Производительность бэкенда существенно возросла благодаря различным оптимизациям запросов, а также интегрирован AI-бэкенд OpikAssist. Во фронтенде реализованы значительные изменения пользовательского интерфейса: унифицированная вкладка "Logs", отображение вложений изображений в представлении потоков, настройки цветовых карт на уровне рабочей области, а также общее улучшение отзывчивости и стабильности, при этом были устранены несколько уязвимостей безопасности.
