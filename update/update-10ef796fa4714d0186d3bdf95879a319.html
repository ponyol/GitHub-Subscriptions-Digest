Суммаризация (на русском)

Обновления включают добавление многоязычных API SDK (Python, Go, TypeScript) для взаимодействия с асинхронным API PaddleOCR, предоставляющих функции надежной обработки ошибок и загрузки файлов. В числе важных исправлений — изоляция кэша pip для многоархитектурных сборок Docker, предотвращающая конфликты, и улучшение автоматического версионирования. Кроме того, внесены корректировки в ссылки документации, обновлены схемы API для сервисов, а также добавлена поддержка многостраничных TIFF-файлов и оборудования Metax.
