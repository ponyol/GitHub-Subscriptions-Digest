This release significantly expands support for AI coding assistants, adding 11 new providers including Zed, Open Interpreter, Amazon Q CLI, GitHub Copilot, and more. It also includes crucial fixes for provider compatibility, such as correcting Zed data paths, tolerating older database schemas, and improving task index reading for Cline-family tools. Key new features enhance usability with headless session export, one-click full project backup, and improved UI font scaling. Additionally, analytics now provide detailed skill and subagent usage breakdowns, and build processes are made more reproducible. --- Этот выпуск значительно расширяет поддержку помощников по кодированию на основе ИИ, добавляя 11 новых провайдеров, включая Zed, Open Interpreter, Amazon Q CLI, GitHub Copilot и другие. Он также включает важные исправления для совместимости провайдеров, такие как корректировка путей данных Zed, поддержка старых схем баз данных и улучшение чтения индексов задач для инструментов семейства Cline. Ключевые новые функции повышают удобство использования благодаря экспорту сессий без графического интерфейса, резервному копированию всех проектов в один клик и улучшенному масштабированию шрифтов пользовательского интерфейса. Кроме того, аналитика теперь предоставляет подробную разбивку использования навыков и субагентов, а процессы сборки стали более воспроизводимыми.
