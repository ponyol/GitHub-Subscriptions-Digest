Суммаризация (на русском)

Recent updates focus on enhancing robustness, security, and observability within the ADK. Key fixes include preserving empty string text parts, improving Vertex AI RAG memory scoping, and ensuring initial session state is maintained during rewinds. Significant improvements were made to error handling for parallel tool calls and MCP tools, alongside new OpenTelemetry tracing and metrics. Additionally, several security vulnerabilities, such as filter injection and SSRF, were addressed. --- Последние обновления ADK сосредоточены на повышении надежности, безопасности и наблюдаемости. Важные исправления включают сохранение пустых текстовых частей, улучшение области видимости памяти Vertex AI RAG и обеспечение сохранения исходного состояния сессии при перемотке. Были внесены значительные улучшения в обработку ошибок для параллельных вызовов инструментов и инструментов MCP, а также добавлены новые трассировки и метрики OpenTelemetry. Кроме того, устранены несколько уязвимостей безопасности, таких как инъекции фильтров и SSRF.
