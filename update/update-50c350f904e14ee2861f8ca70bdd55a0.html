Суммаризация (на русском)

This update resolves critical bugs including use-after-free issues in RDB buffer handling and batch attribute removal, and a SIGSEGV data race in schema array access. Data integrity and concurrency are enhanced through safe `uint64_t` comparators and read locks for writer queries to prevent defragmentation races. The Bolt protocol received numerous fixes covering serialization, authentication, and memory management, significantly improving its robustness. Furthermore, the release features extensive test suite enhancements, dependency updates, and Docker image security hardening. --- Это обновление устраняет критические ошибки, включая проблемы use-after-free при обработке буфера RDB и пакетном удалении атрибутов, а также состояние гонки SIGSEGV при доступе к массивам схемы. Целостность данных и параллелизм улучшены за счет безопасных компараторов `uint64_t` и блокировок чтения для запросов записи, предотвращающих состояния гонки при дефрагментации. Протокол Bolt получил многочисленные исправления, охватывающие сериализацию, аутентификацию и управление памятью, что значительно повысило его надежность. Кроме того, выпуск включает значительные улучшения набора тестов, обновления зависимостей и усиление безопасности образов Docker.
