Суммаризация (на русском)

This update introduces significant new features like compound tag filtering using `tag_groups` and enhances performance by optimizing semantic retrieval with `UNION ALL` and per-bank HNSW indexes. The project has been refactored into `hindsight-api-slim` and `hindsight-all-slim` packages for flexible dependency management, while expanding LLM and reranker support to include MiniMax and Jina-MLX (for Apple Silicon). Additionally, numerous fixes improve stability across various components, addressing API errors, database deadlocks, and enhancing asynchronous operation management, alongside comprehensive documentation and improved type hints. --- Это обновление представляет значительные новые функции, такие как составная фильтрация по тегам с использованием `tag_groups`, и повышает производительность за счет оптимизации семантического поиска с помощью `UNION ALL` и индексов HNSW для каждого банка. Проект был реорганизован в пакеты `hindsight-api-slim` и `hindsight-all-slim` для гибкого управления зависимостями, а также расширяет поддержку LLM и реранкеров, включая MiniMax и Jina-MLX (для Apple Silicon). Кроме того, многочисленные исправления улучшают стабильность различных компонентов, устраняя ошибки API, тупиковые ситуации в базе данных и улучшая управление асинхронными операциями, наряду с всесторонней документацией и улучшенными подсказками типов.
