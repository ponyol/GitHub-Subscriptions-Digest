Суммаризация (на русском)

This release significantly enhances execution management and reliability, particularly for nested agent call chains. It introduces multi-hop pause propagation, allowing parent agents to correctly pause their clocks when awaiting a child, and implements pause-aware timeout checks to prevent premature terminations. Furthermore, security is improved with a new opt-in default-deny mode for tag-based authorization, and user-initiated cancellations are now properly honored without accidental retries. *** Этот релиз значительно улучшает управление выполнением и надежность, особенно для вложенных цепочек вызовов агентов. Введены многоступенчатая передача пауз, позволяющая родительским агентам корректно приостанавливать свои таймеры при ожидании дочерних процессов, а также реализованы проверки таймаутов с учетом пауз для предотвращения преждевременного завершения. Кроме того, повышена безопасность за счет нового режима "запрет по умолчанию" для авторизации на основе тегов, а отмены, инициированные пользователем, теперь корректно обрабатываются без случайных повторных попыток.
