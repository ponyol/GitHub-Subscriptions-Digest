Суммаризация (на русском)

Living Canvas — это новое расширение для редактора Lem, которое визуализирует графы вызовов функций Lisp в виде интерактивного холста. Оно отображает отношения между функциями с иерархическим расположением, позволяет переходить к исходному коду, группирует функции по файлам и улучшает обнаружение графов вызовов с помощью `sb-introspect`. Также добавлено расширение MCP-сервера, позволяющее ИИ-агентам взаимодействовать с Lem через стандартизированный HTTP JSON-RPC протокол для управления буферами и выполнения Lisp-выражений.
