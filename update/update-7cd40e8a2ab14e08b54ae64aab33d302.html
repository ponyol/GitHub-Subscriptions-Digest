Суммаризация (на русском)

Flet v0.85.0 включает ключевые улучшения инфраструктуры, в том числе поддержку многоархитектурных образов Docker для сборки и критические исправления внутреннего механизма сопоставления различий UI для повышения стабильности и корректного обновления интерфейса. Значительно повышена производительность, особенно для `MatplotlibChart`, благодаря более быстрому нативному рендерингу (композитинг на GPU) и устранению критической утечки памяти в веб-версии. Новые функции добавляют настраиваемые переходы тем, расширенные возможности управления видеоплеером (изменение плейлиста, скриншоты) и поддержку потоковой передачи для `AudioRecorder`, что дополняется различными исправлениями ошибок в рендеринге UI, обработке данных и событиях на мобильных устройствах.
