Суммаризация (на русском)

Это обновление значительно повышает безопасность и улучшает опыт разработчиков, одновременно внедряя новые возможности RAG. Основные функции включают подписание Ed25519 JWS в Python SDK для обеспечения подлинности полезной нагрузки, шифрование X25519 JWE на основе DID для безопасной связи агентов, а также новое хранилище знаний на уровне управления, предлагающее контекстно-зависимое встраивание и векторный поиск. Также была переработана система Python harness для обеспечения единообразия, добавлена возможность перезапуска рабочих процессов с повторным использованием прошлых результатов и исправлены критические ошибки сериализации JSON и валидации схем OpenAI.
