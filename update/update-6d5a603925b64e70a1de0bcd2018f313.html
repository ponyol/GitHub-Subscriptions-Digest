Суммаризация (на русском)

Проект представил новый клиент `mcp-use` для командной строки и значительно улучшил интеграцию Zod, поддерживая схемы Zod наряду с JSON Schema для определения инструментов. Ключевые обновления в управлении сессиями включают автоматическое восстановление для транспортов HTTP/SSE, интеграцию Redis и FileSystemSessionStore для персистентности, а также улучшенные системы уведомлений клиентов. Была удалена поддержка WebSocket-транспорта в пользу потокового HTTP/SSE, наряду с комплексными обновлениями зависимостей (например, TypeScript 5.9.3), переработанной документацией и различными улучшениями пользовательского интерфейса/телеметрии.
