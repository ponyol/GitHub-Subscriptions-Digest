This update introduces significant compatibility improvements, notably fixing FBGEMM/CUTLASS and vLLM PDL errors on Blackwell (SM100) GPUs, enabling support for newer hardware. It also addresses various bugs, including PEFT import issues and Kaggle telemetry misclassification, while improving RL training stability and state restoration. A new feature for raw text data preparation has been added, alongside numerous code duplications reductions and quality-of-life fixes. **Russian Translation:** Это обновление включает значительные улучшения совместимости, в частности, исправляя ошибки FBGEMM/CUTLASS и vLLM PDL на графических процессорах Blackwell (SM100), что обеспечивает поддержку нового оборудования. Также устранены различные ошибки, включая проблемы импорта PEFT и неверную классификацию телеметрии Kaggle, при этом улучшена стабильность обучения RL и восстановление состояния. Добавлена новая функция для подготовки необработанных текстовых данных, наряду с многочисленными сокращениями дублирования кода и улучшениями качества.
