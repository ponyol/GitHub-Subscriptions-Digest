Суммаризация (на русском)

The update introduces several new features, such as UI for team soft budgets with email alerts, IP-based access control for MCP servers, and enhanced guardrails supporting HTTP, MCP, and agents. It also adds full support for Claude Opus 4.6, along with integration of new ElevenLabs and GPT models. Key fixes address deprecated embedding models, SSO role extraction for Keycloak, and various UI/A2a agent gateway issues. Additionally, the release includes performance improvements and significant UI refactoring. --- Это обновление добавляет несколько новых функций, таких как пользовательский интерфейс для мягких бюджетов команд с уведомлениями по электронной почте, контроль доступа на основе IP для серверов MCP и улучшенные брандмауэры с поддержкой HTTP, MCP и агентов. Включена полная поддержка Claude Opus 4.6, а также интеграция новых моделей ElevenLabs и GPT. Основные исправления касаются устаревших моделей эмбеддингов, извлечения ролей SSO для Keycloak и различных проблем UI/шлюза агентов A2a. Кроме того, релиз включает улучшения производительности и значительный рефакторинг пользовательского интерфейса.
