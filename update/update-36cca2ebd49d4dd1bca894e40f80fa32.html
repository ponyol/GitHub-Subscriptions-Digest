Суммаризация (на русском)

This release primarily focuses on achieving comprehensive API consistency across all 10 language bindings (Rust, Python, Node.js, PHP, Go, Java, C#, Elixir, Ruby, and WebAssembly), ensuring unified configurations and data structures. Key improvements include a systematic restoration of sccache for faster CI builds, enhanced benchmark result publishing to GitHub Releases with permanent URLs, and the addition of robust contract testing for the API. The update also brings Bun runtime support, critical bug fixes for element extraction in several FFI bindings, and improved Docker plugin initialization for OCR and embeddings. --- Этот выпуск в первую очередь направлен на достижение всеобъемлющей согласованности API во всех 10 языковых привязках (Rust, Python, Node.js, PHP, Go, Java, C#, Elixir, Ruby и WebAssembly), обеспечивая унифицированные конфигурации и структуры данных. Ключевые улучшения включают систематическое восстановление sccache для ускорения сборок CI, расширенную публикацию результатов бенчмарков в GitHub Releases с постоянными URL-адресами и добавление надежного контрактного тестирования для API. Обновление также включает поддержку среды выполнения Bun, критические исправления ошибок для извлечения элементов в нескольких привязках FFI и улучшенную инициализацию плагинов Docker для OCR и встраиваний.
