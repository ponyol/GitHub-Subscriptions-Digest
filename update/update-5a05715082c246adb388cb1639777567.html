Суммаризация (на русском)

Этот релиз значительно расширяет возможности, добавляя поддержку региональных конечных точек для `SecretManagerClient` и улучшая `BashTool` с помощью настраиваемых ограничений ресурсов и надежного управления процессами. Он также вводит настраиваемые префиксы представлений для `BigQueryLoggerConfig` для предотвращения конфликтов данных и обеспечивает поддержку в реальном времени для модели `gemini-3.1-flash-live-preview`. Среди других значимых улучшений – расширенная поддержка схем аутентификации для инструментов MCP, улучшенное взаимодействие с LLM через описания в `SKILL.md`, а также важные исправления, такие как скрытие учетных данных в плагине аналитики BigQuery и буферизация вызовов инструментов для более связных ответов.
