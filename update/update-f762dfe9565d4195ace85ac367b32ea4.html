Суммаризация (на русском)

Это обновление вводит всеобъемлющую встроенную систему происхождения данных, использующую DerivationRecorder для построения подробных DAG-ов доказательств для всех выведенных фактов, включая сложные преобразования и агрегации. Новый пакет provenance поддерживает обратную цепочку для вычисления этих деревьев доказательств, которые можно исследовать и запрашивать с помощью инструмента `mgwhy`. Критическая ошибка, вызывавшая скрытые коллизии ключей групп в агрегации `evalDo`, была исправлена путем использования инъективной строковой карты, что обеспечивает корректность агрегатов. Кроме того, добавлена поддержка сжатия `zstd` и инструмент `scinfo`.

Исходный текст

- Add full provenance via in-engine derivation recorder. The new DerivationRecorder hook fires during evaluation at each derivation point: plain rule firings, let-transform emissions, and do-transform (aggregation) emissions. When no recorder is installed the callbacks are a single nil check away from the hot path. The provenance package gains a MemoryRecorder that buffers events and a BuildFromRecording() that assembles the same ProofNode DAG as the post-hoc Explain(). Two new kinds (KindLetRow, KindDoAggregate) carry transform metadata; the schema gains uses_transform and group_key predicates. mgwhy gains -mode=simple|full. Full mode handles aggregation (group key plus the input facts that fed the group), let-transforms row-wise, and falls back to the existing post-hoc behavior for plain Datalog. Delta-prefixed predicates from semi-naive evaluation are normalized away so consumers always see the original logical rule. - Fix silent group-key collision in evalDo aggregation. The do-transform grouping in evalDo used a 32-bit FNV hash of the key constants directly as a map key, with no equality fallback. Two distinct group keys hashing to the same uint32 value silently merged into a single group, corrupting aggregates. Birthday bound around 2^16 made this likely well below 100k groups. Replace the hash-keyed map with a string-keyed map whose key is a length-prefixed concatenation of the key constants' canonical String() forms — injective by construction. Add a regression test that runs group_by + sum over 5000 distinct integer keys. - Add provenance support for derived facts. New provenance package computes proof trees for IDB facts by backward-chaining against the final fact store. Handles positive Datalog, equality/inequality, recursion with cycle detection, and stratified negation via closed-world absence. Proof nodes carry 128-bit content-addressed IDs so identical sub-proofs form a DAG. Includes the mgwhy command, which prints proof trees or emits the proof DAG as Mangle facts (proves, uses_rule, premise, edb_leaf, absence_leaf, binding, rule_source) that can be loaded back into mg and queried recursively. - Add scinfo tool to display simplecolumn file info. - Add zstd compression support to simplecolumn factstore.
