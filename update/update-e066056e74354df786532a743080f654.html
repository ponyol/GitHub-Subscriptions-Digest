Суммаризация (на русском)

This update significantly improves the synchronization system by adding continuous sync for SharePoint 2019, enhancing its resilience through improved error handling (e.g., OCR), and boosting performance via data batching. Key architectural changes include a major refactoring of the source domain and a complete transition from Qdrant to Vespa as the primary vector database. Additionally, new administrative endpoints for cursor management, a resilient OCR fallback mechanism, and numerous bug fixes were implemented. **Russian Translation:** Это обновление значительно улучшает систему синхронизации, добавляя непрерывную синхронизацию для SharePoint 2019, повышая ее отказоустойчивость за счет улучшенной обработки ошибок (например, OCR) и производительности благодаря пакетной обработке данных. Внесены ключевые архитектурные изменения, включая рефакторинг домена источников и полный переход от Qdrant к Vespa как основной векторной БД. Также добавлены административные конечные точки для управления курсорами, реализован отказоустойчивый механизм резервирования OCR и исправлены многочисленные ошибки.
