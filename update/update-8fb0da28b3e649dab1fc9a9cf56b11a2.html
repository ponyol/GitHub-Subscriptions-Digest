Суммаризация (на русском)

Изменения включают сужение разрешений токена GitHub для повышения безопасности. Кроме того, были добавлены реализации функции `kick` для устройств `virtio-mem` и `virtio-pmem`, чтобы обеспечить обработку событий очереди перед созданием снимков. Наконец, функция `handle_queue` была сделана публичной для фаззера `virtio-pmem`, что соответствует подходу для других фаззеров устройств.
