When docker specific ignore file is detected, it creates a hidden docker directory (i.e., `.hidden-docker-dir`) under the build context, and places Dockerfile and ignore file under there. This hidden directory is passed to the builder shim and used by buildkit daemon to correctly figure out the docker specific ignore file.
