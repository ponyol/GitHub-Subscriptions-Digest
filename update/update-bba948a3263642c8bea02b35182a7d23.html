Суммаризация (на русском)

Nori теперь позволяет пользователям определять собственный список «рабочих сообщений» для пользовательского интерфейса (TUI), который может заменять встроенные шутливые сообщения, при этом сохраняя существующий переключатель для пользовательских сообщений. Кроме того, была введена функция логирования прокси-сервера ACP wire, позволяющая записывать необработанные JSON-RPC сообщения межпроцессного взаимодействия в файлы JSONL для диагностики.
