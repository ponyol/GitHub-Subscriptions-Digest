Суммаризация (на русском)

Эта серия изменений в основном направлена на улучшение обработки MSR (Model-Specific Register) на архитектуре x86_64 для гостевых операционных систем. Критическое исправление затрагивает MSR IA32_MTRRdefType, позволяя гостям правильно устанавливать типы памяти для таких областей, как pmem, в write-back, устраняя предыдущие проблемы с производительностью, когда они помечались как uncached-minus. Кроме того, IA32_PAT_MSR добавлен в список исключений, что дает гостям больше контроля над атрибутами страниц, а значения MTRR MSR теперь автоматически генерируются для улучшения удобства обслуживания.

Signed-off-by: Egor Lazarchuk <yegorlz@amazon.co.uk> - fix(x86_64): specify IA32_MTRRdefType MSR on boot The IA32_MTRRdefType MSR describes the default memory type used for physical addresses which are outside of any configured memory ranges, as well as whether MTRRs and fixed ranges are enabled. Without enabling this MSR, guest kernel is not able to change memory types for memory ranges outside main memory. This was causing pmem region to be marked as `uncached-minus` which instructed the cpu to skip all caches (L1, L2, L3) when reading/writing to that memory region. To fix this set IA32_MTRRdefType set to 0x806: - bit 11 enables MTRR - bits 0..7 specify the memory type used by default - value 6 represents `write-back` type Now guest can correctly set pmem memory region to `write-back` memory type.
