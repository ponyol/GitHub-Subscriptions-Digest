Суммаризация (на русском)

Недавние обновления вносят несколько улучшений в протокол FE, включая добавление дополнительного смысла сообщениям наблюдателя для поддержки специфических функций исполнителя, а также новое сообщение протокола для индикации сбоев при создании вызовов функций. Кроме того, система теперь надежно обрабатывает ошибки, когда исполнитель не может создать выходные BLOB-объекты, вызывая исключение `InternalError SDK` в пользовательском коде для более чистого информирования о сбоях.

Исходный текст

- Add extra meaning to watcher message in FE protocol (#479) This helps us to implement https://github.com/tensorlakeai/indexify/issues/1868 using this extra meaning on Executor side. - Add FE protocol message for failing to create Function Call (#478) Don't wait for the message yet as Executor is not sending it yet. - Handle error when Executor fails to create output BLOB This raises InternalError SDK exception into user code if this fails running a function. The allocation fails cleanly if this fails upload of value returned from the function to blob store.
