Python's default text-mode open performs universal-newlines translation, which is what was shrinking the text Serena sent in didOpen. Override open_file in HlslLanguageServer to preload LSPFileBuffer contents with newline="" so the bytes sent to the server match what it reads from disk, sidestepping the stale-tree condition entirely. The fix is scoped to hlsl_language_server.py; no core files are touched. Verified with a 28-shader sweep over a Unity HDRP workspace where the crash was 100% reproducible (TerrainRayMarch.shader -> TerrainSDF.hlsl); all files now return symbols cleanly.
