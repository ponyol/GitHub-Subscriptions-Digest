Суммаризация (на русском)

Версия 2.1.3 устраняет критическую ошибку в SearchGraph, перенося бэкенд DuckDuckGo на `ddgs`. В новых версиях также добавлена поддержка OpenAI Batch API через `SmartScraperMultiBatchGraph` для экономии до 50% на вызовах LLM. Проект включает обновление модели MiniMax по умолчанию до M3 и исправления импорта для совместимости с обновленными библиотеками.
