Суммаризация (на русском)

The CugaAgent SDK was significantly enhanced with a TokenUsageTracker, enabling full LLM conversation trajectory support and ensuring proper callback merging across all execution methods. New features include semantic memory ("user facts") for Cuga-lite, allowing agents to store and retrieve user-specific information to enhance context. Additionally, a unified sandbox-aware execution model was introduced to standardize agent workspaces and require LLMs to use relative paths, alongside fixes for MCP tool naming and schema handling. --- SDK CugaAgent был значительно улучшен благодаря интеграции TokenUsageTracker, что позволило полноценно отслеживать траектории разговоров LLM и обеспечило правильное объединение пользовательских колбэков во всех методах выполнения. Среди новых функций — семантическая память ("факты пользователя") для Cuga-lite, позволяющая агентам хранить и извлекать информацию, специфичную для пользователя, для улучшения контекста. Кроме того, была введена единая модель выполнения с учетом "песочницы", стандартизирующая рабочие пространства агентов и требующая от LLM использования только относительных путей, а также внесены исправления для обработки имен инструментов MCP и их схем.
