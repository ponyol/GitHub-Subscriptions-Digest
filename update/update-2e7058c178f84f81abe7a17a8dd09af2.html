Суммаризация (на русском)

Этот выпуск значительно улучшает Guardrail API с функциями V2, такими как метаданные, идентификатор сеанса и поддержка изображений, а также новый универсальный API для внешних провайдеров. Введен Z.AI (Zhipu AI) как встроенный провайдер, расширена поддержка моделей для Databricks, Kimi и Claude, а также добавлена транскрипция аудио для OVHcloud. Другие ключевые обновления включают рефакторинг LLM API для приема ввода типа list[str], важные исправления для SSO и проверки командных бюджетов, а также новые возможности, такие как интеграция GitHub Copilot Embedding API и информация о пользователе OIDC для JWT Auth.
