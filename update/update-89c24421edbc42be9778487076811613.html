Он также интегрирует официальный маркетплейс навыков Airtable и новые плагины для машинного обучения. Кроме того, были добавлены несколько новых навыков, включая pdf-fill-studio для локального заполнения PDF-форм, android-cicd для публикации в Google Play, bleu для планирования и building-blog для веб-разработки.
