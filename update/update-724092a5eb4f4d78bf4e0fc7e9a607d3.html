Суммаризация (на русском)

Recent updates to `voxtype` (formerly `voice-type`), a local voice dictation CLI tool, have significantly improved its performance and user experience. Key changes include optimizing transcription engines (Parakeet, MLX) with fixes for GPU cache leaks and slow startup times, along with various reliability enhancements for microphone input and segmentation. User experience has been notably refined through the introduction of an expressive 'talking ghost' recording overlay, an interactive setup wizard, improved default segmentation ('hold' mode), and comprehensive documentation. --- Недавние обновления `voxtype` (ранее `voice-type`), инструмента командной строки для локальной голосовой диктовки, значительно улучшили его производительность и пользовательский опыт. Ключевые изменения включают оптимизацию движков транскрипции (Parakeet, MLX) с исправлениями утечек кэша GPU и медленного запуска, а также различные улучшения надежности для ввода с микрофона и сегментации. Пользовательский опыт был заметно доработан благодаря внедрению выразительного индикатора записи в виде 'говорящего призрака', интерактивного мастера настройки, улучшенной сегментации по умолчанию (режим 'hold') и всеобъемлющей документации.
