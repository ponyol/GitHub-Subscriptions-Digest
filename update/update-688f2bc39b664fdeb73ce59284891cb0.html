Суммаризация (на русском)

This release significantly enhances system stability and media handling capabilities across various channels. Key improvements include a new pluggable Context Engine for custom context management, extensive fixes for media delivery (HEIC support, normalization, size limits), and robust error handling for gateway, authentication, and channel integrations like iMessage and Feishu. The update also streamlines developer experience through dependency cleanup, refined tooling, and a new web search onboarding flow. --- Этот релиз значительно повышает стабильность системы и улучшает обработку медиафайлов для различных каналов. Среди ключевых улучшений — новая подключаемая система Context Engine для управления контекстом, обширные исправления для доставки медиа (поддержка HEIC, нормализация, ограничения размера) и усиленная обработка ошибок для шлюза, аутентификации и интеграций с каналами, такими как iMessage и Feishu. Обновление также оптимизирует работу разработчиков за счет удаления неиспользуемых зависимостей, улучшенных инструментов и нового процесса онбординга с поиском в интернете.
