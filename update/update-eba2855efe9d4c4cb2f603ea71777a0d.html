Суммаризация (на русском)

Этот выпуск добавляет поддержку новых моделей OpenAI gpt-5.5 и gpt-5.4-mini для Copilot, а также интегрирует AWS Bedrock. Он улучшает возможности переопределения конфигурации моделей, позволяя пользователям устанавливать лимиты контекста и ценообразование для каждой модели, а также поддерживает дополнительные файлы конфигурации для глубокого слияния. Важные исправления включают решение проблем с обновлением токенов OAuth для динамических клиентов, предотвращение ошибок Anthropic 400 и корректную обработку вывода рассуждений от моделей типа Mistral. Кроме того, пользовательские команды теперь поддерживают описания и именованные аргументы, а информация о чате доступна через API.
