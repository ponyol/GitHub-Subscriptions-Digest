Суммаризация (на русском)

This update introduces durable runtime support for deterministic execution environments, alongside significant enhancements to agent-to-agent (A2A) communication and telemetry for improved error reporting and tracing. New features include PDF support and streaming for Anthropic models, an optimized BigQuery analytics plugin with auto-views and better tracing, and expanded tooling for skills management and data services like Dataplex and Bigtable. The release also resolves several bugs, notably with temporary state management in sequential agents and improved agent discovery. --- **Русский перевод:** Это обновление внедряет поддержку длительного выполнения для детерминированных сред, а также значительно улучшает меж-агентное взаимодействие (A2A) и телеметрию для более точной отчетности об ошибках и улучшенной трассировки. Новые функции включают поддержку PDF и потоковой передачи для моделей Anthropic, оптимизированный плагин аналитики BigQuery с автоматическим созданием представлений и улучшенной трассировкой, а также расширенные инструменты для управления навыками и службами данных, такими как Dataplex и Bigtable. Релиз также устраняет несколько ошибок, в частности, связанных с управлением временным состоянием в последовательных агентах и улучшенным обнаружением агентов.
