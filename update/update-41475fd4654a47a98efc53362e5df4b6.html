Это обновление значительно улучшает интерфейс `cognee-frontend` для локального (OSS) режима, начиная с автоматической синхронизации общего кода из репозитория SaaS, за исключением облачных функций. Оно вводит баннер на панели управления и модальное окно для упрощения настройки ключа LLM API, а также исправляет процесс регистрации агентов и функциональность страницы API-ключей для взаимодействия с локальным бэкендом.
