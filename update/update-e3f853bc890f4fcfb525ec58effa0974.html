Vulpea v2.6.0 delivers a significant performance and responsiveness upgrade through the introduction of **asynchronous extraction** via a background worker process and 'full-write' mode, virtually eliminating UI freezes during indexing. This release also features faster element-granularity parsing, optimized link scanning, and a refined extractor plugin API with an opt-in AST, alongside numerous bug fixes and comprehensive documentation updates. *** Vulpea v2.6.0 представляет собой значительное улучшение производительности и отзывчивости благодаря внедрению **асинхронного извлечения данных** через фоновый рабочий процесс и режим 'full-write', практически исключая зависания пользовательского интерфейса во время индексации. Этот выпуск также включает более быстрый синтаксический анализ с детализацией по элементам, оптимизированное сканирование ссылок и улучшенный API плагинов-извлекателей с явно подключаемым AST, наряду с многочисленными исправлениями ошибок и всесторонними обновлениями документации.
