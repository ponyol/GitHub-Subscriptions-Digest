Проект получил значительные обновления инфраструктуры, включая модернизацию GitHub Actions для совместимости с Node 24 и исправление проблем с wildcard-маршрутами `path-to-regexp` для предотвращения сбоев в работе. Была проведена масштабная рефакторинг, включающая удаление Deno из Docker-сборок и обновление шаблона развертывания Zeabur до PREBUILT_V2 с пользовательскими конфигурациями Postgres. Кроме того, была внедрена комплексная инфраструктура тестирования фронтенда, исправлены многочисленные юнит-тесты и расширена документация, в частности, для `pgvector` с использованием AI-встраиваний.
