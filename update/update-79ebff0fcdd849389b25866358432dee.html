Суммаризация (на русском)

Это обновление вводит комплексную функцию "recall" (отзыва) для сред разработки Cursor, Antigravity и Claude, позволяя агентам ИИ предварительно извлекать прошлую информацию из "palace" перед ответом, используя новый протокол, хуки, навыки и правила. Одновременно были значительно улучшены основные бэкэнд-системы: теперь обеспечивается проверка идентичности эмбеддера для предотвращения повреждения данных из-за несоответствия моделей, стандартизированы хуки обслуживания для таких операций, как переиндексация, а расчеты подобия при поиске стали учитывать метрику для повышения точности. Дополнительные изменения включают новые инструменты Mempalace Control Protocol (MCP) для управления "hallways" и различные исправления ошибок.
