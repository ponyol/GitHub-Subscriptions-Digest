Суммаризация (на русском)

This update features a major overhaul of the OCR pipeline, introducing layout-driven processing, configurable OCR modes, and refined text region generation. Key new functionalities include detecting code blocks in DOCX, supporting inline formulas and emphasis in JATS, and adding compatibility for legacy binary office formats. Performance has been significantly improved for XLSX merged cell processing and EasyOCR model loading. Additionally, several fixes address stability issues, such as guarding against crashes from out-of-range table names and conditional imports, while enhancing CLI progress feedback. --- Это обновление включает значительную переработку конвейера OCR, внедряя обработку на основе макета, настраиваемые режимы OCR и улучшенную генерацию текстовых областей. Среди ключевых новых функций — обнаружение блоков кода в DOCX, поддержка встроенных формул и выделений в JATS, а также добавление совместимости с устаревшими бинарными форматами Office. Производительность была значительно улучшена для обработки объединенных ячеек XLSX и загрузки моделей EasyOCR. Кроме того, ряд исправлений направлен на повышение стабильности, например, защита от сбоев из-за некорректных имен таблиц и условных импортов, а также улучшена обратная связь о ходе выполнения в CLI.

A numeric namest pointing past the declared columns reached cell_offst[start - 1] and raised IndexError, which is caught at the call site so the whole table is dropped from the output. Extend the existing wrong-column guard to also reject a start that is below 1 or past the last column, so such an entry degrades like a mismatched-column row instead of crashing the table.
