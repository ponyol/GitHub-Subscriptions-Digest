Суммаризация (на русском)

This update primarily addresses `is_blocked` data consistency by introducing a `bd recompute-blocked` command and integrating repair into `bd doctor`. It also fixes a critical issue where `dolt pull` could block due to uncommitted configuration changes, now ensuring explicit config commits and auto-resolving conflicts. Additionally, many CLI commands gain proxied-server support, and `bd init` now features an idempotent `--init-if-missing` flag for easier setup. --- Данное обновление в основном решает проблему согласованности данных `is_blocked`, представляя новую команду `bd recompute-blocked` и интегрируя исправление в `bd doctor`. Оно также устраняет критическую проблему, при которой `dolt pull` мог быть заблокирован из-за незакоммиченных изменений конфигурации, теперь обеспечивая явные коммиты конфигурации и автоматическое разрешение конфликтов. Кроме того, многие команды CLI теперь поддерживают режим прокси-сервера, а `bd init` получил идемпотентный флаг `--init-if-missing` для упрощения настройки.
