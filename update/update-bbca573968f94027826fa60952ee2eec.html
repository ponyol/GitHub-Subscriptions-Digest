This update introduces a new, AI-optimized bug report template and client-side telemetry for enhanced system maintainability and observability. Key features include intelligent load prioritization for segment operations, a new `orderby` capability, and an API for retrieving replication configurations. Numerous fixes address issues like macOS build compatibility, bloom filter leaks, and idempotency, complemented by security upgrades to Go (1.24.12) and gpgv. Extensive new tests also improve coverage for three-valued logic and snapshot functionality. --- Это обновление представляет новый шаблон отчетов об ошибках, оптимизированный для ИИ-агентов, и клиентскую телеметрию, что повышает удобство обслуживания и наблюдаемость системы. Ключевые улучшения включают интеллектуальную приоритизацию загрузки для операций с сегментами, новую возможность `orderby` и API для получения конфигураций репликации. Множество исправлений устраняют проблемы совместимости сборки macOS, утечки bloom-фильтров и идемпотентности, дополненные обновлениями безопасности Go (1.24.12) и gpgv.
