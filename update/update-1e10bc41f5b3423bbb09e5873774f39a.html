Суммаризация (на русском)

Обновление значительно повышает производительность ядер GPU и моделей ИИ, включая поддержку структурированных блочных матричных умножений с FP4 и улучшенную многопроцессорную широковещательную передачу. Стандартная библиотека Mojo получила декоратор `@align(N)`, реорганизованные API рефлексии и более четкую обработку ошибок, при этом `Tensor` переименован в `Buffer` в MAX/Graph API для ясности. Кроме того, добавлена поддержка новых моделей, таких как Qwen3-VL и DeepSeekV3.2, наряду с различными улучшениями инфраструктуры и CI.

MODULAR_ORIG_COMMIT_REV_ID: 0cad553caf788c7c7420f4a6db6b90e4d1aacb6b - [stdlib] Remove `Boolable` and `Defaultable` for `Error`. This PR removes the `Boolable` and `Defaultable` trait conformances from Mojo's `Error` type, enforcing better error handling practices. By removing `Defaultable`, we ensure that every `Error` must be constructed with meaningful context. Default-constructing an error produces an empty, unhelpful error message that defeats the purpose of error reporting. By removing `Boolable`, we eliminate the confusing pattern of treating errors as boolean values. if you have an `Error` instance, you have an error. Optionality should be expressed through `Optional[Error]` or by simply not raising an error, rather than overloading the `Error` type itself with boolean semantics.
