Суммаризация (на русском)

The Milvus version has been bumped to v3.0-beta, bringing significant enhancements such as improved QueryCoord task scheduling, expanded JSON Path Indexing with new types (Sort, Bitmap, Hybrid), and unification of filesystem access for better I/O metrics. Several fixes address critical issues like streaming node rolling upgrades, element-level search deduplication, and array element null checks, alongside updating GPU Docker images to CUDA 12.9.1. General optimizations were applied across metadata handling, replication, and various components to improve performance and stability. Additionally, unused GitHub workflows were removed, and Python client test dependencies were updated. Версия Milvus обновлена до v3.0-beta, внеся значительные улучшения, такие как оптимизация планирования задач QueryCoord, расширение индексации JSON Path с новыми типами (Sort, Bitmap, Hybrid) и унификация доступа к файловой системе для более точных метрик ввода-вывода. Ряд исправлений устраняет критические проблемы, такие как поэтапные обновления потоковых узлов, дедупликация результатов поиска на уровне элементов и проверки значений NULL в элементах массива, а также обновлены образы GPU Docker до CUDA 12.9.1. Общие оптимизации были применены к обработке метаданных, репликации и различным компонентам для повышения производительности и стабильности. Кроме того, были удалены неиспользуемые рабочие процессы GitHub и обновлены зависимости тестов Python-клиента.
