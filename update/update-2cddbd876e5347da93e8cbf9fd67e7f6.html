Суммаризация (на русском)

This release significantly enhances the memory system for Eve agents, introducing a reliable, automatic long-term memory backed by the Hindsight REST API, replacing less dependable model tool-calling. The control plane received notable UI/UX improvements, including an animated "memories constellation" with detailed dialog views, the removal of the older Graph view, and a fix to display all mental models. Furthermore, LLM interactions are more robust and configurable with per-operation temperature, timeout, and retry settings, alongside stricter schema handling. Performance is also improved via a distributed bank statistics cache, and new integrations expand the platform's capabilities. --- **Russian Translation:** Данный релиз значительно улучшает систему памяти для агентов Eve, внедряя надежную, автоматическую долгосрочную память, поддерживаемую REST API Hindsight, что заменяет менее надежный вызов инструментов моделью. Панель управления получила заметные улучшения UI/UX, включая анимированное "созвездие воспоминаний" с подробными диалоговыми окнами, удаление устаревшего вида "Граф" и исправление, позволяющее отображать все ментальные модели. Кроме того, взаимодействие с LLM стало более надежным и настраиваемым благодаря параметрам температуры, таймаутов и повторных попыток для каждой операции, а также более строгой обработке схем. Производительность также повышена за счет распределенного кэша статистики банков, а новые интеграции расширяют возможности платформы.
