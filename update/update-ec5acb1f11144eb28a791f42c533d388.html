Суммаризация (на русском)

This update introduces significant UI/UX improvements, including enhanced visual density, a new combined modal for job artifacts with profiling, and fixes for CLI JSON output and task file viewing. Interactive tasks received better automatic status updates and new warnings. Key architectural changes involve the removal of the plugin system and various backend stability fixes. Additionally, Sentry telemetry was added to the CLI installer, alongside addressing several confusing messages and improving testing. *** Это обновление вносит значительные улучшения в пользовательский интерфейс (UI/UX), включая повышенную визуальную плотность, новый объединенный модальный диалог для артефактов заданий с функцией профилирования, а также исправления для вывода JSON в CLI и просмотра файлов задач. Интерактивные задачи теперь имеют улучшенные автоматические обновления статуса и новые предупреждения. Ключевые архитектурные изменения включают удаление системы плагинов и различные исправления стабильности бэкенда. Кроме того, в установщик CLI добавлена телеметрия Sentry, наряду с устранением нескольких неясных сообщений и улучшением тестирования.
