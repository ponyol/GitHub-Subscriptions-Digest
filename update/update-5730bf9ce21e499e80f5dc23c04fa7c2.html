Суммаризация (на русском)

Этот релиз представляет собой значительную переработку пользовательского интерфейса Datasette для манипуляции данными, добавляя встроенную функциональность вставки, редактирования и удаления строк таблицы через интерактивные модальные диалоги. Он включает новые функции, такие как автозаполнение внешних ключей, хук плагина `makeColumnField()` для пользовательских полей форм и шаблон "Create table". Значительные усилия также были направлены на расширение тестового покрытия за счет широкого внедрения Playwright для тестирования пользовательского интерфейса по многим функциям.
