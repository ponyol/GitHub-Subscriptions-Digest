Суммаризация (на русском)

This update introduces significant enhancements across the platform. The Python SDK now supports annotation queues, comprehensive dataset version management, and metadata exposure for online evaluation rules, alongside improved feedback logging. Backend performance has been boosted through query optimizations, and Opus 4.6 is now supported. Frontend improvements include better table loading UX, streamlined navigation to experiment items from traces, and numerous security fixes and dependency upgrades. --- Это обновление вносит значительные улучшения во всю платформу. Python SDK теперь поддерживает очереди аннотаций, комплексное управление версиями наборов данных и предоставление метаданных для правил онлайн-оценки, а также улучшенное логирование обратной связи. Производительность бэкенда была повышена за счет оптимизации запросов, а также добавлена поддержка Opus 4.6. Улучшения внешнего интерфейса включают улучшенный пользовательский опыт при загрузке таблиц, упрощенную навигацию к элементам экспериментов из трассировок и многочисленные исправления безопасности и обновления зависимостей.
