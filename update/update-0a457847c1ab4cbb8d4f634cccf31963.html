The recent updates for Cognee include the release of version 1.4.0 and significant architectural changes. The Gmail connector has been migrated from the core system to a separate `cognee-community` package, enabled by a new connector-agnostic DLT ingestion path that also refines data cleanup. The evaluation framework has been modernized by archiving the old HotpotQA suite and making the BEAM report the new standard. Critical bug fixes improve multi-tenant agent feedback persistence and session data handling, alongside the introduction of a new Islo SDK sandbox deployment option. --- **Russian Translation:** Последние обновления Cognee включают выпуск версии 1.4.0 и значительные архитектурные изменения. Коннектор Gmail был перенесен из основной системы в отдельный пакет `cognee-community`, что стало возможным благодаря новому коннектору-независимому пути приема данных DLT, который также улучшает очистку данных. Система оценки была модернизирована путем архивирования старого набора HotpotQA и принятия отчета BEAM в качестве нового стандарта. Критические исправления ошибок улучшают сохранение обратной связи агентов в многопользовательских средах и обработку данных сессий, а также добавлена новая опция развертывания песочницы Islo SDK.
