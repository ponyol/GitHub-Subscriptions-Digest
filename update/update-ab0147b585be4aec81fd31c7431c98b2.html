Суммаризация (на русском)

Наиболее значительное обновление вводит поддержку нескольких вкладок браузера через одно соединение, используя новый протокол extension-bridge v2 и централизованный `cdpRelay` для оркестрации CDP-сессий. Это обеспечивает лучшее управление дочерними сессиями и включает начальную обратную совместимость для клиентов протокола v1. Кроме того, был добавлен новый рабочий процесс для публикации расширения в Chrome Web Store, а сообщения об ошибках были улучшены для навигации пользователей.
