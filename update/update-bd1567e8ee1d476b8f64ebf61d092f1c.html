Суммаризация (на русском)

Пакет `browse CLI` был выпущен с открытым исходным кодом, предоставив автоматизацию браузера с сохранением состояния для ИИ-агентов, а также новые флаги для управления состоянием браузера между сессиями и сделав `BROWSERBASE_PROJECT_ID` необязательным. Основные возможности API были расширены за счет поддержки пользовательских HTTP-заголовков в вызовах LLM и включения `cdpHeaders` в спецификацию сервера v3, при этом вызовы агентов OpenAI теперь по умолчанию устанавливают `store: false` для предотвращения проблем с хранением данных. В рамках архитектурных изменений сервер Stagehand был разделен на отдельные пакеты v3 и v4, а также были добавлены новые действия GitHub для безопасной обработки запросов на слияние от внешних участников.
