chore: update lock files - fix(mcp): make transport security configurable for remote/LAN deployments (#2518) ## Summary - Adds env-var-based configuration for MCP transport security so cognee-mcp works in Docker/LAN deployments without patching the image - Fixes 421 `Invalid Host header` when clients connect from any non-localhost address (e.g. over LAN, or via `0.0.0.0` bind) - Makes CORS `allow_origins` configurable instead of hardcoded to `http://localhost:3000` ## Problem The MCP SDK's `FastMCP` hardcodes DNS rebinding protection to only allow `localhost`/`127.0.0.1`/`[::1]`. When running `cognee-mcp` in Docker with `network_mode: host` and clients connecting over LAN, every request gets rejected with `421 Invalid Host header`. The CORS middleware also hardcodes `allow_origins` to `http://localhost:3000`, blocking browser-based clients on other hosts. Additionally, `mcp.settings.host` was being set *after* `FastMCP()` init, so the SDK's auto-detection (which keys off the bind host) was always seeing `127.0.0.1` regardless of `--host`. ## Changes **New env vars:** | Variable | Default | Purpose | |----------|---------|---------| | `MCP_DISABLE_DNS_REBINDING_PROTECTION` | `false` | Set to `true` to disable all Host/Origin validation | | `MCP_ALLOWED_HOSTS` | *(empty)* | Comma-separated additional Host patterns (e.g. `192.168.1.50:*`) | | `MCP_CORS_ALLOW_ORIGINS` | `http://localhost:3000` | Comma-separated CORS allowed origins | **Architecture:** - Transport security is configured in `main()` after arg parsing via `_configure_transport_security(host)`, so it sees the actual bind host - SDK defaults are preserved when binding to loopback with no extra hosts (no unnecessary override) - Origins are auto-derived from `MCP_ALLOWED_HOSTS` as `http://<host>` so users don't need to set parallel env vars - Startup logs show the resolved security config for debugging **Example docker-compose for LAN:** ```yaml services: cognee-mcp: image: cognee/cognee-mcp:main network_mode: host environment: TRANSPORT_MODE: "http" MCP_ALLOWED_HOSTS: "192.168.1.50:*" ``` Or to disable protection entirely: ```yaml MCP_DISABLE_DNS_REBINDING_PROTECTION: "true" ``` ## Test plan -
