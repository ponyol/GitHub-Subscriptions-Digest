Суммаризация (на русском)

Это обновление включает в себя ряд исправлений ошибок, новых функций и внутренних улучшений. Основные исправления касаются заголовков API проектов организаций, отсутствующих переменных платформы в тестовых электронных письмах SMTP и различных проблем с конфигурацией SMTP. Новые функции включают публичный API организаций, настраиваемые триггеры сборки VCS, API присутствия и поддержку сред выполнения Bun и Deno для сборок сайтов, а также предоставление более подробных данных в моделях ответов. Значительные внутренние улучшения маршрутизации и внедрения зависимостей были достигнуты благодаря миграции на `utopia-php/http` feat-safe-wildcards.
