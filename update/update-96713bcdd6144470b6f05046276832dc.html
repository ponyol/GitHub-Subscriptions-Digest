Суммаризация (на русском)

Это обновление представляет несколько новых функций, включая поддержку внешних URL-адресов в `st.navigation`, программный выбор в `st.dataframe`, нативные типы контента для статических файлов, ярлыки типов файлов для `st.file_uploader` и `st.chat_input`, а также функцию повторного запуска `on_click` для `st.link_button`. Важные улучшения также позволяют оповещениям автоматически извлекать ведущие иконки из их текста. Значительные исправления ошибок касаются проблем с авторасширением высоты `st.text_area`, устаревших параметров запроса при навигации по страницам и рендерингом `AppTest` для приложений на базе `st.navigation`, наряду с различными обновлениями зависимостей и внутренними улучшениями CI/документации.
