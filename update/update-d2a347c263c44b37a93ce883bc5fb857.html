Суммаризация (на русском)

Это обновление добавляет поддержку песочниц E2B, представляя новую среду `E2BREPL` для выполнения кода Python с использованием SDK E2B-code-interpreter и паттерна HTTP-брокера. Оно позволяет использовать расширенные взаимодействия с LLM, такие как `llm_query()`. Также был добавлен параметр `persistent` для соответствия другим средам, хотя полная поддержка персистентности для E2BREPL еще не реализована.
