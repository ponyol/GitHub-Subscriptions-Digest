Суммаризация (на русском)

Версия 0.5.1 устраняет сбои декодирования пакетов в `model.generate()` для пакетных относительных позиционных вложений. Ранее компоненты `RelPositionMultiHeadAttention` давали сбой, когда позиционные вложения, поставляемые с размером пакета 1, использовались с многоэлементными входными пакетами. Обновление транслирует позиционное вложение до размера пакета запроса, исправляя ошибки изменения формы и обеспечивая корректную работу как для пакетных, так и для одиночных входных данных.

Исходный текст

- 0.5.1 - support batched relative positional embeddings in generate() (#50) (#51) RelPositionMultiHeadAttention and RelPositionMultiHeadLocalAttention assumed pos_emb already had the same batch size as q/k/v, then reshaped p with batch from query tensors. For batched inference (B > 1), positional encoding provides batch 1, which caused reshape failures like: `Cannot reshape array of size ... into shape (B, ...)`. This change updates both attention paths to: - Broadcast p from batch 1 to query batch B when needed. - Raise a clear ValueError when pos_emb batch is neither 1 nor B. Result: fixes batch decode failures in model.generate() while preserving existing behavior for single-item inputs.
