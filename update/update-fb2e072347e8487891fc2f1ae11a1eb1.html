Суммаризация (на русском)

Добавлена схема платежей "upto" для TypeScript и Go SDK, позволяющая осуществлять платежи EVM на основе использования через Permit2. Значительные обновления включают рефакторинг структур путей API для обеспечения согласованности, добавление новых адаптеров фреймворков (Fastify, Echo, net/http) для расширения совместимости промежуточного ПО и улучшение схем расширений обнаружения с автоматическим заполнением методов. Стабильность была улучшена за счет устранения состояний гонки при ленивой инициализации фасилитатора, а также исправлены различные ошибки, касающиеся парсинга заголовков, линтинга и тестов e2e.
