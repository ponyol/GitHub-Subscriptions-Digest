Суммаризация (на русском)

Последние обновления значительно расширяют возможности управления песочницами и образами в Tensorlake. Введена важная новая функция, позволяющая импортировать образы из реестра непосредственно в песочницу без использования Docker, что существенно снижает потребление ресурсов и нагрузку на ввод-вывод. Дополнительно появились новые возможности для управления процессами внутри песочниц, включая политики перезапуска и проверки работоспособности, доступные через команды CLI, такие как `tl sbx ps`, `restart` и `kill`. Также была переработана TypeScript SDK с использованием ядра на Rust для повышения производительности и надежности, а также добавлены общие улучшения CLI, поддержка cloud-init и расширенная совместимость с Dockerfile.

Managed processes return the same `ProcessInfo` object as normal processes, with an extra `managed` field containing supervisor status, restart count, restart policy, health-check config, health status, last exit, last error, and next restart time. `restart_process` / `restartProcess` manually restarts a managed PID through `POST /api/v1/processes/{pid}/restart`.
