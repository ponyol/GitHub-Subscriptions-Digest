Суммаризация (на русском)

Это обновление Faiss повышает надежность, преобразуя фатальные утверждения при десериализации в перехватываемые исключения, что предотвращает сбои из-за некорректных входных данных. Производительность улучшена за счет более эффективного управления таблицей посещений HNSW и добавления оптимизированных ядер AVX2/AVX512 для 8-битного квантования. Кроме того, оно добавляет поддержку IVF-PQ для бэкэнда Metal GPU, расширяет функциональность GPU IVF `add_preassigned` и включает новый вариант Python cuVS 26.02 для aarch64/GH200. Также исправлена ошибка, связанная с выбором кучи Жаккара при поиске IVF.
