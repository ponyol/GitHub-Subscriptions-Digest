Суммаризация (на русском)

This release significantly enhances LocalAI with new capabilities, including true streaming Text-to-Speech for VibeVoice, a new backend for transcription with speaker diarization (MOSS-Transcribe-CPP), and voice-cloning TTS via F5-TTS in CrispASR. Key improvements cover interleaved thinking with tool calls, automatic context size adjustment (`-1`) considering VRAM, and a new API endpoint for model capabilities. Critical fixes improve backend stability by ensuring resumable model downloads, resolving Protobuf versioning issues, broadening OIDC authentication support, and preventing model load retry-storms. --- Этот выпуск значительно улучшает LocalAI, добавляя истинно потоковый синтез речи для VibeVoice, новый бэкенд для транскрипции с диаризацией дикторов (MOSS-Transcribe-CPP) и синтез речи с клонированием голоса через F5-TTS в CrispASR. Важные улучшения включают поддержку чередующегося мышления с вызовами инструментов, автоматическую настройку размера контекста (`-1`) с учетом видеопамяти, а также новую конечную точку API для просмотра возможностей моделей. Критические исправления повышают стабильность бэкенда за счет обеспечения возобновляемой загрузки моделей, устранения проблем с версиями Protobuf, расширения поддержки аутентификации OIDC и предотвращения циклических попыток загрузки моделей после сбоев.
