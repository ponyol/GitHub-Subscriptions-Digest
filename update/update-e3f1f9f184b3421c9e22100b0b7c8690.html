Суммаризация (на русском)

This release significantly enhances PDF extraction capabilities, introducing support for annotation extraction across all language bindings. Key improvements include advanced multi-column and table detection, ligature repair and text encoding normalization, and the integration of bounding boxes for spatial data and inline table/image embedding in markdown output. The OCR system was upgraded with multi-language support via PaddleOCR PP-OCRv5 models and automatic fallback for broken fonts. Additionally, the API now exposes typed fields for extracted keywords, quality scores, and processing warnings, alongside extensive CI/build fixes and underlying PDFium updates. --- **Russian translation:** Этот выпуск значительно расширяет возможности извлечения PDF, добавляя поддержку извлечения аннотаций во всех языковых привязках. Ключевые улучшения включают усовершенствованное обнаружение многоколоночных макетов и таблиц, исправление лигатур и нормализацию текстовой кодировки, а также интеграцию ограничивающих рамок для пространственных данных и встраивание таблиц/изображений в вывод Markdown. Система OCR была обновлена, получив многоязычную поддержку через модели PaddleOCR PP-OCRv5 и автоматический откат при обнаружении поврежденных шрифтов. Кроме того, API теперь предоставляет типизированные поля для извлеченных ключевых слов, оценок качества и предупреждений обработки, наряду с многочисленными исправлениями CI/сборки и обновлениями базовой библиотеки PDFium.
