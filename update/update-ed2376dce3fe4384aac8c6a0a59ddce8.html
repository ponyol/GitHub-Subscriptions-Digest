Суммаризация (на русском)

This update promotes Agent Skills from experimental to stable and introduces source information tracking in telemetry logs. It includes several key CLI and UI fixes, such as preventing Tab key conflicts on Windows, improving large paste handling on macOS, and routing sandbox diagnostic messages to stderr. Additionally, the SDK now supports resuming sessions and extended authentication types, with enhanced CI/CD workflows for releases and new features for exporting session history in various formats. The Qwen OAuth free quota has also been adjusted, and the overall version bumped to 0.10.0. --- Это обновление переводит навыки агента из экспериментальной в стабильную фазу и вводит отслеживание информации об источнике в телеметрических логах. Оно включает несколько ключевых исправлений CLI и пользовательского интерфейса, таких как предотвращение конфликтов клавиши Tab в Windows, улучшенная обработка больших вставок в macOS и маршрутизация диагностических сообщений песочницы в stderr. Кроме того, SDK теперь поддерживает возобновление сессий и расширенные типы аутентификации, с улучшенными рабочими процессами CI/CD для релизов и новыми функциями экспорта истории сессий в различных форматах. Бесплатная квота Qwen OAuth также была скорректирована, и общая версия обновлена до 0.10.0.
