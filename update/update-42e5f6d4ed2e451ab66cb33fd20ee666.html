The latest updates focus on improving stability, responsiveness, and expanding integration capabilities. Key changes include a promise-based mechanism to ensure dynamic tools are correctly loaded, fixes for OAuth server crashes in native images, and dispatching long-running tasks to background threads to prevent UI unresponsiveness. The release also adds support for new LLM providers (LiteLLM, LM Studio, Mistral, Moonshot), parameterized skills, and introduces a comprehensive protocol for managing providers and models. *** Последние обновления сосредоточены на улучшении стабильности, отзывчивости и расширении возможностей интеграции.
