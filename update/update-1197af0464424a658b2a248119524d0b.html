- Add Git repository status command - Always show CLI credential tokens - Add repo scoped Git token CLI support - Add Artifact Storage SDK and CLI commands - Skip AWS-backed CI steps for fork PRs (#776) ## Summary - keep build, lint, and unit tests running for forked PRs - skip AWS/ECR-backed local integration steps when PRs come from forks - run cloud CI jobs from the prod GitHub environment only - stop passing `TENSORLAKE_API_URL` from secrets for cloud tests so SDKs use production defaults - keep localhost Indexify tests using their local URL overrides ## Context Forked PRs do not receive the private repo vars/secrets needed by the AWS credential step.
