Суммаризация (на русском)

Это обновление значительно расширяет возможности SSH и улучшает тестирование. Внедрена новая среда интеграционного тестирования на базе Docker Compose для всесторонней сквозной проверки потоков аутентификации SSH (по публичному ключу, по паролю) и обработки команд, охватывающая различные алгоритмы и проверки ключей хоста. Кроме того, реализована поддержка RFC 8308 для обнаружения методов аутентификации клиента, что позволяет динамически выбирать оптимальный алгоритм аутентификации RSA с публичным ключом на основе возможностей сервера, а также улучшает поддержку подписей RSA-SHA2 и устаревшего SSH-RSA.

- Update changelog - Add live integration tests for SSH algorithms and auth flows Introduce a Docker Compose-backed OpenSSH test environment and a dedicated `ssh/integration-tests` ASDF system to run live end-to-end checks against localhost. The new test harness covers: - public key authentication with Ed25519, RSA-SHA2-256, RSA-SHA2-512, and SSH-RSA - password authentication - `run-command` stdout/stderr/exit-code handling - shell and subsystem helpers - strict vs non-strict host key checking - server signature algorithm discovery via `server-sig-algs` Also extend unit coverage for algorithm negotiation and RSA-SHA2-512 host-key verification, and update the README to reflect the broader algorithm support and the new integration test workflow. - RFC 8308 ext-info and RSA-SHA2 auth algorithm selection Implement RFC 8308 client-auth discovery by advertising `ext-info-c` in the initial KEXINIT, parsing `SSH_MSG_EXT_INFO`, and caching `server-sig-algs` in transport state. Use the advertised signature list to select the best RSA publickey auth algorithm, falling back to `ssh-rsa` when no extension info is available. Also update RSA signing/verification helpers to support SHA-1 signatures for legacy `ssh-rsa`, add host-key algorithm constants, reject role-invalid `ext-info-c` from servers, and expand tests/docs for ext-info parsing and RSA auth selection.
