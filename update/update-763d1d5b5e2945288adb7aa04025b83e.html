Суммаризация (на русском)

Выпущена версия Datasette 1.0a35, представляющая значительные обновления в управлении схемой базы данных. Ключевые дополнения включают новые модальные окна пользовательского интерфейса и JSON API для создания и изменения таблиц, с полной поддержкой операций со столбцами, первичными ключами и управления внешними ключами. Обновление также включает вспомогательный инструмент для статичных ресурсов с защитой от кэширования, расширенную документацию и различные улучшения пользовательского интерфейса и исправления ошибок.
