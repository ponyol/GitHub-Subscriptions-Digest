Этот выпуск модернизирует тестирование доступа к сети, заблаговременно вызывает предупреждения о конфиденциальности сети при публикации портов для улучшения пользовательского опыта, а также вводит флаг `--init` для команд `run/create` для управления зомби-процессами. Основные исправления включают повышение надежности `DirectoryWatcher` для резолверов DNS и улучшение логирования исключений API-сервера. Кроме того, обновлена зависимость `containerization`, добавлен скрипт `update-container` и отменен предыдущий вариант изменения времени выполнения для обеспечения постоянной конфигурации.
