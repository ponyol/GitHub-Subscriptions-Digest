Суммаризация (на русском)

Обновление значительно улучшает меж-агентное (A2A) взаимодействие за счет автоматизации обнаружения протоколов, обеспечения распространения идентификаторов пользователей и корректной пересылки токенов доступа суб-агентам. Оно расширяет возможности развертывания, добавляя поддержку Podman, корректное управление HPA для собственных развертываний и `imagePullSecrets` для приватных реестров контейнеров. Важные исправления включают привязку шлюза OpenClaw к интерфейсу loopback, очистку имен инструментов для совместимости с Bedrock API и добавление тайм-аутов для регистрации `RemoteMCPServer` для повышения стабильности. Кроме того, пользовательский интерфейс теперь поддерживает настройку разрешенных доменов, пересылку пользовательских заголовков для расширенного RBAC и сортировку сессий по недавней активности.
