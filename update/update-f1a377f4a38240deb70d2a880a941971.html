Суммаризация (на русском)

This update introduces several key enhancements across the system. The macOS application now offers users more control with environment variable overrides and a "Fast Synch" toggle, alongside a fix for PDF inputs on Safari. Backend stability is significantly improved through better error handling for streaming data, download progress, and graceful instance deletion, preventing various crash scenarios. Furthermore, critical fixes ensure accurate `reasoning_tokens` counting for thinking models, resolve a major memory leak in the BatchGenerator (especially for Qwen3.5), and incorporate necessary MLX LM refactor updates for improved model functionality. Russian translation: Этот пакет обновлений представляет несколько ключевых улучшений по всей системе. Значительно улучшена стабильность бэкенда за счет более надежной обработки ошибок при потоковой передаче данных, отслеживании хода загрузки и корректном удалении экземпляров, что предотвращает различные сценарии сбоев. Кроме того, критические исправления обеспечивают точный подсчет `reasoning_tokens` для "мыслящих" моделей, устраняют серьезную утечку памяти в BatchGenerator (особенно для Qwen3.5) и включают необходимые обновления рефакторинга MLX LM для улучшения функциональности моделей.
