Суммаризация (на русском)

This release brings substantial enhancements to user workflow and system stability, including fixing the `/clear` command order, improving auto-advancement with chain flag persistence, and introducing a research gate to prevent premature planning. Significant work was done on context management to reduce prompt sizes, enable caching, and modularize large agent files, alongside adaptive context enrichment for 1M models. The update also expands runtime support (Kilo, OpenCode, Augment, Cline) and automated UI verification (Playwright-MCP), while numerous fixes address Windows compatibility, concurrency, and user file preservation. Additionally, new debugging tools and stricter development governance were introduced. *** **Russian translation:** Этот выпуск значительно улучшает пользовательский рабочий процесс и стабильность системы, исправляя порядок команды `/clear`, улучшая авто-продвижение с сохранением флага `chain` и добавляя исследовательский шлюз для предотвращения преждевременного планирования. Проделана большая работа над управлением контекстом, включая уменьшение размеров промптов, кеширование и модульную декомпозицию файлов агентов, а также адаптивное обогащение контекста для моделей с 1M токенов. Обновление также расширяет поддержку сред выполнения (Kilo, OpenCode, Augment, Cline) и автоматическую проверку UI (Playwright-MCP), при этом многочисленные исправления затрагивают совместимость с Windows, параллелизм и сохранение пользовательских файлов. Кроме того, были введены новые инструменты отладки и ужесточено управление разработкой.
