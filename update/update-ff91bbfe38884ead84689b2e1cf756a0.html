Суммаризация (на русском)

This update introduces significant UI/UX enhancements, including a new "Guardrail Garden" marketplace for managing guardrails, a redesigned guardrail creation form, and improved usage tracking with prefixed credential tags and enhanced logs functionality. It also adds robust new guardrails, such as content filters for insults and competitor names, alongside comprehensive topic blocking capabilities. Core system reliability is boosted through self-healing database connections, Redis pool fixes, and performance optimizations for streaming responses, while CI/CD is improved with better test management and new UI unit tests. --- Это обновление вносит значительные улучшения в пользовательский интерфейс и опыт, включая новую торговую площадку "Guardrail Garden" для управления "стражами", переработанную форму создания "стражей" и улучшенный учет использования с префиксами для тегов учетных данных и расширенной функциональностью логов. Также добавлены надежные новые "стражи", такие как контент-фильтры для оскорблений и названий конкурентов, а также всесторонние возможности блокировки тем. Надежность основной системы повышена за счет самовосстановления подключений к базе данных, исправлений пула подключений Redis и оптимизации производительности для потоковой передачи ответов, а CI/CD улучшен благодаря лучшему управлению тестами и новым модульным тестам UI.
