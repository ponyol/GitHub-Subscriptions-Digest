Суммаризация (на русском)

Этот апдейт сосредоточен на значительных улучшениях для Kubeflow, особенно в интеграции с ModelKit, путем внедрения новых компонентов пайплайна, примеров инференса KServe и рефакторинга для использования `reference` вместо `uri` для соответствия OCI. Также существенно улучшена обработка "подсказок" (prompts) при генерации Kitfile и операциях упаковки/распаковки. Среди других ключевых изменений — исправление ошибок CI, добавление автоматической документации и обновление основных зависимостей Go и GitHub actions.
