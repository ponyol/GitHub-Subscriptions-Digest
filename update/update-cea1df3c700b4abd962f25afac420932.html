Суммаризация (на русском)

Это обновление добавляет функции поиска и пагинации для веток репозитория, а также улучшенную генерацию SDK для валидаторов запросов веток. Среди ключевых улучшений производительности — пропуск неактивных преобразований изображений, в то время как внутренние системы были рефакторизованы (CI раннеры и очереди сборок) для повышения стабильности. Релиз также улучшает обработку параметров API для OpenAPI/Swagger и содержит исправления для OAuth/OIDC, управления сессиями и тестов предварительного просмотра GraphQL.
