Суммаризация (на русском)

Этот релиз значительно улучшает интеграцию с OpenAI Agents, добавляя такие функции, как `memory_instructions` и шаблоны для использования в продакшене, а также обновляет интеграцию OpenClaw для сохранения памяти в формате JSON с учетом вызовов инструментов для каждой сессии. Ключевые улучшения включают режим структурированного дельта-обновления для ментальных моделей, настраиваемые элементы управления отзывом для каждой модели и улучшенную логику консолидации с параметром `max_memories_per_round` и бюджетами повторных попыток. Панель управления теперь предлагает обновленную статистику банков памяти, граф совместной встречаемости сущностей и улучшенную прозрачность операций, а общая надежность повышена за счет исправлений, касающихся повторных попыток LLM, ошибок переранжирования и планирования задач воркеров.
