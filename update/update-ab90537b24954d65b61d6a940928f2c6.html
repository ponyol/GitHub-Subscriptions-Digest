Суммаризация (на русском)

Это обновление значительно перерабатывает генерацию sitemap и robots.txt в Next.js, а также представляет новый мощный LLMRouter для каскадного многомодельного вывода в Django-LLM, который поддерживает структурированные выходные данные и механизмы отката при сбоях. Проект также улучшает Django REST Framework интерактивным просматриваемым API с использованием Tailwind v4 и Alpine.js. Среди других заметных изменений — новый API-клиент Hey с хуками SWR, обновленные зависимости пакетов и рефакторинг импортов API-клиента.
