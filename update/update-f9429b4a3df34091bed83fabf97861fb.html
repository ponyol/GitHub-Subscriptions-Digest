- Delegated execution (#1425) This is a functionally complete implementation of delegated execution, without any performance optimization or atomicity guarantees (all communication is synchronous and doesn't store request state/makes request state recoverable). ## New classes - **`ViewProxy`** (`catalog/view_proxy.py`) — client handle for a hosted view/snapshot. - **`ProxyClient`** (`service/proxy_client.py`) — abstract transport for proxy RPCs. - **`InProcessProxyClient`** (`service/proxy_client.py`) — in-process transport (no HTTP). - **`ProxyHttpClient`** (`service/proxy_client.py`) — HTTP transport to a proxy daemon. - **`ProxyRequest`** (`service/proxy_protocol.py`) — serialized proxy request. - **`ProxyResponse`** (`service/proxy_protocol.py`) — serialized proxy response. - **`TablePathKey`** (`catalog/table_path.py`) — version identity of a table path, used for CAS-gated mutations. - **`ProxyResultCursor`** (`_query.py`) — cursor over a materialized proxy result set. New function-based modules: - **`service/proxy_daemon.py`** — daemon entrypoint and lifecycle/discovery API. - **`service/proxy_dispatch.py`** — server-side request dispatch. ## Significantly changed classes - **`TableProxy`** (`catalog/table_proxy.py`) — full hosted-table API with client-side validation. - **`InsertableTableProxy`** (`catalog/insertable_table_proxy.py`) — hosted insert from rows/Query/Table sources. - **`CatalogProxy`** (`catalog/catalog_proxy.py`) — delegated catalog create/get/move/drop. - **`TableMdPath`** (`catalog/table_path.py`) — metadata-backed path supports queries, indexes, and snapshots without a live `TableVersion`. - **`Table`** (`catalog/table.py`) — shared client-side argument/mutability validation. - **`Query` / `ResultCursor` / `ResultSet`** (`_query.py`) — proxy execution and a public result schema. - **`ColumnRef`** / **`SimilarityExpr`** (`exprs/`) — proxy-aware embedding/index resolution. - **`Error`** (`exceptions.py`) — error codes that round-trip across the wire. - **`Runtime`** (`runtime.py`) — per-catalog routing for local vs proxy. ## Remaining functional gaps - doesn't deal with local media correctly (tests only work because the test proxy daemon is running on the same machine) - **Snapshots**: metadata reports a version-qualified path/name (`test_snap:0`) instead of the bare path; snapshot-mutation errors carry the daemon's bare name, not the full `pxt://` path; `rename_column` on a snapshot raises an internal error instead of a clean one; pinned-version / snapshot-only column resolution differs. - **Dropped-table detection**: query builders (`select`/`group_by`/`where`) and reused handles don't detect a dropped table (the check only runs daemon-side at dispatch); args are serialized before that check, so a bad arg can mask the error. - **Dropped-index detection**: a serialized query referencing a since-dropped index doesn't error on reload. - **Base-table column refs**: a base-table column referenced through a view/snapshot query can fail to resolve over proxy. ## Test conversion (`tests/test_*.py`) The dual-mode harness is new (master has 0 proxy tests). **253 of 472** `test_` methods in tests/test_*.py. now also run against the proxy. - PXT-1223: make metadata migration atomic and fix convert_51.py (#1426) - PXT-1224: add_embedding_index() uses index definition (#1429) For unnamed indices, uses the actual definition, not the auto-generated name, to detect duplicates. - Bump pandas to 2.3 in dev environment (#1431)
