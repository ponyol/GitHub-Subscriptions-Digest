This update introduces key user experience improvements, notably a conversation rewind feature for history management and enhanced authentication flows with a new custom API key wizard and OpenRouter support. It also significantly upgrades core functionalities, expanding the code review pipeline with new CLI tools and improving Language Server Protocol (LSP) integration for more accurate code intelligence. Furthermore, the release unifies background task management for subagents and shells, adds a file read cache for performance, and refines notification systems across VSCode and terminals. --- Это обновление включает в себя ключевые улучшения пользовательского опыта, в частности, функцию перемотки разговора для управления историей и улучшенные потоки аутентификации с новым мастером настройки пользовательского ключа API и поддержкой OpenRouter. Оно также значительно модернизирует основные функции, расширяя конвейер проверки кода новыми инструментами CLI и улучшая интеграцию с протоколом языкового сервера (LSP) для более точного интеллектуального анализа кода. Кроме того, выпуск объединяет управление фоновыми задачами для субагентов и оболочек, добавляет кэш чтения файлов для повышения производительности и уточняет системы уведомлений в VSCode и терминалах.
