Суммаризация (на русском)

The latest updates involve a major refactoring of the core runtime system to improve stability, error handling, and event delivery. Key enhancements for agents and tools include stricter, fail-closed permission checks, skills managing their own tools, and new reasoning effort controls for models. Furthermore, the copilot gains deeper integration with applications for data access, alongside numerous UI/UX improvements across chat, history, and settings. --- Последние обновления включают крупный рефакторинг базовой среды выполнения для повышения стабильности, обработки ошибок и доставки событий. Ключевые улучшения для агентов и инструментов включают более строгие проверки разрешений с запретом по умолчанию, управление инструментами непосредственно навыками и новые элементы управления "усилием рассуждения" для моделей. Кроме того, помощник теперь глубже интегрирован с приложениями для доступа к данным, а также внесены многочисленные улучшения пользовательского интерфейса и опыта взаимодействия в чатах, истории и настройках.
