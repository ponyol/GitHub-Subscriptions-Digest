Суммаризация (на русском)

Обновление включает значительные улучшения, такие как поддержка запуска инструментов в отдельных потоках в живом режиме с сохранением пользовательского ввода и корректной передачей буферизованных событий, более гибкий инструмент Google Search с возможностью использования пользовательских моделей, а также новые инструменты API для разговорной аналитики. Оно также интегрирует OpenTelemetry для улучшенной трассировки в BigQuery и при не-Gemini инференсе, улучшает аутентификацию для списка инструментов MCP и вводит опции командной строки для управления функциями. Основные исправления касаются обработки путей в скриптах развертывания для Windows, скрытия конфиденциальных данных в логах и обработки асинхронных URL-адресов в инструментах миграции, а также включает обновления зависимостей, улучшение документации и доработку шаблонов.
