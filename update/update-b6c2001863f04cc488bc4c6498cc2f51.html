Суммаризация (на русском)

This release significantly enhances GPU kernel performance and correctness, notably improving SM100 MLA prefill for GLM-style models, adding Apple M5 NVFP4 support for FLUX.2-dev, and fusing softmax into top-k sampling. Model capabilities are expanded with vision support for Gemma4, advanced tool-calling for GLM-5.x/Kimi, and NVFP4 integration for several models. Core language improvements include NumPy interop and more flexible memory management for `LinkedList` and `Dict`. Additionally, serving infrastructure gains multi-device dKV offload, improved benchmarking, and new profiling tools. --- Этот релиз значительно улучшает производительность и корректность GPU-ядер, в частности, улучшая префилл SM100 MLA для моделей в стиле GLM, добавляя поддержку Apple M5 NVFP4 для FLUX.2-dev и объединяя softmax в выборку top-k. Возможности моделей расширены за счет поддержки зрения для Gemma4, расширенных функций вызова инструментов для GLM-5.x/Kimi и интеграции NVFP4 для нескольких моделей. Улучшения основного языка включают взаимодействие с NumPy и более гибкое управление памятью для LinkedList и Dict. Кроме того, инфраструктура обслуживания получает разгрузку dKV для нескольких устройств, улучшенные бенчмаркинг и новые инструменты профилирования.

The e4m3fn format has a subnormal floor of 0.002, so tail probabilities can silently underflow to 0.0 and their value contributions are dropped entirely. The P values have a value between [0, 1] and therefore we already know their maximum values. So, we add a compile-time bias of +8 to the exp2 exponent (equivalent to multiplying P by 256 before the cast), shifting all probabilities up by 8 bits before quantization.
