Суммаризация (на русском)

The update introduces significant architectural improvements, including renaming the core "Task" tool to "Agent" (and adding an "Explore" agent), implementing a robust hooks extension mechanism for custom plugins, and allowing configurable runtime output directories. The VS Code IDE companion sees major user experience improvements such as image paste support, enhanced completion handling with a Tab key fill-only behavior, fuzzy file search, and better token usage display. Various fixes enhance system stability, particularly for ACP connections and graceful shutdowns, alongside crucial documentation updates (e.g., PR templates, Discord links) and an enriched data export feature with detailed metadata and statistics. --- Обновление вносит значительные архитектурные улучшения, включая переименование основного инструмента «Task» в «Agent» (и добавление агента «Explore»), реализацию надежного механизма расширений (хуков) для пользовательских плагинов и возможность настраивать каталоги вывода во время выполнения. Расширение для VS Code IDE получает значительные улучшения пользовательского опыта, такие как поддержка вставки изображений, улучшенная обработка автозавершения с поведением заполнения только по клавише Tab, нечеткий поиск файлов и более информативное отображение использования токенов. Различные исправления повышают стабильность системы, особенно в отношении соединений ACP и корректного завершения работы, наряду с важными обновлениями документации (например, шаблонов запросов на слияние, ссылок Discord) и расширенной функцией экспорта данных с подробными метаданными и статистикой.
