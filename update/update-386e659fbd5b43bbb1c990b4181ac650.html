Этот релиз добавляет настраиваемые размеры стека и кучи для QuickJS, а также улучшенную обработку множественных комментариев cypher. Исправлена значительная ошибка, из-за которой команда `GRAPH.COPY` завершалась сбоем при наличии других несинхронизированных графов в базе данных; теперь проверка синхронизации графа запускается только для форков BGSAVE. Также внесены минорные обновления зависимостей для GitHub Actions.
