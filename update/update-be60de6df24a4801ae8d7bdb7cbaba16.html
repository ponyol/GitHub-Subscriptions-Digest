Суммаризация (на русском)

The updates primarily focus on enhancing compatibility and stability for AI models, especially Anthropic's pre-4.6 versions, by correctly translating adaptive thinking parameters to prevent request failures. Significant improvements were made to streaming API error handling, introducing mid-stream fallback for retriable errors, accurate status mapping, and better usage accounting for failed streams. The Multi-Cloud Provider (MCP) and DCR bridge received security and functionality upgrades for client-held credentials and authentication. Additional features include an LLM-based classifier for intelligent routing, UI modernizations, and improved observability and spend logging. --- **Russian Translation:** Обновления в основном направлены на повышение совместимости и стабильности для моделей ИИ, особенно для версий Anthropic до 4.6, путем корректного преобразования параметров адаптивного мышления для предотвращения сбоев запросов. Были внесены значительные улучшения в обработку ошибок потокового API, включая возможность отката в середине потока для повторных ошибок, точное сопоставление статусов и улучшенный учет использования при неудачных потоках. Многооблачный провайдер (MCP) и мост DCR получили обновления безопасности и функциональности для клиентских учетных данных и ретрансляции аутентификации. Дополнительные функции включают классификатор на основе LLM для интеллектуальной маршрутизации, модернизацию пользовательского интерфейса и улучшенные возможности наблюдения и логирования расходов.
