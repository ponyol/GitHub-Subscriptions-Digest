This update heavily refines AI functionalities, introducing a workspace file picker, enhanced agent context management with cost tracking, and a redesigned model picker supporting new models and configurable endpoints. Core improvements span the editor and explorer, preventing data loss on file deletion, optimizing deep file tree display, and adding syntax highlighting for languages like Go, C, C++, Java, C#, and PHP. The terminal now features split panes, performance upgrades, font size/WebGL controls, and robust WSL workspace integration, alongside general UI/UX enhancements and customizable shortcuts. --- Это обновление значительно улучшает функциональность ИИ, представляя средство выбора файлов рабочей области, улучшенное управление контекстом агента с отслеживанием стоимости и переработанный селектор моделей с поддержкой новых моделей и настраиваемых конечных точек. Основные улучшения затронули редактор и проводник, предотвращая потерю данных при удалении файлов, оптимизируя отображение глубоких деревьев файлов и добавляя подсветку синтаксиса для языков, таких как Go, C, C++, Java, C# и PHP.
