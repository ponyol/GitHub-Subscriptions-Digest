Суммаризация (на русском)

Версия 4.x Org-GTD содержит значительные улучшения, особенно для просмотра графов, который теперь поддерживает кликабельные узлы, ленивую загрузку для более быстрого запуска и может использоваться для заголовков задач или из повестки дня. Перемещение файлов (refiling) было доработано для исключения буферов WIP, а отображение свойств в повестке дня теперь аккуратно извлекает описания из org-ссылок. Обновление также включает общие исправления для стабильности просмотра графов, улучшения документации и оптимизации производительности.
