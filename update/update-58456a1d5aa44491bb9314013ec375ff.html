This update introduces a new Foreign Function Interface (FFI) system, deeply integrating JavaScript types and primitives directly into the Lisp environment. This major overhaul eliminates many compatibility layers, adds native reader support for JS values, and optimizes their emission. The release also includes a significant fix for multiple value handling, along with various other stability improvements and CI/CD enhancements. --- Это обновление реализует новую систему Foreign Function Interface (FFI), глубоко интегрируя типы и примитивы JavaScript непосредственно в среду Lisp.
