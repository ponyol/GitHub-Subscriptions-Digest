Суммаризация (на русском)

Flet 0.86.1 introduces significant updates, including a new AI agent feature in Flet Studio with enhanced API interaction through `flet-mcp` improvements. Key performance boosts come from the new `RawImage` control for high-speed pixel streaming and raw RGBA Matplotlib frames over DataChannels, alongside making `canvaskit` the default web renderer. The release also fixes Windows build issues on non-UTF-8 locales, provides clearer web worker download error messages, and includes important Android-specific breaking changes regarding package extraction and x86 architecture support. --- Flet 0.86.1 представляет значительные обновления, включая новую функцию AI-агента в Flet Studio с улучшенным взаимодействием с API благодаря доработкам `flet-mcp`. Ключевые улучшения производительности достигаются за счет нового элемента управления `RawImage` для высокоскоростной потоковой передачи пикселей и использования необработанных кадров Matplotlib RGBA через DataChannels, а также установления `canvaskit` рендерером по умолчанию для веба. Релиз также исправляет проблемы сборки Windows в локалях без UTF-8, обеспечивает более понятные сообщения об ошибках при загрузке веб-воркеров и включает важные изменения для Android, касающиеся извлечения пакетов и поддержки архитектуры x86.
