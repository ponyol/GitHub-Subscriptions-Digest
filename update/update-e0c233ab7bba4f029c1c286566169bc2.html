Это обновление значительно расширяет возможности агентов, вводя новый автоматический режим чата по умолчанию, который нативно вызывает инструменты и поддерживает вложения изображений и закрепленные документы в контекстах агентов. Оно также добавляет бета-функцию интеллектуального выбора навыков (ISS), менеджер инструментов MCP и интегрирует API Perplexity Search как нового поставщика веб-поиска. Незначительные обновления включают улучшенный пользовательский интерфейс управления документами рабочего пространства с индикаторами количества и общие уточнения документации.
