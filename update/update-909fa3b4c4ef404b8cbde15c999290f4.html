Суммаризация (на русском)

Это исправление устраняет ошибку, при которой команда `CLI -it` не могла перенаправлять `stdout`. Ранее внутренний тип `Terminal` ошибочно инициализировался файловым дескриптором `stderr` вместо `stdin`, что мешало корректной работе с `stdout`. Теперь `Terminal` всегда инициализируется с `stdin` (дескриптор 0), а `stdout` и `stderr` получают свои правильные дескрипторы, что обеспечивает корректное перенаправление вывода.

- CLI: Fix -it not being able to pipe stdout (#951) Fixes #949 Typically if one fd is a tty, it's common for all 3 of stdio to be the same, but that is not always the case. In our case we were using our Terminal type from Containerization to comb through err/out/in and give us a type backed by one of the 3 if -t was supplied. It happens that stderr is the first we check, so our Terminal() is backed by fd 2.
