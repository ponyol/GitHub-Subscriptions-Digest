Суммаризация (на русском)

This update significantly enhances document processing capabilities and refines existing functionalities. It introduces OpenDocument backend support, integrates NVIDIA Nemotron-OCR with enhanced batching, and enables inference of PDF heading levels for improved hierarchy representation. The release also features structured error categorization for clearer failure reporting, crucial fixes for DOCX, XLSX, PPTX, and Asciidoc parsing, and improved per-file logging for ASR and batch conversions. --- **Русский перевод:** Это обновление значительно расширяет возможности обработки документов и совершенствует существующие функции. Оно добавляет поддержку бэкенда OpenDocument, интегрирует NVIDIA Nemotron-OCR с улучшенной пакетной обработкой и позволяет определять уровни заголовков PDF для лучшего представления иерархии. Выпуск также включает структурированную категоризацию ошибок для более четкой отчетности о сбоях, важные исправления для парсинга форматов DOCX, XLSX, PPTX и Asciidoc, а также улучшенное логирование каждого файла для пакетных и ASR-преобразований.
