Суммаризация (на русском)

This extensive update primarily focuses on enhancing system stability, performance, and introducing new features. Key improvements include memory-aware batch splitting to prevent OOMs, rate limiting for WAL operations, and optimized query request fanout. New capabilities like force promote for primary-secondary failover, `ORDER BY` support for queries, and StructArray group-by for element-level search have been added. Numerous bug fixes address race conditions, resource leaks, deadlocks, and panics, significantly improving overall system robustness and reliability. --- Этот обширный пакет обновлений преимущественно направлен на повышение стабильности системы, производительности и внедрение новых функций. Ключевые улучшения включают разделение пакетов с учетом памяти для предотвращения ошибок OOM, ограничение скорости для операций WAL и оптимизированное распределение запросов. Добавлены новые возможности, такие как принудительное продвижение для аварийного переключения primary-secondary, поддержка `ORDER BY` для запросов и группировка StructArray для поэлементного поиска. Многочисленные исправления ошибок устраняют состояния гонки, утечки ресурсов, взаимоблокировки и сбои, значительно повышая общую надежность и стабильность системы.
