Суммаризация (на русском)

Обновление включает значительные оптимизации памяти, особенно для моделей с длинным контекстом и `head_dim=256`, переводя использование памяти для предварительной обработки с O(L^2) на O(L), а также уточняет пороговые значения давления памяти для лучшего использования системных ресурсов. Оно также содержит множество исправлений для потоковой передачи чатов OpenAI и обнаружения рассуждений, вводит поддержку моделей Ornith и квантования oQe imatrix, а также ускоряет MiniMax M3 с помощью разреженного внимания. Критическое исправление сборки закрепляет `nanobind` для обеспечения совместимости ABI с MLX 0.31.2, решая проблемы с пользовательскими расширениями ядра, такими как для GLM и MiniMax M3.
