Суммаризация (на русском)

Recent updates introduce significant enhancements and critical bug fixes across the ADK ecosystem. New features include improved A2A integration with lifespan parameters and EventAction processing, expanded toolsets like a Spanner Admin Toolset and Slack integration, and support for Anthropic's structured `thinking_blocks`. Key fixes address issues with structured datastores in `DiscoveryEngineSearchTool`, prevent event compaction with pending function calls, and ensure correct handling of arbitrary tool responses from Anthropic LLMs, alongside various other reliability and developer experience improvements. --- Последние обновления привносят значительные улучшения и критические исправления ошибок во всей экосистеме ADK. Новые функции включают улучшенную интеграцию A2A с параметрами жизненного цикла и обработкой EventAction, расширенные наборы инструментов, такие как Spanner Admin Toolset и интеграция со Slack, а также поддержку структурированных `thinking_blocks` Anthropic. Основные исправления касаются проблем со структурированными хранилищами данных в `DiscoveryEngineSearchTool`, предотвращают уплотнение событий с ожидающими вызовами функций и обеспечивают правильную обработку произвольных ответов инструментов от Anthropic LLM, наряду с различными другими улучшениями надежности и удобства для разработчиков.
