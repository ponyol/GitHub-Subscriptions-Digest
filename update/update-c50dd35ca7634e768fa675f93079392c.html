Суммаризация (на русском)

This release significantly expands integrations, introducing AgentMail, Credential blocks, Profound AI, LaunchDarkly, Extend AI, Tailscale, AWS Secrets Manager, and Fireworks AI, while greatly enhancing Rootly and Rippling. Major updates to PostHog analytics improve event tracking, complemented by new email notifications, interactive Models and Academy pages, and refined UI elements like improved sorting/filtering across resource lists. Underlying improvements include concurrency control, server-side credential hiding, robust security fixes (SSRF, ReDoS), and enhanced logging with deep-linking capabilities. --- Это обновление значительно расширяет интеграции, добавляя AgentMail, блок учетных данных, Profound AI, LaunchDarkly, Extend AI, Tailscale, AWS Secrets Manager и Fireworks AI, а также значительно улучшая существующие интеграции Rootly и Rippling. Крупные обновления аналитики PostHog улучшают отслеживание событий, дополняемые новыми уведомлениями по электронной почте, интерактивными страницами моделей и Академии, а также улучшенными элементами пользовательского интерфейса, такими как расширенная сортировка/фильтрация по всем спискам ресурсов. Внутренние улучшения включают управление параллелизмом, скрытие учетных данных на стороне сервера, надежные исправления безопасности (SSRF, ReDoS) и улучшенное журналирование с возможностью глубоких ссылок.
