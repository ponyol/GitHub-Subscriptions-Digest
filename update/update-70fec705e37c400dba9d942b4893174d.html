Суммаризация (на русском)

Недавние обновления включают изменения в документации, в частности, обновление ссылок на версию 0.8.6 в файле README и документации Docker. Более значимым является исправление критической ошибки, связанной с валидацией конфигурации краулера. Ранее некорректный ввод JSON для `markdown_generator` (с использованием "options" вместо "params") приводил к скрытым сбоям и запутанным крашам. Теперь в `CrawlerRunConfig` добавлена проверка типа, которая выдает четкие сообщения об ошибках, указывающие ожидаемый тип и требуемый ключ "params" при получении некорректного ввода.
