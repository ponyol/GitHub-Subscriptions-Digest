The project has aligned its Python version to 3.10+, updated README badges and documentation, and improved code quality through extensive cleanup and linting with Ruff. Numerous fixes enhance agent and workflow stability, artifact handling, and dependency compatibility, while security measures were strengthened by protecting CI workflows and removing potentially risky automated agents. New features include mTLS support for GCP API calls, GCS and E2B environment integrations, an experimental Antigravity SDK agent wrapper, and support for Live API translation configurations. Unit test execution performance was also significantly improved. --- Проект привел версию Python в соответствие с 3.10+, обновил бейджи и документацию в README, а также улучшил качество кода за счет масштабной очистки и внедрения линтера Ruff.
