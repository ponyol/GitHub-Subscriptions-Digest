Суммаризация (на русском)

Выпущена версия 1.11.1, устраняющая критическую ошибку в управлении сессиями AI-чата. Обновление исправляет проблему, при которой пользовательские пути `claude_home` или `codex_home` некорректно передавались обработчиком `action_handler` при возобновлении сессии после поиска. Ранее это приводило к невозможности возобновить сессии, особенно запущенные с `--claude-home`, поскольку система ошибочно использовала путь `~/.claude` по умолчанию.

Исходный текст

- bump: version 1.11.0 → 1.11.1 - Merge pull request #63 from pchalasani/fix/aichat-resume fix: forward claude_home/codex_home in search resume action - fix: forward claude_home/codex_home from session dict in action_handler The action_handler closure inside search() was not passing claude_home/codex_home from the session dict to execute_action, so "resume as is" after a search with --claude-home fell back to ~/.claude and couldn't find the session.
