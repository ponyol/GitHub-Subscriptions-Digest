Суммаризация (на русском)

Это обновление представляет унифицированные движки вывода для семейств моделей, поддерживающие HuggingFace Transformers и ONNX Runtime для классификации изображений, а также интегрирует API KServe v2 для моделей классификации изображений и обнаружения объектов. Также введена версия `docling-parse v5` (устаревшие версии теперь не рекомендуются) и добавлен флаг устаревания для аннотаций. Основные исправления включают устранение несоответствий при парсинге страниц PDF, предотвращение уязвимостей безопасности типа XML External Entity (XXE) и улучшенную обработку альтернативного текста изображений AsciiDoc.
