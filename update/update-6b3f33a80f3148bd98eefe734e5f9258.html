The updates from v0.6.63 to v0.6.72 significantly bolster platform stability, security, and integration capabilities. Key improvements include extensive hardening and fixes for numerous connectors like SAP Concur, Workday, and Atlassian, alongside new integrations for Grok-4.3 and GPT-Image-2 models. These versions also introduce considerable UI/UX refinements, such as advanced table features, improved markdown rendering with zoom controls, robust file management, and enhanced logging and debugging tools including data drains and detailed execution traces. --- Обновления версий с v0.6.63 по v0.6.72 значительно повышают стабильность платформы, безопасность и интеграционные возможности. Ключевые улучшения включают обширные доработки и исправления для многочисленных коннекторов, таких как SAP Concur, Workday и Atlassian, а также новые интеграции моделей Grok-4.3 и GPT-Image-2.
