Суммаризация (на русском)

This update significantly overhauls the C# language server, switching to official NuGet.org packages and Microsoft's .NET install scripts, alongside crucial improvements to Roslyn symbol normalization and hover information. Additionally, it enhances C/C++ language server capabilities with fixes for Clangd and the integration of CCLS, while general language server infrastructure benefits from features like lazy file opening and asynchronous project initialization, boosting performance and reliability. --- Это обновление существенно перерабатывает языковой сервер C#, переходя на официальные пакеты NuGet.org и установочные скрипты Microsoft .NET, наряду с критически важными улучшениями нормализации символов Roslyn и информации при наведении. Помимо этого, улучшены возможности языкового сервера C/C++ за счет исправлений для Clangd и интеграции CCLS, а общая инфраструктура языкового сервера выигрывает от таких функций, как ленивое открытие файлов и асинхронная инициализация проектов, что повышает производительность и надежность.
