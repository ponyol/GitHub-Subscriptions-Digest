This update introduces a major API restructuring, promoting eager tensor-based modules to `max.nn` and integrating `max.experimental` functionalities directly into top-level modules. Key kernel optimizations include migrating Blockwise FP8 to a structured architecture, adding fused Expert Parallelism kernels, and enhancing GPU broadcast performance. The release also expands model support with features like Hadamard Transform for Deepseek V3.2, LoRA for Llama3, and an integrated LongBench v2 evaluator, alongside numerous bug fixes and test re-enabling.
