Суммаризация (на русском)

Основное обновление внедряет адаптивное, основанное на плотности фрагментирование для извлечения сущностей, специально разработанное для обработки больших, насыщенных сущностями входных данных, которые ранее приводили к таймаутам LLM. Эта система интеллектуально обрабатывает контент, применяя фрагментирование только к входным данным объемом более 1000 токенов с высокой плотностью сущностей, оставляя при этом меньший или менее плотный контент без изменений. Релиз также включает примеры, демонстрирующие его поведение для различных типов контента, и исчерпывающие модульные тесты, наряду с незначительными увеличениями версий и корректировками значений по умолчанию для фильтров.
