This update introduces key features including "Prefab Apps" for building UIs with automatic wiring and comprehensive documentation for various app patterns. It also adds an experimental "CodeMode" transform for generative UIs and new search transforms (Regex, BM25) for efficient tool discovery. Critical fixes address auth header leakage, improve logging, and optimize performance through lazy loading and caching. --- Это обновление вводит ключевые функции, включая "Prefab Apps" для создания пользовательских интерфейсов с автоматической привязкой и исчерпывающей документацией по различным шаблонам приложений. Также добавлены экспериментальный трансформатор "CodeMode" для генеративных пользовательских интерфейсов и новые трансформаторы поиска (Regex, BM25) для эффективного обнаружения инструментов. Внесены критические исправления, устраняющие утечки заголовков авторизации, улучшающие ведение журнала и оптимизирующие производительность за счет ленивой загрузки и кэширования.
