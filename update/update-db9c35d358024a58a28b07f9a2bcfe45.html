Суммаризация (на русском)

Ключевые обновления включают обеспечение возможности повторного использования и повышение надежности сохранения политик ToolGuard. Интеграции с LLM были улучшены благодаря поддержке MiniMax M3, исправленной обработке `top_p` для моделей Bedrock/Claude, а также усовершенствованному управлению бюджетом контекста и профилями WatsonX. Безопасность была повышена путем ограничения путей к файлам для загрузки знаний и проверки сгенерированного кода Python перед его выполнением. Кроме того, значительный рефакторинг разделил `manage_routes` на подмодули, и была исправлена ошибка во фронтенде, связанная с состоянием потоковой передачи при отмене запроса.

Several Bedrock-hosted Claude models (opus-4-5/4-6, sonnet-4-5) reject requests that specify both temperature and top_p, failing on the first LLM call. Only include top_p when present in the model settings.
