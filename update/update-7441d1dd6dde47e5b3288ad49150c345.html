Суммаризация (на русском)

This update significantly improves LM Studio integration, featuring accurate download status tracking and correct handling of Hugging Face model URLs, while also refining MLX download offers. The Text User Interface (TUI) gains substantial usability enhancements, such as clearer range filters, improved text input in plan mode, and a simulated GPU indicator with search in the community leaderboard. Furthermore, the release expands community benchmark data, unifies API serializers for better consistency, and introduces a detailed benchmarking guide. --- Эта версия значительно улучшает интеграцию с LM Studio, включая точное отслеживание статуса загрузки и корректную обработку URL-адресов моделей Hugging Face, а также уточняет предложения по загрузке MLX. Текстовый пользовательский интерфейс (TUI) получил существенные улучшения юзабилити, такие как более понятные фильтры диапазонов, улучшенный ввод текста в режиме планирования и индикатор симулированного GPU с функцией поиска в общедоступной таблице лидеров. Кроме того, релиз расширяет данные сообщества по бенчмаркам, унифицирует API-сериализаторы для повышения согласованности и представляет подробное руководство по бенчмаркингу.
