Это обновление добавляет расширенные логи оркестрации для большего числа провайдеров, новые возможности CLI для верификации жизненного цикла провайдеров и управления интерактивными задачами агентов, а также включает диаграмму производительности для каждой задачи. Оно содержит многочисленные исправления для специальных символов в расширенном предварительном просмотре, устраняет логические ошибки, связанные с файлами контрольных точек и обработкой SSH-портов, а также решает проблемы с открытием интерактивных сессий VS Code в новой вкладке. Обновление также привносит значительные улучшения CLI для управления командами и секретами, обеспечивает постоянное удаление секретов команды и предоставляет полный обзор состояния специальных секретов.
