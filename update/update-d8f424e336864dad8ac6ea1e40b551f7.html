Суммаризация (на русском)

This release delivers substantial performance and reliability improvements, alongside new features. It addresses issues like double-decompression of gzipped responses and optimizes database queries for log states, dataset items, and project updates, including buffering project last-updated timestamps in Redis. The SDK now supports memory-bound, resumable trace and dataset exports/migrations, preserves tags during CLI export/import, and integrates Mistral AI. Additionally, the release introduces a spend budget for LLM-as-judge evaluators, enhances Claude Agent SDK trace content capture, and redesigns the Optimization Studio UI. --- **На русском языке:** Этот выпуск содержит значительные улучшения производительности и надежности, а также новые функции. Он устраняет проблемы, такие как двойная декомпрессия gzip-ответов, и оптимизирует запросы к базам данных для состояний логов, элементов наборов данных и обновлений проектов, включая буферизацию временных меток последнего обновления проекта в Redis. SDK теперь поддерживает экспорт трассировок и миграцию наборов данных с ограниченным объемом памяти и возможностью возобновления, сохраняет теги при экспорте/импорте через CLI и интегрируется с Mistral AI. Кроме того, выпуск вводит бюджет расходов для оценщиков LLM-as-judge, улучшает захват содержимого трассировок Claude Agent SDK и перерабатывает пользовательский интерфейс Optimization Studio.
