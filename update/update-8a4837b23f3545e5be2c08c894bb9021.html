Суммаризация (на русском)

Версия 0.2.24 значительно улучшает обработку ошибок при сбоях ASR-бэкенда, решая проблему, когда серверы выглядели работоспособными, но выдавали пустые субтитры. Теперь система будет явно сигнализировать о сбое, если ASR-бэкенд не производит никакого вывода, а процесс разогрева (warmup) будет вызывать ошибки вывода вместо того, чтобы скрывать их. Кроме того, AudioProcessor получил сторожевой таймер (watchdog) для ошибок, который срабатывает, если 20 секунд аудио не дают никакого результата, что улучшает раннее обнаружение остановок обработки.

Исходный текст

- version 0.2.24 - fail loudly when the ASR backend produces nothing Two incidents in two days shipped servers that looked healthy while every session showed empty captions: the torch 2.13 MLX device mismatch (#383) and CTranslate2 wheels carrying PTX newer than the GPU driver. In both cases the per-chunk exceptions were logged as warnings and nothing else surfaced. - warmup now raises instead of swallowing inference errors (both the SimulStreaming path and warmup_asr): warmup exercises the exact code every session runs, so a failing warmup means a useless server; - AudioProcessor gains a one-time ERROR watchdog when 20 s of audio produced neither a token nor a buffer character, pointing at the earlier warnings for the root cause. Also: README rows for --translation-backend alignatt, submodule bumped to the standalone v0.2 tower tip.
