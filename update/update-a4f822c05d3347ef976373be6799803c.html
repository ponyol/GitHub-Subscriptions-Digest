Это обновление для ADK-Python представляет важные новые функции, в частности, добавляет поддержку пользовательских меток (labels) для заданий BigQuery, чтобы улучшить отслеживание, мониторинг и организацию. Оно также включает новый инструмент `vector_store_similarity_search` для Spanner, позволяющий выполнять поиск сходства по таблицам векторных хранилищ Spanner. Кроме того, исправлена ссылка API Registry Toolset на производственную среду.
