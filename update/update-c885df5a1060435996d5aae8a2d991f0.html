Суммаризация (на русском)

Это обновление добавляет новую переменную `buffer-terminator-refresh-tab-bar` для управления принудительным обновлением состояний и имен вкладок во всех фреймах. Также была переработана система подавления запросов процессов в `buffer-terminator--kill-buffer`, что сделало ее более целенаправленной и позволило избежать полного отключения всех функций запросов. Кроме того, теперь имена буферов на панели вкладок обновляются перед закрытием видимого буфера.

Исходный текст

- Add buffer-terminator-refresh-tab-bar Introduces the buffer-terminator-refresh-tab-bar variable to control whether the package forces a state and name refresh of all tabs across all frames. - Refactor process query suppression in buffer-terminator--kill-buffer Previously, buffer-terminator--kill-buffer bypassed process exit prompts by temporarily setting kill-buffer-query-functions to nil. This was overly broad and ignored all other query functions registered by different packages. - Update comments - Update pre-commit hooks - Refresh tab-bar buffer names before killing visible buffer
