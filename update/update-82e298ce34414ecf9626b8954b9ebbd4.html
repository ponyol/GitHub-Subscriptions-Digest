Это обновление улучшает обработку документов, добавляя поддержку форматов шаблонов Office (.dotx, .potx, .xltx) и обновляя существующие навыки для .docx, .pptx, .xlsx. Ключевые улучшения включают консолидацию вспомогательных функций Office с использованием явных шагов zip/unzip и улучшенную безопасность при работе с архивами (защита от символических ссылок и обхода пути). Валидатор красной разметки был исправлен для обнаружения неотслеживаемых изменений, а преобразования LibreOffice теперь надежно работают в изолированных средах.

Исходный текст

- Update docx, pptx, and xlsx skills (#1447) Add support for template formats (.dotx, .potx, .xltx) across validation and the helper scripts. Consolidate the shared office helpers into a single module, replacing the pack/unpack pipeline with explicit zip/unzip steps. Extraction now rejects symlink and path-traversal archive entries. Move run merging to a standalone docx script, since it only ever applied to Word documents. Fix the redlining validator so it compares against the original even when a document has no tracked changes, which is when an untracked edit would otherwise go unreported. Provision a LibreOffice user profile per invocation so conversions work in sandboxed environments. Trim the skill docs to the guidance that earns its place.
