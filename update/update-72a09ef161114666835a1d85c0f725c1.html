Суммаризация (на русском)

This release introduces a comprehensive Playground UI redesign with new features like per-prompt runs and a split-scroll results table. Key backend improvements focus on performance and reliability, including refactored Quartz-based retention jobs and rate limiting for trace/span queries. The update also extends project-scoping across numerous V2 frontend pages and backend APIs (e.g., datasets, alerts, experiments), and enhances the SDKs with better project name support, blueprint versioning, and automatic evaluation reporting. Additionally, a new agent onboarding flow and an integrated assistant sidebar improve user experience. --- **Русский перевод:** Этот релиз представляет всеобъемлющий редизайн пользовательского интерфейса Playground с новыми функциями, такими как запуск отдельных промптов и таблица результатов с раздельной прокруткой. Ключевые улучшения бэкенда сосредоточены на производительности и надежности, включая переработанные задания по удержанию данных на основе Quartz и ограничение частоты запросов для трассировок/спанов. Обновление также расширяет область действия проектов (project-scoping) на многочисленные страницы V2 фронтенда и API бэкенда (например, наборы данных, оповещения, эксперименты), а также улучшает SDK за счет лучшей поддержки имен проектов, версионирования чертежей и автоматической отчетности по оценкам. Кроме того, новый процесс адаптации агентов и интегрированная боковая панель помощника улучшают пользовательский опыт.
