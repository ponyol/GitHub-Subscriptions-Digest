Суммаризация (на русском)

This update introduces significant new capabilities, including experimental fine-tuning support with TRL for models, along with comprehensive user authentication and OIDC integration. It also adds a standalone agent run mode, a UI for managing model pipelines, and enhanced model gallery filtering. Key fixes address tracing settings persistence, Intel SYCL backend compatibility, and improved error reporting in the UI, alongside various dependency updates. --- Это обновление добавляет значительные новые возможности, включая экспериментальную поддержку тонкой настройки моделей с TRL, а также комплексную аутентификацию пользователей и интеграцию OIDC. Также добавлен автономный режим работы агентов, пользовательский интерфейс для управления конвейерами моделей и улучшенная фильтрация в галерее моделей. Основные исправления включают сохранение настроек трассировки, совместимость с бэкендами Intel SYCL и улучшенную отчетность об ошибках в пользовательском интерфейсе, а также различные обновления зависимостей.
