Суммаризация (на русском)

This update introduces new features like a `--runtime` flag for container commands, a `--pull` option for image builds, and support for resource limits (rlimits), along with a significant kernel upgrade to Kata 3.26.0. It resolves several critical bugs, including SELinux conflicts with overlayfs, stale builder cache issues, and fixes in networking and CI workflows. The release also enhances user experience through warnings for auto-created named volumes and refactored client APIs for improved clarity and efficiency. --- Это обновление добавляет новые функции, такие как флаг `--runtime` для команд контейнеров, опцию `--pull` для сборки образов и поддержку ограничений ресурсов (rlimits), а также включает значительное обновление ядра до Kata 3.26.0. Оно устраняет несколько критических ошибок, включая конфликты SELinux с overlayfs, проблемы устаревшего кэша сборщика и недочеты в сетевых и CI-рабочих процессах. Релиз также улучшает пользовательский опыт за счет предупреждений при автоматическом создании именованных томов и переработанных клиентских API для повышения ясности и эффективности.
