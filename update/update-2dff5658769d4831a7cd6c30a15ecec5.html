Суммаризация (на русском)

This release introduces a substantially expanded Computer Algebra System (CAS) with an extensible rule engine, polynomial manipulation, equation solving, Risch integration, special functions, and series expansions. Key infrastructure improvements include a new Cheney semispace garbage collector backend. Graphics capabilities are significantly enhanced, offering new fractal explorers (arbitrary-polynomial, bicomplex Tetrabrot), deep zoom for Mandelbrot, and a 4D maze, alongside numerous Qt6 UI and rendering module updates. Finally, Babylonian base-60 (sexagesimal) input/output with cuneiform glyphs was added. --- **Russian Translation:** Этот выпуск представляет значительно расширенную систему компьютерной алгебры (CAS) с расширяемым механизмом правил, манипуляциями с полиномами, решением уравнений, интегрированием по Ришу, специальными функциями и разложениями в ряды. Основные улучшения инфраструктуры включают новый полупространственный сборщик мусора Cheney. Графические возможности значительно расширены, предлагая новые фрактальные исследователи (для произвольных полиномов, бикомплексный Тетраброт), глубокое масштабирование для множества Мандельброта и 4D-лабиринт, а также множество обновлений модуля Qt6 для пользовательского интерфейса и рендеринга. Наконец, добавлена поддержка ввода-вывода в вавилонской шестидесятеричной системе счисления с использованием клинописных символов.
