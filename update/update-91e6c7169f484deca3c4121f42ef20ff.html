This release focuses on security and performance, migrating document processing (PPT/DOC/PDF) to an isolated-vm sandbox. It expands integration capabilities with new support for Monday.com, Bright Data, Agiloft, AWS IAM/STS, enhanced Atlassian triggers, and SharePoint for Excel. The update also delivers numerous UI/UX improvements across chat, terminal, sidebar, and search, alongside documentation enhancements, performance optimizations, and agent logic restructuring. --- Этот выпуск сосредоточен на безопасности и производительности, перенеся обработку документов (PPT/DOC/PDF) в изолированную среду isolated-vm. Он расширяет возможности интеграции за счет новой поддержки Monday.com, Bright Data, Agiloft, AWS IAM/STS, улучшенных триггеров Atlassian и SharePoint для Excel.
