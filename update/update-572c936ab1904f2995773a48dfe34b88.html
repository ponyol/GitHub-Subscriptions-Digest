Суммаризация (на русском)

Эти обновления значительно повышают производительность и улучшают конфигурируемость. Ключевые изменения включают оптимизацию хранения индексов встраивания до 16-битной точности, улучшение конфигурируемости моделей SpaCy и запуск тестов производительности на выделенных, более мощных раннерах. Кроме того, были добавлены новые стресс-тесты и представлен ноутбук Twelvelabs, демонстрирующий новые возможности поиска по сходству.

- Update doc-extract-text-from-office-files.ipynb - Add a "read only random ops" stress-tests job (#1047) Adds a stress-tests job that runs random-ops with only 1 read/write worker and N-1 read-only workers, but with all operations and data types enabled (even those that have known concurrency bugs involving multiple writes). - [PXT-916] Store embedding indexes as halfvecs (#1007) Adds a parameter to `Table.add_embedding_index` that controls the float precision used (16 or 32 bit, currently implemented using pgvector's halfvec and vector). The parameter defaults to 16 bit, which is different from the current behavior that always uses the regular float32 vector. To reconcile this difference, a catalog migration is implemented that adds precision=32bit to all embedding indexes in the schema. - Update test_index.py - PXT-875 Run perf tests on a dedicated larger runner (#1024) The errors that we are getting at present indicate that the standard runners may have insufficient resources. - Various import fixes (#1042) - Add missing imports to two documentation notebooks - And missing `require_package()` statements in a few places - Add several missing imports to `nightly.yml` - Proper configurability for spaCy models (#1039) Removes the hard-coded dependency on the `en_core_web_sm` spaCy model. Adds a `spacy_model` parameter to `document_splitter` and `string_splitter`. Moves spaCy model management out of `Env` and into a `pixeltable.utils.spacy` module. Users will now need to install a spaCy model separately in order to use sentence separators, but this is the generally accepted practice. (The model will be validated in output_schema() and Pixeltable will print a helpful error message if it is not installed.) - Readme Updates (#1041) Refresh Gallery | What Pixeltable Handles | Pixeltable Cloud | Remove Examples - Twelvelabs notebook (#1013) Cookbook for 12labs. I've also added the new similarity search that enables you to search with video, audio, and others, and showcase how to retrieve the embeddings as well. Please review.
