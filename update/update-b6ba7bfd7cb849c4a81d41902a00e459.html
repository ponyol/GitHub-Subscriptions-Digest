Суммаризация (на русском)

This major update introduces comprehensive LLM integration for VLM OCR, embeddings, and structured data extraction, along with a significantly faster `pdf_oxide` PDF backend. It also vastly improves content extraction quality through enhanced filtering, native table/structure tree heading detection, and corrected image handling across various formats, while adding new styled HTML output options. The release delivers numerous stability fixes, better API consistency across all language bindings, and migrates the project's license to Elastic License 2.0 (ELv2). *** Это крупное обновление представляет комплексную интеграцию LLM для VLM OCR, встраивания текста и извлечения структурированных данных, а также значительно более быстрый бэкэнд PDF `pdf_oxide`. Оно также значительно улучшает качество извлечения контента за счет расширенной фильтрации, нативного обнаружения заголовков таблиц и структуры дерева, а также исправленной обработки изображений в различных форматах, одновременно добавляя новые стилизованные варианты вывода HTML. Релиз содержит множество исправлений стабильности, улучшенную согласованность API для всех языковых привязок и переносит лицензию проекта на Elastic License 2.0 (ELv2).
