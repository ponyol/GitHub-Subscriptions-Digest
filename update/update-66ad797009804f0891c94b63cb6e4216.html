Суммаризация (на русском)

Это обновление представляет две основные функции для управления и интеграции агентов. Во-первых, реализован минимальный бесстатусный мост на TypeScript/Bun для подключения платформы агентов Linear к управляемым агентам через исходящие веб-хуки CMA, использующий метаданные для хранения данных сессии. Во-вторых, разработан тонкий сервер MCP, предоставляющий API сессий CMA через stdio и HTTP, что позволяет Claude Desktop или claude.ai управлять размещенными агентами CMA с помощью вызовов инструментов. Обе эти функции служат мостами для расширения совместимости и контроля агентов на различных платформах.
