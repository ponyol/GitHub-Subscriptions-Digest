Суммаризация (на русском)

This update introduces a new "Events" feature with a frontend UI, API, and documentation for managing event subscriptions. It significantly enhances the S3 destination by adding IAM role assumption for secure access and improving data organization. The release also includes a new layered sync configuration system, true incremental sync for Google Drive, and critical fixes for Vespa integration, Qdrant error handling, and various other bug resolutions to improve overall stability and flexibility. --- Это обновление представляет новую функцию "События" с пользовательским интерфейсом, API и документацией для управления подписками на события. Оно значительно улучшает целевое хранилище S3, добавляя возможность использования ролей IAM для безопасного доступа и улучшая организацию данных. Релиз также включает новую многоуровневую систему конфигурации синхронизации, настоящую инкрементальную синхронизацию для Google Drive, а также критические исправления для интеграции с Vespa, обработки ошибок Qdrant и различные другие исправления ошибок для повышения общей стабильности и гибкости.
