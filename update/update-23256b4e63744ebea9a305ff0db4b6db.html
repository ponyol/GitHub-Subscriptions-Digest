Суммаризация (на русском)

Недавние обновления включают критическую поддержку ребрендинга Google Gemini Notebook (notebook.google.com), устраняя проблемы со входом в систему и подключением к API. Среди основных новых функций — комплексное управление чат-сессиями (список, получение, экспорт, сохранение в заметки) с загрузкой стенограмм с сервера, а также улучшенные возможности `download_all` с расширенной документацией и тестированием. Прочие улучшения касаются уязвимостей зависимостей и исправляют обнаружение установок `uvx` для пользователей расширения рабочего стола на Windows.

- fix: support Google's Gemini Notebook rebrand at notebook.google.com (#269), bump to 0.9.3 Google is rolling out a rebrand of NotebookLM that redirects some signed-in accounts to notebook.google.com instead of notebooklm.google.com. This broke nlm login (sign-in detection didn't recognize the new host), all API calls (client always targeted the old host regardless of where the account landed), and the NOTEBOOKLM_BASE_URL escape hatch (rejected the new host outright). notebook.google.com is now a recognized host for login detection and the base-URL allowlist. The CLI also records which host a signed-in session actually lands on (per-profile, in metadata.json) and every client construction path routes requests there automatically, with precedence NOTEBOOKLM_BASE_URL env var > persisted profile host > default. Non-migrated accounts see no behavior change.
