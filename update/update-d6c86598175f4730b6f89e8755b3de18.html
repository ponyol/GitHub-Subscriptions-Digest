Суммаризация (на русском)

Это обновление добавляет поддержку новых моделей Gemini (3.6-flash и 3.5-flash-lite) и улучшает обработку вывода JSON для API DeepSeek и GLM, передавая схемы в системных сообщениях. Также были удалены несколько устаревших моделей Copilot API, включая старые версии GPT, Claude, Gemini и Grok, которые больше недоступны. Для бэкэндов GLM теперь следует использовать `gptel-make-deepseek`.
