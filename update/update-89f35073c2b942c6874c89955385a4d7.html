Суммаризация (на русском)

The "code mode" feature has undergone a major overhaul, transitioning from an external `acpx` tool to an integrated in-app Agent Client Protocol (ACP) client. This enables real-time streaming of agent actions, live inline permission requests, and interactive rendering of coding runs directly within the chat interface. Key enhancements include a configurable approval policy, a new LLM-based auto-permission mode, and several robustness fixes ensuring reliable agent lifecycle management. Additionally, minor UI improvements and platform-specific fixes were implemented. --- **Russian Translation:** Функция "режима кода" была значительно переработана, перейдя от использования внешнего инструмента `acpx` к интегрированному клиентскому протоколу агента (ACP) внутри приложения. Это позволяет в реальном времени транслировать действия агента, отображать запросы разрешений непосредственно в чате и интерактивно визуализировать выполнение кода. Среди ключевых улучшений — настраиваемая политика одобрения, новый режим автоматических разрешений на основе LLM и ряд исправлений для повышения надежности управления жизненным циклом агента. Также внесены небольшие улучшения пользовательского интерфейса и исправлены платформенные ошибки.
