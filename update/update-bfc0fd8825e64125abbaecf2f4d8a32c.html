Исходный текст

- Iterators Refactor Part 1 (#992) Moves iterators from `pxt.iterators` to the appropriate `pxt.functions` module, e.g., `pxt.iterators.video.FrameIterator` becomes `pxt.functions.video.frame_iterator`. I've left the names unchanged (`_iterator`, `_splitter`) for now. Marks the iterator `create()` methods as `@deprecated`; `pxt.iterators` can now be considered deprecated as a public package. Fixes a few bugs in iterator initialization that were uncovered by making the initializer parameters explicit. Updates the SDK docs for the new iterators and removes `pxt.iterators` from the SDK docs. I haven't updated the notebooks and markdown yet; I'll do that once we've finalized the names.
