Суммаризация (на русском)

Это обновление значительно повышает производительность SimpleDirectoryReader за счет оптимизации обхода директорий. Ранее программа считывания сканировала все дерево проекта перед фильтрацией исключенных директорий, что приводило к многоминутным задержкам, особенно при наличии больших папок node_modules или dist, и вызывало проблемы с готовностью сервера. Новый подход отсекает исключенные директории до начала обхода и передает предварительно отфильтрованный список файлов, что значительно сокращает задержку при переиндексации и решает проблему #127.

Исходный текст

- Merge pull request #130 from bxw91/patches/document-loader-fix perf: prune excluded dirs during traversal (closes #127) - perf: prune excluded dirs during traversal Previously SimpleDirectoryReader walked the full project tree before filtering against exclude_patterns. On trees with large node_modules, .next, or dist dirs this added multi-minute latency to every reindex and made the server miss its own /health/ readiness window — start.py then SIGTERMs its own process after 120s. Switch to a pruning os.walk that drops excluded directories before descending. Pass resulting file list via input_files instead of input_dir to skip SimpleDirectoryReader's second internal walk. Closes #127
