Суммаризация (на русском)

Это обновление включает значительные улучшения в области упаковки и поддержки. Упаковка теперь использует gcc14 для Linux, поддерживает версии Python с 3.11 по 3.14 (удаляя 3.10) и исключает устаревшие 64-разрядные двоичные файлы для macOS, что соответствует последним изменениям ONNX Runtime. Кроме того, все примеры на C/C++, C# и Python были переписаны для стандартизации, улучшая функциональное соответствие между языками и удаляя неподдерживаемые примеры, такие как движок SLM. Также добавлена информация о версии к библиотеке `onnxruntime-genai-cuda.dll` для лучшей отслеживаемости.

Исходный текст

- Sync packaging changes with ONNX Runtime (#1967) Changes in this PR: - Use gcc14 for linux packaging. - Build Python 3.11 ~ Python 3.14 packages. - Remove Python 3.10 package. - Further remove references to macOS x64 packages. - Remove onnxruntime-genai-cuda.lib from custom nuget packages. - [Build][Packaging] macOS packaging to skip building x86_64 (#1966) ONNX Runtime >= 1.24.0 will no longer ship x86_64 binaries. So, ort-genai should skip querying and shipping those. - Add versioning to the onnxruntime-genai-cuda.dll (#1965) Add version information to onnxruntime-genai-cuda.dll library at build time. - Rewrite all examples using standardization (#1939) ### Description This PR rewrites all examples in C/C++, C#, and Python to use standardized approaches for running inference with ONNX Runtime GenAI. It also removes the SLM engine, chat app, and Genny examples since they are now deprecated and not maintained. Users can try out [Foundry Local](https://foundrylocal.ai), which is powered by ONNX Runtime GenAI, if interested in similar examples. ### Motivation and Context Examples across the languages and across functionalities are often out-of-sync. For example, a Python example may get updated but its equivalent C/C++ and C# examples do not. This PR fixes this by synchronizing feature parity across the various examples. We can use this standardization to continue maintaining feature parity in the future. - Add RAII wrappers for ORT Model Editor API types (#1953)
