Суммаризация (на русском)

This update introduces `mempalace serve` for secure, turnkey remote team deployments, along with significant documentation improvements, especially for backend configuration and table layouts. Key feature additions include expanded content support for LaTeX files, automatic population of the associative graph from mined conversations, and preservation of original authored timestamps. The release also delivers crucial performance optimizations for Qdrant and pgvector, and resolves several reliability issues across backends and the HTTP transport. --- Это обновление представляет `mempalace serve` для безопасного развертывания удаленного сервера для команд, а также значительно улучшает документацию, особенно по настройке бэкендов и макетам таблиц. Среди ключевых добавлений — расширенная поддержка файлов LaTeX, автоматическое заполнение ассоциативного графа из обработанных бесед и сохранение исходных временных меток авторства. Релиз также включает важные оптимизации производительности для Qdrant и pgvector, а также устраняет ряд проблем с надежностью бэкендов и HTTP-транспорта.
