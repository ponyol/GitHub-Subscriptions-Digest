Суммаризация (на русском)

This update introduces new features such as StructArray support (including index access and array length functions), streaming node resource group isolation, and a collection-scoped snapshot lifecycle with compaction protection. It also decouples Parquet metadata loading for improved performance. Key bug fixes address data integrity, replication stability, and compatibility, while overall performance is enhanced through C++ optimizations and reduced data copies in search/query operations. --- Это обновление представляет новые функции, такие как поддержка StructArray (включая доступ по индексу и функции длины массива), изоляция групп ресурсов потоковых узлов и жизненный цикл снимков на уровне коллекций с защитой от уплотнения. Также было разделено чтение метаданных Parquet для повышения производительности. Основные исправления ошибок касаются целостности данных, стабильности репликации и совместимости, при этом общая производительность улучшена за счет оптимизации C++ и сокращения копирования данных в операциях поиска/запроса.
