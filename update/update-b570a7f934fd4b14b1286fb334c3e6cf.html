The system removed legacy AI-related CLI flags in version 0.10.0, streamlining the interface. A new "bug triage" workflow extension was added, and workflow execution received significant enhancements, such as a `continue_on_error` step field, JSON output, and the ability to resume runs with updated inputs or execute YAML files without a project.
