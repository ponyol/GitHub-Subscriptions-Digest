Суммаризация (на русском)

This release brings a major refactor of the `oc-path` utility, streamlining its internal architecture, removing less-used grammar features and YAML support, and ultimately moving it into a plugin. New features include Gateway task ledger RPCs and structured ACPX agent arguments. The update also improves CLI diagnostics for plugin agent tools and fixes issues like stalled Google Gemini responses and Cloudflare gateway auth transport. Overall, these changes aim for a more robust and efficient system. --- **Russian translation:** Эта версия включает значительный рефакторинг утилиты `oc-path`, упрощающий её внутреннюю архитектуру, удаляющий редко используемые грамматические функции и поддержку YAML, и в конечном итоге перемещающий её в плагин. Среди новых функций — RPC-вызовы реестра задач шлюза (Gateway task ledger RPCs) и поддержка структурированных аргументов агентов ACPX. Обновление также улучшает диагностику CLI для инструментов агентов-плагинов и исправляет такие проблемы, как задержки с ответами Google Gemini и передача аутентификации через шлюз Cloudflare. В целом, эти изменения направлены на создание более надежной и эффективной системы.
