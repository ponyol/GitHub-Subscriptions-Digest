Суммаризация (на русском)

Это обновление включает несколько улучшений в зависимости проекта. `nbconvert` получил исправления безопасности для двух CVE, а также улучшения для обработки WebPDF и исправления ошибок файловой системы. `python-dotenv` теперь поддерживает Python 3.14, изменяет обработку символических ссылок и содержит критические изменения для методов `set_key`/`unset_key`. В `langgraph` реализованы тайм-ауты на уровне узлов для асинхронных операций, `ToolNode` теперь может возвращать список команд или сообщений инструмента, а также исправлено поведение возобновления подграфов.
