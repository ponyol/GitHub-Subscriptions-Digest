Суммаризация (на русском)

The latest `gptel` update introduces basic support for OpenAI, ChatGPT, and Codex subscriptions via a new OAuth login flow. It also significantly improves error reporting for various backends, including Codex and AWS Bedrock, with clearer diagnostic messages. Key fixes address multi-turn tool use in Bedrock and enhance compatibility with Evil visual selections in transient menus. Additionally, users can now redirect the reasoning stream to a separate buffer, and model lists for Gemini and Anthropic have been updated. --- Последнее обновление `gptel` добавляет базовую поддержку подписок OpenAI, ChatGPT и Codex через новый процесс входа по OAuth. Также значительно улучшена отчетность об ошибках для различных бэкендов, включая Codex и AWS Bedrock, с более ясными диагностическими сообщениями. Основные исправления включают устранение проблем с многошаговым использованием инструментов в Bedrock и улучшение совместимости с визуальными выделениями Evil в транзитных меню. Кроме того, теперь пользователи могут перенаправлять поток рассуждений в отдельный буфер, а списки моделей для Gemini и Anthropic были обновлены.

Previously, tool call regions (propertized with `(tool . id)') had no matching arm and fell through to nil, causing the role to be serialized as {} and the raw serialized text to be sent as a plain user message, breaking subsequent requests. Reconstruct the toolUse (assistant) and toolResult (user) message pair from the serialized tool call text, matching the structure expected by the Bedrock Converse API.
