This update log details significant improvements leading to MemPalace version 3.1.0. Key changes include enhanced data stability and performance, achieved through a new ChromaDB migration tool, fixes for HNSW index bloat, and improved pagination for large data collections. Security was significantly bolstered with input hardening, shell injection prevention, and a novel query sanitizer designed to mitigate AI prompt contamination. Additionally, the release introduces new features like the OpenClaw/ClawHub skill, comprehensive agent readiness enhancements, and expanded test coverage. *** Этот журнал обновлений описывает значительные улучшения, приведшие к версии MemPalace 3.1.0. Безопасность была значительно усилена за счет ужесточения обработки входных данных, предотвращения инъекций оболочки и нового санитайзера запросов, разработанного для смягчения загрязнения запросов ИИ-подсказками.
