This update delivers significant performance improvements, including memory optimizations for data loading, faster JSON parsing, and enhanced Go search paths. It also introduces new capabilities like manual refresh for external collections, Storage V2 support for delta logs, and increased default vector field limits. Оно также представляет новые возможности, такие как ручное обновление для внешних коллекций, поддержка Storage V2 для дельта-логов и увеличенные лимиты по умолчанию для векторных полей.
