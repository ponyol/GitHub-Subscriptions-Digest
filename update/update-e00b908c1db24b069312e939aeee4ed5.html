Суммаризация (на русском)

Проект прошел значительный ребрендинг с "Kreuzberg" на "Xberg", что повлекло за собой обновление всех связанных доменов, названий организаций, областей пакетов (например, npm, Maven, crates.io) и документации. Среди ключевых новых функций — поддержка ввода на основе URI и структурированный формат вывода для процессов извлечения, API для анализа сносок и цитат Markdown, а также метод для быстрого подсчета страниц PDF. Существенные внутренние изменения включают миграцию стека TLS с OpenSSL на Rustls для улучшения кроссплатформенной совместимости, оптимизацию установки CLI с помощью автономных бинарных файлов и многочисленные обновления зависимостей, процессов сборки и механизмов публикации для различных языковых привязок.
