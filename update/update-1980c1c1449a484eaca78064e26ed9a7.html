Суммаризация (на русском)

Milvus introduces significant enhancements, including expanded support for external tables (Vortex) with function output fields and configurable storage formats, alongside a new Two-Phase Commit mechanism for imports to ensure data consistency. Core improvements optimize search aggregation, cluster-wide read task management, and garbage collection for dropped segment indexes, while also refining nullable vector handling. Various fixes enhance storage write atomicity, S3 operation robustness, and overall system observability with trace IDs and C++ thread metrics. --- Milvus представляет значительные улучшения, включая расширенную поддержку внешних таблиц (Vortex) с полями вывода функций и настраиваемыми форматами хранения, а также новый механизм двухфазной фиксации для импорта, обеспечивающий согласованность данных. Основные оптимизации затронули агрегацию поиска, управление задачами чтения на уровне кластера и сборку мусора для удаленных индексов сегментов, а также улучшили обработку векторов, допускающих нулевые значения. Множество исправлений повышают атомарность операций записи в хранилище, устойчивость операций с S3 и общую наблюдаемость системы с помощью идентификаторов трассировки и метрик активности потоков C++.

This PR refactors the V3 sync write path into a do-then-commit shape: Phase 1 (slow, runs once outside the retry loop): writeInserts, writeStats, writeDelta, writeBM25Stasts write all the data files (parquet/LOB via the loon writer, deltalog, stat blobs) and each helper returns its contribution (ColumnGroups, SegmentOutput, StatEntry list, DeltaLogEntry list) without touching shared state.
