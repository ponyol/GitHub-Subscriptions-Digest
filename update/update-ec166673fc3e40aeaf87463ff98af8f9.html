This update brings a comprehensive overhaul to the self-update system, making it more robust with Git-based operations, dynamic release notes, and an improved UI for version selection. The chat UI also sees various improvements like increased input height and a unified action menu, coupled with better error handling, Docker workflow automation, and browser agent fixes. --- **Russian Translation:** Это обновление значительно перерабатывает систему самообновления, делая ее более надежной благодаря операциям на основе Git, динамическим примечаниям к выпускам и улучшенному интерфейсу для выбора версий. Значительные улучшения для плагинов включают новые точки внедрения и расширяемое управление ключами API, а также добавление встроенной функции сжатия чата.
