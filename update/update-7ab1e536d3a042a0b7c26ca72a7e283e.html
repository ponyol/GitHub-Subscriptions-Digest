- Use JSON-RPC ping for OAuth auth-discovery probe The probe POST previously sent a JSON-RPC `initialize`, which a strict MCP mock (and potentially some real servers) counted as a real handshake alongside the actual ECA initialize. The integration test `mcp-remote-server-connects` asserts `(= 1 (count init-reqs))` and broke with `(not (= 1 2))`.
