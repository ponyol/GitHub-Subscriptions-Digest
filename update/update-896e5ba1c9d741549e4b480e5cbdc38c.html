Суммаризация (на русском)

Проект претерпел значительную переработку системы сборки, перейдя от 'readies' к комбинации `build.sh` и CMake. Ключевые изменения включают добавление флага `fPIC` для связывания общих библиотек, реализацию флагов `-Bsymbolic` для предотвращения интерпозиции символов, вызывающей сбои из-за несоответствия ABI, и включение `-fno-strict-aliasing` для совместимости с RediSearch. Кроме того, была интегрирована всесторонняя поддержка AddressSanitizer (ASAN) для всех целей, включая сборку Redis с ASAN напрямую для надёжного тестирования.
