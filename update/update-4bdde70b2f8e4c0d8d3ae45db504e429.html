This update introduces robust support for OpenAI's required tool choice and significantly enhances security capabilities with new skills for LLM Prompt Injection, GCP, and Auth0. Пользовательский интерфейс (TUI) получает значительные улучшения производительности, уменьшая задержки прокрутки и оптимизируя отрисовку для более плавной работы. Кроме того, отчетность SARIF улучшена за счет добавления тегов STRIDE, а также внесены различные исправления для интеграции с провайдерами, конфигурации и общей стабильности системы.
