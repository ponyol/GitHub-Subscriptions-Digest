Суммаризация (на русском)

This extensive update introduces GraphRAG integration for advanced document retrieval and a server-side job queue for robust background processing. The project shifts to a plugin-first user experience, makes Ollama the default local model option, and now supports pluggable model providers with updated 2026 LLM versions. Furthermore, improvements include enhanced release automation, CI stability via dynamic versioning, and unified "agent-brain" branding, moving the project from version 1.2.0 to 4.0.0. --- Это обширное обновление внедряет интеграцию GraphRAG для расширенного поиска документов и очередь заданий на стороне сервера для надёжной фоновой обработки. Проект переходит к пользовательскому опыту, ориентированному на плагины, устанавливает Ollama в качестве локального варианта модели по умолчанию и теперь поддерживает подключаемые поставщики моделей с обновлёнными версиями LLM 2026 года. Кроме того, улучшения включают расширенную автоматизацию выпуска, стабильность CI за счёт динамического версионирования и унифицированный брендинг «agent-brain», переводя проект с версии 1.2.0 на 4.0.0.
