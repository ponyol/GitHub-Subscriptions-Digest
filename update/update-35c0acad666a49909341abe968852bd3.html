Суммаризация (на русском)

Это обновление в основном представляет миграцию DatabaseSessionService на схему сериализации JSON, а также новый инструмент командной строки `adk migrate session` для миграции базы данных. Также добавлен APIRegistryToolset для интеграции инструментов из реестра Cloud API в агенты и улучшена прогрессивная потоковая передача SSE для поддержки потоковой передачи аргументов вызовов функций. Наконец, исправление устраняет проблему с параметром `per_agent` при использовании URI удаленных сеансовых сервисов.
