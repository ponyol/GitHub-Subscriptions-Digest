Суммаризация (на русском)

This release features significant architectural enhancements, including a unified `on_complete_callback` abstraction across all storage backend interfaces and enabling lazy memory allocation by default in multi-process mode, supported by new `memcpy` c-extensions. Further improvements include converting ZMQ client-server communication to router type and adding an HTTP debug server. The update also addresses numerous bug fixes, memory leaks, and CI/CD stability issues across various components. --- Этот выпуск содержит значительные архитектурные улучшения, включая унифицированную абстракцию `on_complete_callback` для всех интерфейсов хранилищ и включение ленивого выделения памяти по умолчанию в многопроцессорном режиме, поддерживаемое новыми C-расширениями `memcpy`. Дополнительные улучшения включают изменение типа обмена данными клиент-сервер ZMQ с `req` на `router` и добавление HTTP-сервера для отладки. Обновление также устраняет многочисленные ошибки, утечки памяти и проблемы стабильности CI/CD в различных компонентах.
