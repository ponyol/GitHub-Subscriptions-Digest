Суммаризация (на русском)

This update significantly enhances Mempalace's configurability and robustness, particularly for text chunking parameters, which now feature comprehensive validation to prevent crashes from invalid inputs. Performance has been boosted for conversation mining and index rebuilds through optimized data handling and progress reporting. Furthermore, the release introduces structured error reporting for API calls, critical bug fixes like preventing `PYTHONPATH` leaks and handling empty metadata, and a new evaluation harness for small LLMs. --- Это обновление значительно улучшает конфигурируемость и отказоустойчивость Mempalace, особенно в части параметров разбиения текста на чанки, которые теперь оснащены комплексной валидацией для предотвращения сбоев из-за некорректных входных данных. Производительность майнинга разговоров и перестроения индексов была повышена благодаря оптимизированной обработке данных и отчетам о прогрессе. Кроме того, релиз включает структурированную отчетность об ошибках для вызовов API, критические исправления ошибок, такие как предотвращение утечек `PYTHONPATH` и обработка пустых метаданных, а также новый инструмент для оценки небольших LLM.
