Суммаризация (на русском)

Обновление значительно расширяет функционал `open-computer` за счет поддержки Windows x64 (WHPX), включая многочисленные исправления для сборки базовых образов, выполнения агентов и совместимости QEMU с различными операционными системами. Новые возможности включают инструмент агента для создания запланированных заданий, а также улучшения пользовательского интерфейса для выбора LLM-моделей, которые теперь группируют загруженные модели отдельно. Были исправлены критические ошибки, связанные с регрессиями цитирования API, интеграцией OpenAI, коннекторами агентов SQL и проблемами с переопределением системных подсказок рабочей области и отображением MCP-серверов, что дополнено мелкими корректировками переменных окружения и обновлениями документации.
