Суммаризация (на русском)

Это обновление добавляет `ToolAnnotations` (подсказки о только для чтения, идемпотентности, деструктивности) ко всем инструментам файловой системы и документирует их в файле README. Это изменение решает проблему, когда клиенты рассматривали все операции файловой системы как универсальные операции записи. Теперь они могут точно различать действия только для чтения и записи, идентифицировать идемпотентные операции и выделять потенциально деструктивные. Данное улучшение обеспечивает более точную работу пользовательского интерфейса и логики повторных попыток, значительно повышая удобство для клиентов и пользователей.

MCP clients can now accurately distinguish read‑only vs. write tools, understand which operations are safe to retry, and highlight potentially destructive actions. ## Server Details - **Server**: filesystem - **Area**: tools (metadata returned via `listTools` / `ListToolsRequest`) and server docs ## Motivation and Context Previously, the filesystem server did not expose ToolAnnotations, so many clients (e.g. ChatGPT Apps) conservatively treated filesystem tools as generic write operations. This led to: - READ operations being surfaced with WRITE badges and confirmation prompts. - No way for clients to know which write tools are idempotent or potentially destructive. This PR aligns the implementation with `servers#2988` and updates the README to clearly document the semantics of each tool.
