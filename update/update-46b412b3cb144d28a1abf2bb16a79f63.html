Суммаризация (на русском)

Это обновление представляет комплексную 9-уровневую платформу эмуляции QEMU для тестирования прошивки ESP32-S3, а также значительные улучшения в демо-версии RuView для двухмодальной оценки позы, которая теперь включает 26-точечную позу и полноценный 6-ступенчатый конвейер внимания RuVector WASM. Выпущено новое настольное приложение RuView Desktop, предоставляющее полный набор функций для управления узлами ESP32, включая обнаружение, прошивку, обновления по воздуху (OTA) и контроль модулей WASM. Кроме того, запущена экосистема крейтов `ruv-neural`, предлагающая передовые инструменты для анализа топологии мозга с физическими моделями сигналов, функциями безопасности и верификацией свидетельств Ed25519.
