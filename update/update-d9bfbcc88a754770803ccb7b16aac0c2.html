Суммаризация (на русском)

The project introduces a new in-app uninstaller for clean removal of all system components and a local network checker to guide users through macOS permission issues. It also enhances the user experience with clearer instance statuses, fixed scrollbars, and the ability to remember last launch settings. Further updates include improved CI/CD for consistent versioning, added RDMA debugging info, custom namespaces for cluster isolation, and a new benchmarking tool. --- Проект представляет новый внутриприложенийный деинсталлятор для чистого удаления всех системных компонентов и проверку локальной сети, чтобы помочь пользователям в решении проблем с разрешениями macOS. Он также улучшает пользовательский опыт благодаря более понятным статусам экземпляров, исправленным полосам прокрутки и возможности запоминать последние настройки запуска. Дополнительные обновления включают улучшенную CI/CD для последовательного версионирования, добавленную отладочную информацию RDMA, пользовательские пространства имен для изоляции кластеров и новый инструмент для бенчмаркинга.
