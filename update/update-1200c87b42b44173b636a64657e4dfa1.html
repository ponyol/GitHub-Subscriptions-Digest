Суммаризация (на русском)

Это обновление добавляет коннекторы SGLang XPU для передачи KV-кэша LMCache на устройствах Intel, а также повышает производительность хранилища благодаря поддержке NVMe io_uring_cmd и новому коннектору Google Cloud Bigtable. Реализованы возможности горячей замены DAX во время выполнения через общий API перенастройки L2 и многопутевая выгрузка KV-кэша. Существенно оптимизирована производительность резервного механизма передачи блоков Python и механизма сопоставления на уровне токенов CacheBlend для более эффективного повторного использования KV-кэша. Дополнительно внедрены новые функции управления квотами L2 и проведен рефакторинг основной инфраструктуры.
