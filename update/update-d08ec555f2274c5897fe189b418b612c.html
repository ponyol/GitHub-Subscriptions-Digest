Суммаризация (на русском)

This update refines the core architecture by migrating to the `uncalled-for` dependency injection package and improving tool/resource decorators for greater extensibility. It significantly expands functionality with `Message` support for image and audio content, Google GenAI sampling, and enhanced tool discovery via client-side pagination limits and decomposed CodeMode features (e.g., Search, GetSchemas). Security is also strengthened through new MultiAuth capabilities, additional authentication providers (PropelAuth), flexible OAuth CSP settings, and various token verification fixes. --- Это обновление улучшает базовую архитектуру путем перехода на пакет внедрения зависимостей `uncalled-for` и улучшая декораторы инструментов/ресурсов для большей расширяемости. Оно значительно расширяет функциональность, добавляя поддержку изображений и аудио в объекты `Message`, семплирование Google GenAI и улучшенный механизм обнаружения инструментов с ограничением постраничной разбивки на стороне клиента и декомпозированными функциями CodeMode (например, Search, GetSchemas). Безопасность также усилена благодаря новым возможностям MultiAuth, дополнительным провайдерам аутентификации (PropelAuth), гибким настройкам CSP для OAuth и различным исправлениям проверки токенов.
