Суммаризация (на русском)

This release significantly enhances the application by introducing new features like telemetry support, a "Better Auth" OAuth provider, and improved Inspector functionalities such as editable server aliases, stream protocol support, and a dynamic UI background. Critical bug fixes address authentication issues (Auth0 configuration, duplicate authorization calls) and cross-platform compatibility, while also updating the deprecated Claude AI model. Additionally, chat components have gained advanced tool management and screenshot capabilities, and several core dependencies were updated. **Russian Translation:** Этот релиз значительно улучшает приложение, добавляя новые функции, такие как поддержка телеметрии, провайдер OAuth "Better Auth" и улучшенные возможности инспектора, включая редактируемые псевдонимы серверов и поддержку потокового протокола, наряду с динамическим фоном пользовательского интерфейса. Важные исправления ошибок касаются проблем аутентификации (конфигурация Auth0, дублирующиеся вызовы авторизации) и кроссплатформенной совместимости, а также обновления устаревшей модели ИИ Claude. Кроме того, компоненты чата получили расширенные возможности управления инструментами и создания скриншотов, а также были обновлены некоторые основные зависимости.
