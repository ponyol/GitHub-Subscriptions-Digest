Суммаризация (на русском)

This update introduces a significant rebranding from "Bailian" to "ModelStudio" across documentation, API keys, and internal references. Key improvements include enhanced authentication for Alibaba Cloud ModelStudio Standard API keys, now supporting multiple model IDs and providing better user feedback. The permission system received substantial upgrades with human-readable labels, improved deny rule feedback, and robust checks for tool execution within ACP/MCP modes. Additionally, the release refactors and documents "Qwen Code hooks," addresses various search and tooling issues, and improves graceful error handling for shell PTY race conditions. --- Это обновление включает значительный ребрендинг с "Bailian" на "ModelStudio" в документации, ключах API и внутренних ссылках. Основные улучшения касаются аутентификации для стандартных ключей API Alibaba Cloud ModelStudio, которая теперь поддерживает несколько идентификаторов моделей и предоставляет более информативную обратную связь пользователям. Система разрешений получила существенные доработки, включившие удобочитаемые метки, улучшенную обратную связь при отказе в доступе и надежные проверки выполнения инструментов в режимах ACP/MCP. Кроме того, в релизе переработаны и задокументированы "Qwen Code hooks", устранены различные проблемы с поиском и инструментами, а также улучшена обработка ошибок, связанных с условиями гонки в PTY оболочки.
