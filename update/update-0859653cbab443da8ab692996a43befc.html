- Add computer-use-best-practices quickstart (#402) * Add computer-use-best-practices quickstart A pedagogical, native-macOS reference implementation of a computer-use agent that pairs with Anthropic's computer-use best-practices guide. It is meant to be read and adapted rather than imported as a library, and demonstrates the patterns from the guide concretely: explicit tool definitions, correct image sizing and pruning, prompt caching, server-side compaction, batched tool calls, a sandboxed shell, and trajectory recording with a viewer. Also updates the root README with a Computer Use Best Practices section (and refreshes the stale Browser Tools API Demo entry to Browser Use Demo, matching the current directory), and adds cross-link callouts to the computer-use-demo and browser-use-demo READMEs clarifying how the three relate. * Silence pyright reportPrivateImportUsage in computer-use-demo computer_use_demo/loop.py imports AnthropicBedrock/AnthropicVertex directly from the anthropic package. The SDK re-exports these from its .lib submodules via a star-import without listing them in __all__, so newer pyright flags them as private imports even though they are the SDK's documented API and work at runtime. This is a pre-existing failure on main that surfaces whenever CI runs against computer-use-demo.
