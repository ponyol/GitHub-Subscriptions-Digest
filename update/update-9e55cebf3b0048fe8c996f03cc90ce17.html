Суммаризация (на русском)

Этот релиз представляет новый локальный пользовательский интерфейс для Pixeltable и значительно улучшает систему типов JsonType с расширенной параметризацией. Важное исправление устраняет чрезмерное планирование в RateLimitsScheduler, значительно сокращая ошибки 429 и повторные запросы для повышения стабильности. Среди прочих ключевых обновлений — рефакторинг каталога для повышения эффективности, очистка каналов данных таблиц и исправление ошибок при преобразовании версий каталога.
