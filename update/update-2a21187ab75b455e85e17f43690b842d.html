Этот релиз значительно улучшает инфраструктуру за счет автоматизированной синхронизации `schema.prisma`, обнаружения расхождений и переноса публикации PyPI в GitHub Actions OIDC для повышения безопасности CI/CD. Основные обновления функций включают обеспечение соблюдения бюджетных лимитов в многоподовых развертываниях с помощью счетчиков на базе Redis, а также внедрение маршрутизации с резервированием на основе проверки работоспособности и порядка для более надежного управления моделями. Кроме того, обновлены поддерживаемые модели LLM и ценообразование, например, удалены надбавки за токены свыше 200k для Claude Opus/Sonnet 4.6, наряду с различными исправлениями в области безопасности и очистки данных.
