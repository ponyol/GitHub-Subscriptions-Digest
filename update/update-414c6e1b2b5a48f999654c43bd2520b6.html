Add Silero VAD Support to Nemotron Streaming ASR (#2035) ## Add Silero VAD (Voice Activity Detection) to Nemotron Streaming ASR ### Summary Integrates [Silero VAD](https://github.com/snakers4/silero-vad) into the `StreamingProcessor` base class so that audio chunks without speech are automatically skipped before reaching the encoder/decoder pipeline. VAD is **disabled by default** and activated by adding a `"vad"` section to `genai_config.json`, or at runtime via `SetOption`/`GetOption`. ### Motivation In streaming audio pipelines, many chunks contain silence or background noise. Without VAD, every chunk goes through the full RNNT encoder→decoder→joiner pipeline. By gating on speech detection, we skip silent chunks — saving compute and reducing end-to-end latency. ### Design **Config-driven**: VAD is enabled when the `"vad"` section exists in `genai_config.json` (no separate `enabled` boolean). The `SileroVad` class uses GenAI's `Model::CreateSession()` and `Model::CreateSessionOptionsFromConfig()` to inherit provider options, session options, and run options from the config. **State infrastructure**: `SileroVadState` inherits from `State`, so VAD inference uses `State::Run()` — getting EP support, run options, `session_terminate`, and graph capture for free. **Consecutive silence logic**: Instead of dropping every silent chunk immediately (which breaks natural pauses between words/sentences), the processor tracks consecutive silent chunks and only starts dropping after `silence_duration_ms` worth of silence elapses. `prefix_padding_ms` sets a minimum floor of silence to always keep for context. Speech resets the counter. **Generic key-value API**: Following the same pattern as tokenizer options, all VAD settings are controlled via `SetOption`/`GetOption` rather than VAD-specific methods. This avoids API surface bloat and is extensible. **Reusable base class**: All VAD logic lives in `StreamingProcessor` (base class), so any future streaming processor (Whisper, etc.) gets VAD support by calling `InitVadFromConfig()` and `ShouldDropChunk()`. ### Config Add to `genai_config.json`: { "model": { "vad": { "filename": "silero_vad.onnx", "threshold": 0.3, "silence_duration_ms": 3360, "prefix_padding_ms": 560, "session_options": {}, "run_options": {} } } } Presence of the `"vad"` section enables VAD. Omit the section entirely to disable. ### API Surface All languages use the same generic `SetOption`/`GetOption` pattern on `StreamingProcessor`: | Key | Values | Description | |---|---|---| | `vad_enabled` | `"true"` / `"false"` | Enable/disable VAD at runtime | | `vad_threshold` | float as string | Speech probability threshold (default: `"0.5"`) | | `silence_duration_ms` | int as string | Silence duration before dropping chunks (default: `"3360"`) | | `prefix_padding_ms` | int as string | Minimum silence to keep for context (default: `"560"`) | C API: `OgaStreamingProcessorSetOption` / `OgaStreamingProcessorGetOption` (2 functions) ### Changes #### Core -
