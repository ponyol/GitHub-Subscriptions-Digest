Суммаризация (на русском)

Milvus introduces significant enhancements to its core architecture and data management capabilities. Key updates include a refactor of the load balancing system with a unified `AssignPolicy` interface and various strategies, alongside the introduction of read-only external collections for seamless integration with external data sources. The data model is improved with expanded `StructArray` support for diverse fixed-dimension vector types and nested field indexing, coupled with robust handling of nullable vector fields across upserts and indexing. Furthermore, new features such as on-the-fly MinHash computation for similarity search, automated storage version upgrade compaction, and enhanced security controls for KMS key revocation are implemented. *** Milvus представляет значительные улучшения в своей основной архитектуре и возможностях управления данными. Ключевые обновления включают рефакторинг системы балансировки нагрузки с унифицированным интерфейсом `AssignPolicy` и различными стратегиями, а также введение внешних коллекций только для чтения для бесшовной интеграции с внешними источниками данных. Модель данных улучшена за счет расширенной поддержки `StructArray` для различных типов фиксированной размерности векторов и вложенного индексирования полей, в сочетании с надежной обработкой векторов с возможностью значений null при операциях upsert и индексировании. Кроме того, реализованы новые функции, такие как вычисление MinHash "на лету" для поиска сходства, автоматизированная политика уплотнения для обновления версий хранилища и улучшенные меры безопасности для отзыва ключей KMS.
