Суммаризация (на русском)

This set of changes largely focuses on regenerating language bindings and their respective end-to-end tests for a wide array of targets, including Zig, Swift, Java, PHP, Node, Ruby, and many others. This widespread regeneration was necessary to integrate numerous fixes and improvements within the `alef` binding generator and the `kreuzberg` core library. These updates address critical issues such as FFI compatibility, correct handling of optional parameters, JSON serialization, various language-specific template problems, type mismatches, and enhanced rendering/extraction logic for formats like PDF, XML, EPUB, and email. The process also involved significant updates to the testing infrastructure to ensure stability and correctness across all supported languages. --- **Russian translation:** Этот набор изменений в основном посвящен перегенерации языковых привязок и соответствующих сквозных тестов для широкого круга целей, включая Zig, Swift, Java, PHP, Node, Ruby и многие другие. Эта масштабная перегенерация была необходима для интеграции многочисленных исправлений и улучшений в генераторе привязок `alef` и базовой библиотеке `kreuzberg`. Эти обновления устраняют критические проблемы, такие как совместимость FFI, правильная обработка необязательных параметров, сериализация JSON, различные проблемы с шаблонами, специфичные для языков, несоответствия типов, а также улучшенная логика рендеринга и извлечения для таких форматов, как PDF, XML, EPUB и электронная почта. Процесс также включал значительные обновления тестовой инфраструктуры для обеспечения стабильности и корректности во всех поддерживаемых языках.
