Суммаризация (на русском)

This update focuses on enhancing Milvus's core capabilities, addressing both performance and stability. It delivers critical bug fixes related to data consistency, memory management, and concurrency, while introducing significant new features such as raw string literals, bitwise operators in filter expressions, support for struct arrays, and a function chain API for search rerank. Performance optimizations for parsing, segment loading, and I/O are also included, alongside strengthened test coverage and external integrations. --- Это обновление направлено на улучшение основных возможностей Milvus, касающихся как производительности, так и стабильности. Оно содержит критические исправления ошибок, связанных с согласованностью данных, управлением памятью и параллелизмом, а также внедряет важные новые функции, такие как необработанные строковые литералы, побитовые операторы в выражениях фильтров, поддержку массивов структур и API цепочки функций для переранжирования поиска. Также включены оптимизации производительности для парсинга, загрузки сегментов и операций ввода-вывода, наряду с усиленным тестовым покрытием и внешними интеграциями.
