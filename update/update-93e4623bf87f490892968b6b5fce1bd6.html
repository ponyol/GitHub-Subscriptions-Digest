Суммаризация (на русском)

Приложение теперь поддерживает Firebase Cloud Messaging (FCM) для push-уведомлений. Основные обновления включают расширенную интеграцию нейронных процессоров (NPU), в том числе обнаружение SoC во время выполнения для выбора NPU-специфичных моделей, включение NPU в качестве ускорителя в пользовательском интерфейсе и доработку логики загрузки моделей. Кроме того, API бэкенда LiteRT-LM был переработан в запечатанный класс, чтобы обеспечить более гибкие и специфичные для бэкенда конфигурации для CPU, NPU и GPU.
