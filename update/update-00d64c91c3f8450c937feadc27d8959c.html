Суммаризация (на русском)

The recent updates introduce a new `SkillToolset` for managing and loading skills, making them more optimizable and robust against errors. Significant improvements were made to session management, including enhanced database session services with better concurrency handling (e.g., PostgreSQL, Vertex AI), and the web API server was expanded with features like optional `new_message` for session resume, auto-session creation, and new health/version endpoints. Additionally, memory bank functionalities were extended with new write modes, and capabilities for prompt optimization and compaction were added. --- Последние обновления представляют новый набор инструментов `SkillToolset` для управления и загрузки навыков, делая их более оптимизируемыми и устойчивыми к ошибкам. Значительные улучшения коснулись управления сессиями, включая усовершенствованные службы сессий базы данных с лучшей обработкой параллелизма (например, PostgreSQL, Vertex AI), а также расширение веб-API сервера функциями, такими как опциональное `new_message` для возобновления сессий, автоматическое создание сессий и новые конечные точки для проверки состояния и версии. Кроме того, функциональность банка памяти была расширена новыми режимами записи и добавлены возможности для оптимизации и сжатия промптов.
