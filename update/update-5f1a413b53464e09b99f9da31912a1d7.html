Суммаризация (на русском)

This release primarily focuses on a major security upgrade for the API, transitioning to Bearer token authentication and enforcing a mandatory API key for server startup by default. Concurrently, it significantly expands the Multi-Client Protocol (MCP) CLI, introducing commands for server management (`mcp start/stop`), prompt interaction, and resource listing/reading. The update also includes crucial fixes for CI/testing flakiness and scope leaks, alongside general documentation and plugin maintenance. *** Этот выпуск преимущественно посвящен значительному обновлению безопасности API, переходящему на аутентификацию с использованием токенов Bearer и принудительному требованию обязательного ключа API для запуска сервера по умолчанию. Одновременно с этим, значительно расширены возможности командной строки Multi-Client Protocol (MCP), добавлены команды для управления сервером (`mcp start/stop`), взаимодействия с промптами и просмотра/чтения ресурсов. Обновление также включает важные исправления для нестабильности CI/тестирования и проблем с утечкой области видимости, а также общие улучшения документации и плагинов.
