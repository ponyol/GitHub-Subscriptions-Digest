Суммаризация (на русском)

Это обновление улучшает поддержку WebGPU за счет включения захвата графов и улучшения обработки кеша. Оно исправляет критические ошибки, включая неверные ответы при обработке нескольких запросов в пакете и ошибку в обработке навигации. Кроме того, оно повторно включает поддержку VitisAI с внешней библиотекой для WinML и добавляет поддержку предварительно квантованных моделей Qwen2.5-VL.

- Enable webgpu graph capture in base.py (#1991) This pull request updates the WebGPU execution provider configuration and rotary embedding cache handling in the model builder to support advanced graph and cache features. The main changes improve WebGPU support by enabling graph capture and setting cache-related attributes when requested. - Fix incorrect batch responses when using multiple prompts (#1986) When running with batch_size > 1, only the last prompt's response was correct; other responses decoded as "!!!!". The generator was created with batch_size=1 because search options were taken only from CLI args (which have no --batch_size), so get_search_options() defaulted it to 1 while the model config correctly had batch_size=len(prompts). Fix: In model-generate.py, set search_options["batch_size"] = len(prompts) before calling params.set_search_options() so the generator's batch size matches the number of prompts. --------- Co-authored-by: kunal-vaishnavi <115581922+kunal-vaishnavi@users.noreply.github.com> - Fix guidance bug (#1988) Fixes bug introduced in https://github.com/microsoft/onnxruntime-genai/pull/1870 where we were computing the mask after resetting the internal state of the guidance processor. Also fixes these issues: - Enables debug build when guidance is enabled. - Fixes bug where we log without checking if logging was enabled. - [VitisAI] external_ep_libray support fix for WinML (#1984) VitisAI+external_ep_libray was disabled for WinML. The change enables it. - Support Qwen2.5-VL pre-quantized models in qwen.py (#1985) - Fix `Qwen25VLTextModel.load_weights()` to support pre-quantized models. - The `load_weights()` method in `Qwen25VLTextModel` completely overrides the base class, bypassing the OGA support for loading pre-quantized models. This causes a `NotImplementedError: "normal_kernel_cpu" not implemented for 'Int'` when trying to convert quantized Qwen2.5-VL models. - This PR checks `self.quant_type` and delegates to `super().load_weights()` for quantized/GGUF models, consistent with the pattern used in `internlm.py`
