Суммаризация (на русском)

Были устранены несколько критических ошибок, включая проблемы с разрешением области видимости вложенных паттернов, сбои из-за разыменования NULL при сканировании OPTIONAL MATCH и некорректное применение фильтров после операций записи. Исправлено поведение проекции карты на нулевую сущность (теперь она возвращает null), а вызовы RedisModule_Yield теперь ограничены только загрузкой AOF для предотвращения ошибок "BUSY". Также были удалены команды управления доступом graph.ACL и graph.PASSWORD, и исправлены проблемы сборки на macOS arm64, связанные с OpenSSL.
