This update significantly enhances both user experience and core functionalities. Key frontend improvements include pre-populating online score rule fields for faster setup, introducing comprehensive dataset export with S3 multipart uploads and cleanup, and better management of experiment tags. The SDK now features robust ChatPrompt support, OpenAI SORA video logging, and optimized dataset streaming for evaluations. Additionally, various backend optimizations, UI responsiveness improvements, and dependency updates contribute to overall platform stability and performance. --- **Russian Translation:** Это обновление значительно улучшает как пользовательский опыт, так и основные функциональные возможности.
