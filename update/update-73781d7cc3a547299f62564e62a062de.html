Суммаризация (на русском)

Критическое исправление для agent-tunnel гарантирует, что форки аутентифицируются с использованием логина подписки claude.ai пользователя вместо унаследованного ключа API, предотвращая проблемы с оплатой и сбои аутентификации. Кроме того, добавлена новая внутрисессионная команда `>trim` и утилита командной строки `aichat trim-in-place` для обрезки текущей сессии Claude Code без прерывания. Эта функция позволяет пользователям предварительно просматривать сэкономленные токены, применять изменения и включает надежную обработку резервных копий и целостности сессии, значительно улучшая рабочий процесс управления длинными беседами.
