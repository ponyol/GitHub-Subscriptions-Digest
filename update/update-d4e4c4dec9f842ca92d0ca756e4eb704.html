Суммаризация (на русском)

This release introduces major new features such as the `st.iframe` command for embedding various content, enhanced filter modes for `st.selectbox` and `st.multiselect`, and a `single-row-required` selection mode for `st.dataframe`. It also adds `autoscroll` to `st.container` and a `required` parameter to `st.pills` and `st.segmented_control`. Key improvements include better OpenMetrics compliance, enhanced Starlette/ASGI support, and a fix for programmatic dataframe selections, alongside Pandas 3.x compatibility and various visual and stability bug fixes. --- Этот выпуск представляет основные новые функции, такие как команда `st.iframe` для встраивания различного контента, улучшенные режимы фильтрации для `st.selectbox` и `st.multiselect`, а также режим выбора `single-row-required` для `st.dataframe`. Также добавлены параметр `autoscroll` для `st.container` и параметр `required` для `st.pills` и `st.segmented_control`. Среди ключевых улучшений — лучшая совместимость с OpenMetrics, расширенная поддержка Starlette/ASGI и исправление программного выбора данных в датафреймах, наряду с совместимостью с Pandas 3.x и различными исправлениями визуальных ошибок и ошибок стабильности.
