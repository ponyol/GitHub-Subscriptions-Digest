Это обновление значительно улучшает ModelKit и DataSets, добавляя поддержку удаленных ссылок и улучшая функциональность `kit init` с помощью флага `--depth` и нормализации путей в стиле Unix. Также расширен реестр агентов `--as-skill` десятью новыми агентами и улучшены уведомления об обновлениях версии CLI для менее навязчивого взаимодействия с пользователем. Релиз включает различные обновления зависимостей для Go и GitHub Actions, а также общие улучшения документации.
