Суммаризация (на русском)

This update significantly enhances the Curry compiler by completing its "eval-elimination" migration, enabling native compilation for various forms like `define-syntax` and `receive`, which resolves lexical scoping bugs. It also introduces a content-hash keyed transparent `.scc` cache for improved performance, adds a `--timings` flag, and integrates CI benchmarking. New features include a Language Server Protocol (LSP) module and SRFI 149 macro extensions, alongside crucial fixes for GUI examples and module export enforcement. --- Это обновление значительно улучшает компилятор Curry, завершая миграцию "eval-elimination", что позволяет нативную компиляцию для различных форм, таких как `define-syntax` и `receive`, и устраняет связанные с этим ошибки лексической области видимости. Также внедрен прозрачный кэш `.scc`, использующий хеш содержимого, для повышения производительности, добавлен флаг `--timings` и интегрировано бенчмаркинг в CI. Среди новых функций — модуль Language Server Protocol (LSP) и расширения макросов SRFI 149, а также важные исправления для GUI-примеров и обеспечения соблюдения правил экспорта модулей.
