Суммаризация (на русском)

This Serena update significantly improves stability and performance, particularly for C++ (Clangd) and Lean4 language server caches, which now correctly invalidate stale symbol data. It also introduces new language support for mSL (mIRC Scripting Language), complete with LSP features like symbol finding, references, and definitions. The release includes numerous bug fixes across various components, dependency updates, and enhancements to documentation and CI/CD workflows. Additionally, a new option to disable usage reporting has been added. **Russian Translation:** Это обновление Serena сосредоточено на значительном повышении стабильности и производительности, особенно для кэшей языковых серверов C++ (Clangd) и Lean4, которые теперь корректно инвалидируют устаревшие данные символов. Также добавлена поддержка нового языка mSL (mIRC Scripting Language) с полным набором функций LSP, таких как поиск символов, ссылок и определений. Релиз включает многочисленные исправления ошибок в различных компонентах, обновления зависимостей, а также улучшения в документации и рабочих процессах CI/CD. Кроме того, появилась новая опция для отключения отправки данных об использовании.
