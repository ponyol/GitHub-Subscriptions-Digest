Суммаризация (на русском)

The project underwent a significant update culminating in version 0.3.0, focusing on improved security, task ergonomics, and robust recovery from interrupted operations. Key features include enhanced GitRepo grant mechanisms with native OS sandboxing (macOS Seatbelt, Linux Landlock), a new `@sp.task` syntax, and automatic/manual tools to repair orphaned operations after crashes. Documentation was extensively revised to accurately reflect shipped features and clarify internal terminology, alongside improved diagnostics and Python 3.14 support. --- Проект претерпел значительное обновление, кульминацией которого стал выпуск версии 0.3.0, сфокусированный на улучшении безопасности, эргономики задач и надежном восстановлении после прерванных операций. Ключевые особенности включают улучшенные механизмы предоставления прав GitRepo с использованием нативной песочницы ОС (macOS Seatbelt, Linux Landlock), новый синтаксис `@sp.task` и автоматические/ручные инструменты для восстановления "осиротевших" операций после сбоев. Документация была тщательно пересмотрена для точного отражения реализованных функций и уточнения внутренней терминологии, наряду с улучшенной диагностикой и поддержкой Python 3.14.
