Суммаризация (на русском)

Это обновление добавляет поддержку обучения LoRA для аудиовизуальных мультимодальных моделей Gemma, включая улучшения валидации, новые тесты и документацию. Оно также решает проблемы с нехваткой памяти для пользователей Mac с 16 ГБ ОЗУ, добавляя пример конфигурации бюджета памяти. Кроме того, были применены незначительные корректировки форматирования кода для поддержания согласованности.
