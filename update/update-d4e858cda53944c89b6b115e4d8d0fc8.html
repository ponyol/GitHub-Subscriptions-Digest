Суммаризация (на русском)

Недавние обновления коннектора SharePoint Online значительно повышают точность контроля доступа. Система теперь корректно обрабатывает утверждение "Все, кроме внешних пользователей", предотвращая невидимость файлов, доступных через него. Кроме того, коннектор больше не предоставляет избыточный доступ, прикрепляя все группы сайта к каждому файлу; вместо этого он точно определяет область просмотра общих ссылок и другие разрешения для каждого элемента на основе ответов Graph. Это также исправляет проблему, при которой ссылки общего доступа в пределах организации ошибочно делали файлы общедоступными для всех пользователей арендатора.

SharePoint returns it as a member of site groups with ``PrincipalType=4`` (same as Entra federated groups), but with the ``rolemanager`` claim provider rather than ``federateddirectoryclaimprovider``. Our existing PT=4 branch in ``_parse_sp_group_member`` only matched the Entra shape, so the claim hit ``return None`` and was silently dropped. Net effect: any file accessible only via a site group that contained this claim was invisible in search to internal users without an alternate access path. No log line, no warning — just a silent drop.
