Суммаризация (на русском)

This update introduces comprehensive Gemma 4 unified support, including audio input and improved handling of vision tensors and tool calls. It adds new selectable PDF and file processing engines (MarkItDown, VLM OCR) for various document types. Key stability and performance enhancements include fixes for engine pool eviction races, DeepSeek-V4 memory leaks, and optimized memory management. The macOS app received significant improvements, exposing more settings for VLM and DFlash, and enhancing model directory management and user onboarding. --- Это обновление представляет комплексную поддержку Gemma 4 unified, включая аудиовход и улучшенную обработку визуальных тензоров и вызовов инструментов. Добавлены новые выбираемые механизмы обработки PDF и других файлов (MarkItDown, VLM OCR), поддерживающие различные типы документов. Ключевые улучшения стабильности и производительности включают исправления гонок вытеснения в пуле движков, утечек памяти DeepSeek-V4 и оптимизированное управление памятью. Приложение для macOS значительно обновлено, предлагая больше настроек для VLM и DFlash, а также улучшенное управление каталогами моделей и процесс адаптации пользователей.
