Суммаризация (на русском)

This update primarily introduces a comprehensive, multi-ecosystem release automation system for TypeScript and Python packages within a monorepo, featuring flexible versioning, stable/prerelease workflows, and robust, idempotent CI/CD practices. It also includes significant bug fixes and enhancements to the LangGraph integration, improving state streaming, event handling, and data consistency. Additionally, critical fixes were applied to components like ADK middleware, `ag-ui-strands`, and `mastra`, alongside the addition of `AgentCapabilities` types to the Python SDK. --- Это обновление в первую очередь представляет комплексную систему автоматизации релизов для пакетов TypeScript и Python в монорепозитории, с гибким управлением версиями, рабочими процессами для стабильных и предварительных релизов, а также надежными, идемпотентными практиками CI/CD. Оно также содержит значительные исправления ошибок и улучшения интеграции LangGraph, повышающие надежность потоковой передачи состояний, обработки событий и согласованности данных. Кроме того, были применены критические исправления для таких компонентов, как ADK middleware, `ag-ui-strands` и `mastra`, а также добавлены типы `AgentCapabilities` в Python SDK.
