Это обновление значительно расширяет возможности бинарного ввода-вывода, добавляя поддержку чисел с плавающей точкой IEEE754, спецификацию типов Lisp для `map` и опцию `:conc-name`. Оно улучшает функциональность записи за счёт всесторонней поддержки `defbinio` и других бинарных типов, оптимизированной производительности во время выполнения и новой реализации `vector-emitter-output`. Релиз также включает важную документацию в виде файла README и новые тесты для `defbinio`.
