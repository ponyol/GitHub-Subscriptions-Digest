Суммаризация (на русском)

В систему контрольных точек `DeltaChannel` внесены ключевые улучшения для предотвращения снижения производительности в долгоживущих потоках. Снимки теперь принудительно создаются по истечении максимального количества супершагов или на основе обновлений канала, что обеспечивает эффективное сохранение редко записываемых каналов. Это включает публичный API для получения истории дельта-каналов и специализированные оптимизации производительности для механизмов сохранения Postgres и SQLite. Отдельно, Python SDK получил новые возможности фильтрации по `metadata` для заданий cron и опцию `return_minimal` для обновлений потоков.
