This update significantly enhances AI/LLM-related functionalities, including improved handling of attachments for LLM-as-judge scorers with performance fixes and configurable size limits, and accurate cost calculation for OpenAI audio models. Performance and stability are boosted by various ClickHouse query optimizations, reactive online-scoring, and a new HTTP client liveness health check. The SDK and CLI now offer project-scoped export/import with ID-based naming, flexible MCP server configuration, and improved runner poll logging. Additionally, the Optimization Studio deployment is simplified, allowing a separate algorithm model. --- Это обновление значительно улучшает функциональность, связанную с AI/LLM, включая улучшенную обработку вложений для оценщиков LLM-as-judge с исправлениями производительности и настраиваемыми ограничениями размера, а также точный расчет стоимости для аудиомоделей OpenAI. SDK и CLI теперь предлагают экспорт/импорт с привязкой к проекту и именованием по ID, гибкую конфигурацию сервера MCP и улучшенное журналирование опросов раннера.
