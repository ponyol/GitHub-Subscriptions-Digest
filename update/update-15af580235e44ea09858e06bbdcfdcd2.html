Суммаризация (на русском)

Последние обновления `eca` сосредоточены на значительном улучшении производительности, усовершенствовании управления чатами и исправлении основных ошибок. Основные улучшения производительности включают значительное ускорение взаимодействия в длинных чатах и вывода инструментов за счет внедрения кэширования и оптимизированной подсветки синтаксиса. Функциональность чата теперь включает более точное применение выбора к активным чатам, уникальные идентификаторы для новых чатов и улучшения пользовательского интерфейса, такие как кнопки удаления для поставленных в очередь запросов. Кроме того, исправлены ошибки некорректного слияния рабочих деревьев и проблема с клавишей backspace в Emacs, а новая функция упрощает интеграцию с запускаторами песочниц.

- fix(util): don't merge nested paths as sibling worktrees (#238) The `merged` worktree fallback in `eca-session` previously declared two paths to be the same repo purely on `git rev-parse --git-common-dir` equality. That equality is also true for any subdirectory of a git-tracked $HOME (yadm/chezmoi/`git init ~`), so a buffer whose `default-directory` is `~` (e.g. the doom scratch buffer) would trigger `workspace/didChangeWorkspaceFolders` and silently append `~` to a session that the user had explicitly created with `C-u M-x eca` on `~/.config/eca`, surfacing both roots in the chat modeline. Real git worktrees are always sibling directories, never nested, so the inner predicate in `eca--session-for-worktree` now additionally requires that ROOT and the candidate folder are not in an ancestor/descendant relationship, via a new `eca--paths-nested-p` helper that compares `file-truename`-normalized, trailing-slash paths.
