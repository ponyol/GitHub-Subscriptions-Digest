Суммаризация (на русском)

Недавние обновления значительно улучшают CLI Browserbase, добавляя новые команды, такие как `browse upload` для загрузки файлов и `browse get markdown` для преобразования HTML в Markdown. Теперь пользователи могут настраивать параметры сеанса Browserbase с помощью глобальных флагов CLI (например, прокси, стелс-режим, решение капчи). Команда `browse env local` теперь по умолчанию запускает изолированный браузер, с явной опцией `--auto-connect` для повторного использования существующего экземпляра Chrome. Кроме того, улучшена поддержка LLM за счет интеграции промежуточного ПО и улучшенной обработки параметров моделей GPT 5.x, а также исправлены рабочие процессы выпуска сервера и восстановлен стек Drizzle для server-v4.
