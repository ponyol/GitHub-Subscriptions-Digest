Суммаризация (на русском)

FluidAudio значительно расширил свои возможности потоковой обработки, представив ресурсоэффективную обработку больших аудиофайлов и диаризацию речи в реальном времени с помощью NVIDIA Sortformer, теперь поддерживающую перекрывающуюся речь. Добавлены новые демонстрационные видеоролики, демонстрирующие эти функции, а также официальные оболочки для платформ React Native и Rust. Проект также отмечает WhisKey, клавиатуру для iOS/macOS, использующую диаризацию речи FluidAudio для конфиденциального голосового ввода.
