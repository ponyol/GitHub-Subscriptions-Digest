Суммаризация (на русском)

Добавлен новый четырехэтапный конвейер для генерации данных Supervised Fine-Tuning (SFT), который преобразует траектории выполнения агентов из сред, таких как ALFWorld, WebShop и Search-agent, в требуемый формат данных SFT. Этот конвейер проясняет обработку шагов завершения, особенно для ALFWorld, и задокументирован с обновленными примерами. Пользователи предоставляют свои собственные данные выполнения (rollout) для конвейера.

Исходный текст

- Update README with SFT data generation details Added a reference to the SFT data generation examples in the README. - Trim defensive prose from sft_data_generation docs - Remove reproducibility caveats from sft_data_generation README - Add SFT data generation pipeline (addresses #27) Adds examples/sft_data_generation/ — a four-stage pipeline that turns agent rollout trajectories into the SFT data format released at https://huggingface.co/datasets/Jianwen/SkillRL-SFT-Data, for ALFWorld, WebShop, and Search-agent. Stages: preprocess/ parse rollout txt + dedupe loops skill_memory/ per-trajectory memories + aggregate to static skill bank distillation/ o3 reasoning + (ALFWorld) synthetic done step postprocess/ sharegpt -> alpaca pairs + (WebShop) action validation Documents the synthetic done step construction (the source of confusion in #27): ALFWorld terminates at the winning action, so we extend each winning trajectory by one synthetic terminal frame whose obs reuses the env response from the winning action and whose admissible_actions includes `done`. WebShop and Search don't need this since their winning actions (click[buy now], <answer>) terminate naturally. Rollout is not included — users run their own model and pass the trajectory dump to the pipeline.
