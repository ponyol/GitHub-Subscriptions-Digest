Парсер стриминга `gptel-openai` был обновлен для корректной обработки имен инструментов `:null`. Это изменение устраняет проблему, при которой некоторые API, совместимые с OpenAI (например, Openrouter), предоставляли `:null` в последующих частях стриминговых вызовов инструментов после первоначального указания фактического имени. Обновление улучшает совместимость и надежность для стриминговых вызовов инструментов с такими API.

Исходный текст
