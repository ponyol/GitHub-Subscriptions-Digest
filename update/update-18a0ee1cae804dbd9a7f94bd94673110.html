Суммаризация (на русском)

The updates primarily focus on enhancing the robustness and reliability of agent interactions, especially for Long-Running Operations (LRO) and Human-In-The-Loop (HITL) workflows. Key improvements include comprehensive integration tests and fixes to ensure correct persistence and deduplication of tool call events, resolving issues with event streaming and stale session data. Additionally, an automatic device pairing feature was added to the Kotlin chat application for `clawg-ui` endpoints. Although advanced streaming function call argument logic was introduced, it was later removed due to upstream dependencies, prioritizing overall system stability. --- Обновления в основном сосредоточены на повышении надежности и устойчивости взаимодействий агентов, особенно для длительных операций (LRO) и рабочих процессов с участием человека (HITL). Основные улучшения включают комплексные интеграционные тесты и исправления для обеспечения корректного сохранения и дедупликации событий вызовов инструментов, устранение проблем с потоковой передачей событий и устаревшими данными сеансов. Кроме того, в чат-приложение на Kotlin добавлена функция автоматического сопряжения устройств для конечных точек `clawg-ui`. Несмотря на то, что ранее была введена сложная логика потоковой передачи аргументов вызовов функций, впоследствии она была удалена из-за зависимостей от вышестоящих компонентов, с целью приоритезации общей стабильности системы.
