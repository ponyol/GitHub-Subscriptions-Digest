Суммаризация (на русском)

This update delivers new features for session management, allowing export, import, and sharing, along with support for project-local configuration overrides. Performance is significantly boosted through optimizations in UI rendering and markdown parsing for streamed content. Additionally, it includes numerous bug fixes to improve error handling, validate URLs, ensure correct headless mode behavior, and resolve multi-line paste issues, alongside essential dependency updates and code refactorings. --- Это обновление добавляет новые функции для управления сессиями, включая экспорт, импорт и обмен, а также поддержку локальных конфигураций для проектов. Производительность значительно повышена благодаря оптимизации рендеринга пользовательского интерфейса и парсинга Markdown для потокового содержимого. Кроме того, оно содержит множество исправлений ошибок для улучшения обработки ошибок, проверки URL-адресов, обеспечения корректного поведения в безголовом режиме и решения проблем с многострочной вставкой, наряду с важными обновлениями зависимостей и рефакторингом кода.
