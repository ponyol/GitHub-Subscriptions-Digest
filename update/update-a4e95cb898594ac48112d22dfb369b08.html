Суммаризация (на русском)

Это обновление представляет новое кроссплатформенное мобильное приложение на Flutter, демонстрирующее полное использование Batch API Speechmatics, включая многоязычную транскрипцию с моделью Melia-1, диаризацию диктора, перевод и функции речевого интеллекта. Также добавлен отдельный пример для транскрибирования аудио с переключением кодов с использованием многоязычной модели Melia, с возможностью идентификации языка для каждого слова. Кроме того, были устранены несколько проблем совместимости Flutter-приложения с iOS и обновлены зависимости проекта.
