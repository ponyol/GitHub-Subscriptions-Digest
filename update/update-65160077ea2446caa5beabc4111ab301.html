Суммаризация (на русском)

Внедрены два срочных исправления. Первое устраняет ошибку `UnmappedInstanceError` в конечной точке обновления администратора, которая возникала из-за того, что `crud.organization.get()` по умолчанию возвращал схему Pydantic вместо модели ORM. Проблема была решена путем явного запроса модели ORM через `enrich=False`. Второе исправление касается некорректной генерации фрагментов кода для конечной точки поиска.

Исходный текст

- hotfix: use ORM model instead of schema in admin upgrade endpoint crud.organization.get() returns a Pydantic schema by default (enrich=True), which caused UnmappedInstanceError when db.refresh() was called. Fixed by passing enrich=False to get the actual ORM model. - hotfix: wrong code snippet generation for search endpoint
