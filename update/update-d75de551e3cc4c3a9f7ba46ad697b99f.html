This update significantly enhances execution precision by migrating to `performance.now()` for sub-millisecond timing and improving backend scalability through Redis migrations for socket and room managers. It introduces new integrations for Cal.com, Similarweb, YouTube, and Clerk, alongside structured terminal output and advanced workflow control features like "run from/until block" and nested execution snapshots.
