Суммаризация (на русском)

This update significantly enhances platform functionalities, particularly for self-hosted environments. Key changes include migrating to Deno Deploy v2 with fixes for function timeouts, introducing self-hosted database backup/restore, and implementing rotatable API keys for enhanced security. New features such as native memory recall via pgvector, dashboard display of compute container logs, Razorpay payment support, and O(1) table row counters are also introduced, alongside numerous UI and reliability fixes. --- Это обновление значительно расширяет функциональность платформы, особенно для самохостинговых сред. Ключевые изменения включают миграцию на Deno Deploy v2 с исправлением таймаутов функций, внедрение резервного копирования и восстановления баз данных для самохостинга, а также реализацию ротируемых ключей API для повышения безопасности. Также добавлены новые функции, такие как нативное извлечение памяти с помощью pgvector, отображение логов контейнеров на панели управления, поддержка платежей Razorpay и счетчики строк таблиц O(1), наряду с многочисленными исправлениями пользовательского интерфейса и повышением надежности.
