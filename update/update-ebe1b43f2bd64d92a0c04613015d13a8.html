Суммаризация (на русском)

Это обновление внедряет поддержку нативных структурированных выводов для Claude Sonnet 4.5 и Opus 4.1, используя новый механизм API вместо предыдущего обходного пути с инструментами. Оно динамически преобразует схемы JSON в модели Pydantic с помощью специализированной библиотеки, обеспечивая более чистую поддержку потоковой передачи. Решение об использовании структурированных выводов теперь является более четкой конфигурацией при регистрации модели, а тесты для Sonnet 4.5 были обновлены.
