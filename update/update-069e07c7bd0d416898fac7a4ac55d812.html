Суммаризация (на русском)

Версия Scrapegraph-ai 2.1.5 включает критическое исправление ошибки: теперь `model_tokens` корректно удаляется из `llm_params`, чтобы предотвратить его непредвиденную передачу клиентам моделей, что устраняет ошибки с API, совместимыми с OpenAI. Этот выпуск также обновляет README, добавляя сравнение Open Source и Managed API. Наконец, рабочий процесс CI был улучшен для запуска только детерминированных модульных тестов.
