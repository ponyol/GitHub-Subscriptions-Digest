    Обновления касаются исправления проблемы с обновлением графика истории звезд, вызванной недавними ограничениями API GitHub. Теперь GitHub ограничивает доступ к `/stargazers` только администраторам и участникам, что приводило к сбою стандартного `GITHUB_TOKEN` в CI. В качестве решения используется персональный токен доступа (PAT) участника для получения данных о звездах и выделенный `STAR_HISTORY_TOKEN` для обновления.
