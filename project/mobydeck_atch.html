    Представлена новая команда `rm` для управления данными сессий. Она позволяет удалять сокеты и логи для сессий, которые больше не запущены или завершили работу. Обратите внимание, что запущенные сессии сначала должны быть завершены командой `kill`, прежде чем их можно будет удалить с помощью `rm`.
