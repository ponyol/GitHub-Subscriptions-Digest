  • Updates in main (13 commits) UpdateType.COMMIT_BATCH

    Это обновление представляет две новые функции управления памятью для устройства virtio-balloon Firecracker: подсказку свободных страниц (free page hinting) и отчетность свободных страниц (free page reporting). Эти механизмы позволяют гостевой ОС информировать хост о неиспользуемых страницах памяти, что позволяет хосту более эффективно высвобождать их, включая огромные страницы. Подсказка страниц предлагает отчетность по запросу с управлением через API, тогда как отчетность страниц непрерывно уведомляет хост для снижения RSS виртуальной машины.
  • Updates in main (4 commits) UpdateType.COMMIT_BATCH
    2025-11-21 16:07 UTC
    Эта серия изменений в основном направлена на улучшение обработки MSR (Model-Specific Register) на архитектуре x86_64 для гостевых операционных систем. Критическое исправление затрагивает MSR IA32_MTRRdefType, позволяя гостям правильно устанавливать типы памяти для таких областей, как pmem, в write-back, устраняя предыдущие проблемы с производительностью, когда они помечались как uncached-minus. Кроме того, IA32_PAT_MSR добавлен в список исключений, что дает гостям больше контроля над атрибутами страниц, а значения MTRR MSR теперь автоматически генерируются для улучшения удобства обслуживания.
