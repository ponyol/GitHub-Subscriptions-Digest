    A new permanent observability subsystem, **cvdiag**, has been introduced to diagnose the persistent red↔green cell flap on the staging dashboard. It captures and correlates the full request path (probe→backend→aimock→edge) across various integrations, storing detailed event and raw byte data. By default, cvdiag is inert, requiring explicit enablement via an environment variable, and includes robust secret scrubbing. --- Новая постоянная подсистема наблюдения, **cvdiag**, была внедрена для диагностики сохраняющейся проблемы «красно-зеленого мерцания» на панели мониторинга стейджинга. Она фиксирует и коррелирует полный путь запроса (probe→backend→aimock→edge) во всех интеграциях, сохраняя подробные данные о событиях и необработанные байты. Эта система предназначена для оперативной диагностики оставшихся причин проблемы с помощью запросов к панели мониторинга, что позволяет избежать длительных ручных расследований. По умолчанию cvdiag неактивна, требует явной активации через переменную окружения и включает надежное скрытие конфиденциальных данных.
