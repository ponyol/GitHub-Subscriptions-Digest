    Основное обновление — добавление поддержки аутентификации keyboard-interactive (RFC 4256). Эта реализация включает обработку сообщений `SSH_MSG_USERAUTH_INFO_REQUEST` и `INFO_RESPONSE`, вспомогательный инструмент командной строки для запроса данных у пользователя, а также поддержку потоков аутентификации с частичным успехом. Новая функциональность интегрирована в API `connect`/`authenticate`, тщательно протестирована с помощью модульных и интеграционных тестов, а также дополнена обновленной документацией и журналом изменений.

Внедрена новая среда интеграционного тестирования на базе Docker Compose для всесторонней сквозной проверки потоков аутентификации SSH (по публичному ключу, по паролю) и обработки команд, охватывающая различные алгоритмы и проверки ключей хоста.
